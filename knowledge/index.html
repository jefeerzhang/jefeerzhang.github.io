和 AI Agent 高效沟通

让它知道你想解决什么，而不只是告诉它做什么。

核心观点：让它知道你想解决什么，而不只是告诉它做什么。需求还不清楚时，也可以直接说出来，请它帮你一起理清。

为什么同一句话，有时得不到想要的结果？

假设你把一份课堂笔记交给 AI，说：“帮我整理一下。”它很可能会把内容分类、加标题，整理得整整齐齐。但如果你的真正目的是准备下周的考试，你可能更需要一份突出重点、区分相似概念、方便自测的复习材料。

问题不一定是 AI 不会整理，而是它不知道你为什么要整理。你心里的“整理”，和它理解的“整理”，可能不是同一件事。

AI Agent 可以先理解为一种能根据目标，分步骤协助完成任务的 AI 工具。不同工具能使用的资料和工具并不一样，所以涉及具体文件、网页或操作时，也要说明这些材料在哪里，以及希望它做什么。

和 Agent 沟通，最重要的不是背一段完美的提示词。更有用的做法是：让它了解你的目的，再根据结果逐步调整。如果你自己还没有想清楚，也可以告诉它：我现在的想法还很模糊，请先帮我理清。

下面四个方法可以帮助你把这句话用起来。

一、先说目的，不只说动作

同一个动作，用途不同，合适的结果也会不同。

先看整理课堂笔记。如果你只说：

帮我整理这份课堂笔记。

这句话不是错的，但 Agent 不知道你想拿整理结果做什么。你可以换一种说法：

帮我整理这份课堂笔记，我要用它复习下周的考试，尤其想弄清那些容易混淆的概念。

现在，任务还是“整理笔记”，但目的清楚了：用于考试复习。Agent 就有依据把容易混淆的概念放在一起比较，而不是只按原来的顺序抄一遍。

再看自我介绍。如果只说：

帮我写一段自我介绍。

它不知道这是写给谁看的，也不知道什么内容对你最重要。你可以补充：

帮我写一段自我介绍，用在摄影社招新面试。我没有摄影经验，但希望让对方了解我的兴趣和愿意投入时间学习的态度。

这个例子里，“摄影社面试”是使用场景，“没有经验”是现有情况，“让对方了解兴趣和学习态度”是目的。有了这些信息，Agent 才更容易围绕你真正想表达的内容来写。

说清目的，Agent 才有依据决定什么内容更重要。

二、把模糊要求变成可检查的标准

“简单”“清楚”“好读”各有不同的理解，具体标准能帮助双方对齐。

比如，你想让 Agent 解释云存储。如果你说：

把云存储解释得简单一点。

它可能用一段很短的话解释，也可能用了你听不懂的专业词。你可以把“简单”拆成几项具体要求：

向一个没学过计算机的人解释云存储：不超过 150 字，先用一个生活比喻，再举一个使用场景，不使用未解释的专业术语。

这样，收到结果后，你可以逐项检查：字数是否符合要求？有没有生活比喻？有没有具体场景？有没有出现没解释的专业术语？“简单一点”就变成了可以检查的标准。

再看活动通知。如果你说：

帮我写一份读书会通知，要清楚、好读。

你觉得“清楚”是分行列出信息，Agent 也许会认为写成一段完整文字就足够清楚。可以这样说：

根据下面的活动信息写读书会通知。按“时间、地点、参加对象、报名方式”四项分行写，每项一句，不加开场寒暄；缺少的信息标为“待补充”，不要编造。

这段要求说明了内容、格式和信息不足时怎么处理。你还需要把实际掌握的活动信息提供给它；如果没有提供地点，它就应该标“待补充”，而不是自己编一个地点。

把要求写成能检查的结果，可以减少“我以为”和“它以为”的差别。

三、说清希望它怎样帮忙；必要时说明做到哪里停

不是每个任务都要马上给出最终答案。有时先提问，有时先检查，会更适合你的目的。

假设你想学摄影，但还没想清楚自己喜欢拍人像、风景，还是日常生活。你可以说：

我想学摄影，帮我安排一下。

但这句话没有说明你希望它先做什么，它可能马上给你一份学习计划。如果你现在连学习方向都还不确定，不妨这样说：

我想学摄影，但还没想清楚主要拍什么。先问我三个关键问题，根据回答总结我的学习需求。等我确认后，再安排学习计划。

这里有两个动作：先提问并总结；等你确认后，再做计划。这个“停一下”很重要，因为你还要判断它有没有理解你的需求。

再看检查文章。如果你说：

帮我看看这篇文章，处理一下。

“处理一下”可能被理解为直接改写。如果你希望自己先决定改哪里，可以说：

先检查这篇文章的结构，指出最影响理解的三个问题，并说明原因。暂时不要修改原文，等我决定改哪些问题后再动手。

这样，Agent 的第一步是检查和解释；是否修改、修改哪些内容，由你决定。

把期待的协助方式和暂停位置说清楚，能让你保留关键决定。

这里也有一个实用方法：当你不知道该怎么提问时，不必假装自己已经想清楚。你可以直接说：“我现在只有一个模糊的想法。先问我几个关键问题，帮我把需求理清楚。”

四、用具体反馈逐步对齐，优先改一句而不是重开

第一版不合适时，指出哪里要保留、哪里要改，以及为什么改，通常比只说“不好”更有用。

假设 Agent 帮你写了一份班级活动通知。时间、地点和报名方式都写对了，但语气像正式公文。如果你只说：

太僵硬了，不好，重写。

Agent 知道你不满意，却不知道哪些内容可以保留，也不知道你想改成什么语气。你可以这样反馈：

时间、地点和报名方式都保留。删掉“为丰富同学们的课余生活”这类开场，第一句直接说“这周六我们一起去……”，其余语气也改成同学之间说话的样子。

这个反馈既指出要保留的信息，也给出一句你希望采用的表达。Agent 可以沿着这个方向修改，你也不用从头解释整个任务。

再看周末安排。假设你原本想休息，Agent 却排了很多跨区打卡地点。你可以不只说“重新安排”，而是指出它理解错了什么：

你把我的目标理解成了“尽量多去几个地方”，但我想要的是放松、不赶时间。保留公园散步，删掉跨区打卡，每天最多安排两个活动，重新给我一版。

这里最关键的一句是“我想要的是放松、不赶时间”。因为你纠正的不只是某个景点，而是 Agent 对整个目标的理解。后面的“保留”“删掉”和“每天最多两个活动”，则告诉它怎样把这个目标落实到新版本里。

反馈越具体，Agent 越容易保留有用内容，并沿着正确的目的修改。

不必每次都重开一个对话。当前结果里如果已经有可用部分，可以直接指出来，让 Agent 在此基础上调整；如果任务已经完全改变，再重新说明目标和背景。

一个通用句式

前面四件事，可以浓缩成一段话：

我想达到______，现在的情况是______。请帮我______，结果需要符合______（也可以参考______）。这次先做到______，暂时不要______。如果关键信息不足，请先问我。

收到结果后，可以继续补一句：

保留______，把______改成______，因为我真正需要的是______。

还没想清楚时，可以直接说：

先别急着给方案，问我几个关键问题，帮我把需求理清楚。

这些句式是帮助你组织想法的工具，不是必须逐字填写的表格。简单任务可能只用一句话；任务比较复杂时，再补充背景、标准和暂停位置。让 Agent 追问，也可以同时告诉它你目前已经知道什么，这样对话更容易进入正题。

试一试：把一句模糊请求说清楚

选一件最近你真的想做的事。可以是复习一门课、参加社团面试，或者安排一次班级活动。先写一句你平时会发给 Agent 的请求，再补充下面三项：

  1. 你真正想达到什么目的？
  2. 你怎么判断结果是否符合要求？
  3. 你希望 Agent 先做什么，在哪一步等你决定？

例如，第一版是：“帮我复习这章内容。”

补充后可以变成：“我下周要参加考试，现在对这章的几个概念容易混淆。请根据我提供的课堂笔记，先列出三组容易混淆的概念，每组用一个例子说明区别。缺少依据的地方先问我，不要自行补充课堂没有讲过的结论。”

拿到结果后，再检查它有没有使用你提供的材料。如果有一组解释还不清楚，你可以继续说：“第一组的对比很清楚，保留。第二组请换一个生活中的例子，因为我需要能在考试时自己解释出来。”

让对话围绕目的往前走

可以用四个问题回顾这四个方法：

  • 目的：我想解决什么问题？
  • 标准：怎样的结果才符合我的要求？
  • 方式：我希望它先做什么，在哪一步等我？
  • 反馈：哪些内容保留，哪些内容要改？为什么？

需要记住：把要求说清楚，可以帮助 Agent 更好地理解任务，但不能保证每次结果都正确。用它辅助学习时，重要概念、引用和数字仍要回到课堂材料或可靠来源核对。最终采用什么内容，判断和责任仍在自己手里。

记住一句话就够了：让它知道你想解决什么，而不只是告诉它做什么。
