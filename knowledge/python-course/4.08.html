为什么学这个

数据到手，怎么把它变成一个集合？

拿到一个充满重复值的列表或字符串，想快速去重？这节教你集合的两种创建方式。但先剧透两个「现象」：空的大括号 {} 造出来的其实是字典（本章第一大坑），以及去重后的输出顺序可能和书写顺序不同——这些都不是你代码写错了。

💡 打个比方
{} 是一扇双开门，空集合要走侧门

{} 像一扇双开门——推开是字典的家（Python 规定：空的大括号就是空字典）；想进空集合，只能走 set() 的侧门。而带内容的门牌倒很分明：大括号里有冒号是字典，没有冒号就是集合。

核心概念

两种创建方式 + 一个必须记住的例外

  • 直接创建：使用大括号 {} 直接包含元素，逗号分隔；如果有重复元素，会自动去重
  • set 函数：把字符串、列表、元组等可迭代对象转换为集合（转换顺便完成去重）
  • 空集合只能通过函数创建：写 set()——{} 创建的是空字典，不是空集合！
ST1 = {1, 2, 3, 2, 1}
print(ST1)       # 输出 {1, 2, 3}：5 个元素进去，重复的自动消失
ST2 = set()
print(ST2)       # 输出 set()：这才是空集合
ST3 = set('12321')
print(ST3)       # 输出 {'3', '2', '1'}：字符串被拆成单字符再去重
交互示例

🔬 创建方式切换台

x = {}
print(type(x))
# <class 'dict'>

空的大括号造出来的是字典！

y = set()
print(type(y))
# <class 'set'>

空集合只能这样造。

ST1 = {1, 2, 3, 2, 1}
print(ST1)
# {1, 2, 3}

五个元素进去，三个元素出来——「不重复性」现场发挥。

ST3 = set('12321')
print(ST3)
# {'3', '2', '1'}

字符串被拆成一个个字符，再自动去重；顺序带「随机感」是无序性的正常表现。

❓ 测验

在 Python 中执行 type({})，结果是？

✏️ 填空

创建空集合只能通过函数 ____，因为空的大括号 {} 在 Python 里表示空字典。

⚠️ 避坑
{} 不是空集合；输出顺序「随机」不是 bug

坑一：ST = {} 造出来的是空字典。之后调用 add()、remove() 等集合方法统统报 AttributeError。想要空集合，永远写 set()。

坑二：set('12321') 输出 {'3', '2', '1'}，顺序和书写不一致、每次运行还可能不同——这是集合无序性的正常表现，不是程序出错，也不必去「修正」它。

✅ 小结
你现在知道了

创建集合两条路：带元素的大括号 {}（自动去重）与 set(可迭代对象) 转换；空集合只能 set()，{} 是空字典；输出顺序不固定是无序性的正常表现。下一节：集合真正的威力——交、差、并、补四大运算。
