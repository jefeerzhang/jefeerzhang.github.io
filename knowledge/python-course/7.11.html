为什么学这个

7.03 说的「当前程序运行目录」，到底在哪？

学相对路径时（7.03）提过：不带盘符的路径都从「当前程序运行目录」出发找文件——这个目录的正式名字叫工作目录。它通常就是 Python 文件或 jupyter 文件所在的目录。为什么 open('《悯农》.txt') 不写全路径也能找到？因为 Python 默认到工作目录里找。会用 getcwd 查看它、chdir 改变它，相对路径才算真正学明白。

💡 打个比方
工作目录像「你现在站立的房间」，相对路径都是「出门左转」式的指路

你在哪个房间，说「隔壁那间」才有意义——工作目录就是 Python 当前站立的房间，相对路径全从脚下出发。os.getcwd() 是「看一眼自己在哪个房间」；os.chdir(path) 是「换一个房间站」——换完之后，所有「隔壁那间」式的相对路径指路全部重新计算，这就是 chdir 好用又危险的原因。

核心概念

三个工作目录方法

方法作用返回值
os.getcwd()获取当前工作目录字符串
Path.cwd()获取当前工作目录Path 对象
os.chdir(path)把工作目录改变到目标路径无（None）
  • cwd 是 current working directory（当前工作目录）的缩写，两种写法记一对「手动挡 / 自动挡」
  • getcwd() 返回字符串、Path.cwd() 返回 Path 对象——这是两者唯一的实质差别
  • chdir 的参数相对路径、绝对路径都行；目标目录不存在会报 FileNotFoundError
  • 呼应 7.03：相对路径的起点「当前程序运行目录」就是这里的工作目录——两节说的是同一件事
课堂代码

PPT 原例：查看与切换工作目录

import os
from pathlib import Path

print(Path.cwd())
os.chdir('C:\\')
print(os.getcwd())

输出结果（不同电脑结果可能不同）：

C:\Users\xxx
C:\
  • Path.cwd() 打印出程序启动时的工作目录，通常是 .py 文件所在文件夹
  • os.chdir('C:\\') 把工作目录切到 C 盘根目录——注意 Windows 路径里 \ 要写成 \\
  • 切换后再 os.getcwd() 查询，返回的已经是新目录 C:\
  • 此刻若执行 open('笔记.txt')，Python 会到 C:\ 底下去找，而不是原来的文件夹
交互示例

chdir 前后，同一个相对路径指向不同的地方

import os

print(os.getcwd())          # 假设当前在 C:\code
os.chdir('C:\\code\\data')  # 换到子目录 data
print(os.getcwd())

# 同一个相对路径，起点变了
with open('score.txt', 'r', encoding='utf-8') as f:   # 实际打开 C:\code\data\score.txt
    print(f.readline())

输出结果（示例；运行前需先建好 C:\code\data 目录和其中的 score.txt）：

C:\code
C:\code\data
张三 95
  • score.txt 这个相对路径在 chdir 前指向 C:\code\score.txt，chdir 后指向 C:\code\data\score.txt——起点跟着工作目录走
  • 这也解释了为什么有人运行代码报「找不到文件」：文件其实在别处，而工作目录不是你以为的那个
  • 不确定时先 print(os.getcwd()) 看一眼，再决定用相对还是绝对路径
❓ 测验

os.getcwd() 的返回值是什么类型？

✏️ 填空

os 模块中获取当前工作目录的方法是 os.＿＿()；把工作目录改变到目标路径的方法是 os.＿＿(path)；pathlib 中获取工作目录的方法是 Path.＿＿()。（填方法名，用空格隔开）

⚠️ 避坑
四个高频翻车点

①每台电脑结果不一样：Path.cwd() 的输出取决于程序放在哪运行，别把书上的 C:\Users\xxx 当标准答案；

②chdir 之后相对路径全变：切换工作目录后，之前写好的相对路径打开的文件可能「突然找不到」；

③「Python 文件所在目录」和「工作目录」通常相同但不是一回事：工作目录可以随时 chdir 改变，文件位置不会跟着变；

④chdir 到不存在的目录直接报错：FileNotFoundError——先确认目标目录存在（下一节就学怎么新建）。

✅ 小结
你现在知道了

工作目录是程序当前所在的目录（通常是 .py 或 jupyter 文件所在目录），相对路径都从这里出发；os.getcwd() 返回字符串、Path.cwd() 返回 Path 对象、os.chdir(path) 可切换工作目录；chdir 后所有相对路径的起点随之改变。下一节：在工作目录里新建文件夹——mkdir 与 makedirs。
