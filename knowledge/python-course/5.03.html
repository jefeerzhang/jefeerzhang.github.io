为什么学这个

条件为假时，能不能「走另一条路」？

单分支 if 有个遗憾：条件为假时只能「什么都不做」。可现实里经常是二选一：猜对了说恭喜、猜错了说遗憾；a 大输出 a、否则输出 b。双分支结构 if-else 解决的就是这件事——仍然只有一条判断语句，但有两条分支，根据条件的真假不同而执行对应的分支。两条分支互斥，每次只走一条。

💡 打个比方
双分支像「岔路口」，单分支像「独行桥」

if-else 是一个岔路口：一条判断语句、两条必选之路——条件为真走左边（代码块_真），为假走右边（代码块_假），不存在「原地站着」这个选项。而单分支 if 是一座独行桥：条件为假就不过了，直接沿原路继续往前走。区别就一句话：假的时候，是「空手而过」还是「走另一条路」。

核心概念

if-else 语法与注意事项

if <条件>:
    <代码块_真>
else:
    <代码块_假>
  • else 语句不能单独使用——必须跟着某个 if，跟它配对
  • else 后面不能有条件，直接写冒号 else:（条件只在 if 后面判断）
  • else 必须有冒号，冒号下一句同样要缩进
  • 两个代码块必须都有，不能省略——暂时不知道写什么，可以用 pass 语句占位（pass 是 2.06 讲过的保留字，意思是「什么也不做」）
  • 两条分支互斥：条件真只走代码块_真，条件假只走代码块_假，绝不同时执行
课堂代码

示例 01：猜数升级版——猜错也有话说了

num = eval(input("请您猜一个数吧！"))
if num % 3 == 2 and num % 5 == 3 and num % 7 == 2:
    print(f"您输入的数字是{num},恭喜你答对了！")
else:
    print("对不起，您答错了！")
print("欢迎再猜一次")
  • 条件与 5.02 的物不知数完全相同：除以 3 余 2、除以 5 余 3、除以 7 余 2
  • 输入 23：三个条件全真 → 走 if 分支 →「您输入的数字是23,恭喜你答对了！」
  • 输入 21：21 % 3 == 0，第一个条件就为假 → 走 else 分支 →「对不起，您答错了！」
  • 无论走哪条分支，最后都输出「欢迎再猜一次」——它在 if-else 结构之外
交互示例

切换输入，看清两条分支各走哪条

  • 23 % 3 == 2　→　2 == 2　True ✓
  • 23 % 5 == 3　→　3 == 3　True ✓
  • 23 % 7 == 2　→　2 == 2　True ✓　→　and 全真，条件为 True
  • 走 if 分支：print(f"您输入的数字是{num},恭喜你答对了！")
  • else 分支被跳过
  • print("欢迎再猜一次")　→　照常执行
运行输出：
您输入的数字是23,恭喜你答对了！
欢迎再猜一次
  • 21 % 3 == 2　→　0 == 2　False ✗　→　and 一假即假，条件为 False
  • 走 else 分支：print("对不起，您答错了！")
  • if 分支被跳过
  • print("欢迎再猜一次")　→　照常执行
运行输出：
对不起，您答错了！
欢迎再猜一次
课堂代码

示例 02：求两个数的最大值

a = eval(input('请输入第一个数字：'))
b = eval(input('请输入第二个数字：'))
if a >= b:
    print(f'最大值是{a}')
else:
    print(f'最大值是{b}')
  • 输入 5 和 3：5 >= 3 为真 → 走 if 分支 → 输出「最大值是5」
  • 注意条件用的是 >=：输入 5 和 5 时也走 if 分支，两个数相等不会漏判
  • 下一节的 IF 表达式，会把这段六行代码压缩成三行——先把它看懂
❓ 测验

关于 else 语句，下面哪种说法是正确的？

✏️ 填空

双分支结构的两个代码块必须都有，不能省略，可以用 ＿＿ 语句占位。

⚠️ 避坑
三个高频翻车点

①else 不能单独使用——前面没有一个和它配对的 if，直接 SyntaxError。else 永远是「跟着 if 走」的；

②else 后面写条件直接语法错——写成 else x > 0: 会报错。条件只能写在 if 后面，else 只是「否则」，不需要也无法再判断；

③两个代码块都不能省——if 分支或 else 分支空着不写都会报错。真的没内容可写，用 pass 占位，先把架子搭起来。

✅ 小结
你现在知道了

双分支结构仍只有一条判断语句，但有两条分支：条件真走代码块_真、假走代码块_假，互斥且必走其一。else 不能单独使用、后面不能写条件、必须有冒号且下一句缩进；两个代码块都不能省略，可用 pass 占位。如果两个分支只是在「给变量赋不同的值」，还有更简洁的写法——下一节的 IF 表达式，一行搞定。
