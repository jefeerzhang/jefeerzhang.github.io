为什么学这个

字符串取字符的本领，列表全都有——还更强

列表和字符串一样都属于有序序列，因此也可以通过序号进行索引和切片。不同之处在于：字符串索引对应的是字符，列表索引对应的是列表元素——而列表的元素也可能是列表，因此可以通过多次索引找到「元素的元素」。这一手「套娃访问」是本章的重要考点。

💡 打个比方
快递箱里还有小快递箱：先拆外箱，再拆内箱

列表套列表，就像快递箱里还装着小快递箱。L4[3] 是拆开外箱——拿到里面的整个小箱子 ['A', 'B', 'C']；L4[3][1] 是再拆内箱——从小箱子里拿出第 2 件物品 'B'。想取到最里面的东西，就一层一层往下拆。

核心概念

索引、切片与套娃访问

  • 索引和切片的规则与字符串完全一致：左闭右开、可省略、可负数、可加步长
  • 区别：字符串索引取到字符，列表索引取到元素（元素可以是任何类型）
  • 元素还是列表时，用多次索引层层深入：L4[3][1]
L4 = [1, 2, 3, ['A', 'B', 'C']]
print(L4[2], L4[-2])          # 3 3
print(L4[3][1], L4[-1][-1])   # B C
print(L4[:2], L4[2:], L4[3][1:])
print(L4[::2], L4[::-1], L4[3][::-1])

输出结果：

3 3
B C
[1, 2] [3, ['A', 'B', 'C']] ['B', 'C']
[1, 3] [['A', 'B', 'C'], 3, 2, 1] ['C', 'B', 'A']
  • 第 1 行：正、负索引都指向同一个元素 3
  • 第 2 行：L4[3] 拿到内层列表，再 [1] 拿到 'B'——套娃访问；负索引同理，L4[-1] 是最后一个元素（内层列表），L4[-1][-1] 就是 'C'
  • 第 3 行：切片规则照旧，L4[3][1:] 是对内层列表切片
  • 第 4 行：L4[::-1] 整个列表倒序——内层列表作为「一个元素」被原样搬动
🔬 交互示例

套娃拆解：一层一层看清楚

L4 = [1, 2, 3, ['A', 'B', 'C']]
print(L4[3])

输出结果：

['A', 'B', 'C']

拆开外箱——索引 3 取出的是整个内层列表，还不是一个字符。

L4 = [1, 2, 3, ['A', 'B', 'C']]
print(L4[3][1])

输出结果：

B

先拆外箱再拆内箱——第二次索引 [1] 从内层列表里取出单个元素 'B'。

L4 = [1, 2, 3, ['A', 'B', 'C']]
print(L4[3][1:])

输出结果：

['B', 'C']

对内层列表切片——从索引 1 取到末尾，左闭右开的规矩原样适用。

❓ 测验

L4 = [1, 2, 3, ['A', 'B', 'C']]，L4[3][1] 的值是？

✏️ 填空

列表的元素也可能是列表，可以通过＿＿索引找到元素的元素。

⚠️ 避坑
L4[3] 和 L4[3:4] 不是一回事

L4[3] 是索引，直接得到内层列表本身 ['A', 'B', 'C']；L4[3:4] 是切片，得到的是「装着内层列表的新列表」 [['A', 'B', 'C']]——外面还多套一层。考试最爱在这里设陷阱。

另外：套娃访问别忘了第二次索引——只写 L4[3] 拿到的还是列表，要取 'B' 必须再 [1]。索引越界才报错、切片越界不报错，和字符串完全一样的规矩。

✅ 小结
你现在知道了

列表是有序序列，索引与切片规则和字符串完全一致（左闭右开、可省略、可负步长）；区别在于索引对应的是元素而非字符。元素也可能是列表，通过多次索引层层深入（L4[3][1] → 'B'），切片同理（L4[3][1:] → ['B', 'C']）。下一节：往列表里加元素的三种方法。
