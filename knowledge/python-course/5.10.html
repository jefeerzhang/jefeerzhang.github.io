为什么学这个

「逐个处理」是程序最常见的活儿

遍历循环是指逐一遍历某个迭代对象的循环方式：每次提取一个元素并执行一次循环语句块，因此循环执行次数由迭代对象中元素的个数确定。想把名字列表挨个打印、想把一段话逐字检查、想把成绩单挨个判断及格——都要靠它。上一节的 range() 已经让你见过 for 了，这一节正式认识它的本职工作。

💡 打个比方
遍历元素像「点名时直接叫名字」，遍历索引像「按学号点名再查名字」

只关心「每个人是谁」，就直接叫名字（遍历元素，直接拿到值）；还要记录「这是第几个人」，就得先按学号 1、2、3 点下去，再对照花名册查名字（遍历索引，range(len(s)) 先拿下标，再用 s[i] 查值）。只看内容用前者，要记「第几个」用后者。

核心概念

for 循环：自动取值、自动前进

  • 语法：for <循环变量> in <迭代对象>: 换行缩进后写 <循环语句块>
  • for 把 while 三要素里的两件自动化了：循环变量的「初始化」和「更新」都由 for 自动完成，你只负责写循环体——对照 5.07 的 while「初始化、条件、更新」三件套，for 省心得多
  • 迭代对象无元素时，循环语句一次也不会执行（不报错，直接跳过）
  • 迭代对象通常包括：range() 函数、字符串、列表、元组、集合、字典等
  • 字符串、列表、元组都属于有序序列，遍历方式基本相似，主要有「遍历元素」和「遍历索引」两种
  • 遍历索引时，由于索引是整数，需要借助 range() 和 len() 函数——range(len(s)) 是「长度变下标」的经典组合
适用场景：只关心内容本身，不关心位置——最常用的方式。
# 字符串版：逐个取出字符
s = 'PYTHON'
for c in s:
    print(c, end=" ")
P Y T H O N
# 列表版：逐个取出元素
ls = ['张三', '李四', '王五']
for item in ls:
    print(item)
张三
李四
王五

循环变量 c、item 每次「自动领取」下一个元素，领取到没有就停——不用你写 i += 1。

适用场景：需要「边遍历边知道位置」，比如要打印第几个、或按下标修改元素。
# 字符串版：用索引遍历
s = 'PYTHON'
for i in range(len(s)):
    print(f'元素索引为{i},值为{s[i]}')
元素索引为0,值为P
元素索引为1,值为Y
元素索引为2,值为T
元素索引为3,值为H
元素索引为4,值为O
元素索引为5,值为N
# 列表版：用索引遍历
ls = ['张三', '李四', '王五']
for i in range(len(ls)):
    print(f'元素索引为{i},值为{ls[i]}')
元素索引为0,值为张三
元素索引为1,值为李四
元素索引为2,值为王五

拆开看：len(s) 得到 6，range(6) 生成 0~5 的下标，s[i] 再按下标取值——三步合成一句话。

❓ 测验

for c in 'ABC': 循环体一共执行几次？

✏️ 填空

遍历索引时，由于索引是整数，需要借助 ＿＿ 和 len() 函数。（一个空，函数名或调用形式均可）

⚠️ 避坑
三个高频翻车点

①循环变量名别与迭代对象重名：for ls in ls: 语法上不报错，但循环一遍后 ls 被改成单个元素，后续代码再用 ls 就乱了套——起个不一样的名字；

②range(len(s)) 是「长度变下标」的经典组合：len 得到元素个数，range 左闭右开正好生成 0 ~ 个数-1 的全部下标，两者天生一对；

③空序列一次都不执行：对空列表 [] 或空字符串 '' 遍历，循环体直接被跳过、不报错——别以为没输出就是程序坏了。

✅ 小结
你现在知道了

for <循环变量> in <迭代对象>：每次取一个元素执行一次循环体，次数由元素个数决定，空序列一次不执行；字符串、列表、元组是有序序列，遍历分「遍历元素」和「遍历索引」两种——只看内容用前者，要记位置用 range(len(s)) 拿下标。下一节：遍历字典，走「键值对」路线。
