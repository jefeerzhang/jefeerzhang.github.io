为什么学这个

不用自己造轮子，Python 已经帮你造好了

上一节你学会了函数的定义与调用，但大部分常用功能根本不用自己写——Python 解释器出厂就自带了一批「成品函数」。会用它们，你的编程效率直接翻倍。这一节解决三个问题：

  • Python 的函数按来源分哪三类？
  • 最常用的内置函数有哪些？怎么用？
  • 拿到一个新函数，如何快速试出它的效果？
💡 打个比方
函数三类来源 = 手机的三种 App

内置函数像手机出厂自带的 App（计算器、相机）——开机就能用，不需要安装；第三方库函数像应用商店的 App——得先下载安装（安装库）再导入使用；自定义函数像你自己开发的小工具——按自己的业务需求量身编写。

核心概念

函数按来源分三类

  • 内置函数（Built-in）：解释器自带，无需导入，直接使用——本节主角。
  • 第三方库函数：由其他开发者编写，需先安装并导入库才能使用（后面的 math 模块会再见）。
  • 自定义函数：根据具体业务需求自行编写的函数（上一节学的 def）。

🔍 试算演示：先自己猜输出，再切换看答案

print(abs(-10))          # 输出：10
print(round(3.14159, 2)) # 输出：3.14（保留 2 位小数）
print(sum([1, 2, 3]))    # 输出：6（列表求和）

要点：round(x, n) 的第二个参数 n 表示保留几位小数；sum() 通常接收一个列表。

print(len('Python'))  # 输出：6（数一数有几个字符）
print(max(1, 2, 3))   # 输出：3
print(min(1, 2, 3))   # 输出：1

要点：len() 数的是序列的长度；max() / min() 可以直接接收多个参数。

❓ 测验

abs(-10) 的结果是？

✏️ 填空

内置函数由解释器自带，无需＿＿即可直接使用。（填一个词）

⚠️ 避坑
别给变量起内置函数的名字！

如果你写了 len = 100，那么之后调用 len('Python') 就会报错——因为 len 这个名字已经被你的整数 100 「占用」了，原来的内置函数被覆盖掉了。同理，max、sum、type 这些名字都不要拿来当变量名（这正是上一节「命名规则」的实战应用）。

另一个提醒：类型转换函数不是「万能钥匙」——int('abc') 会直接报错，字符串里必须是合法的数字才行。

✅ 小结
你现在知道了

函数按来源分三类：内置函数（自带免导入）、第三方库函数（安装并导入）、自定义函数（自己写）。四大家族要记牢：数值处理 abs / round / pow / sum，类型转换 int / float / str / list，数据结构 len / max / min，查询类 type / help。下一节：最常用的输入输出函数 input() 和 print()。
