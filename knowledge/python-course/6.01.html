为什么学这个

同一段代码要写三遍？复制粘贴迟早出事

想象你要给三位同学各打印一行欢迎语，再算三个圆的面积——最直接的做法是把相似的代码复制三遍。但复制粘贴有三个隐患：代码越写越长、改一处要记得改另外两处（漏一处就是 bug）、读代码的人抓不住重点。从这一章开始，Python 给你提供了一个终极武器——函数（function）：把一段代码打包起来、起个名字，哪里需要就在哪里「喊一声」它的名字。本章 18 个知识点，全部围绕它展开。

💡 打个比方
函数像一台「榨汁机」：放水果进去，出果汁来，机器反复用

榨汁机买回来之后不会自己转（定义好但不工作），把水果放进去（传入参数）、按下开关（调用），它才吐出果汁（返回值）。最妙的是：一台机器今天榨橙子、明天榨苹果，机器本身不用重买——函数也一样，定义一次，参数换一换，就能反复调用。

核心概念

什么是函数？它好在哪？

  • 定义：函数是一段具有特定功能、可重用的代码块；经过定义，一个函数等价于一组代码，需要时直接调用即可实现该组代码的功能
  • 优点一：提高效率——实现模块化开发和测试，把大程序拆成一个个小函数，各管一摊，编程效率大幅提高
  • 优点二：重复使用——一次定义、多次使用，避免重复造轮子；写好的函数还能搬到下一个程序里接着用
  • 优点三：可阅读性强——函数名就是「这段代码在干什么」的说明标签，显著提高代码的可阅读性和可维护性
交互示例

同一件事的两种写法：复制三遍 vs 定义一次调用三次

任务：给 lihua、xiaoming、tom 各打印一行欢迎语。先看「不用函数」的写法：

# 写法一：不用函数，复制粘贴三遍
print("欢迎 lihua 来到 Python 课堂！")
print("欢迎 xiaoming 来到 Python 课堂！")
print("欢迎 tom 来到 Python 课堂！")

现在换「用函数」的写法——把「打印欢迎语」这件事打包成 welcome()，定义一次、调用三次：

# 写法二：用函数，定义一次，调用三次
def welcome(name):
    print(f"欢迎 {name} 来到 Python 课堂！")

welcome("lihua")
welcome("xiaoming")
welcome("tom")

两种写法的输出结果完全相同：

欢迎 lihua 来到 Python 课堂！
欢迎 xiaoming 来到 Python 课堂！
欢迎 tom 来到 Python 课堂！
  • 写法二的 def welcome(name): 就是「定义榨汁机」，三行 welcome(…) 就是「按下三次开关」
  • 如果哪天欢迎语要改成英文，写法一要改三处，写法二只改函数体里的一行——这就是可维护性
  • 现在看不懂 def 的语法没关系，6.03 会逐块拆解；本节先建立「函数 = 可复用的代码块」这个直觉
❓ 测验

下面哪个说法不是函数的优点？

✏️ 填空

函数是一段具有特定功能、可重用的＿＿；它的三大优点是提高＿＿、＿＿使用、可＿＿性强。（三空用空格隔开，例如：代码块 效率 重复 阅读性 的风格）

⚠️ 避坑
三个高频翻车点

①定义了却从不调用：函数定义好但不调用，函数体一行都不会执行，也不报错——白写了。榨汁机买来不用，是榨不出果汁的；

②以为函数能「少打字」就随便包：两三行的代码反复出现，才值得包成函数；把只有一处使用的代码强行包成函数，反而多跳一层、更难读——粒度要适中；

③复制粘贴三遍后再想改：需求一变就要改三处，漏改一处就是隐藏 bug。看到「相似代码出现第二次」就该警觉：是不是该写函数了。

✅ 小结
你现在知道了

函数是一段具有特定功能、可重用的代码块，定义后调用即可实现那组代码的功能；三大优点——提高效率（模块化开发测试）、重复使用（避免重复造轮子）、可阅读性强（易读易维护）；定义不等于执行，必须调用才生效。下一节：看看 Python 世界的函数都从哪来。
