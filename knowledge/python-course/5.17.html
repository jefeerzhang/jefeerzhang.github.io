为什么学这个

收官之战：把选择、循环、异常三套结构串成完整程序

到这里，本章 17 节只剩最后一步：单独认识 if、while、for、try 都不难，难的是在一个程序里让它们协同工作。这一节用三个递进任务做总演练——古算题练「枚举 + 条件」，成绩单练「遍历 + 多分支 + 分装」，防摔计数器练「while True + try-except + break」——它们正是本章作业第 1~6 题的综合缩影。冲过这一关，本章就圆满收官了。

💡 打个比方
这一节像「驾考综合路考」——方向盘、油门、安全气囊一起用，才算是会开车了

科目二练单项目：倒库（选择结构）、坡起（循环结构）都能过。但真正上路，要方向盘（选择）随时判断路况、油门（循环）持续前进、安全气囊（异常处理）兜底保命三者配合。下面三个任务就是三段「路考路线」，跑通了，你就从「会写语句」升级成「会写程序」。

核心概念

三个任务的「配方」各是什么

  • 任务一「物不知数」：枚举范式——for 遍历所有候选 + if 多条件筛选。世上没有直接公式时，「挨个试」就是计算机最擅长的笨办法
  • 任务二「成绩单流水线」：数据处理范式——遍历字典 + if-elif 判档 + 列表分装，这是作业第 5 题的完整思路
  • 任务三「防摔计数器」：健壮交互范式——while True + try-except + break，异常不退出、算对才收工，这是作业第 6 题的骨架
  • 三个任务共享一个思想：先想清楚「谁是循环、谁是判断、哪里会出意外」，再动手写代码
交互示例

三大任务实战：点按钮逐个解锁

📋 任务卡：「有物不知其数，三三数之剩二，五五数之剩三，七七数之剩二。问物几何？」——找出 200 以内所有满足条件的数（呼应 5.02 的单分支版，这里升级为遍历版）
# 物不知数：三三数之剩二，五五数之剩三，七七数之剩二
for num in range(1, 200):
    if num % 3 == 2 and num % 5 == 3 and num % 7 == 2:
        print(num, end=' ')

输出结果：

23 128
  • 枚举 + 条件范式：range(1, 200) 把 1~199 全部试一遍，if 三个余数条件用 and 连接，同时满足才打印
  • 最小解是 23，下一个解是 23 + 105 = 128（3、5、7 的最小公倍数是 105，解每隔 105 出现一个）
  • 对比 5.02：那时只用 if 判断一个已知的数，现在用 for 遍历——「循环负责海选，选择负责终审」
📋 任务卡：把成绩单里及格的装进一个列表、不及格的装进另一个列表（呼应 5.05 五分制转换的判档思路 + 5.11 遍历字典）——这是作业第 5 题的思路骨架，作业请自己完成，下面留了两处空让你填
scores = {'张三': 95, '李四': 58, '王五': 82, '赵六': 44}
pass_list = []        # 及格名单
fail_list = []        # 不及格名单
for k, v in scores.items():
    if v >= 60:
        pass_list.append(k)      # ① 及格：把「谁」装进去？
    elif v < 60:
        fail_list.append(____)   # ② 不及格：这里该装什么？
print(f'及格：{pass_list}')
print(f'不及格：{fail_list}')
  • scores.items() 每轮给出一对「键值 (k, v)」——k 是姓名、v 是分数（5.11 遍历字典）
  • 判档用 if-elif：v >= 60 走及格分支，否则走不及格分支（5.05 多分支思想）
  • ①② 两空的答案都是变量 k——装进名单的是「人名」而不是分数。补全后输出应为：及格：['张三', '王五'] 和 不及格：['李四', '赵六']
  • 作业第 5 题在此基础上再加判档细分（优/良/及格/不及格），思路完全同款——请独立完成
📋 任务卡：不断让用户输入正数并累加，输入非法字符不崩溃（提示后继续），输入非正数才结束——这是作业第 6 题的骨架（呼应 5.16 除法计算器），作业请自己补全
total = 0
while True:
    try:
        x = float(input('输入一个数：'))
    except ValueError:
        print('输入无效')
        continue          # 异常不退出，回到循环开头重新输入
    if x <= 0:
        break             # 只有合法输入才走到这里，非正数才收工
    total += x
print(f'总和为{total}')
  • 三套结构各就各位：while True 提供无限循环，try-except 接住乱输入的 ValueError，break 负责正常退出
  • 用户输 'abc' → float() 抛 ValueError → except 打印提示后 continue，程序不崩溃、循环继续（5.15 + 5.16 的合体）
  • 关键在执行顺序：只有 try 块成功执行（x 拿到了合法数值），才轮得到 if 和 break——把 break 放在 try 外面紧跟其后，正合 5.16 里「else 里放 break」的同款思路
  • 输入 3、5、abc、4、-1 试跑，应输出：输入无效 和 总和为12.0
❓ 测验

按任务一的代码 for num in range(1, 200) 运行，程序共输出几个解？

✏️ 填空

防摔计数器中：while True 循环里，只有 ＿＿ 块中的代码成功执行后，流程才能走到 break、正常退出循环。（填保留字）

⚠️ 避坑
综合实战的三个高频翻车点

①range 上界差一：想枚举到 199 就写 range(1, 200)，写成 range(1, 199) 会漏掉 199——左闭右开永远记得「要多大就多写 1」；

②分装列表时装错东西：任务二里 append 的应该是姓名 k，顺手写成 v 就成了「及格分数表」——先想清楚列表里要存什么；

③continue 和 break 用反：异常后想「重来」用 continue，想「结束」用 break——写反了要么死循环要么提前收工，跑一遍输入 'abc' 就能验证。

✅ 小结
本章通关！你现在知道了

选择结构负责判断（if / if-else / if-elif-else / 嵌套），循环结构负责重复（while / for + range / break、continue / 循环嵌套），异常处理负责兜底（try-except-else-finally）。三个综合任务示范了「枚举 + 条件」「遍历 + 判档 + 分装」「无限循环 + 异常接住 + 条件退出」三大范式。三套结构协同起来，就能把任何想法变成完整程序——第五章「程序控制」全部 17 节完成，去做作业吧！
