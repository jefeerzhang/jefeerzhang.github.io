为什么学这个

四个运算符，把元组用起来

数据装进了元组，接下来自然会问：两个元组能不能拼？能不能重复？能不能查某个元素在不在？这一节用 4 个运算符解决所有问题——+ 拼接、* 重复、in 与 not in 成员判断。它们和列表、字符串的用法几乎一样，又是「学一次、通吃三种序列」。作业里判断元素是否存在的问题，考的就是 in 和 not in。

💡 打个比方
糖葫芦、复印机与点名册

+ 像把两串糖葫芦串成一长串——注意是产生一根新串，原来两根完好无损；* 像复印 N 份——(1, 2)*3 复印三份接在一起；in / not in 像点名——喊一声名字，看它应不应到，应到返回 True，不应到返回 False。三个比方的共同点：谁也不会被破坏，原元组永远原封不动。

核心概念

四个运算符速查表

操作符描述
tp1 + tp2将元组 tp1 和 tp2 相加（拼接），形成一个新的元组
tp * N元组 tp 元素重复 N 遍，形成一个新的元组
x in tp判断元素 x 是否在元组内，返回 True 或 False
x not in tp判断元素 x 是否不在元组内，返回 True 或 False
  • + 和 * 都产生新元组，原元组不变——元组不可变，运算自然不会改动它
  • in / not in 返回布尔值 True 或 False，常与 if 搭配做条件判断
  • in 判断的是值相不相等，不看类型——1 in (1.0,)、1 in (True,) 都是 True；只有值本身不相等（如整数 1 与字符串 '1'）才返回 False
交互示例

🔬 in 的类型细节：1 和 '2' 的点名现场

元组 (1, 2) 里装的是整数 1 和 2

print(1 in (1, 2))

输出：

True

解读：1 是整数，元组里恰好有整数 1——点名应到，返回 True。

print('2' in (1, 2))
print('2' not in (1, 2))

输出：

False
True

解读：'2' 是字符串，和整数 2 长得像但不是一回事（呼应 3.19 的类型问题）——字符串不在元组里，in 返回 False，not in 反而返回 True。

课堂代码

PPT 原例：四行验四种运算

print((1, 2)*3)
print((1, 2) + ('5', '6'))
print(1 in (1, 2))
print('2' not in (1, 2))

输出结果：

(1, 2, 1, 2, 1, 2)
(1, 2, '5', '6')
True
True
  • (1, 2)*3：把 (1, 2) 重复三遍接成一串，共 6 个元素
  • (1, 2) + ('5', '6')：拼接各自保留原类型，数字还是数字、字符串还是字符串
  • '2' not in (1, 2) 为 True：说明字符串 '2' 确实不在这个整数元组里
❓ 测验

print('2' in (1, 2)) 的输出是？

✏️ 填空

x not in tp 判断元素 x 是否____元组内。

⚠️ 避坑
+ 两边都得是元组；* 复制的是引用

第一坑：+ 两边必须都是元组——(1, 2) + 3 报 TypeError；想追加一个元素要写成 (1, 2) + (3,)，注意 3 后面的逗号——上一节的「身份证」又出现了！

第二坑：* 复制的是引用——tp = ([1, 2],) * 3 会得到三个指向同一个列表的元素，改其中一个，三个一起变。元素全是数字、字符串时无此烦恼，这里先混个脸熟。

定心丸：+ 和 * 的结果都是新元组，原元组永远不变。

✅ 小结
你现在知道了

元组四大运算：+ 拼接、* 重复、in 成员判断、not in 反向判断；+ 和 * 都产生新元组、原元组不变；in / not in 返回 True 或 False，依据是值相等（1 in (1.0,) 为 True；整数 1 与字符串 '1' 则是两个不相等的值）；+ 两边必须是元组，单个元素要带逗号写成 (3,)。下一节：元组的函数与方法。
