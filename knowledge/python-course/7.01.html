为什么学这个

程序一关，数据就没了？

前六章写的程序有个共同「毛病」：变量、列表、字典全都住在内存里——程序运行时活蹦乱跳，程序一结束（或者电脑一关机重启），内存清空，什么都没留下。想让成绩、日记、计算结果留到明天，就必须把它们以文件的形式存进硬盘。本章是全课程的最后一章，也是「让程序成果留下来」的关键一章——从这一节开始，你的程序第一次拥有了「记忆」。

💡 打个比方
硬盘像一座图书馆：文件是书，文件夹是书架，路径是索书号

把硬盘想象成一座巨大的图书馆：文件是一本本的书（每本书都有名字）；文件夹（目录）是书架和阅览室，把书分门别类摆好；最顶层的根目录是图书馆大门——想找任何一本书都得先过这道门；而路径就是「索书号」：告诉系统「从大门进去 → 左转文学区 → 第三排书架 → 从上往下第 2 本」，一步一步精确定位到你想要的那本书。

核心概念

四个必须分清的词

  • 文件：逻辑上具有完整意义、且能在磁盘上永久保存的信息集合。它有名字（如 scores.txt），扩展名表示它的类型
  • 文件夹（目录）：存放文件和其他文件夹的容器，用来把众多文件分类摆放——文件夹里套文件夹，一层层展开就像一棵倒挂的树
  • 根目录：位于目录树最顶端的目录，是所有文件或目录的起点。Windows 下如 C:\，Linux/macOS 下是 /
  • 路径：为了准确定位文件和文件夹的位置、用字符串表示的目录树分层结构，如 C:\Users\hhq\Desktop\notes.txt
  • 内存 vs 硬盘：程序运行时从内存获取和写入数据，速度快但关机即失；要永久保存，必须以文件形式写入硬盘（外存）
课堂代码

内存里的数据会消失，文件里的不会

name = input('请输入你的名字：')
print('你好，' + name)
# 程序运行期间，name 住在内存里活得好好的
# 但程序一结束，name 就消失了——下次运行，谁也不记得你输过什么

# 想留下来？写进文件（本章后面几节会详细讲语法）
with open('guest.txt', 'w', encoding='utf-8') as file:
    file.write(name)    # 数据「落盘」，永久保存在硬盘上
  • 第 1~2 行：name 存在内存里，程序关掉就没了
  • 第 8 行：把 name 写进 guest.txt 后，哪怕关机重启，双击文件依然能看到
  • 现在看不懂 with open(...) 没关系——这正是后面几节要学的「文件操作三步曲」

⚠️ 避坑
三个高频翻车点

①别把「文件」和「文件名」混为一谈：文件是磁盘上那份信息的本体，文件名只是它的「标签」；扩展名（.txt、.py）决定系统用什么方式对待它；

②目录是「树」不是「网」：文件夹里可以套文件夹，但每一层只能有一个父目录——从根目录到任何一个文件，路径只有一条；

③别以为变量删了文件也会没：del name 只清内存里的变量，硬盘上的文件纹丝不动——内存和外存是两个世界。

✅ 小结
你现在知道了

文件是能在磁盘上永久保存的信息集合；文件夹是分类存放文件的容器；根目录是目录树起点；路径是用字符串精确定位文件的方式。内存数据关机即失，想留下程序成果必须写文件。下一节：文件分文本和二进制两大类，它们的脾气完全不同。
