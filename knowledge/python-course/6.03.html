为什么学这个

上一节说要「自己造函数」，怎么造？从 def 这一行学起

内置函数是别人的成果，第三方库是社区的成果——而自定义函数是你自己的成果。定义函数有一套固定语法：def 开头、函数名、参数、冒号、缩进的函数体，需要时再加一句 return。这套语法里有 6 个「零件」，缺一个都会报错。这一节我们把语法解剖开，每个零件点开看清楚，以后写函数就不会漏件。

💡 打个比方
定义函数像「写菜谱」：def 是「菜谱」两个字，参数是配料表，函数体是步骤，return 是端上桌的成品

def 相当于在菜谱本上写「菜谱：」（告诉 Python：接下来登记一道新菜）；菜名是函数名；「用料：鸡蛋 2 个」是参数；后面的步骤（打蛋、搅拌、下锅）是缩进的函数体；最后「装盘上桌」是 return 返回结果。菜谱写好了菜不会自动做好——定义 ≠ 执行，要等有人「点菜」（调用），下节细讲。

核心概念

语法解剖图：6 个零件逐个看

def 函数名(参数):
    缩进的函数体
    return 返回值

👇 六张卡片点击展开，每个零件都有细节：

① def

定义函数的保留字，不能用作变量名

def 是 Python 的保留字（关键字），意思是「我要定义一个函数了」。它就像菜谱本封面的「菜谱」两个字——见到它，Python 就知道后面登记的是函数。

👆 点击展开

② 函数名

命名规则与变量类似：任何有效的标识符

函数名的命名规则与变量一样（字母、数字、下划线，不能以数字开头），建议「见名知义」：算 sums 就叫 getsum，打招呼就叫 welcome。同样要避开保留字和内置函数名。

👆 点击展开

③ 参数

零个或多个，逗号分隔；无参数也要保留括号

参数可以有零个或多个，多个参数之间用逗号分隔，如 def getsum(a, b):。即使没有任何参数，一对圆括号也必须保留，如 def hello():——括号是「这是个函数」的标志。

👆 点击展开

④ 冒号

冒号必须要有；冒号下一行缩进也是语法要求

第一行末尾的冒号必须要有，少了就报 SyntaxError；而且冒号下一行必须缩进——这两条都是语法要求，和 if、for、while 的规矩一脉相承（第五章的缩进习惯这里直接复用）。

👆 点击展开

⑤ 函数体

实现功能的那组代码，每次被调用时执行

缩进的那一段就是函数体，装着「这道菜的做法」。注意：函数体每次被调用时才执行——定义时 Python 只是把它登记造册，一行都不会跑。

👆 点击展开

⑥ return

返回值的保留字；无返回值时返回 None

return 是保留字，作用是「把结果端出去」：函数执行到 return 就结束，并把后面的值交回给调用处。如果函数里没有 return，调用后返回的是 None（空值）——这个坑 6.04 重点讲。

👆 点击展开
  • 六条注意事项合起来记：def 是保留字；函数名与变量命名类似；参数零或多个、逗号分隔、无参也留括号；冒号必须有、下一行必须缩进；函数体每次被调用时执行；return 是保留字，无返回值时返回 None
课堂代码

PPT 原例：从无参、双参到返回两个值

例 1：无参数、无 return——只负责打印：

def hello():
    print("Hello World!")

例 2：两个参数、一个返回值——返回 a + b 的和：

def getsum(a, b):
    c = a + b
    return c

例 3：一个 return 同时返回两个值——圆的面积和周长：

def circular(r):
    area = 3.14 * r**2
    perimeter = 2 * 3.14 * r
    return area, perimeter
  • 例 1 对照零件：无参数 → 括号照样保留；没有 return → 调用后返回 None
  • 例 2 对照零件：参数 a、b 逗号分隔；return c 把计算结果交出去
  • 例 3 的 return area, perimeter 一次返回两个值——它们会被打包成一个元组，正是第四章「元组」的用武之地，下节调用时用 S, L = circular(30) 解包接收
交互示例

缺一个零件会怎样？报错现场还原

# 零件 ④ 缺失：忘写冒号
def hello()
    print("Hello World!")

SyntaxError: expected ':'
# 零件 ③ 乱来：无参数却不写括号
def hello:
    print("Hello World!")

SyntaxError: expected '('
  • 冒号、括号是「语法件」——缺了直接 SyntaxError，程序根本跑不起来
  • return 是「逻辑件」——不写不报错，只是拿不到返回值（返回 None），这种错更隐蔽
  • 把函数名命名成 def 这种保留字同样直接报错
❓ 测验

关于函数的定义语法，下列说法错误的是？

✏️ 填空

定义函数用保留字＿＿；第一行末尾必须有＿＿；函数体必须＿＿；函数中没有 return 语句时，调用后返回＿＿。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①忘写冒号 / 忘缩进：def 行末没冒号、或函数体顶格写，都是 SyntaxError——冒号和缩进是绑定的语法要求；

②无参数时省略括号：写成 def hello: 直接报错——括号是函数的「身份证」，哪怕没有参数也不能省；

③把「返回两个值」当成返回两个独立的量：return area, perimeter 实际返回的是一个元组 (area, perimeter)——接收时要用 S, L = circular(30) 解包，第四章的知识点在这里接上了。

✅ 小结
你现在知道了

定义函数的语法：def 函数名(参数): + 缩进函数体 + 可选的 return 返回值；def 和 return 都是保留字；函数名命名同变量；参数零或多个、逗号分隔、无参也留括号；冒号与缩进是语法要求；函数体每次被调用时才执行；无 return 时返回 None；一个 return 可以返回多个值（打包成元组）。下一节：调用这些函数。
