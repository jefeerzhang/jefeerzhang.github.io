为什么学这个

前面的操作都围绕「一个文件」，接下来要管理「一堆文件」了

从这一节起进入第二部分：目录与路径操作——新建文件夹、查看目录内容、改名、删除……这些活儿 Python 里有两大模块都能干：传统的 os / os.path 和现代的 pathlib。考试两种都可能考，工作中两种都得认识，所以本章后面每一节都用「os 方法 + Path 方法」双写法展示。先把两家的脾气摸清楚。

💡 打个比方
os 像「手动挡」，pathlib 像「自动挡」

开手动挡（os / os.path）：换挡、离合处处自己操心——操作的是字符串，函数一层套一层，Windows 和 Linux 的差别也得自己留心；开自动挡（pathlib）：顺手就好——路径是一个对象，属性方法一路「点」下去，系统差异自动适配。新手觉得自动挡香，但考纲和大量老代码仍要求认识手动挡——两种都要会看、会写。

核心概念

两大模块对比

  • os / os.path（传统方案）：核心面向字符串操作；函数式嵌套调用写法繁琐；需手动判断适配系统差异；可读性较差、代码冗长；胜在 Python 2 / 3 全版本兼容
  • pathlib（现代方案）：核心面向对象（Object）；链式属性调用简洁优雅直观；自动适配 Win / Linux / Mac；语义接近自然语言；要求 Python 3.4+
  • 两者不是替代关系而是并存：老项目、教材、考题常见 os，新代码推荐 pathlib
  • 用法统一记住：import os + from pathlib import Path，本章例题都会这样开头

    课堂代码
    
同一件事两种写法：判断文件存在

    
import os
from pathlib import Path

# 传统方案：os.path 函数式写法
print(os.path.exists('a.txt'))

# 现代方案：Path 对象方法写法
print(Path('a.txt').exists())

    
输出结果（当前目录没有 a.txt 时）：

    
False
False

    
    
      
  • os.path 版：exists 是 os.path 模块里的函数，把路径字符串当参数传进去
    • 
      
  • pathlib 版：先造出 Path('a.txt') 这个路径对象，再调用它自带的 .exists() 方法
    • 
      
  • 读法差别：一个是「问 os.path：a.txt 存在吗？」，一个是「a.txt 自己报告：我存在吗？」——后者更接近自然语言
    • 
    

  

      

    交互示例
    
链式调用的优雅：pathlib 一路点下去

    
from pathlib import Path

p = Path('作业') / '第三章' / 'notes.txt'
print(p)
print(p.name)        # 文件名
print(p.stem)        # 主名（不含扩展名）
print(p.suffix)      # 扩展名
print(p.parent)      # 上级目录

    
输出结果（Windows 下）：

    
作业\第三章\notes.txt
notes.txt
notes
.txt
作业\第三章

    
    
      
  • / 运算符可以直接拼接路径——pathlib 重载了它，比手写字符串拼接安全得多
    • 
      
  • .name、.stem、.suffix、.parent 都是属性，链式点出来，不用记函数名
    • 
      
  • 同样的活儿用 os.path 得分别调 os.path.join、os.path.basename、os.path.splitext、os.path.dirname——写起来冗长多了
    •

    ⚠️ 避坑
    

      
四个高频翻车点

      
①版本问题：pathlib 要 Python 3.4+，老环境（Python 2）只能用 os / os.path——考试看到「任何版本可用」的说法都是错的；

      
②两种写法别硬混：Path('a.txt').exists() 是对象方法，os.path.exists('a.txt') 是模块函数——把 Path 对象直接塞给 os.path 的某些函数可能出兼容问题，学阶段一种写法用到底；

      
③Windows 路径分隔符：手写字符串路径时 \ 要写成 \\ 或用 /，用 pathlib 的 / 拼接就自动适配，不易出错；

      
④别背「谁淘汰谁」：两套方案并存，老代码读 os、新代码写 pathlib，都要认识。

    ✅ 小结
