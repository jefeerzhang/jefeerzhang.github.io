为什么学这个

open('scores.txt') 到底打开的是哪个 scores.txt？

你的电脑上可能有 10 个文件夹里各有一个 scores.txt。open() 怎么知道你要哪个？答案藏在路径里：要么给它一个绝对路径（从根目录开始的全名），要么给它一个相对路径（从「程序现在站的地方」出发的短名）。作业第 1、2 题读写 scores.txt 时写错路径，就会撞上 FileNotFoundError——先把这一节吃透，能少踩一半的坑。

💡 打个比方
绝对路径是「完整地址」，相对路径是「从我这儿走」

给快递员写「北京市海淀区XX路XX号」（绝对路径），谁在哪儿寄都能送到，但啰嗦；跟室友说「楼下超市往右拐」（相对路径），前提是你们俩都站在宿舍里——短小灵活，但换个「参考位置」就指错地方了。程序运行时站的地方叫当前工作目录，相对路径全靠它定位。

核心概念

两种定位方式 + 两个定位符

  • 绝对路径：从根目录开始向下寻找，提供完整位置信息，唯一且精确。Windows 例：C:\Users\YourName\Documents\report.txt；Linux/macOS 例：/home/yourname/Documents/report.txt
  • 相对路径：相对当前程序运行目录（当前工作目录）定位，无需完整路径、更短更灵活，是项目开发首选——代码挪到别的电脑也能跑（可移植性好）
  • 定位符 .（一个点）：代表当前目录，写在路径最前面时点号可以省略——./logs/app.log 等价于 logs/app.log
  • 定位符 ..（两个点）：代表上一级目录，可以连续使用往上跳多级——../notes.txt 是「回到上一级找 notes.txt」，../../x.txt 是「往上跳两级」
  • 书写建议：Windows 里反斜杠 \ 是转义字符，路径要写成双反斜杠 \\，或者干脆用正斜杠 /（两个系统都认，最省心）
课堂代码

PPT 原例：同一文件的不同写法

# 绝对路径：从根目录开始，写全写死
file = open('C:\\xxx.py')              # 双反斜杠，转义安全（用完记得 file.close()，或改用 with 语句）
file = open('C:/xxx.py')               # 正斜杠写法，与上面等价

# 相对路径：相对当前工作目录
file = open('xxx.py')                  # 就在当前目录里，点号可省略
file = open('./xxx.py')                # 加上 . 也可以
file = open('a_file/aa.txt')           # 当前目录下的 a_file 文件夹里
  • 第 2、3 行：同一个文件的两种绝对路径写法，推荐正斜杠
  • 第 6、7 行：'xxx.py' 和 './xxx.py' 完全等价
  • 作业里把 scores.txt 和程序放在同一个文件夹，直接 open('scores.txt') 最省事

📋 PPT 原表：相对路径怎么「翻译」成绝对路径

假设当前工作目录路径写法含义
C:\（file 所在处）'xxx.py'等价 'C:\\xxx.py'
'a_file\\aa.txt'等价 'C:\\a_file\\aa.txt'
C:\b_file'..\\xxx.py'先回上一级 C:\，再找 xxx.py，等价 'C:\\xxx.py'
'..\\a_file\\aa.txt'先回上一级，等价 'C:\\a_file\\aa.txt'

📌 读法：看到相对路径，就把它拼到「当前工作目录」后面；看到 ..，先往回退一级再拼。

交互示例

为可移植性，优先用相对路径

# 反例：绝对路径——换个电脑、挪个文件夹就失效
file = open('C:/Users/hhq/Desktop/homework/scores.txt', 'r', encoding='utf-8')

# 正例：相对路径——只要 scores.txt 和程序在同一文件夹，走哪儿都能跑
file = open('scores.txt', 'r', encoding='utf-8')
  • 绝对路径把 hhq 写死在代码里，交作业时老师的电脑上根本没有这个目录
  • 相对路径只说「就在旁边」，代码拷到哪儿都能找到文件——这就是可移植性
  • 「当前工作目录」具体是哪儿？本章第 11 节（工作目录）会专门讲怎么查看和修改
❓ 测验

当前工作目录是 C:\b_file，相对路径 ..\notes.txt 指向哪里？

✏️ 填空

相对路径中，. 代表＿＿目录（点号可省略），.. 代表＿＿目录（可重复使用）。（两空用空格隔开）

⚠️ 避坑
三个高频翻车点

①单反斜杠会「吃字」：Windows 路径 'C:\table\note.txt' 里 \t、\n 被当成转义符（制表符、换行符），路径面目全非——写成 C:\\table\\note.txt 或直接用正斜杠 C:/table/note.txt；

②相对路径的「参照物」是程序运行目录，不是 .py 文件所在目录：从 IDE 不同位置运行，参照物可能不同，报 FileNotFoundError 时先想想「程序现在站在哪儿」；

③大小写与拼写：'Scores.txt' 和 'scores.txt' 是两个名字——路径错一个字母都找不到文件。

✅ 小结
你现在知道了

绝对路径从根目录开始、唯一精确但写死；相对路径相对当前工作目录、短小灵活且可移植，是项目首选。. 代表当前目录（可省略），.. 代表上一级目录（可连续使用）。Windows 下路径用双反斜杠或正斜杠避免转义问题。下一节：把打开、读写、关闭三步串成「文件操作三步曲」。
