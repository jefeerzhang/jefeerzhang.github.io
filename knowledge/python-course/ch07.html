✍️ 本章作业（ipynb 格式提交）

  1. 创建一个文件名为 scores.txt 的文本文件，并向该文件内写入如下信息：姓名 语文 数学 英语；张三 85 76 91；李四 89 92 96；王五 72 84 88。
  2. 从 scores.txt 文件内读取信息，分别输出三个人的平均成绩和三个科目的平均成绩。
  3. 输出文本文件 scores.txt 的文件信息，包括文件大小、文件创建时间、文件修改时间、文件最后访问时间等。
  4. 输出文本文件 scores.txt 真实路径，并根据路径提取并输出其所在目录。再根据路径判断其是否是一个文件，如果是的，将 scores.txt 文件删除。
  5. 在当前文件夹下，新建一个名为 Python 的文件夹，并将文件夹名称修改为 Python123。
  6. 判断 Python123 文件夹是否是一个空文件夹，如果是的，将 Python123 文件夹删除。
