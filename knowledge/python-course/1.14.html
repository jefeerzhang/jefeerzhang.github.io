为什么学这个

同一个 Python，为什么会有两个「不兼容」的版本？

你在网上搜代码、找教程时，几乎一定会撞上这样一个坑：明明照着敲，程序却报错——很可能那是一段 Python 2 的老代码。分清 2 和 3，能帮你：

  • 一眼识别老代码：看到 print "Hello" 这种写法，立刻知道「这是 Python 2.x 的，我不能直接照抄」。
  • 考试常考三大差异：打印输出、除法运算、迭代对象，这一节一张表全部搞定。
  • 确认自己电脑装的是哪个版本，避免环境搭错、作业跑不通。
💡 打个比方
Python 2 和 3，像「繁体字和简体字」

两个版本长得像、渊源深，但书写规则不同：很多字写法变了（print 要加括号了），老文章（旧代码）直接拿新规则读会出问题——这就是「不向后兼容」。

而且就像今天出版、教育、日常交流都通行简体字一样，现在整个 Python 世界通行 Python 3：2020 年 1 月 Python 2 官方停止维护后，学 Python 2 就像在现代社会学写繁体字——当作文化了解可以，当作日常书写就落伍了。你今天学的、未来要用的，默认全部是 Python 3。

核心概念

一场「壮士断腕」的大版本升级

  • Python 3 于 2008 年发布：为了修掉 Python 2 时代积累的设计缺陷（其中最出名的就是除法和字符编码问题），社区决定推出一个大版本——但代价是不向后兼容，很多 2.x 的老代码不能原样运行。
  • 过渡期长达十多年：旧项目迁移缓慢，社区一度「两代并存」。直到 2020 年 1 月 Python 2 官方停止维护（不再有安全更新），Python 3 才彻底成为绝对主流。
  • 今天学的一切默认 Python 3：本课程、主流教程、AI 领域的框架，全部基于 Python 3。
  • 鉴别老代码的信号：看到 print "Hello"（print 后直接跟内容、没括号），基本可以断定是 2.x 写法；看到 xrange() 也是同理。
🎬 交互示例

三大核心差异：切换对比亲手看

点击下方按钮，在 Python 2.x 与 Python 3.x 之间切换，观察同三件事的写法与结果差异：

🧟 Python 2.x 写法（2020 年已停止维护）

print "Hello"        # 打印输出：print 语句，不用括号
1 / 2                # 除法运算：结果 0（整数除法，小数被截断）
range(3) / xrange(3) # 迭代对象：range 与 xrange 两个并存

⚠️ 注意 1 / 2 的结果：0。因为 2.x 里两个整数相除默认取整数部分，1 除以 2 等于 0.5，截断后剩 0——无数初学者的血泪坑。

🚀 Python 3.x 写法（你正在学的版本）

print("Hello")       # 打印输出：print 函数，必须加括号
1 / 2                # 除法运算：结果 0.5（浮点除法）
range(3)             # 迭代对象：统一用 range()，xrange 已取消

✅ 在 3.x 里 1 / 2 返回 0.5，符合数学直觉；print 变成了标准函数；range() 一统天下。

💡 结论：同样三行代码，两个版本的结果和规则完全不同——这就是「不向后兼容」的含义。网上搜到的老代码若跑不通，先怀疑版本问题。

⚠️ 避坑
照抄网上代码报错？八成是版本不对

最常见的坑：从老教程或旧帖子里抄来 print "Hello"，在 Python 3 里直接报语法错误。记住信号：print 后面没括号、出现 xrange、1/2 得 0——这些都是 Python 2 的痕迹。老代码想用，要么改写成 3.x 语法（print 加括号、xrange 换 range），要么另找 3.x 版本的资料。

第二个坑：有些电脑同时装了 2 和 3，命令行敲 python 却启动了 2.x，作业怎么做都错。所以下一节的「试一试」请务必做——先确认版本，再写代码。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 2 与 Python 3 的区别：Python 3 于 2008 年发布且不向后兼容，2020 年 1 月 Python 2 停止维护。三大差异：打印输出（print "Hello" 与 print("Hello")）、除法运算（1/2 在 2.x 得 0 整数除法、在 3.x 得 0.5 浮点除法）、迭代对象（2.x 有 range 和 xrange、3.x 统一为 range）。请：1）再补充 2 个两者的其他差异；2）给我一段 Python 2 老代码让我练习改写成 Python 3，我改完你再批改；3）出 2 道单选题考我，等我作答后再公布答案。
🔧 试一试：确认你的电脑跑的是 3.x（3 分钟）
  1. 按 Win + R 输入 cmd 打开命令行，输入 python --version 回车。
  2. 看输出：若显示 Python 3.x.x（如 Python 3.11.5），恭喜，环境没问题，可以放心往下学。
  3. 若显示的是 Python 2.x.x，请按第 1.17 节（Python 环境搭建）的步骤重新安装 Python 3，别在 2.x 上写作业。
  4. 顺手再进交互模式验证本节所学：输入 1 / 2，如果输出 0.5，说明你确实跑在 Python 3 上——亲眼见证与 2.x 的差异。
✅ 小结
你现在知道了

Python 3 于 2008 年发布、不向后兼容；2020 年 1 月 Python 2 停止维护，Python 3 成为绝对主流。三大差异记牢：print "Hello" → print("Hello")；1/2=0 → 1/2=0.5；range()/xrange() → range() 统一。今天学的一切默认 Python 3，看到无括号的 print 就知道那是 2.x 老代码。下一节，我们给 Python 本尊画像——它的六大特点。
