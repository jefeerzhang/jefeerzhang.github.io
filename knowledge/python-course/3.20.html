为什么学这个

列表的「自带技能」：查找、排序、复制

上一节的函数要写成 len(ls)，这一节的方法要写成 ls.index(x)——它们长在列表自己身上，用「点」调出来。五个方法覆盖了最高频的操作：查位置、数个数、排序、倒序、复制。其中 sort 的脾气最特别（没有返回值！），是本章考试最爱挖的坑。

💡 打个比方
查座位号、点名报数、按身高整队

index 像「查座位号」——报上名字，告诉你他坐第几位；count 像「点名报数」——数一数这个名字出现了几次；sort 像「按身高整队」——矮的在前高的在后（降序就反过来）；reverse 像「向后转」——整支队伍原地掉头；copy 像「抄一份名单」——在复印件上乱涂乱画，原件毫发无损。

核心概念

五个常用方法速查表

方法功能说明
ls.index(x)索引返回列表中 x 第一个匹配项的索引位置
ls.count(x)计数返回列表中元素 x 的数量
ls.sort(reverse=False)排序默认升序 reverse=False；降序 reverse=True；无返回值（返回 None），直接改变原有元素顺序
ls.reverse()逆序反向排列列表中元素
ls.copy()复制复制列表，生成新的列表副本

点击卡片展开用法示例：

index

查第一个匹配项的位置
L = [70, 95, 88]
L.index(95) → 1
找不到会报 ValueError。

count

统计元素出现次数
L = [70, 88, 88]
L.count(88) → 2
没有则返回 0，不报错。

sort

就地排序，无返回值
L.sort() 升序
L.sort(reverse=True) 降序
直接改原列表，返回 None！

reverse

整队向后转
L = [1, 2, 3]
L.reverse() 后 L 变 [3, 2, 1]
注意：是「倒着排」，不是「从大到小」。

copy

生成新的列表副本
b = L.copy()
改 b 不影响 L。
注意：浅复制，嵌套列表共享内层。

方法 vs 函数

为什么一个用点、一个不用？
函数：len(L)、max(L)——写在外面
方法：L.index(95)——用「点」长在 L 身上
本质都是对列表的操作。

🔬 sort 的两个关键点——先猜再切

L = [3, 1, 2]
L = L.sort()　# ✗ 错误！sort() 返回 None，L 变成了 None

正确写法：
L.sort()　# 先就地排好
print(L)　# [1, 2, 3]　再用 L
scores = [70, 95, 88]
scores.sort(reverse=True)
print(scores)　# [95, 88, 70]　降序，从大到小
# reverse=False 是默认值，即升序
课堂代码

PPT 要点：sort 会「直接改变原有元素顺序」

L = [3, 1, 2]
print(L.sort())    # None　← sort 没有返回值！
L.sort()
print(L)           # [1, 2, 3]　原列表已被直接改变
L.reverse()
print(L)           # [3, 2, 1]
  • print(L.sort()) 打印出的是 sort 的返回值（None），不是排好序的列表
  • 想边排序边输出？分两步：先 L.sort()，再 print(L)
  • reverse 与 sort(reverse=True) 不同：前者只倒序、不管大小
❓ 测验

L = [3, 1, 2]，执行 L = L.sort() 后，L 的值是？

✏️ 填空

sort() 默认＿＿序排列，要降序需设 reverse=＿＿。（两空连填，中间空格隔开）

⚠️ 避坑
L = L.sort() 会把 L 变成 None！

这是本章第一大坑：sort() 没有返回值（返回 None）。错误写法 L = L.sort() 会让 L 直接变成 None，后面再对 L 做任何列表操作都报错。正确姿势：L.sort() 之后继续用 L。

坑二：index 只找第一个，count 是全部计数。列表里有多个 88 时，index(88) 只返回最靠前那个的位置。

坑三：copy 是浅复制——列表里若还套着列表，副本与原件共享内层列表（改内层会互相影响，一句带过，知道即可）。

✅ 小结
你现在知道了

index 查第一个匹配项位置、count 统计个数、sort 排序（默认升序，reverse=True 降序，无返回值、直接改原列表）、reverse 逆序、copy 生成新副本。记住口诀：sort 完别赋值，直接用。下一节实战：用这套组合拳完成成绩排序和统计！
