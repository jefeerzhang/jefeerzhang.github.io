为什么学这个

名单写错了，改一个字就行

前面学了怎么往列表里加元素、删元素，这一节解决最日常的需求：改。比如点名册上有人名字写错了、库存表里某个数字要更新——不必删了再加，直接「指哪改哪」。列表是可变序列，这正是它和字符串最本质的区别之一，也是本章作业的高频考点。

💡 打个比方
点名换人 vs 整排换人

索引赋值像「点名换人」：老师喊「3 号出列，6 号顶上」——只换那一个人，队伍人数不变。切片赋值像「整排换人」：把 3 号到 4 号这一整排都换掉，新来几个人都行——来 4 个人，队伍就自动变长；来 1 个人，队伍就自动变短。列表永远帮你把队站好。

核心概念

索引赋值改单个，切片赋值改一片

  • 可变序列：列表支持通过索引直接赋值来修改指定位置的元素，操作会直接改变原列表
  • 单个修改：L[i] = 新值，把下标 i 的元素换成新值
  • 多个修改：L[M:N] = 新列表，一次赋值同时替换一段元素
  • 长度自动伸缩：切片赋值时，新序列的长度不必与切片长度相同——原来占 2 个位置塞进 4 个，列表就变长；塞进 1 个，列表就变短
  • 赋的值甚至可以是另一个列表：把 [7, 8] 整个塞进一个位置，列表里就会出现「列表套列表」

🔬 逐步推演：先在心里猜结果，再点下面的按钮看答案

起始：L7 = [1, 2, 3, 4, 5]。执行 L7[2] = 6 会怎样？

L7[2] = 6
print(L7)　→　[1, 2, 6, 4, 5]
# 下标 2 的 3 被换成 6，其余不动

接着执行 L7[3] = [7, 8]——把一个列表塞进一个位置？

L7[3] = [7, 8]
print(L7)　→　[1, 2, 6, [7, 8], 5]
# 下标 3 整个变成列表 [7, 8]（套娃！）

再执行 L7[3:5] = [9, 10]——切片赋值，2 个位置换 2 个元素。

L7[3:5] = [9, 10]
print(L7)　→　[1, 2, 6, 9, 10]
# 下标 3、4 的 [7, 8] 和 5 被换成 9、10

最后执行 L7[2:4] = [11, 12, 13, 14]——2 个位置塞 4 个元素？

L7[2:4] = [11, 12, 13, 14]
print(L7)　→　[1, 2, 11, 12, 13, 14, 10]
# 原本占 2 个位置，塞进 4 个，列表自动变长！
课堂代码

PPT 原例：四步连起来看

L7 = [1, 2, 3, 4, 5]
L7[2] = 6
print(L7)      # [1, 2, 6, 4, 5]
L7[3] = [7, 8]
print(L7)      # [1, 2, 6, [7, 8], 5]
L7[3:5] = [9, 10]
print(L7)      # [1, 2, 6, 9, 10]
L7[2:4] = [11, 12, 13, 14]
print(L7)      # [1, 2, 11, 12, 13, 14, 10]
  • 每一步的赋值都直接改在 L7 身上，没有产生新列表
  • 第 4 步是精髓：L7[2:4] 原本只占 2 个位置，却塞进 4 个元素——列表从 5 个元素变成 7 个，长度悄悄变了
❓ 测验

L = [1, 2, 3, 4, 5]，执行 L[1:3] = [9] 后，L 的值是？

✏️ 填空

列表是可变序列，通过索引直接＿＿即可修改元素，操作会直接改变＿＿列表。（两空连填，中间空格隔开）

⚠️ 避坑
字符串可改不了！还有「悄悄变长变短」的陷阱

坑一：字符串是不可变序列。列表能 L[0] = 'x'，字符串不能——s[0] = 'x' 会直接报 TypeError: 'str' object does not support item assignment。想改字符串只能重新切片拼接生成新串。这是列表与字符串最本质的区别之一，考试爱考。

坑二：切片赋值左右长度不一致不报错。2 个位置塞 4 个元素，Python 不吭声就把列表撑长了——如果你本意是「一对一替换」，结果列表却悄悄变了长，后面的索引全乱套。写切片赋值前，先数一数两边元素个数。

✅ 小结
你现在知道了

列表是可变序列：索引赋值 L[i] = 新值 改单个元素；切片赋值 L[M:N] = 新列表 一次改多个，且新序列长度不必与切片相同——列表自动伸缩，塞入子列表还会出现嵌套。字符串不可变，s[0]='x' 会报 TypeError。下一节：列表的运算符与四个统计函数。
