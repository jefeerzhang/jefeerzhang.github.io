为什么学这个

字典建好了，怎么把里面的东西拿出来？

创建字典只是第一步，真正的日常操作是取值：按键拿单个值，或者一眼看清字典里所有的键、所有的值、所有的键值对。这一节的两个表格（访问值、三视图）是本章考试与作业的核心考点——本章作业第 5 题求总成绩，用的就是三视图里的 values()。

💡 打个比方
闯门 vs 敲门，和点菜系统的三个页面

dc[key] 像「直接闯门」：没有这间房就一头撞墙，当场报 KeyError；dc.get() 像「敲门问询」：没人应答也不吵闹，带句话就走——默认带一句 None，或者你指定的兜底值。

三视图像点菜系统的三个页面：菜品名单（keys，有什么菜）、价格表（values，各多少钱）、整张菜单（items，菜和价一一对应）。三个页面看的是同一份菜单，只是呈现的角度不同。

核心概念

两个访问方法 + 三个视图方法

访问值——两种方式，区别在「键不存在」时的表现：

方法说明
dc[key]查询键为 key 对应的值 value；key 不存在则报错（KeyError）
dc.get(key, value)查询键为 key 对应的值 value；key 不存在则返回 value，value 默认情况下为 None

三视图——keys / values / items，分别拿到字典的键、值、键值对：

方法说明
dc.keys()获取字典的所有键，返回值为 dict_keys 类型，可以转为列表
dc.values()获取字典的所有值，返回值为 dict_values 类型，可以转为列表
dc.items()获取字典的所有键值对，返回值为 dict_items 类型，可以转为列表
  • 三视图返回的不是列表，是 dict_keys / dict_values / dict_items 类型的「视图」对象
  • 想按列表的方式用（下标、len 之外的列表操作），先 list() 转换
  • items() 转成列表后，每个元素是一个 (键, 值) 元组
交互示例

🔬 [] vs get() 大对决

用 [] 查一个不存在的键——直接撞墙

DC5 = {'a': 1, 'b': 2, 'c': 3}
print(DC5['a'])   # 查存在的键，没问题
print(DC5['d'])   # 查不存在的键……

输出结果：

1
KeyError: 'd'

键不存在时立刻报 KeyError，程序中断——严格派眼里没有「差不多」。

用 get() 查一个不存在的键——带句话走

DC5 = {'a': 1, 'b': 2, 'c': 3}
print(DC5.get('d'))      # 不给兜底值，默认返回 None
print(DC5.get('d', 4))   # 给了兜底值 4，就返回 4

输出结果：

None
4

键不存在也不报错：没指定兜底值返回 None，指定了就返回兜底值——温和派永远有台阶下。

🔬 三视图现场演示

DC6 = {'a': 1, 'b': 2, 'c': 3}
print(DC6.keys(), list(DC6.keys()))
print(DC6.values(), list(DC6.values()))
print(DC6.items(), list(DC6.items()))

输出结果（视图对象原样 vs 转成列表）：

dict_keys(['a', 'b', 'c']) ['a', 'b', 'c']
dict_values([1, 2, 3]) [1, 2, 3]
dict_items([('a', 1), ('b', 2), ('c', 3)]) [('a', 1), ('b', 2), ('c', 3)]
  • 前半段是视图对象（带着 dict_keys 等「外壳」），后半段是 list() 转换后的普通列表
  • items() 转列表后，每个元素是 (键, 值) 元组，如 ('a', 1)
❓ 测验

DC5 = {'a': 1}，执行 print(DC5['d']) 会？

✏️ 填空

dc.get(key, value) 在 key 不存在时返回 ___，value 默认为 ___。（两空连填，中间用空格隔开）

⚠️ 避坑
KeyError 高发区与「先 list 再下标」

dc['d'] 查不存在的键是新手最常见报错 KeyError——数据来源不确定时，优先用 get()。也别以为键「看起来在」就一定在：键区分类型，'3' 和 3 是两个不同的键（4.18 的 DC8 就埋了 'c': '3' 这样的例子）。

三视图对象不能直接用下标：DC6.keys()[0] 会报错，要先 list(DC6.keys())[0]。还有 items() 转列表后每个元素是 (键, 值) 元组，想单独拿键要用 item[0]。

✅ 小结
你现在知道了

访问值两种方式：[] 严格（键不存在报 KeyError），get() 温和（返回兜底值，默认 None）。三视图：keys() 拿所有键、values() 拿所有值、items() 拿所有键值对，返回视图对象，list() 后可按列表用。下一节：往字典里添加和修改键值对。
