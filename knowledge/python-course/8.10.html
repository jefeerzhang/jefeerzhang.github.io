为什么学这个

一只鸭子：既会飞，又会游泳，技能从哪来？

上一节我们让 Student 继承了 Person——一个子类、一个父类，这叫单继承。但现实中的分类常常是「多技能叠加」的：鸭子既属于「会飞的动物」又属于「会游泳的动物」。Python 对此非常慷慨，支持多重继承——一个子类可以同时继承多个父类，把所有父类的属性和方法一次收齐。这是 Python 面向对象的一大特色，语法上只是「括号里多写几项」而已。

💡 打个比方
多重继承像「唐老鸭拜了两位师父」：一位教飞行，一位教游泳

Flyable 是飞行教练，Swimmable 是游泳教练，Duck 同时拜在两人门下——两位师父的技能全部学到手，一只既会飞又会游泳的唐老鸭就诞生了。唯一的规矩是：如果两位师父教了同名的招式，听谁的？按 MRO 顺序（方法解析顺序）查找，简单理解成「按括号里从前到后」即可——真正的规则叫 C3 线性化，本章了解即可、不必深究。

核心概念

多重继承的写法与规则

  • 语法：括号里写多个父类，用逗号分隔——class 子类(父类1, 父类2):
  • 全盘接收：子类同时拥有所有父类的属性和方法，如 Duck 既有 fly() 又有 swim()
  • 父类之间互不认识：Flyable 和 Swimmable 各自独立定义，互不干扰，Duck 只是「汇总」它们
  • 同名方法看顺序：多个父类有同名方法时，按 MRO 顺序（方法解析顺序，简记为「括号内从前到后」）查找，本章了解即可
  • 初始化方法同理：如果多个父类都有 __init__，通常也只排在前面的那个会被自动执行，其余要手动 super() 或 父类名.__init__() 调用

🔬 多重继承实验台：点按钮执行 PPT 测试流程（Duck 同时继承 Flyable、Swimmable）

点按钮模拟运行～先创建对象，再调用方法。
课堂代码

PPT 原例：Duck(Flyable, Swimmable)

class Flyable:                      # 父类1：会飞
    def fly(self):
        print(f'{self.name}会飞！')

class Swimmable:                    # 父类2：会游泳
    def swim(self):
        print(f'{self.name}会游泳！')

class Duck(Flyable, Swimmable):     # 多重继承
    def __init__(self, name):
        self.name = name

d = Duck('唐老鸭')
d.fly()
d.swim()

输出结果：

唐老鸭会飞！
唐老鸭会游泳！
  • Duck(Flyable, Swimmable)：一个括号装两个父类，逗号分隔——Duck 同时拥有两套技能
  • d.fly() 用的是 Flyable 的方法、d.swim() 用的是 Swimmable 的方法——两个父类的方法在同一个对象上都能调
  • self.name 是 Duck 自己的 __init__ 创建的——父类方法里照样能用它，和上一节的道理相同
❓ 测验

Flyable 和 Swimmable 都定义了 run()，执行 class Duck2(Flyable, Swimmable) 后，Duck2().run() 调用的是谁的 run？

✏️ 填空

多重继承的写法：class 子类(父类1, 父类2):，多个父类之间用＿＿分隔；当多个父类有同名方法时，Python 按括号内的＿＿顺序查找（这叫 MRO 顺序）。（第一空填分隔符，第二空填查找方向，两空用空格隔开）

⚠️ 避坑
三个高频翻车点

①父类方法里用到的属性，子类 __init__ 必须创建：Flyable.fly 里用了 self.name，若 Duck 的 __init__ 忘了写 self.name = name，一调用 fly 就 AttributeError——父类只提供方法，数据还得有人创建；

②多个父类都有 __init__ 时只自动执行一个：与上一节同理，需要父类的初始化逻辑时要显式调用，别想当然「每个父类的 __init__ 都会跑」；

③滥用多重继承：父类一多、「技能」一冲突，查找顺序就变复杂——零基础阶段建议像本节这样，让每个父类各管一摊互不重名，MRO 了解即可。

✅ 小结
你现在知道了

Python 支持多重继承：一个子类可以同时继承多个父类，括号里逗号分隔——class 子类(父类1, 父类2):，子类同时拥有所有父类的属性和方法；多个父类有同名方法时按括号内的顺序（从前到后）查找，即 MRO 顺序，本章了解即可不必深究。下一节：继承再往前一步——同一个方法在不同子类对象上各显神通，这就是多态。
