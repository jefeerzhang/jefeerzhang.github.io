为什么学这个

同一个数，竟然有四副"面孔"

Python 的整数类型 int 有 4 种进制表示：十进制、二进制、八进制和十六进制。默认采用十进制，其他进制需要使用引导符号。还有一条关键规则：其他进制输出时会自动转为十进制。这一节解决三个问题：

  • 四种进制分别用什么引导符号？由哪些数字组成？
  • 为什么 0b1010、0o12、0xA 打印出来全是 10？
  • 不同进制的数，在内存里到底以什么形式存储？
💡 打个比方
钱没变，只是写法不同

口袋里装着一张十元。记在账本上写「10」，用二进制记账就是「1010」，八进制记账是「12」，十六进制记账是「A」——钱一直没变，变的只是记账的写法。四种进制也一样：写法不同，数值相同，计算机内心认的始终是同一个数。

核心概念

四种进制的"身份证"

先看"同一个数，四副面孔"——点击卡片展开每种写法：

十进制写法

10 —— 日常写法，默认进制
无引导符号，由 0-9 组成，如 10、-100。这是我们从小用到大的写法，也是 Python 的默认进制。
👆 点击展开

二进制写法

0b1010 —— 引导符号 0b / 0B
由 0 和 1 组成，如 0b1010（等于十进制 10）、-0B11（等于十进制 -3）。计算机内部最爱二进制。
👆 点击展开

八进制写法

0o12 —— 引导符号 0o / 0O
由 0-7 组成，如 0o12（等于十进制 10）、-0O77（等于十进制 -63）。注意 0 后面跟的是字母 o（octal），不是数字 0。
👆 点击展开

十六进制写法

0xA —— 引导符号 0x / 0X
由 0-9 和 a-f（或 A-F）组成，a=10、f=15。如 0xA（等于十进制 10）、-0XFF（等于十进制 -255）。常见于颜色值、内存地址。

实战演示

写法不同，值相同，类型也相同

decimal_num = 10     # 十进制
binary_num  = 0b1010 # 二进制
octal_num   = 0o12   # 八进制
hex_num     = 0xA    # 十六进制

print(binary_num, octal_num, hex_num)   # 输出：10 10 10
print(type(decimal_num))                # 输出：<class 'int'>
print(type(binary_num))                 # 输出：<class 'int'>

💡 关键结论：四种写法的值完全相等——它们存的是同一个整数，只是「写出来的样子」不同（计算机内部按二进制存储，十进制、十六进制都只是给人看的写法）；打印时其他进制会自动转为十进制输出，类型也全部是 int。

❓ 测验

二进制数 0b1010 对应的十进制值是？

✏️ 填空

十六进制的引导符号是＿＿（大写或小写都可以）。

⚠️ 避坑
引导符号写错，Python 直接不认

① 引导符号里混入非法数字会报错：二进制只能有 0 和 1，写 0b102 会报 SyntaxError；八进制不能出现 8、9，写 0o89 同样报错。

② 别把八进制的 o 写成数字 0：0012 不是八进制写法（会报 SyntaxError: leading zeros in decimal integer literals are not permitted），0o12 才是。0 后面紧跟的是字母 o 或 x 或 b。

③ 输出永远是十进制：哪怕你用 0b1010 赋值，print 出来也是 10——别惊讶"我的二进制去哪了"，它一直都在，只是换回了十进制的"脸"。

✅ 小结
你现在知道了

Python 整数有 4 种进制写法：十进制（默认，无引导符号）、二进制（0b）、八进制（0o）、十六进制（0x）。写法不同但值相同——进制写法只是给人看的「外观」，值本身完全一样（计算机内部一律按二进制存储），输出时自动转回十进制，类型都是 int。下一节：小数的"惊喜"——浮点数与精度陷阱。
