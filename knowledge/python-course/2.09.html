为什么学这个

程序与用户对话的两扇门

之前写的程序都是「自说自话」，数据写死在代码里。想让程序听用户说话（输入）、再把结果告诉用户（输出），就要用这一节的三个内置函数：

  • input()：从键盘读取一行，让用户「说话」
  • print()：把对象输出到屏幕，让程序「回话」
  • eval()：把字符串当成表达式真的执行，常用于把输入转成数值
💡 打个比方
快递柜、广播喇叭和纸条算式

input() 像快递柜取件——程序停下来等你把东西放进去，你不放它就一直等；print() 像广播喇叭——把结果喊出来给大家听；eval() 像收到一张写着算式的纸条，你不仅读它，还真的把它拿去算出结果。

核心概念

三个函数怎么用？

  • input()：从键盘读取一行文本，用法为 变量名 = input('提示语')。返回值永远是字符串类型。
  • print()：将对象输出到屏幕，可指定分隔符和结束符——默认分隔符为空格 ' '，默认结束符为换行符。
  • eval()：将字符串作为 Python 表达式执行，常用于把输入的字符串转为数值。

🔍 三合一演示台：切换查看每个函数的代码、输出与要点

age = input('请输入年龄：')   # 输入：21
print(age)                    # 输出：21
print(type(age))              # 输出：<class 'str'>

要点：屏幕上显示的是 21，但 type() 告诉你它的真身是 str（字符串）——input() 返回的永远是字符串。

print(1, 2, 3)              # 输出：1 2 3（默认空格分隔）
print(1, 2, 3, sep='-')     # 输出：1-2-3（自定义分隔符）
print(1, 2, 3, sep='*', end=' ')   # 输出：1*2*3 然后不换行
print(4, 5, 6)              # 接在上面 → 1*2*3 4 5 6

要点：sep 管中间用什么隔开，end 管结尾接什么——把 end 改成空格，下一条 print 就接在同一行了。

result = eval(input('请输入计算表达式：'))   # 输入：2+3
print(result)                # 输出：5
print(type(result))          # 输出：<class 'int'>

要点：eval() 把字符串 '2+3' 当成真正的表达式去算，得到整数 5——它是「字符串 → 数值」的常用捷径。

❓ 测验

input() 函数的返回值类型永远是？

✏️ 填空

print() 的默认分隔符是＿＿，默认结束符是＿＿。（两空连填，中间用空格隔开）

⚠️ 避坑
input() 给你的「数字」其实是字符串！

你输入 21，input() 返回的是字符串 '21'，不是整数 21。直接拿去做算术运算，会出错或行为完全不符合预期：

age = input('请输入年龄：')   # 输入 21，age 是 '21'（str）
print(age * 2)                # 输出 2121，而不是 42！字符串乘 2 是重复两遍

正确做法：先转换再运算——用 int(age)、float(age)，（eval(input()) 能一步到位，但它会把输入当代码执行，有安全风险，不建议使用）。

  2. 运行 age = input('请输入年龄：')，输入 21 回车。

✅ 小结
你现在知道了

input() 从键盘读一行文本，返回值永远是字符串；print() 把对象输出到屏幕，默认空格分隔（sep）、换行结束（end）；eval() 把字符串当表达式执行，常用于把输入转成数值。最大的坑：输入 21 得到的是 '21'，算术运算前必须转换。下一节：让代码更整齐的缩进与注释规范。
