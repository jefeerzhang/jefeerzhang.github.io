为什么学这个

同样是文件，为什么 .txt 能直接看，.jpg 打开是乱码？

双击 日记.txt，记事本哗一下就打开了；双击 照片.jpg，得靠看图软件渲染半天；用记事本强行打开 .jpg，只会看到一堆「天书」。这是因为文件按编码方式分成两大类——文本文件和二进制文件。分清这两类，你才知道本章该用 'r' 模式还是 'rb' 模式去打开文件，这是后面一切操作的前提。

💡 打个比方
文本文件像「明信片」，二进制文件像「密码信」

文本文件是一张明信片：内容是白纸黑字，谁拿起来都能直接读懂，不需要任何工具。二进制文件是一封密码信：内容是按特定格式加密的字节流，得拿着对应的「解码器」（专门软件）才能还原成图片、音乐或视频——用错了解码器（比如用记事本开 .mp3），读出来的全是乱码。

核心概念

两大门派对照卡

  • 按编码方式划分，文件分为文本文件和二进制文件两大类
  • 文本文件：存储人类能直接阅读理解的字符串（英文字母、汉字、数字等），可用记事本或浏览器直接查看、编辑
  • 二进制文件：存储采用特定编码格式的二进制字节（图形图像、音视频、可执行文件等），必须由专门软件解码才能读取或修改
  • 经验判断：看扩展名——txt、csv、html、py 一般是文本；jpeg、mp3、mp4、exe、docx、xlsx 是二进制。扩展名只是命名约定，不是类型的判据（见本页避坑②）
  • 冷知识：docx 和 xlsx 其实是一个压缩包（二进制）——不信可以用压缩软件打开试试

💌文本文件 · 明信片

  • 内容：人类可读的字符串
  • 查看：记事本、浏览器直接打开
  • 常见扩展名：txt / csv / html / py
  • 本章主角，用 'r'、'w' 等模式处理

🔐二进制文件 · 密码信

  • 内容：特定编码格式的字节流
  • 查看：必须用专门软件解码
  • 常见扩展名：jpeg / mp3 / mp4 / exe / docx / xlsx
  • 要用 'rb'、'wb' 等模式处理，且严禁指定 encoding
课堂代码

亲眼看一看：读文本是字，读二进制是字节

# 文本文件：'r' 模式 + encoding，读出来人能看懂
with open('古诗.txt', 'r', encoding='utf-8') as file:
    print(file.read())    # 锄禾日当午，汗滴禾下土。

# 二进制文件：'rb' 模式（b = binary），读出来是字节
with open('照片.jpg', 'rb') as file:
    print(file.read(10))  # b'\xff\xd8\xff\xe0\x00\x10JFIF'——看不懂才是正常
  • 读文本文件用字符模式 'r'，还可以告诉 Python 用什么编码（encoding）来翻译
  • 读二进制文件用字节模式 'rb'，得到的是原始字节（b'...' 开头），Python 不会帮你翻译
  • 本章练习主要处理文本文件——作业的 scores.txt 就是典型文本文件

⚠️ 避坑
三个高频翻车点

①别用记事本打开二进制文件：看到的「乱码」不是文件坏了，而是记事本硬着头皮把字节当文字翻译——文件本身完好无损；

②别以为扩展名改了类型就变了：把 song.mp3 改名 song.txt 只是换了「标签」，内容还是二进制字节，记事本打开依旧乱码；

③docx、xlsx 不是文本文件：名字里没有 x 的 .doc 才是老式格式；.docx/.xlsx 本质是 zip 压缩包（二进制），别被「能装文字」骗了。

✅ 小结
你现在知道了

按编码方式文件分两类：文本文件存人类可读的字符串（txt/csv/html/py），记事本直接看；二进制文件存特定编码的字节（jpeg/mp3/mp4/exe/docx/xlsx），要专门软件解码。docx、xlsx 其实是压缩包。本章主要处理文本文件。下一节：怎么用「路径」准确说出一个文件在哪。
