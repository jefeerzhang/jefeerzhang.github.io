为什么学这个

成绩分五档，难道要写五个 if 吗？

前面学过单分支和双分支，可现实中的判断往往不止两档：成绩分 A~E 五档、BMI 分四类、优惠券分三级。多分支结构就是「有多条判断语句，根据判断条件不同，执行不同代码块」的分支结构——用一条 if-elif-else 链把所有档位串起来，是本章作业里出场率最高的写法。

💡 打个比方
多分支像「景区分道检票」：从 A 道口开始依次问，符合就进，后面的道口不再看

检票员站在第一个道口问：「你的票符合条件 1 吗？」符合就放行进园，后面的道口他一眼都不再看；不符合才走到第二个道口接着问……一直问到兜底的 else 通道。所以队伍的排序（条件的顺序）非常重要——要是把普通票通道排在 VIP 通道前面，VIP 也会被先拦进普通通道，因为「命中即停」。

核心概念

if-elif-else 语法与四条注意事项

if <条件1>:
    <代码块_真1>
elif <条件2>:
    <代码块_真2>
elif <条件3>:
    <代码块_真3>
……
else:
    <代码块_假>
  • if 语句必须作为起始语句，不可或缺——整条链从它开始
  • elif 语句位于中间，数量不限——想要多少档就写多少个
  • else 语句必须放在结尾，可以省略——省略后可能所有条件都不满足、一个分支也不执行
  • 条件判断从上到下依次执行：某一条件为真就执行它所属的代码块，后续语句均不会执行；条件为假则向下继续判断，直至 else 语句。因此，语句顺序十分重要
课堂代码

PPT 原例：百分制成绩转五分制

score = float(input("请输入一个百分制成绩："))
if score >= 90.0:
    grade = "A"
elif score >= 80.0:
    grade = "B"
elif score >= 70.0:
    grade = "C"
elif score >= 60.0:
    grade = "D"
else:
    grade = "E"
print(f"对应的五分制成绩是：{grade}")
  • 输入 80：80 不满足 >=90，往下走；满足 >=80，得到 B，后面全部跳过
  • 输入 59：前四个条件全为假，落到 else，得到 E
  • elif 的条件是隐含前置条件的：elif score >= 80.0 能被执行到，说明 score >= 90.0 已经不成立了——这正是顺序在暗中帮忙
交互示例

顺序对了才靠谱：正确顺序 vs 顺序写反

score = float(input("请输入一个百分制成绩："))
if score >= 90.0:
    grade = "A"
elif score >= 80.0:
    grade = "B"
elif score >= 70.0:
    grade = "C"
elif score >= 60.0:
    grade = "D"
else:
    grade = "E"

条件从严格到宽松排列，输入 95 → A，输入 80 → B，输入 59 → E，全部正确。

score = float(input("请输入一个百分制成绩："))
if score >= 60.0:
    grade = "D"   # ← 95 分也会先命中这里！
elif score >= 90.0:
    grade = "A"
elif score >= 80.0:
    grade = "B"
elif score >= 70.0:
    grade = "C"
else:
    grade = "E"

把 >=60 放到最前面后，输入 95：第一个条件 95>=60 就为真，命中 D，后面的 A、B、C 根本没机会被判断——这就是本章最经典的易错点：命中即停，顺序排错就错档。

🚌 输入 80 的判定之旅（正确顺序版）
1
条件 1：80 >= 90.0？假，向下继续判断
2
条件 2：80 >= 80.0？真！执行 grade = "B"
3
后面的 elif、else 全部跳过不再判断，直接执行最后一行 print
4
输出：对应的五分制成绩是：B

✏️ 填空

多分支结构中：if 语句必须作为起始语句；elif 语句位于中间，数量＿＿；else 语句必须放在＿＿，可以省略。（两空用空格隔开）

⚠️ 避坑
三个高频翻车点

①条件顺序要从严格到宽松：先 >=90 再 >=80 再 >=60……反着写就会像上面那样把 95 分误判成 D；

②elif 是关键字，不是 else if：从 C、Java 等语言转过来的同学常写成 else if，Python 里会直接语法错误——Python 的写法就是 elif；

③else 可以省略，但要想清楚：省略 else 后如果所有条件都为假，整个分支一个代码块都不执行，程序会「沉默地」跳过——不报错，但可能不是你想要的。

✅ 小结
你现在知道了

多分支用一条 if-elif-else 链处理多档判断：if 必须打头、elif 居中数量不限、else 收尾可省略；条件从上到下判断、命中即停，后面的分支不再执行，所以条件要从严格到宽松排序、语句顺序十分重要。下一节：当判断需要「先分大类再分小类」时，把分支套进分支——嵌套分支结构。
