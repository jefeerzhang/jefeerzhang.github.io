为什么学这个

程序会「做判断」，全靠这两个运算符

前面的算术运算符负责「算数」，但真实的程序还需要做判断：分数够不够 60？密码对不对？两个条件是不是同时成立？这就要靠比较运算符和逻辑运算符。这一节你将搞懂三件事：

  • 比较运算符怎么用？它们的返回值只有两种
  • and、or、not 三个逻辑运算符各自什么脾气？
  • 布尔值竟然还能当数字 1 和 0 参与算术？
💡 打个比方
裁判只回答「是」或「否」

比较运算符像一位铁面裁判：你递给它两个数，它只回答「是（True）」或「否（False）」，绝不多说一个字。
逻辑运算符像三个性格不同的班主任：and 是严师——两门课都及格才算过关，挂一门都不行；or 是仁师——一门及格就行，要求宽松；not 爱唱反调——你说真它偏说假，你说假它偏说真。

核心概念

两张表记住全部运算符

  • 比较运算符：比较两个值的关系，结果只能是布尔值——True（对）或 False（错）。比较还能连着写，如 0 < x < 10，等价于 0 < x and x < 10。
  • 逻辑运算符：把多个 True / False 组合起来做综合判断。and / or 有短路求值特性（and 左侧为假就不再算右侧，or 左侧为真就不再算右侧），返回值也不一定是布尔值，而是决定结果的那个操作数——如 0 or 'abc' 得到 'abc'。
  • 冷知识：布尔值其实可以当数字用——True 相当于 1，False 相当于 0，能直接参与算术运算。
比较运算符含义示例
>大于5 > 3 → True
<小于5 < 3 → False
==等于5 == 5 → True
!=不等于5 != 3 → True
>=大于或等于5 >= 5 → True
<=小于或等于5 <= 3 → False
逻辑运算符口诀示例
and（与）全真为真，有假为假True and False → False
or（或）全假为假，有真为真True or False → True
not（非）非真即假，非假即真not True → False
a, b = 10, 2
print(a > b, a < b, a == b)    # 输出：True False False
print(a >= b, a <= b, a != b)  # 输出：True False True
实战演示

两个进阶玩法

🔍 点击切换，看看布尔值的两副面孔：

print(True + True, True + False, False + False)  # 输出：2 1 0

True 相当于 1、False 相当于 0，可以直接参与算术。统计「满足条件的个数」时，这个技巧特别好用。

print(True and True and False and False)  # 输出：False
print(True or True or False or False)     # 输出：True
print(True or True and False)             # 输出：True
print(not True or True and False)         # 输出：False

and 的优先级高于 or：先算 True and False → False，再算 True or False → True。第三行因此输出 True。最后一行则是先 not True → False、再 True and False → False，最后 False or False → False。

❓ 测验

print(True or True and False) 的输出是？

✏️ 填空

比较运算符的返回值只能是布尔值 ＿＿ 或 False。（注意 Python 中的大小写）

⚠️ 避坑
「==」和「=」，一个字符之差，天壤之别

① == 是判断相等（返回 True/False），= 是赋值。写混了轻则逻辑出错（该判断的地方赋了值），重则直接语法报错（比如 if x = 5: 会报 SyntaxError）。判断相等，永远用两个等号。

② 布尔值可参与算术（True + True 的结果是 2），这不是 bug 而是特性——统计列表里有多少个成绩及格时，把每个 score >= 60 的结果直接加起来就行，非常方便。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 的比较运算符和逻辑运算符。请：1）解释 6 个比较运算符和 and、or、not 的规则，说明返回值是什么类型；2）演示布尔值当数字用的例子，比如 True + True 的结果；3）逐步推导 print(True or True and False) 为什么输出 True；4）出 2 道单选题考我，等我作答后再公布答案。
🔧 试一试：亲手按下裁判的哨子（3 分钟）
  1. 进入交互模式，输入 print(True + True + False) 回车——看看结果是不是 2？想一想为什么。
  2. 再输入 print(not True or True and False) 回车，先自己推一遍答案，再看输出是不是 False。
  3. 推不出来的话，按顺序拆：not True 是什么？True and False 是什么？最后把两个结果用 or 连起来。
  4. 试试 10 > 2 和 10 = 2——第二个会怎样？体会 == 和 = 的区别。
✅ 小结
你现在知道了

比较运算符（>、<、==、!=、>=、<=）的结果只能是布尔值 True 或 False；逻辑运算符 and「全真才真」、or「有真就真」、not「唱反调」；布尔值可当 1/0 参与算术，适合统计个数；判断相等要用 ==，= 是赋值。下一节：这么多运算符混在一起，谁先算谁后算？——运算符优先级。
