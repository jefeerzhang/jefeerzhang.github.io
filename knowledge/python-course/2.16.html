为什么学这个

一个表达式里挤满运算符，谁先动手？

在 Python 代码中，不同运算符的优先程度并不相同。在复杂运算表达式中，优先级高的运算符先运算，相同运算级别一般从左向右运算（幂运算 ** 是唯一的例外，它从右向左结合）。搞不清这个，表达式一复杂就会算错——而且是不报错的那种错。这一节你将掌握：

  • Python 的 6 级优先级阶梯，从幂运算到赋值
  • 怎么用小括号改变运算顺序
  • 遇到复杂表达式，如何一步步拆解出正确结果
💡 打个比方
排队坐 bus：VIP 先上，括号是贵宾通道

表达式里的运算符像在排队上车：** 是 VIP，永远第一个上；乘除一伙（*、/、//、%）排第二；加减排第三；比较和逻辑运算符殿后，最后上车的是赋值——活都是先干完才交货的。
而小括号就像贵宾通道：不管排到哪，包在括号里的运算直接插队到最前；多层括号时，里层括号的内容优先计算。

核心概念

6 级优先级阶梯（1 最高，6 最低）

第 1 级**
幂运算——最优先；注意它从右向左结合，2**3**2 等于 2**9 等于 512
第 2 级*　/　//　%
乘、除、取整、取余——同一级从左向右
第 3 级+　-
加、减——比乘除低一级
第 4 级<　<=　>　>=　!=　==
比较运算符——先算数，再比大小
第 5 级not　>　and　>　or
逻辑运算符——not 最高，and 次之，or 最低
第 6 级=　+=　-=　*=　/= …
赋值运算符——最后执行

💡 规则总结：优先级高的先运算；同级一般从左向右（** 从右向左）；括号里的优先运算，多层括号先算里层。本表只列最常用的六级，完整表还含一元运算符（-x、~x）、位运算符（&、|、^、<<、>>）、成员与身份运算（in、not in、is、is not）等，用不到的级别不必背——拿不准就加括号。

实战演示

括号怎么改写运算顺序

a, b, c, d = 10, 5, 3, 2
print(a*b + c*d, a*(b + c)*d, a*(b + c*d))  # 输出：56 160 110
  • a*b + c*d：先算两个乘法 50 和 6，再相加 → 56
  • a*(b + c)*d：括号强制先算 5+3=8，再 10*8*2 → 160
  • a*(b + c*d)：里层括号中先算 c*d=6，再 5+6=11，再 10*11 → 110

🔍 推理挑战：点击切换，看看一个逻辑表达式如何被优先级「拆解」

a, b, c, d = 10, 5, 3, 2
print(not a>b or b>c and d>c)  # 输出：False

第一步：比较先算——a>b → True（10>5）、b>c → True（5>3）、d>c → False（2>3），式子变成 not True or True and False。
第二步：not 最高——not True → False；然后 and——True and False → False，式子变成 False or False。
第三步：or 最后——False or False → False。

a, b, c, d = 10, 5, 3, 2
print(not ((a>b or b>c) and d>c))  # 输出：True

加了两层括号，运算顺序被彻底重排：里层括号先算 a>b → True、b>c → True，or 连接得 True or True → True；外层括号里 True and False → False（d>c 是 False）；最后 not False → True。对比左边的版本：同样的四个比较，括号一换，结果从 False 翻转为 True——这就是括号的力量。

❓ 测验

print(2 + 3 * 2) 的输出是？

✏️ 填空

想改变运算顺序，可以使用＿＿——包在里面的运算会优先执行，多层括号则优先计算里层。

⚠️ 避坑
优先级写错不报错，只会悄悄算错

① 拿不准就加括号——代码是写给人看的，括号不丢人。a*(b + c) 比 a*b + a*c 更容易看出「先加再乘」的意图，哪怕结果一样。

② 优先级写错通常不会报错，表达式照样运行，只是结果悄悄错了——这种 bug 比崩溃更危险。尤其逻辑表达式里 not、and、or 混用时，建议一律加括号标明意图。

  2. 输入 print(a*b + c*d, a*(b + c)*d, a*(b + c*d)) 回车，对照预期输出 56 160 110——同一个式子，加个括号结果差这么多。

  4. 再跑一遍 print(not a>b or b>c and d>c) 和 print(not ((a>b or b>c) and d>c))，看看括号如何让逻辑结果翻转。
✅ 小结
你现在知道了

运算符有 6 级优先级：** 最高，乘除其次，加减再次，然后是比较、逻辑（not > and > or），赋值最低；同级从左向右算；小括号可以改变优先级，多层括号先算里层。拿不准就加括号——优先级错了不报错，只会悄悄算错。下一节（本章最后一节）：Python 自带的数学工具箱——数值函数与 math 模块。
