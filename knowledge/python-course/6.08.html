为什么学这个

要算「任意多个数」的和，参数写几个才够？

上一节的 getpow 参数数量是固定的，可现实中很多函数不知道调用者会传几个值：求和可能传 2 个数也可能传 100 个数，报个名可能一个名字都没有也可能来一串。总不能写 100 个参数吧？Python 的答案是不定长参数——允许零到多个参数，而且有两种形式，收进来的「容器」还不一样。

💡 打个比方
*args 像自助餐托盘，**kwargs 像快递登记单

单星 *args：大家按先后顺序往托盘上放盘子——按位置传递，放完一起装进一个袋子，这个袋子是元组 tuple（按顺序排好、不许再改）。双星 **kwargs：每件物品都得贴上标签「名称=东西」——按名称传递，逐条登记到一个本子上，这个本子是字典 dict（键值对，按名字取东西）。托盘可以是空的，本子也可以是空白的——不定长参数允许零到多个。

核心概念

两种形式，两种容器

  • 单星 *args：需要按位置传递，参数以元组 tuple 形式导入函数——函数内拿到的是一个装满「位置上的值」的元组
  • 双星 **kwargs：需要按名称传递（调用时写 a=1 这种形式），参数以字典 dict 形式导入——键是参数名，值是传的值
  • 零到多个：一个都不传也可以——args 是空元组 ()，kwargs 是空字典 {}
  • 名字可以随便起：*args、**kwargs 只是约定俗成，真正起作用的是星号——写成 *canshu 效果一样
  • 两种形式可以同时出现在一个函数里：def f(a, *args, **kwargs)——单星在前、双星在后
课堂代码

PPT 原例：fun1 收元组，fun2 收字典

def fun1(*args):
    print(args)
    print(type(args))

fun1(1, 2, 3)

输出结果：

(1, 2, 3)
<class 'tuple'>

双星形式：

def fun2(**kwargs):
    print(kwargs)
    print(type(kwargs))

fun2(a=1, b=2, c=3)

输出结果：

{'a': 1, 'b': 2, 'c': 3}
<class 'dict'>
  • fun1 按位置收到 1、2、3，打包成元组 (1, 2, 3)
  • fun2 按名称收到 a=1、b=2、c=3，登记成字典 {'a': 1, 'b': 2, 'c': 3}
  • type() 一验便知：单星收 tuple，双星收 dict

🔬 不定长参数实验台：左边填按位置传的值（逗号隔开），右边填按名称传的（名称=值），看分别装进什么容器

点「调用！」开始实验
❓ 测验

def fun2(**kwargs): print(kwargs)，调用 fun2(x=10, y=20) 后，kwargs 的类型和内容是？

✏️ 填空

不定长参数有两种形式：单星 *args 需按＿＿传递，参数以＿＿形式导入；双星 **kwargs 需按＿＿传递，参数以＿＿形式导入。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①只写名字不写星号：def fun1(args) 里的 args 只是普通必须参数——不定长的灵魂在星号，*args 才会打包；

②给双星按位置传值：fun2(1, 2, 3) 报 TypeError——**kwargs 只认名称，必须写 fun2(a=1) 这种形式；

③把元组当列表改：args 收到的是 tuple，args.append(4) 会报 AttributeError——元组不可增删，求和请遍历累加或用 sum(args)。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 函数的不定长参数。请：1）用「自助餐托盘装元组、快递登记单装字典」的类比解释 *args 与 **kwargs 的区别；2）出 5 道判断题考我（涉及按位置与按名称传递、收到的容器类型、零个参数的情况）；3）带我一步步写一个用 *args 求任意多个数之和的函数 fun3，从 print(args) 观察开始。
🔧 试一试：直接演练作业第 3 题（5 分钟）
  1. 本章作业第 3 题要求用不定长参数求和。先搭骨架：def fun3(*args):，函数体第一行先写 print(args)，调用 fun3(1, 2, 3) 亲眼看看收到的是不是元组。
  2. 删掉 print，写求和：total = 0，用 for i in args: 遍历累加，最后 return total——元组可以直接遍历，和列表一样。
  3. 三种情况都测一遍：fun3(1, 2)、fun3(1, 2, 3, 4, 5)、fun3()——最后这个是零个参数，结果应该是 0，这正是「不定长」的意义。
  4. 挑战：一行版本 return sum(args)——想想为什么内置函数 sum 能直接吃下这个元组。
✅ 小结
你现在知道了

参数数量不定时用不定长参数，允许零到多个：单星 *args 按位置传递、以元组 tuple 导入；双星 **kwargs 按名称传递、以字典 dict 导入；星号才是关键，args/kwargs 只是习惯名。作业第 3 题的 fun3 就靠它。下一节：传进去的值，函数里改了之后外面会不会变——取决于数据类型。
