为什么学这个

程序崩溃太狼狈？给代码装上「安全气囊」

上一节的异常一抛出来程序就直接崩溃，对用户太不友好了。针对异常可以使用保留字 try、except、else 和 finally 进行处理：把可能有风险的代码放进 try 块里监控，一旦出异常就按预案接管，程序不再崩溃、而是优雅地继续运行。这一节的「除法计算器」就是本章作业第 6 题的直接模板。

💡 打个比方
try 像「保险柜」：把有风险的代码锁进去，出事有预案、不出事有奖励

try 是保险柜——把可能出问题的代码锁进去重点看护；except 是「出险理赔方案」——真出事了按条款赔付（执行处理代码）；else 是「平安无事奖励」——全程没出险才发；finally 是「离场手续」——无论出没出险，走的时候都要办（资源清理）。四件套各司其职，缺一不可乱序。

核心概念

try-except-else-finally 四件套

  • try（必选）：包含可能引发异常的代码，是监控区域——一旦某行出异常，立刻跳出 try 块
  • except（必选）：捕获并处理 try 块中抛出的异常；可写多个、可指定异常类型、可用元组同时捕获多种（如 except (ValueError, SyntaxError, TypeError):）
  • else（可选）：仅当 try 块中没有发生异常时才执行
  • finally（可选）：无论是否异常都会执行，常用于资源清理（关文件、提示收尾等）

执行规则：如果程序没有异常，则正常执行完代码块 1，然后执行代码块 3；如果程序有异常，则从异常代码处跳出代码块 1，转而执行代码块 2。最后，不论有没有异常，都执行代码块 4。

try:
    <代码块1>    # 可能出异常的代码（监控区域）
except:
    <代码块2>    # 出异常时执行（处理预案）
else:
    <代码块3>    # 没出异常时才执行（平安奖励）
finally:
    <代码块4>    # 无论是否异常都执行（离场手续）
交互示例

两条执行路线 + 课堂例程「除法计算器」

  • try代码块 1 从头到尾执行完毕，没有触发任何异常
  • else「平安无事」——接着执行代码块 3
  • finally最后照例执行代码块 4
  • except整段被跳过，一行都不执行
  • try代码块 1 执行到出异常的那一行立刻中断，后面没跑的行不再执行
  • except跳出来执行代码块 2——按预案处理，程序不崩溃
  • finally最后照例执行代码块 4
  • else出过异常，奖励没了——整段被跳过

课堂例程：除法计算器（while True + 四件套）

while True:
    try:
        a = float(input('请输入被除数：'))
        b = float(input('请输入除数：'))
        print(f'运算结果为：{a/b}')
    except ZeroDivisionError:
        print("除数为0！")
    except (ValueError, SyntaxError, TypeError):
        print("输入错误，请重新输入。")
    else:
        print("运行无误")
        break
    finally:
        print("请重新运行")

这个例子的妙处：break 放在 else 里——只有真正算对了（无异常）才会执行「运行无误」并退出 while True 循环；除零、乱输入都会被对应的 except 接住，循环继续。而 finally 每一轮都会打印「请重新运行」。

❓ 测验

无论是否发生异常都会执行的代码块，应该放在哪个保留字后面？

✏️ 填空

try 块中代码无异常时，执行完代码块 1 后接着执行代码块 ＿＿，最后执行代码块 ＿＿。（两空连填，中间用空格或直接相连）

⚠️ 避坑
三个高频翻车点

①else 必须跟在所有 except 之后、finally 之前：顺序写错（如 else 放在 except 前面）会直接报语法错误——记忆口诀「try → except×N → else → finally」；

②except 不写类型会捕获一切异常：写起来省事，但会把没预料到的 bug 也悄悄吞掉、掩盖问题。初学阶段可以接受，以后要养成指定异常类型的好习惯；

③finally 每轮都执行，包括最后一轮：课堂例程算对了 30÷5 之后，else 里的 break 先退出循环，但 finally 的「请重新运行」仍然会打印——这正是「不论有没有异常都执行」的体现，别以为是程序写错了。

✅ 小结
你现在知道了

try-except-else-finally 四件套：try 监控风险代码、except 接住异常（可多个、可指定类型、可元组捕获多种）、else 只在无异常时执行、finally 无条件执行。无异常走 try→else→finally，有异常走 try（中断）→except→finally。break 放进 else，就能实现「算对了才退出循环」。下一节：综合实战，把本章三套结构串成完整程序。
