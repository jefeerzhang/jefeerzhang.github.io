为什么学这个

本章最后一站：Python 的数学工具箱

算绝对值、开平方、四舍五入、取最大值……这些常用的数学操作不需要你手写公式——Python 已经把工具准备好了。这一节认识两组工具：

  • 内置函数：开箱即用，abs、sum、max、min、round、pow 随叫随到
  • 类型转换函数：int、float、bin、oct、hex、complex，在类型之间搭桥
  • math 模块：开方、对数、指数、三角函数的专业工具箱，用前要先 import
💡 打个比方
随身瑞士军刀 vs 专业工具箱

内置函数像你口袋里的瑞士军刀——abs、sum、max 这些小工具掏出来就能用，不需要任何准备。math 模块像墙角的专业工具箱——里面有开方机、对数仪、三角函数量角器，家伙更专业，但用之前得先 import math 把箱子打开，工具才拿得到。

核心概念

三张工具清单，点击卡片展开

  • int() 转换是直接截断小数部分，不是四舍五入：int(1.99) → 1、int(-1.99) → -1。
  • math.ceil() 向上取整、math.floor() 向下取整——取整方向和 // 一致（都朝负无穷方向取），区别是它们一律返回整数（7.0 // 2 得到的是 3.0），意图也更直白。
  • math.pi 就是 π（3.1415926…），本章作业第 5 题计算圆柱体积要用它，别忘了先 import math。

实战演示

打开工具箱，跑一段完整代码

import math                      # 先把工具箱打开

print(math.sqrt(2))              # 1.4142135623730951  ← 2 的平方根
print(math.log10(100))           # 2.0                 ← 100 是 10 的几次方？
print(math.sin(0.5 * math.pi))   # 1.0                 ← sin(90°)
print(math.ceil(-1.5))           # -1                  ← 向上取整（往大的方向）
print(math.floor(-1.5))          # -2                  ← 向下取整（往小的方向）
print(math.pi)                   # 3.141592653589793   ← 圆周率 π

# 顺手试试内置函数
print(abs(-10), sum([1,2,3]), max(1,2,3), min(1,2,3))  # 10 6 3 1
print(round(3.14159, 2), pow(2, 3))                     # 3.14 8
  • 对比 math.ceil(-1.5) → -1 和 math.floor(-1.5) → -2：ceil 是「往大的方向」取整，floor 是「往小的方向」取整——负数时方向感最明显。
  • 圆柱体积 = math.pi * r * r * h，作业第 5 题的公式已经送上门了。
❓ 测验

int(1.99) 的结果是？

✏️ 填空

使用 math 模块前需要先 ＿＿ math，之后才能调用 math.sqrt() 等函数。（填英文关键字或中文）

⚠️ 避坑
int() 截断 ≠ 四舍五入；负数取整看方向

① int() 转换浮点数时直接砍掉小数部分，不管小数多大：int(1.99) → 1、int(-1.99) → -1。想四舍五入要用 round()，别把两者混为一谈。

② round() 遇到「正好 .5」时是向偶数舍入（银行家舍入），不是「逢五进一」：round(0.5) → 0、round(1.5) → 2、round(2.5) → 2；受二进制浮点表示影响，round(2.675, 2) → 2.67 也不是 2.68。需要严格「四舍五入」时请用 decimal 模块的 ROUND_HALF_UP，别指望 round()。

③ 忘了 import math 就直接写 math.sqrt(2)，会报 NameError: name 'math' is not defined——工具箱还没打开就想拿工具。另外注意 math.ceil(-1.5) → -1 而 math.floor(-1.5) → -2，负数取整时别想当然。

✅ 小结
你现在知道了，本章也毕业了

内置函数（abs、sum、max/min、round、pow）开箱即用；类型转换函数里 int() 是截断不是四舍五入，bin/oct/hex 负责进制转换；math 模块要先 import，提供 sqrt、log、exp、三角函数、ceil/floor 和 math.pi。至此本章 17 个知识点全部学完——从两大核心到数学工具箱，去目录页回顾一遍吧！
