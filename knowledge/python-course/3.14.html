为什么学这个

认识了列表，怎么把数据「装进去」？

上一节知道了列表是「白板上的购物清单」，这一节解决第一个动作：把清单写出来。Python 提供两条路：用中括号直接写，或者用 list() 函数把现成的数据「转换」成列表。两种方式都要熟练——作业和考试里它们经常一起出现。

💡 打个比方
装行李箱 vs 拆包裹重新分装

中括号直接创建像自己动手装行李箱：想要什么，就亲手把什么放进去，放什么、放几个全由你决定。

list() 则像把现成的包裹拆开重新分装：拿到字符串 '12345'，拆开后把 5 个单字符一个一个装进新列表。注意——拆出来的是「字符」，不是数字，这个坑下面细说。

核心概念

两种创建方式

  • 直接创建：使用中括号 [] 直接包含元素，是最直观的方式
  • list() 函数：将字符串、元组、range 对象等可迭代对象转换为列表
  • list() 不传参数 → 得到空列表 []
  • list(字符串) → 把每个字符拆开，逐个变成列表元素
L1 = list()
print(L1)        # []
print(type(L1))  # <class 'list'>

L2 = [1, None, '3', True, L1]
print(L2)        # [1, None, '3', True, []]

L3 = list('12345')
print(L3)        # ['1', '2', '3', '4', '5']

看懂这三段：L1 是空参数得到空列表；L2 演示了混装任意类型——数字、None、字符串、布尔值，甚至把另一个列表 L1 整个嵌套进去；L3 演示了 list(字符串) 把 '12345' 拆成 5 个单字符。

🔬 交互示例

两种创建方式对比

langs = ['Python', 'C', 'Java']
nums = [10, 20, 30]
empty = []
print(langs, nums, empty)

输出结果：

['Python', 'C', 'Java'] [10, 20, 30] []

想装什么就写什么，元素类型随意、数量随意，一行搞定。

print(list('abc'))      # 拆开字符串
print(list((1, 2, 3)))  # 元组转列表
print(list())           # 不传参数 → 空列表

输出结果：

['a', 'b', 'c']
[1, 2, 3]
[]

list() 负责「拆开重装」：把可迭代对象里的东西一个一个取出来，装进新列表。

❓ 测验

list('abc') 的结果是？

✏️ 填空

list() 不传参数时得到＿＿列表。

⚠️ 避坑
拆出来的是字符，不是数字

list('12345') 得到的是 ['1', '2', '3', '4', '5']——5 个字符串，不是数字 1~5！想得到数字列表，需要用后面章节的循环或推导式，先把这颗雷记在心里。

另一个坑：list(123) 会报 TypeError: 'int' object is not iterable——数字不是可迭代对象。list() 只能拆字符串、元组、range 这类「能一个一个取出来」的东西，单个数字没法拆。

✅ 小结
你现在知道了

创建列表的两种方式：中括号 [] 直接包含元素（最直观）；list() 函数把字符串、元组、range 等可迭代对象转成列表（不传参数得到空列表）。list(字符串) 把每个字符拆开变成元素——拆出来的是字符串不是数字；list(数字) 会报错。列表可以混装任意类型，甚至嵌套另一个列表。下一节：像字符串一样对列表索引和切片。
