为什么学这个

让程序「看情况办事」——选择结构的第一步

到目前为止，我们的程序都是「一条道走到黑」。但现实问题常常要看情况：成绩大于 90 才夸你，输入的数对了才说恭喜。单分支 if 是最基本的选择结构——根据条件判断是否执行某段代码：条件为真就做，为假就跳过。它靠的是第二章 2.15 讲的比较与逻辑运算符产生的布尔值。本章作业第 1、2 题就从这里开始。

💡 打个比方
单分支 if 像「安检门」

你推着行李过安检：有违禁品（条件为真）才被拦下来说话，没违禁品（条件为假）直接通过，什么都不发生。连续写两个 if，就是连过好几道安检门——每道门独立判断，这道门拦不拦你，跟下一道门毫无关系。门后的话（代码块）只有被拦下才执行；走完了门（if 语句结束），后面的路照常走。

核心概念

if 语法与四条注意事项

if <条件>:
    <代码块_真>    # 缩进（惯例是 4 个空格）
  • if 是表示分支结构的关键字（2.06 讲过的保留字之一）
  • 条件是用于产生一个为 True 或者 False（布尔值）的表达式——正是 2.15 的比较与逻辑运算符干的活；结果为真则执行代码块，为假则跳过；表达式支持多个条件并列（用 and、or 连接）
  • : 冒号是语法格式的要求，必须要有——漏了直接 SyntaxError
  • 冒号下一行的缩进也是语法格式的要求；缩进取消，代表 if 语句结束
课堂代码

示例 01：两个独立的 if 判断成绩

score = float(input("请您输入一个成绩："))
if score > 90:
    print("成绩不错！")
if score < 80:
    print("还需继续努力！")
print("欢迎下次查询")
  • 输入 90：90 > 90 为假、90 < 80 为假——两个 if 都跳过，只输出「欢迎下次查询」
  • 输入 70：70 < 80 为真——输出「还需继续努力！」，然后照常输出「欢迎下次查询」
  • 两个 if 是独立的两道门：条件可以同时不满足，也可以恰好一个满足，互不影响
  • 最后一行 print 没有缩进——它不在任何 if 里，所以永远执行

课堂代码

示例 02：物不知数——三个条件 and 并列

《孙子算经》里有道名题：「今有物不知其数，三三数之剩二，五五数之剩三，七七数之剩二，问几何？」——一个数除以 3 余 2、除以 5 余 3、除以 7 余 2，它是多少？用取余运算（2.14）加逻辑运算符 and（2.15）就能让计算机帮我们验证：

num = eval(input("请您猜一个数吧！"))
if num % 3 == 2 and num % 5 == 3 and num % 7 == 2:
    print(f"您输入的数字是{num}，恭喜你答对了！")
print("欢迎再猜一次")
  • 三个条件用 and 并列：必须全部为真，整个条件才是 True
  • 验证 23：23 % 3 == 2 ✓、23 % 5 == 3 ✓、23 % 7 == 2 ✓——答对！输出「您输入的数字是23，恭喜你答对了！」
  • 换成其他数，只要有一个余数不满足，and 结果就是 False，if 里的 print 被跳过，只输出「欢迎再猜一次」
❓ 测验

if 语句中，条件表达式的结果是什么类型？

✏️ 填空

冒号下一行的＿＿是语法格式的要求，缩进取消代表 if 语句＿＿。（两空连填）

⚠️ 避坑
四个高频翻车点

①漏冒号、漏缩进都是语法错误——if score > 90 后面少了 :，或者冒号下一行顶格写，都会报 SyntaxError（详见 5.14）；

②边界差异——score > 90 在输入 90 时不成立，score >= 90 在输入 90 时成立。一字之差，结果完全不同，写条件前先想清楚边界算不算；

③= 与 == 写混——条件里要判断相等必须用 ==（比较运算），写成一个 = 就成了赋值，直接语法错误；

④别把 if 里的缩进当可选——缩进多少行，哪些行就属于这个 if；缩进一取消，if 就结束了。

🔧 试一试：亲手解开千年古算题（5 分钟）
  1. 把示例 02 敲进 IDLE 跑一遍，输入 23——看看程序怎么对你说「恭喜你答对了！」。
  2. 再试试 128、233——它们也满足三个余数条件！符合条件的数还有无穷多个：23、128、233……每隔 105 出现一个。这类题在民间叫「韩信点兵」。

✅ 小结
你现在知道了

单分支 if 是最基本的选择结构：条件表达式产生布尔值（呼应 2.15），为真执行代码块、为假跳过；if 后必须有冒号，冒号下一行必须有缩进，缩进取消即 if 结束；多个条件可以用 and、or 并列。条件为假时「什么都不做」——想让程序「走另一条路」，就要用下一节的双分支结构 if-else。
