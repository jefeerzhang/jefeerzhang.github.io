✍️ 本章作业（ipynb 格式提交）

  1. 根据输入成绩做如下判断：如果大于等于 90，输出「优秀」；如果大于等于 70，输出「良好」；如果大于等于 60，输出「及格」；否则输出「不及格」。
  2. 根据输入的月份，输出该月份的天数，例如输入 1，返回 31；输入 2，返回 28 或 29；输入 3，返回 31；输入 4，返回 30。
  3. 现有列表 ls1 = [2, 3, 5, 75, 32, 4, 15, 23, 55, 20, 9]，通过遍历循环选出其中所有 5 的倍数，放入一个新的列表 ls2，输出 ls2。
  4. 通过遍历循环求 1+2!+3!+...+10! 的和。（提示：! 是阶乘，可以使用 math.factorial() 函数得到阶乘结果）
  5. 现有成绩字典 scores = {'张三': 95, '李四': 58, '王五': 82, '赵六': 44}，通过遍历字典，将及格同学和不及格同学的姓名分别装入两个列表，输出这两个列表。
  6. 编写程序能够持续接收用户输入的正数并自动累加求和；当用户输入负数或零时，立即停止程序并输出最终的累加总和。需要添加异常处理，避免因用户输入错误导致程序终止。
