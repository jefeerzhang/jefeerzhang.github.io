为什么学这个

程序世界里的「文字」，都叫字符串

你打的每一句话、你的名字、一个手机号，在 Python 里都以字符串的形式存在。它是编程中最常用的数据类型之一——表示文本数据，离了它，程序连一句「Hello」都说不出口。本章的一切（索引、切片、格式化……）都建立在这一节的基础上，先把「怎么把一段文字装进 Python」学扎实。

💡 打个比方
引号是字符串的「包装袋」

想让 Python 认出「这是文字」，就得把它装进引号这个包装袋里。袋子有三种规格：单层（单引号）、双层（双引号）、加厚款（三引号）。但有一条铁律：袋子必须成对使用，不能交叉——就像袜子要配对，左脚棉的右脚丝的，走起路来准出乱子。'Hello" 这样一边单引号一边双引号，Python 会直接报错。

核心概念

字符串是什么，怎么写？

  • 定义：字符串是由 0 个或多个字符组成的有序字符序列，用于表示文本数据
  • 单引号：'Hello, Python!'
  • 双引号："Hello, World!"
  • 三引号：'''多行字符串'''——支持直接换行
  • 引号必须成对出现，不能交叉使用；单引号和双引号在功能上完全等价，三引号可以换行
  • 空字符串 '' 也是合法的字符串——「0 个字符」也行

最容易被忽略的一点：数值和字符串的区别就在于有没有引号。看这段课堂代码：

# 数值和字符串的区别在于引号
print(123, "123")
print(type(123), type("123"))

输出结果：

123 123
<class 'int'> <class 'str'>

打印出来长得一样，但 123 是整数 int（能做加减乘除），"123" 是字符串 str（是三个「字符」）。123 + 1 得 124，而 "123" + 1 会报错。

print('Hello, Python!')
  • 最简洁的写法，适合不含单引号的文本
  • 要在单引号字符串里换行？须在行尾加续行符 \——注意它只是「把代码折到下一行写」，输出不会换行；真要在字符串里换行得写 \n，或者改用三引号。例如 print('abc \ 123')
print("Hello, World!")
  • 和单引号完全等价，两种引号给了你选择空间
  • 同理，双引号字符串也能用 \ 折行（同样不产生换行），如 print("abc \ 123")
# 三引号可以直接换行
print('''a
b
c''')
  • 三个单引号（或三个双引号）包裹，内容里可以直接按回车换行，不用任何续行符
  • 写多行文本（如一首诗、一段说明）时最方便
❓ 测验

print(type("123")) 的输出是？

✏️ 填空

三＿＿号字符串支持直接换行。（填一个字或一个词）

⚠️ 避坑
成对、不交叉、别用中文引号

三个高频报错：① 引号不成对——'hello 少了收口的袋子，报 SyntaxError；② 引号交叉——'hello" 左单右双，Python 不认；③ 打成中文引号——键盘输入法切到中文状态后打出 "hello"，这几个弯引号（‘ ’ 与 “ ”）在 Python 眼里只是普通字符，根本起不到「包装」的作用。写代码时务必切回英文输入法。

🔧 试一试：三种引号亲手打一遍（5 分钟）
  1. 打开 IDLE，进入交互模式（提示符 >>> 后直接输入）。
  2. 输入 'hello' 回车——Python 把字符串原样显示给你看，还带着单引号。
  3. 输入 "hello" 回车——结果一样，说明单双引号等价。
  4. 输入三引号多行字符串：'''床前 回车（提示符变成 ...），明月光''' 回车，看看多行是怎么被完整保存的。
  5. 最后故意输入 'hello" 交叉引号，亲眼看看报错长什么样，以后就能一眼认出来。
✅ 小结
你现在知道了

字符串是 0 个或多个字符组成的有序字符序列，用来表示文本；单引号、双引号等价，三引号支持直接换行；引号必须成对、不交叉，还要避开中文引号；带引号的是 str，不带的是数值——type() 一验便知。下一节：引号里有些「特殊字符」打不出来怎么办？转义字符登场！
