为什么学这个

学过列表？那这节你等于已经会了

元组也属于有序序列，因此可以通过序号进行索引和切片，索引和切片各参数的含义与列表完全一致：正向从 0 起、反向从 -1 起、切片左闭右开、负步长反向跳。这一节是「复习课 + 一个新坑」——新坑只有一个：切片取出来的东西类型仍是元组，而且取出来之后不许改。

💡 打个比方
一套座位表规则，三种序列通吃

把元组、列表、字符串想成三个剧场：舞台材质不同（一个不可改、一个随便改、一个只能放字符），但座位编号规则完全一样——第一排是 0 号（正向），最后一排是 -1 号（反向），切票永远是「含起点、不含终点」（左闭右开）。你学过一次，三种序列通吃。这就是序列类型统一设计的妙处：规则不增加，只换数据。

核心概念

索引取单个，切片取一段

  • 索引取单个元素：TP5[0] 取第一个、TP5[-1] 取最后一个，返回值就是那个元素本身
  • 切片取一段，结果仍是元组：TP5[1:3] 得到 (1, 5)——哪怕只切出 1 个元素，类型也是元组
  • 步长可正可负：TP5[::-2] 表示从尾部反向、每隔 1 个取一个；TP5[::-1] 是经典的整体逆序写法
  • 语法都是 [start:stop:step]，左闭右开——与字符串、列表一字不差
交互示例

🔬 先猜再看：索引 / 切片双档位

TP5 = (2, 1, 5, 3, 4)

先猜 TP5[0] 和 TP5[-1] 的结果，再点击这里对照——

print(TP5[0], TP5[-1])

输出：

2 4

解读：正向 0 起、反向 -1 起，索引取到的是单个元素：2 和 4。

先猜 TP5[-3:-1] 和 TP5[::-2] 的结果，再点击这里对照——

print(TP5[-3:-1], TP5[::-2])

输出：

(5, 3) (4, 5, 2)

解读：-3:-1 取倒数第 3、第 2 个元素（左闭右开，不含 -1 位的 4）；[::-2] 从末尾倒着每 2 步取 1 个。结果都是元组。

课堂代码

PPT 原例：三行代码覆盖全部考点

TP5 = (2, 1, 5, 3, 4)
print(TP5[0], TP5[-1])
print(TP5[-3:-1], TP5[::-2])

输出结果：

2 4
(5, 3) (4, 5, 2)
  • 第一行考索引：正向 0 与反向 -1
  • 第二行考切片：负区间 -3:-1 与负步长 ::-2，两个结果 (5, 3) 和 (4, 5, 2) 都是元组
  • [::-2] 逐步拆解：从下标 4 取 4 → 下标 2 取 5 → 下标 0 取 2，得 (4, 5, 2)
❓ 测验

TP5 = (2, 1, 5, 3, 4)，TP5[::-2] 的结果是？

✏️ 填空

元组切片取出的结果类型仍是____。

⚠️ 避坑
切片≠单个元素；修改元组会当场翻车

第一坑：切片结果的类型是元组，不是单个元素。TP5[1:3] 得到 (1, 5)，而 TP5[1] 才是单个的 1。考试问「TP5[1:3] 的类型」，答案永远是元组。

第二坑：对元组做「修改式」操作会直接报错——tp[0] = 9 报 TypeError: 'tuple' object does not support item assignment。这是元组与列表的本质区别：列表随便改，元组碰都不能碰（真正的原理 4.06 揭晓）。

✅ 小结
你现在知道了

元组与列表共用同一套索引切片规则（正向 0 起、反向 -1 起、左闭右开、负步长反向）；索引取单个元素，切片取出的仍是元组；元组元素不可修改，赋值会报 TypeError。下一节：元组的运算——拼接、重复与点名。
