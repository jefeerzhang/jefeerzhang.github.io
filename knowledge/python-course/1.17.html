为什么学这个

说了这么多，先把 Python 装进你的电脑

概念学了一圈，是时候真刀真枪动手了——本章作业第 6 题就要求你完成环境搭建并输出 Hello World，这一节是必做项。环境搭建只有一件事：把 Python 本体（解释器）装进电脑。装好之后，你还会认识三种「和 Python 对话」的方式。这节过后：

  • 你的电脑将具备运行任何 Python 代码的能力；
  • 你会知道命令行交互、IDLE、运行 .py 文件三种方式各适合什么场景；
  • 你将亲手避开 90% 新手都会踩的 Add to PATH 大坑。
💡 打个比方
先装「发动机」，驾驶舱随你挑

Python 本体（官方解释器）就像汽车的发动机——没有它，代码什么也跑不起来。而 IDLE、命令行、后面要讲的 Anaconda 和各种 AI IDE，都是不同的驾驶舱：有的简朴耐用，有的豪华智能。学习顺序很重要：先把发动机装好（本节），驾驶舱以后随你的需求挑（下一节）。别一上来就折腾最豪华的座舱，结果发动机还没点火。

核心概念

装好之后，三种方式和 Python 对话

  • ① 命令行交互模式（Command Line）：在 cmd 里输入 python，出现 >>> 提示符，输一行、跑一行、马上看结果——适合试验小代码、验证想法。
  • ② IDLE 集成开发环境：安装 Python 时自带的简易 IDE（ Integrated Development Environment，集成开发环境），有编辑窗口能保存代码——适合初学者写小脚本。
  • ③ 脚本文件方式：把代码存成 .py 文件，在命令行用 python 文件名.py 一次性运行——适合编写正式、可反复使用的程序。
  • 一句话分工：试验用交互模式，写小脚本用 IDLE，正式程序存成 .py 跑。
🔧 安装步骤（跟着点就行，Windows / Mac 通用）

四步装好 Python 本体

  1. 1访问官网下载页：python.org → 顶部菜单 Downloads，网站会自动识别你的系统并给出最新的黄色下载按钮（目前是 Python 3.15.x 系列）。只认 python.org，别从第三方下载站下。
  2. 2双击安装包。Windows 用户务必先勾选安装窗口底部的「Add python.exe to PATH」，再点 Install Now——这是全页最重要的一步！
  3. 3等待进度条走完，出现「Setup was successful」即安装成功，可以顺手点 Close。
  4. 4验证：按 Win + R 输入 cmd 回车，先输入 python --version 看到版本号，再输入 python 进入交互模式——看到 >>> 就成功了。
cmd — 命令行交互模式
C:\Users\you> python --version
Python 3.15.0
C:\Users\you> python
Python 3.15.0 (tags/v3.15.0) on win32
Type "help", "copyright", "credits" or "license"
for more information.
>>> print("Hello World")
Hello World
>>> 1 + 2
3
>>> exit()
（退出交互模式，回到普通命令行）

💡 看懂这个会话：绿色的 >>> 是 Python 在说「我准备好了，请下指令」；你输一行，它答一行，这就是交互模式。Mac 用户在终端（Terminal）里同样适用，Mac 一般预装了 python3，命令写成 python3 即可。

🖥️ 三种使用方式，点按钮切换体验

哪种方式适合现在的你？

适合：试验、验证、做作业里的单行小练习。不用建文件，打开 cmd 输 python 就开工，输一行跑一行，临时算个数、试试函数最方便。缺点是关掉窗口代码就没了，不能保存。

交互模式 — 适合试验
>>> 0.1 + 0.2
0.30000000000000004
>>> print("人生苦短，我用 Python")
人生苦短，我用 Python

适合：初学者写并保存小脚本。IDLE 是安装 Python 时自带的简易 IDE，不用额外下载。开始菜单搜「IDLE」打开的是交互 Shell；点菜单 File → New File 会弹出一个编辑窗口，写好几行代码后保存为 .py，按 F5 运行。

IDLE — 新文件窗口
# 第一份小脚本 first.py
name = input("你叫什么名字？")
print("你好，" + name + "！欢迎来到 Python 世界")

# 按 F5 运行，结果出现在 IDLE Shell 中

适合：正式、可反复运行的程序。用任意编辑器把代码存成 .py 文件，在命令行进入该文件所在目录，输入 python 文件名.py 一次执行全部代码。以后写爬虫、做数据分析，都是这种方式。

cmd — 脚本文件方式
# 文件 hello.py 的内容：
# print("我的第一个 Python 程序！")

C:\Users\you\Desktop> python hello.py
我的第一个 Python 程序！

⚠️ 避坑
两个新手必踩的坑，提前给你拆了

坑一：忘勾 Add python.exe to PATH。装完后在 cmd 输入 python，系统回复「'python' 不是内部或外部命令」。原因是系统在 PATH 环境变量里找不到 Python 的位置。解决思路：最省事的办法是卸载后重装、这次记得勾上；不想重装，也可以手动把 Python 的安装路径（如 C:\Users\you\AppData\Local\Programs\Python\Python315）添加到系统环境变量 PATH 中。

坑二：下载时点到第三方捆绑安装包。某些下载站的「高速下载」「国内镜像下载」按钮会附带全家桶软件。认准 python.org 官网的黄色 Download 按钮，文件名形如 python-3.15.0-amd64.exe，别的不点。

验证口诀：装完必做 python --version——有版本号输出才算真的装好，别自我感觉良好。

✅ 小结
你现在知道了

环境搭建 = 从 python.org 下载官方解释器 + Windows 记得勾 Add python.exe to PATH + 用 python --version 验证。装好「发动机」后，你有三种驾驶方式：命令行交互模式（输一行跑一行，适合试验）、IDLE（自带的简易 IDE，适合小脚本）、把代码存成 .py 文件用 python 文件名.py 运行（适合正式程序）。下一节看看更豪华的座舱：Anaconda 数据分析全家桶和 AI IDE。
