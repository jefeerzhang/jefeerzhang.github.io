为什么学这个

一层循环不够用，就往里再套一层

循环嵌套是指在一个循环的循环体内部，再写入一个或多个循环：外层的叫外层循环，内部的叫内层循环。它是处理二维数据、排列组合等场景的核心语法——打九九乘法表、遍历棋盘格子、穷举所有买法组合，都离不开它。本章压轴的「百钱百鸡」古算题，就是两层 for 的经典应用。

💡 打个比方
循环嵌套像「钟表」：秒针（内层）每转完一整圈，分针（外层）才走一格

外层循环每执行 1 次，内层循环必须完整跑完所有轮次——就像分针走一格的功夫，秒针已经转了一整圈 60 格。百钱百鸡则像「试遍所有买法组合，符合账目的记下来」：公鸡数、母鸡数各管一层循环，把所有组合都试一遍，账目对上的就是答案。

核心概念

语法与三条铁律

  • 语法：for <循环变量1> in <迭代对象1>: 外层缩进块内再写 for <循环变量2> in <迭代对象2>: 及其内层语句块
  • 铁律一：靠缩进区分内外层——内层循环的所有代码必须比外层多一层缩进（缩进错 = 逻辑错）
  • 铁律二：外层走 1 步，内层跑完整一圈——外层每执行 1 次，内层循环必须完整跑完所有轮次，外层才进入下一轮
  • 铁律三：总循环次数 = 外层循环次数 × 每轮外层对应的内层循环次数
  • while 也可以嵌套，for 与 while 混搭同样合法；层数理论上不限，但层数越多总次数增长越猛，两三层最常见

外层 x 走 3 步、内层 y 每圈跑 4 步——总共跑 3 × 4 = 12 次：

外层 x = 0　→　内层完整一圈
y = 0y = 1y = 2y = 3
外层 x = 1　→　内层又完整一圈
y = 0y = 1y = 2y = 3
外层 x = 2　→　内层再完整一圈
y = 0y = 1y = 2y = 3

分针（x）走一格，秒针（y）跑完一整圈——顺序是「x=0 圈内跑完 → x=1 圈内跑完 → …」，内层绝不会半途跳到下一个 x。

《算经》原题：鸡翁一值钱五，鸡母一值钱三，鸡雏三值钱一。百钱买百鸡，问鸡翁、鸡母、鸡雏各几何？

# 假设公鸡是 x，母鸡是 y，小鸡是 z
# 有两个条件等式：x + y + z = 100，5*x + 3*y + z/3 = 100
# x 的取值范围是 0 到 20（100 元全买公鸡最多 20 只）
# y 的取值范围是 0 到 33（100 元全买母鸡最多 33 只）
for x in range(0, int(100/5+1)):            # 公鸡：0~20，共 21 种
    for y in range(0, int(100/3+1)):        # 母鸡：0~33，共 34 种
        z = 100 - x - y                     # 小鸡不用循环！由 x+y+z=100 直接推出
        if 5 * x + 3 * y + z / 3 == 100:    # 只剩一个等式要验证
            print(f'公鸡: {x}只, 母鸡: {y}只, 小鸡: {z}只')
公鸡: 0只, 母鸡: 25只, 小鸡: 75只
公鸡: 4只, 母鸡: 18只, 小鸡: 78只
公鸡: 8只, 母鸡: 11只, 小鸡: 81只
公鸡: 12只, 母鸡: 4只, 小鸡: 84只
  • x 为什么是 0~20：公鸡 5 元一只，100 元最多买 int(100/5) = 20 只
  • y 为什么是 0~33：母鸡 3 元一只，100 元最多买 int(100/3) = 33 只
  • z 为什么不用循环：三个未知数两个等式，用 z = 100 - x - y 消元，z 由 x、y 直接决定——「暴力枚举 + 数学消元」的经典组合
  • 总检查次数：外层 21 次 × 内层 34 次 = 714 次组合检查，每次只验证一个等式
❓ 测验

for x in range(21): 嵌套 for y in range(34):，内层循环体总共执行多少次？

✏️ 填空

外层循环每执行 1 次，内层循环必须＿＿。（一个空，描述内层的执行要求）

⚠️ 避坑
三个高频翻车点

①内层缩进必须比外层多一层：for y 如果和 for x 平齐，那就不是嵌套而是先后两个独立循环——缩进错 = 逻辑错，程序不报错但结果全不对；

②break 只能跳出当前层：内层循环里的 break 跳出内层后，外层还会继续下一轮——想一步跳出两层，要借助标志变量或函数，现在先知道即可；

③z/3 是浮点除法：5*x + 3*y + z/3 == 100 中 z/3 可能带小数，判断相等时要留意精度；z 还必须是 3 的倍数才符合「鸡雏三值钱一」的题意（巧的是四个答案里 z 都满足）。

🔧 试一试：从古算题到乘法表（5 分钟）
  1. 把百钱百鸡完整代码跑一遍，对照输出的四组答案：公鸡 0/4/8/12 只，小鸡数都是 75~84 且能被 3 整除。
  2. 数一数：外层 range(0, 21) 21 次 × 内层 range(0, 34) 34 次 = 714 次组合检查，和铁律三对上了。
  3. 再写循环嵌套的入门经典——九九乘法表：for i in range(1, 10): 嵌套 for j in range(1, i+1):，循环体用 print(f'{j}×{i}={i*j}', end='\t')，内层结束后补一个 print() 换行。
  4. 挑战：把乘法表改成打印直角三角形星星阵（第 i 行打印 i 个 *），体会「内层次数由外层变量决定」的套路。
✅ 小结
你现在知道了

循环嵌套是在一个循环体内再写循环：靠缩进区分内外层，外层每走 1 步、内层完整跑完所有轮次，总次数 = 外层次数 × 内层次数。百钱百鸡用双层穷举 x、y，z 由 x+y+z=100 消元直接推出，714 次检查找到四组解。下一节：常见语法错误，把前面踩过的坑正式盘一遍。
