为什么学这个

列表装「一队人」，字典装「一个人的全部档案」

序列解决的是「一批同类的值怎么放」，但现实数据常常是成对出现的：姓名对应张三、年龄对应 20、语文成绩对应 80。把一堆「键-值」对装进一个容器，就是字典——它是 Python 里最常用的映射类型。本章作业第 4、5 题（购物流程、成绩统计）全靠它，前面的思维升级这一节正式落地。

💡 打个比方
它真的很像《新华字典》

Python 的字典就像真正的《新华字典》：按「字」（键）查「释义」（值），没有人按「第几页第几行」查字典——这正是上一节说的映射思维。而且：同一个字不会收录两次（键唯一），但释义想写多长写多长（值随意）；字典再厚也能增补新字、修订旧释义（动态可变）。

核心概念

字典：包含 0 个或多个「键-值」对的数据集合

字典类型具有和集合类似的性质：键值对之间没有「第几个」的编号且键不能重复。字典用大括号 {} 表示，每个元素是一个「键-值」对：键与值用冒号分隔，「键-值」对之间用逗号分隔：

{1: 2, '姓名': '张三', '年龄': 15, '语文': 80}
键：1、'姓名'、'年龄'、'语文' 冒号：把键和值连成一对 值：2、'张三'、15、80（类型随意） 逗号：分隔多个键值对

字典有四大特性，点击卡片逐一揭晓：

① 无序性

键值对没有「第几个」的编号
字典中的键值对没有固定的顺序，不能通过索引（第几个）访问——想取值只能报键的名字。
点击展开详解

② 键的唯一性

键 Key 必须唯一且不可变
键必须唯一（同一个键只出现一次），且必须可哈希（hashable）——字符串、数字、元组都可以当键，列表不行。

③ 值的可变性

值 Value 可以是任意数据类型
值没有任何类型限制：数字、字符串、列表甚至另一个字典都行，并且支持随时修改。

④ 动态可变

创建后可灵活增删改
字典创建以后，可以灵活地添加、删除或修改其中的键值对——它是和列表一样「活」的容器。

❓ 测验

字典的键（Key）必须满足什么条件？

✏️ 填空

字典中，键与值用 ___ 分隔，「键-值」对之间用 ___ 分隔。（两空连填，中间用空格隔开）

⚠️ 避坑
键唯一的「后者覆盖」与列表不能当键

键必须唯一：给同一个键重复赋值，不会报错，而是「后者覆盖前者」——{'a': 1, 'a': 2} 创建出来只剩 {'a': 2}，前面的 1 被悄悄覆盖，新手常在这里丢数据还不自知。

键必须不可变：d[[1,2]] = 'x' 会直接报 TypeError: unhashable type: 'list'——列表可变，不能当键；把列表换成元组 d[(1,2)] 就没问题。

值没有限制：值想是列表、字典都行，四大特性里「不可变」只约束键，不约束值。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 字典的定义与四大特性：字典是包含 0 个或多个键值对的集合，用大括号表示，键值对无序且键不能重复；键必须唯一且不可变（字符串、数字、元组可以，列表不行），值可以是任意类型并支持修改，字典整体可动态增删改。请：1）用《新华字典》的类比再讲一遍四大特性；2）出 5 道「这个能不能当键」的判断题（包含列表、元组、数字、字符串、浮点数）；3）解释 {'a': 1, 'a': 2} 的结果为什么是 {'a': 2}。
🔧 试一试：亲眼看看「键唯一」（5 分钟）
  1. 在 IDLE 里输入 d = {'a': 1, 'a': 2}，回车。
  2. 输入 print(d)，观察结果：{'a': 2}——只剩下后写的那个，'a':1 被「后者覆盖」了。
  3. 再试 d = {[1,2]:'x'}，看看报什么错（TypeError：列表不能当键）。
  4. 最后试 d = {(1,2):'x'}——元组当键，成功了。体会「键不可变」这条铁律。
✅ 小结
你现在知道了

字典是包含 0 个或多个「键-值」对的数据集合，用大括号 {} 表示，键冒号值、对间逗号；键值对无序且键不重复。四大特性：无序、键唯一且不可变、值任意可改、整体动态可变。下一节：用哪几种方式把字典创建出来。
