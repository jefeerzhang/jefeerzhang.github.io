为什么学这个

getminus(3, 5) 是 −2，getminus(b=3, a=5) 却是 2？

同一个减法函数、同一对数字 3 和 5，只是调用时换了一种写法，结果从 −2 变成了 2。这背后就是参数传递方式的差异：实参到底按什么规则「对号入座」到形参上？这一节搞清「按位置」和「按名称」两种传递方式——这是考试送分题，也是作业里最容易在减法类题目上翻车的地方。

💡 打个比方
按位置像「排队入座」：站在几号位就坐几号座；按名称像「对号入座券」：票上写明你的座位号

食堂打饭，队伍第 1 位拿 1 号餐、第 2 位拿 2 号餐——按位置：谁站哪个顺序谁就对应哪个窗口，顺序乱了拿到的饭就换了。另一种是按名称：餐券上直接写着「a 窗口」，你拿着券去对应窗口，先来后到随便插——顺序无所谓，名字对上就行。

核心概念

两种传递方式的对号入座规则

  • 按位置传递：根据定义与调用的位置顺序一一对应——要求和：实参的数量和位置必须与形参完全一致
  • 按名称传递：写 形参名=实参值，按参数名称一一对应——要求：名称必须与定义完全一致，但顺序可以打乱
  • 按名称传递本质是「点名入座」：b=3 就是明说「把 3 坐到 b 这个位置上」，与书写顺序无关
  • 两种方式可以混用，但按位置的实参必须写在按名称的实参前面（本课先掌握两种基本形式即可）

👇 点击切换，看同一个函数的两种调用方式：

def getminus(a, b):
    c = a - b
    return c

print(getminus(3, 5))

输出结果：

-2

对号入座过程：第 1 个实参 3 → 形参 a，第 2 个实参 5 → 形参 b。函数算 a - b，即 3 - 5 = -2。若写成 getminus(5, 3)，结果就是 2——位置一换，值就换。

def getminus(a, b):
    c = a - b
    return c

print(getminus(a=3, b=5))
print(getminus(b=3, a=5))

输出结果：

-2
2

第一行：a=3、b=5，算 3 − 5 = −2；第二行：虽然写在前面的 b=3，但名称对号——a 接到 5、b 接到 3，算 5 − 3 = 2。顺序打乱，结果由「名称」说了算。

课堂代码

PPT 原例：三种调用三种结果

def getminus(a, b):
    c = a - b
    return c

print(getminus(3, 5))
print(getminus(a=3, b=5))
print(getminus(b=3, a=5))

输出结果：

-2
-2
2
getminus(3, 5)
→
a=3，b=5 → 3−5 = −2
getminus(a=3, b=5)
→
点名入座 → −2
getminus(b=3, a=5)
→
a=5，b=3 → 5−3 = 2
  • 第 1 种：按位置，3、5 依序坐进 a、b
  • 第 2 种：按名称，名称一致、顺序也一致，结果与按位置相同
  • 第 3 种：按名称，顺序打乱——值跟着名称走，a 拿到 5、b 拿到 3，答案变成 2
交互示例

自测实验台：三种调用谁是谁？

先遮住答案，判断下面三行输出，再对照：def getminus(a, b): return a - b

print(getminus(10, 4))
print(getminus(a=10, b=4))
print(getminus(b=10, a=4))

输出结果：

6
6
-6
  • 前两行：位置顺序与名称对应关系一致，都是 a=10、b=4 → 6
  • 第三行：b=10、a=4 → 4 − 10 = −6——名称反了，减数被减数就反了
  • 做减法、除法这类「不满足交换律」的运算时，传递方式的影响最直观——加乘类题目错了都不容易发现
❓ 测验

已知 def getminus(a, b): c = a - b; return c，则 print(getminus(b=3, a=5)) 输出？

✏️ 填空

按＿＿传递：实参与形参按位置顺序一一对应，数量和位置必须一致；按名称传递：名称一一对应，顺序可以＿＿，但名称必须与定义完全＿＿。（三空用空格隔开）

⚠️ 避坑
三个高频翻车点

①减法题默认按位置：作业里 getminus(3, 5) 就是 a=3、b=5，结果是 −2——想当然写成 2 就错了，先想清楚实参坐进哪个形参；

②按名称时写错形参名：getminus(B=3, a=5) 报错——Python 的参数名区分大小写，B 不是 b，名称必须与定义完全一致；

③以为按名称也要求顺序：恰恰相反，按名称传递的意义就是「点名入座」、顺序可打乱；真正必须死守的是名称正确，而不是书写先后。

✅ 小结
你现在知道了

参数传递两种方式：按位置——依定义顺序一一对应，数量和位置必须一致；按名称——写形参名=值点名入座，名称必须与定义完全一致、顺序可打乱。getminus(b=3, a=5) 得 2，因为值跟着名称走。下一节：必须参数与可选参数。
