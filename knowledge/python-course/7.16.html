为什么学这个

上一节说过「删除之前先判断」——拿什么判断？

rename 要求 oldpath 存在，rmdir 要求目录为空，open 要求文件在那儿——前面每一节都绕不开同一个问题：这个路径到底存不存在？它是文件还是目录？这一节的判断类方法就是回答这些问题的「安检仪」，全部返回 True / False，天然适合和第五章的 if 分支搭配。作业第 4 题「判断是否文件」、第 6 题「判断是否空文件夹」都从这里拿工具。

💡 打个比方
判断类方法像「门卫三连问」：有人吗？是住户还是快递？从正门来的吗？

exists 问「这个地址有人吗」；isfile / isdir 问「住的是人（文件）还是公司（目录）」；isabs 问「你登记的是完整地址还是楼层号」；samefile 问「这两个门牌是不是同一户」。门卫只回答「是 / 不是」（True / False），不替你干活——想动手，还得配合 if 来决定。

核心概念

路径相关操作在 os.path 子模块

路径相关操作集中在 os 模块的 path 子模块里，习惯上导入并命名为 path：

import os.path as path
os.path 写法pathlib 写法作用
path.exists(p)Path(p).exists()判断路径是否存在，返回 True / False
path.isfile(p)Path(p).is_file()判断路径是否为文件
path.isdir(p)Path(p).is_dir()判断路径是否为目录
path.isabs(p)Path(p).is_absolute()判断是否为绝对路径
path.samefile(p1, p2)Path(p1).samefile(p2)判断两个路径是否相同
  • 判断类方法的返回值都是 True / False，常与 if 搭配（衔接第五章分支）
  • 路径不存在时 exists 返回 False、isfile / isdir 也返回 False——不报错，很温和
  • isabs 看的是「写法」不是「事实」：以盘符或 / 开头就是绝对路径
  • samefile 判断两个路径是否指向同一个文件或目录（同一层 vs 里面的子目录当然不同）

🔬 判断实验台：先点一个路径，再用四个方法轮流「盘问」它

选择路径：
当前盘问对象：temp5（一个真实存在的目录）。先选路径，再点方法按钮～
课堂代码

PPT 原例：对 temp5 目录逐个盘问

import os.path as path
from pathlib import Path

print(path.exists('temp5'), Path('temp5').exists())
print(path.isfile('temp5'), Path('temp5').is_file())
print(path.isdir('temp5'), Path('temp5').is_dir())
print(path.isabs('temp5'), Path('temp5').is_absolute())
print(path.samefile('temp5', 'temp5//subtemp2'))

输出结果：

True True
False False
True True
False False
False
  • temp5 是真实存在的目录：exists → True，isdir → True，isfile → False
  • 'temp5' 是相对路径写法（没以盘符开头），isabs → False
  • temp5 和它里面的 subtemp2 是两个不同的目录，samefile → False
  • os.path 版和 pathlib 版结果完全一致——两种写法任选，考试都认
交互示例

与 if 搭配：先安检、再干活（衔接第五章）

运行前先在本页所在目录建一个 校训.txt（或先跑 7.17 的第一个例子）。文件不存在时程序会走 else 分支，输出「校训.txt 不存在」——这本身就是「先安检、再干活」的完整演示。

import os.path as path

p = '校训.txt'
if path.exists(p):
    if path.isfile(p):
        print(p, '是一个文件')
    else:
        print(p, '是一个目录')
else:
    print(p, '不存在')

输出结果：

校训.txt 是一个文件
  • 判断方法返回 True / False，直接放进 if 条件——第五章分支在这里落地
  • 先 exists 再 isfile，能区分「不存在」和「存在但不是文件」两种情况
  • 作业第 6 题「判断空文件夹」也是这个套路：if path.isdir(p) and len(os.listdir(p)) == 0

已知「校训.txt」是一个文件，path.isdir('校训.txt') 的返回值是？

⚠️ 避坑
三个高频翻车点

①判断「是不是文件」别用 exists：目录也 exists 返回 True——要区分文件和目录，必须用 isfile / isdir；

②路径不存在不报错、只返回 False：isfile('不存在.txt') 得到 False 而不是异常——这很方便，但也意味着拼写错误会被悄悄当成「不存在」，检查路径写法；

③导入方式别搞混：按 PPT 习惯 import os.path as path 之后用 path.exists(...)；如果只写了 import os，就得写全 os.path.exists(...)，直接写 path.exists 会 NameError。
