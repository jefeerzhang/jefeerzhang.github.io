为什么学这个

类里的方法不止一种「打开方式」

你早就写过 def get_name(self) 这样的方法了——但它只是三种方法之一。有的方法要操作某个对象自己的数据，有的要操作全体共享的类属性，还有的逻辑上属于这个类、却谁的属性都不碰。上一节刚分完「实例属性 vs 类属性」，这一节的三种方法正好一一对应：管自己的、管全班的、谁都不管的。考试读代码题最爱在这张对比表里出题。

💡 打个比方
一对一辅导、发全校通知、借个教室开讲座

实例方法像班主任给某个学生做一对一辅导——必须先指定是哪个学生（self），才能辅导他本人；类方法像教务处发全校通知——面向整个年级（cls），不需要针对某一个人；静态方法像校外机构借学校教室开讲座——活动挂在学校名下，但既不针对某个学生、也不针对全班，谁的数据都不动。口诀：self 管自己、cls 管全班、静态方法像路过借个地方写函数。

🔬 三种方法调用实验台：每种方法点一遍，看谁能用类名调、谁能用对象调

先创建一个对象（count 从 0 变 1），再把三种方法各调用一次。
课堂代码

PPT 原例：一个类里装齐三种方法

class Student:
    count = 0                          # 类属性：学生总数

    def __init__(self, name):
        self.name = name               # 实例属性：学生姓名
        Student.count += 1             # 每创建一个对象，计数 +1

    def get_name(self):                # 实例方法：操作实例属性
        return self.name

    @classmethod
    def get_count(cls):                # 类方法：操作类属性
        return f'当前共 {cls.count} 名学生'

    @staticmethod
    def is_adult(age):                 # 静态方法：谁的属性都不碰
        return age >= 18

s = Student('张三')
print(s.get_name())
print(Student.get_count())
print(Student.is_adult(20))

输出结果：

张三
当前共 1 名学生
True
  • get_name(self) 没有装饰器——实例方法，读的是 s 自己的 name，只能由对象调用
  • get_count(cls) 带 @classmethod——第一个参数 cls 指向类本身，读类属性 count；用 Student.get_count() 调用
  • is_adult(age) 带 @staticmethod——没有 self 也没有 cls，参数只有外面的 age，逻辑上属于类但不碰任何属性
  • 创建对象时 __init__ 里执行 Student.count += 1——用类属性统计「一共建过几个对象」，注意这里用的是类名而不是 self
❓ 测验

关于静态方法（@staticmethod），下列说法正确的是？

✏️ 填空

实例方法的第一个参数是＿＿；类方法要用装饰器＿＿来标记；三种方法中，逻辑上属于类但既不需要操作实例属性、也不需要操作类属性的是＿＿方法。（三空用空格隔开）

⚠️ 避坑
三个高频翻车点

①类方法里写 self：@classmethod 的第一个参数是 cls，方法体里写 self 直接 NameError——读类属性要用 cls.count；

②用类名调实例方法：Student.get_name() 报 TypeError——实例方法的 self 没着落（没说是哪个对象），只能由对象调用；

③静态方法里偷偷用 self：静态方法根本没有 self 这个参数，方法体里写 self 必然 NameError——它就是「谁的属性都不碰」。

✅ 小结
你现在知道了

三种方法一张表记住：实例方法——无装饰器、self 在第 1 位、操作实例属性、只能由对象调用；类方法——@classmethod、cls 在第 1 位、操作类属性、类和对象都能调；静态方法——@staticmethod、无必填参数、什么属性都不操作、类和对象都能调。口诀：self 管自己、cls 管全班、静态方法借个地方写函数。下一节：用双下划线把属性「藏」起来——封装与私有属性。
