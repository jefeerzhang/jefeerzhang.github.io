为什么学这个

上一节说「把 3 传给 a」——a 到底是谁的？3 又是谁的？

getsum(3, 5) 里的 a、b 和 3、5，其实是两种身份完全不同的东西：一个是函数设计者造的「占位变量」，一个是调用者拿出来的「实际数据」。考试最爱考「谁是形参、谁是实参」，而且分不清它们，后面学参数传递方式、作用域都会跟着糊涂。这一节把这两个概念一次掰清。

💡 打个比方
形参像快递单上的「收件人」空栏，实参是你实际填进去的那个名字

快递公司印了十万张一样的快递单，每张单上「收件人：＿＿」都是空栏——这就是形参：设计单据（函数定义）时规定的位置和名字，本身没有内容。你寄件时在空栏里写上「lihua」——这就是实参：调用（寄件）时提供的实际数据。空栏可以填任何名字（参数换值复用），但空栏本身的规则（格式、位置）是设计者定的。

核心概念

形参 vs 实参：一张表看穿

形参（形式参数）

出现在函数定义时，是设计者定义的参数名称——一个占位变量，等调用时才被赋值。

def welcome(name):
    print(f"Hello, {name}")

这里的 name 是形参——它只是个「空栏」。

实参（实际参数）

出现在函数调用时，是调用者提供的参数数据——实际值，可以是字面值或已赋值变量。

Name = 'lihua'
welcome(Name)

这里的 Name（存着 'lihua'）是实参——它是「填进空栏的内容」。

调用时：实参 → 形参　（Name 的值被传递给 name）
  • 形参：定义时设计者定的名字，本质是函数体里用的占位变量
  • 实参：调用时调用者给的值，本质是要传进去的实际数据
  • 两者的连接发生在调用瞬间：实参的值被传递给形参（称为参数传递，下一节细讲传递的两种方式）
  • 名字可以不同（形参叫 name、实参变量叫 Name），Python 认位置和对应关系，不认「名字像不像」
课堂代码

PPT 原例：一次完整的「空栏 → 填写」过程

def welcome(name):
    print(f"Hello, {name}")

Name = 'lihua'
welcome(Name)

输出结果：

Hello, lihua
  • 第 1 行：定义函数，name 是形参（设计 welcome 这张「快递单」时留的空栏）
  • 第 4 行：Name = 'lihua'，变量 Name 存好了实际数据
  • 第 5 行：调用 welcome(Name)，Name 是实参——它的值 'lihua' 被传递给形参 name，于是函数体里的 {name} 变成了 lihua
  • 注意大小写：形参 name 和实参变量 Name 是两个不同的东西，靠实参的值传递联系，不靠名字相同
交互示例

同一张「快递单」，填不同的名字

def welcome(name):
    print(f"Hello, {name}")

welcome('xiaoming')     # 实参是字面值
yourname = 'tom'
welcome(yourname)       # 实参是已赋值变量
welcome('lihua')        # 同一形参，反复使用

输出结果：

Hello, xiaoming
Hello, tom
Hello, lihua
  • 形参 name 始终只有一个；实参每次调用都可以不同——这正是「一次定义、多次使用」的实现机制
  • 实参既可以直接写字面值 'xiaoming'，也可以传已赋值的变量 yourname
  • 每次调用相当于「填一张新快递单」，互不影响

有代码 def greet(name): print(f"Hi, {name}") 和调用 greet('lihua')。下列说法正确的是？

✏️ 填空

形参是函数＿＿时设计者定义的参数＿＿；实参是函数＿＿时调用者提供的参数＿＿。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①位置颠倒：答「调用时的参数是形参」——恰恰相反，定义时的是形参、调用时的才是实参，判断标准永远是「出现在哪一行」；

②以为名字必须相同：形参 name、实参变量 Name、实参 'lihua'，三者互不相干地命名也完全没问题——传递靠调用时的对应关系；

③以为传的是变量本身：welcome(Name) 传进去的是 Name 指向的那个字符串对象 'lihua'，函数体里把 name 重新赋值不会影响外面的 Name——因为重新赋值只是让 name 这个名字指向别的对象，并没有改动原来那份数据。

✅ 小结
你现在知道了

形参：定义时设计者定义的参数名称，是占位变量（快递单空栏）；实参：调用时调用者提供的参数数据（实际填的名字），可以是字面值或已赋值变量；调用瞬间发生参数传递——实参的值传给形参；两者名字可以不同。下一节：传递实参的两种方式——按位置与按名称。
