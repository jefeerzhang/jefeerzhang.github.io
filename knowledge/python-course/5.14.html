为什么学这个

程序写完一跑就报错？先学会「读报错」

Python 的错误主要分为两大类：语法错误（SyntaxError）和运行异常（Exceptions）。语法错误是指代码不符合 Python 的语法规则，解释器在解析阶段就会报错，程序根本无法启动运行；运行异常则是语法正确、但执行过程中遇到了问题。这一节先把六类最常见的语法错误过一遍——看懂报错信息，是编程的第一课，也是本章作业顺利通关的隐藏前提。

💡 打个比方
语法错误像「作文满篇错别字」——老师第一遍扫读就打回，根本不看内容

你把作文交给老师（解释器），老师先通读一遍检查「字写得对不对、句子通不通」。发现错别字就直接退回，一个字的内容都不评。报错信息里的 expected ':' 就是老师的批语——「这里少了冒号」。所以遇到 SyntaxError 别慌：程序还没开始跑，问题一定出在「写法」上，照着批语改字就行。

核心概念

六大类常见语法错误速查表

  • 语法错误发生在解析阶段：解释器逐行「读」代码时发现不合语法的地方，立刻终止，程序一行都不会执行
  • 报错信息最后一行是关键：错误类型 + 说明，如 SyntaxError: expected ':'
  • 报错中的 ^ 符号指向出错位置：定位点通常就在报错的那一行——比如 if 2<3 后少写冒号，报的是第 1 行、箭头也停在 if 这一行的表达式上
  • 学会逐条对照：下表六类错误覆盖了新手 90% 的语法翻车场景，报错时回来看一眼

交互示例

错误现场 vs 修复现场：对照着看

点下面的按钮切换，左边是「老师打回的原稿」，右边是「改对之后的作业」。

场景：if 条件写完忘了冒号

if 2 < 3
print(True)
报错：SyntaxError: expected ':'　（箭头指在 if 行末——「这里少个冒号」）
if 2 < 3:
    print(True)

补上冒号，下一行再缩进，就能正常输出 True。

场景：左括号多写了一个

print((1+2)
报错：SyntaxError: '(' was never closed　（「左括号从未闭合」——有个括号没闭上）
print((1+2))

输出 3。写嵌套括号时从里往外数一遍：几个「(」就要几个「)」。

场景：引号是从输入法里带出来的中文引号

s = ‘1’   # 这两个是全角中文引号，肉眼看几乎一样！
报错：SyntaxError: invalid character '‘' (U+2018)　（「非法字符」——中文引号不是合法的字符串引号）
s = '1'   # 英文半角引号

这是新手最隐蔽的坑：中文引号 ‘ ’ 和英文引号 ' ' 在屏幕上几乎看不出差别，但解释器一眼就认出来了。同理还有中文括号（）、中文逗号，。

❓ 测验

if 2<3: 换行后直接顶格写 print(True)（没有缩进），解释器会报什么错？

✏️ 填空

语法错误是代码不符合 Python 语法规则，解释器在＿＿阶段就会报错，导致程序无法＿＿。（两空连填，中间不加标点，如：解析阶段启动运行）

⚠️ 避坑
三个高频翻车点

①中文引号 ''、中文括号（）是新手最隐蔽的坑：从微信、网页复制代码时极易带进全角符号，肉眼看不出差别，报错却是 invalid character——解决办法：代码一律自己敲，或粘贴后检查输入法状态；

②报 expected ':' 的，是这一行少了冒号：解释器读到冒号本该出现的位置就停下来，箭头指在本行的表达式上（报的也是本行）——顺着行尾往右看，冒号多半就在那儿；

③invalid character 提示多半是全角符号：除了引号和括号，还要警惕中文逗号，、中文冒号：、以及变量名里混进来的空格全角版本。

我刚学了 Python 的六类常见语法错误：引号不匹配、括号不匹配、关键字使用不当、命名不当、缺少冒号、缩进不对。请：1）用「老师批改错别字」的类比解释 SyntaxError 为什么发生在解析阶段；2）出 6 段有语法错误的小代码让我找错并说出报错信息（每段对应一类，其中一段藏中文引号）；3）教我如何从 Traceback 的最后一行和 ^ 符号快速定位错误。
🔧 试一试：故意制造三种语法错误（5 分钟）
  1. 少冒号：输入 if 2<3 回车后再输入 print(True)，运行，读一读报错末行是不是 expected ':'。
  2. 少括号：输入 print((1+2) 运行，看看「'(' was never closed」长什么样。
  3. 中文引号：把输入法切到中文状态，输入 s = '1'（全角引号），运行后读报错——体会 invalid character 的含义。
  4. 把三条报错信息抄进笔记——「看懂报错」是本章的隐性目标，以后见到同款报错能 3 秒定位。
✅ 小结
你现在知道了

Python 错误分语法错误（SyntaxError）和运行异常（Exceptions）两大类：语法错误不符合语法规则、在解析阶段就报错、程序无法启动运行。六大类高频语法错误——引号不匹配、括号不匹配、关键字不当、命名不当、缺冒号、缩进不对——各自的报错提示要能对上号。下一节：语法全对也会出错的「常见运行异常」。
