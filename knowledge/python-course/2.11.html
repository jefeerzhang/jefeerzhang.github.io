为什么学这个

程序要处理数字，先认清数字的"型号"

前面你已经会用变量装数据了，但同样是数字，10 和 3.14 在 Python 眼里是两种不同的类型。类型不同，能做的运算、占用的内存、甚至算出来的结果都可能不一样。这一节带你看清 Python 的三大数值类型：

  • 整数 int：数学意义上的整数，无小数部分，支持正负零及多种进制（二进制、八进制、十六进制），如 10、-5、0b1010、0xA
  • 浮点数 float：带小数部分的实数，支持科学计数法；用二进制存储，可能带来精度问题，如 3.14、-0.5、1.23e-4
  • 复数 complex：由实部 a 和虚部 bj 组成，j 为虚数单位，常用于科学计算与工程领域，如 1+2j、-3j、0.5-1.2j
💡 打个比方
三种数值 = 三张不同的"票"

int 是整数票——就像电影院的座位号，必须是整数，没有"第 7.5 排"；float 是体重秤读数——带着小数点才真实，62.5 公斤；complex 是理科生专属的「双拼套餐」——实部和虚部拼成一盘（1+2j），日常点餐基本用不上。

对经管、文科同学来说，99% 的场景只用 int 和 float 两种；complex 记个名字、见了认识就行。

int 整数

示例：10、-5、0。还支持多种进制写法：二进制 0b1010、十六进制 0xA（下一节细讲）。整数没有大小限制，写多大都行。

实战演示

用 type() 给数字"验明正身"

光说不练假把式，用上一章学的 type() 函数亲自确认每个数的类型：

print(type(10))      # <class 'int'>      整数
print(type(-5))      # <class 'int'>      负数也是整数
print(type(3.14))    # <class 'float'>    带小数点就是浮点数
print(type(1.23e-4)) # <class 'float'>    科学计数法也是浮点数
print(type(1+2j))    # <class 'complex'> 有 j 就是复数
类型英文全称判断口诀典型示例
intinteger（整数）没有小数点10、-5、0b1010、0xA
floatfloating point（浮点）有小数点或 e3.14、-0.5、1.23e-4
complexcomplex（复数）带虚数单位 j1+2j、-3j、0.5-1.2j
❓ 测验

1 + 2j 属于哪种数值类型？

✏️ 填空

浮点数支持＿＿计数法，例如 1.23e-4 就表示 1.23×10⁻⁴。

⚠️ 避坑
别被"看起来是整数"骗了

① 10 和 10.0 是两种类型：type(10) 是 int，type(10.0) 是 float——只要带小数点，哪怕是 10. 这种写法，也是浮点数。

② 1.23e-4 不是"1.23 减 4"，也不是字符串，它是合法的浮点数，值为 0.000123。初见容易懵，见多了就亲切了。

③ 复数里的 j 不能换成别的字母，也不能写成 2j + 1 之外的花样——虚数单位在 Python 里惯例写小写 j（大写 J 也能用，但同一份代码里别混用）。

✅ 小结
你现在知道了

Python 有三大数值类型：int（整数，无小数部分，支持多种进制）、float（浮点数，带小数部分，支持科学计数法，二进制存储可能有精度问题）、complex（复数，实部+虚部 bj，常用于科学计算与工程领域）。日常学习 99% 只用 int 和 float。用 type() 可以随时查看任意值的类型。下一节：整数还有 4 种"脸谱"——四种进制。
