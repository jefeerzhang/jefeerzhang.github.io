为什么学这个

函数里把参数「改」了，函数外面会跟着变吗？

前面几节解决了「怎么传参数」，这一节回答一个更隐蔽的问题：传进去的值，在函数内部被处理后，函数外部的原数据变不变？很多人写过几年代码都答不对——因为答案取决于数据的类型：字符串「改不动」，列表「一改就真改」。搞懂它，以后遇到「函数为什么把我的数据改了」就再也不会懵。

💡 打个比方
不可变像「复印件上批注」，可变像「把原件直接借你改」

老师把复印件给你（不可变数据：整数、字符串、元组）——你在复印件上随便涂改，原件在老师手里毫发无损。老师把原件直接借给你（可变数据：列表、集合、字典）——你在上面改了什么，还回去时就真的是那样了。注意：Python 参数传递传的是对象的引用，函数拿到的是「对同一份数据的使用权」——区别只在这份数据本身让不让你改。

核心概念

两类数据，两种命运

  • Python 参数传递传的是对象的引用——不复制数据，函数内外看到的是同一份数据
  • 不可变数据：整数、字符串、元组——作为参数值不会受函数处理影响
  • 可变数据：列表、集合、字典——作为参数值会受函数处理影响
  • 关键区别在「改」的方式：St = St.upper() 是让名字指向一个新对象（原来的没动）；Ls[i] = … 是原地修改同一个对象（真的动了）
  • id() 是照妖镜：显示对象的内存地址编号——两次 id 相同 = 还是同一个对象；不同 = 换了新对象。注意 id 每次运行的数值都不同，看「变没变」就好，别背数值
交互示例

双实验对照：同一套操作，两种结局

PPT 原例 1：字符串参数 fun3(St)

def fun3(St):
    print(id(St))
    St = St.upper()
    print(id(St))
    print(St)

st = 'abc'
fun3(st)
print(st)

输出结果（id 数值每次运行都不同，看两次是否相同）：

140729828049640
2384621056672
ABC
abc
  • St = St.upper() 造出了一个新字符串对象 ABC，所以两次 id 不同
  • 函数内 St 打印 ABC——但那只是新对象
  • 函数外 print(st) 仍是 abc——原字符串从头到尾没被碰过
📌 结论：不可变数据（字符串）作为参数，不受函数处理影响——复印件上批注，原件无损。

PPT 原例 2：列表参数 fun4(Ls)

def fun4(Ls):
    print(id(Ls))
    for i in range(len(Ls)):
        Ls[i] = Ls[i].upper()
    print(id(Ls))
    print(Ls)

ls = ['a', 'b', 'c']
fun4(ls)
print(ls)

输出结果（两次 id 相同！）：

2384620996672
2384620996672
['A', 'B', 'C']
['A', 'B', 'C']
  • 循环里的 Ls[i] = … 是原地修改：还在同一个列表对象上动手，两次 id 相同
  • 函数内外打印的都是 ['A', 'B', 'C']——外面真的被改了
📌 结论：可变数据（列表）作为参数，会受函数处理影响——原件借你改，还回来就是改过的。
❓ 测验

函数内执行 St = St.upper()（St 是字符串参数），函数外的原字符串会？

✏️ 填空

整数、字符串、元组属于＿＿数据，作为参数值＿＿受函数处理影响（填：不会）；列表、集合、字典属于＿＿数据，作为参数值＿＿受函数处理影响（填：会）。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①背 id 数值：id() 每次运行的数值都不同（连本页示例里的数字在你电脑上也不一样）——只看两次 id 是否相同，相同就是同一个对象；

②把重新赋值当修改：函数内 St = St.upper() 不是「修改了 St」，是让 St 指向新对象——对不可变数据你怎么赋值，外面的原数据都纹丝不动；

③没料到列表被真改了：Ls[i] = …、Ls.append(…) 都是原地修改，函数外的列表会跟着变——不想要这个副作用，调用时传副本：fun4(ls[:]) 或 fun4(list(ls))。

🔧 试一试（5 分钟）
  1. 把 fun3、fun4 原样敲到 IDLE 里运行，重点观察两次 id 是否相同（你的数值一定和页面上的不一样，这很正常）。
  2. 改造 fun4：把循环改成 Ls = Ls + ['d']（整体重新赋值），再运行看函数外 ls 变不变——体会「指向新对象」和「原地修改」的差别。
  3. 传副本实验：把调用改成 fun4(ls[:])，运行后 print(ls)——这次函数外的列表保住了。

✅ 小结
你现在知道了

参数传递传的是对象的引用；不可变数据（整数、字符串、元组）作为参数不受函数处理影响——复印件上批注不影响原件；可变数据（列表、集合、字典）会受影响——原件借你改。用 id() 判断对象是否同一个，看相同与否、别背数值。下一节：变量的作用范围——局部与全局。
