为什么学这个

面向对象凭什么成为主流？靠这三张王牌

上一节我们知道了面向对象是「让对象协作」。但凭什么说它更适合大型程序？答案就是三大特性：封装、继承、多态——它们分别解决「数据安全」「代码复用」「灵活扩展」三个老大难问题。本页先建立整体印象，8.08、8.09、8.11 会逐个深入展开，现在不求甚解、先混个眼熟。

💡 打个比方
三大特性像「一间公司」的三套制度

封装是保密制度：财务室锁着门（隐藏内部细节），前台只留一个报销窗口（暴露必要接口）——员工不必知道账怎么算。继承是新人入职：老员工会的技能新员工自动都会（父类的属性和方法），再学几门新本事就是子类的扩展。多态是同一句「开工」：设计师交付图纸、程序员交付代码、销售交付订单——同一个指令，各自有不同的做法。

核心概念

三大特性速览：点卡片展开细节

① 封装 Encapsulation

隐藏内部细节，只暴露必要接口
定义：将对象的属性（数据）和方法（行为）包装在类中，隐藏内部细节、只暴露必要的接口。

生活例子：银行账户——储户只需会用存款、取款功能，完全不需要了解银行内部的账务处理逻辑。

对应课程：8.08 封装与私有属性
👆 点击展开 / 收起

② 继承 Inheritance

子类自动获得父类的属性和方法
定义：子类可以继承父类的属性和方法，并在此基础上扩展或修改，实现代码复用。

生活例子：动物 → 哺乳动物 → 狗。狗继承了动物的呼吸、移动，还有自己独有的「汪汪叫」。

对应课程：8.09 继承与 super()、8.10 多重继承
👆 点击展开 / 收起

③ 多态 Polymorphism

同一方法，不同对象有不同行为
定义：同一父类的不同子类对象，调用同一个方法可以产生不同的行为，增强灵活性和扩展性。

生活例子：乐器.演奏()——钢琴弹出叮咚声、吉他弹出拨弦声、鼓敲出咚咚声，同一动作各显神通。

对应课程：8.11 多态与方法重写
👆 点击展开 / 收起
  • 封装解决「数据安全」——不让外面乱碰对象的内部数据
  • 继承解决「代码复用」——父类写一次，子类白得一套
  • 多态解决「灵活扩展」——同一个调用入口，换对象就换行为
  • 三者不是并列关系：封装是基础，继承在封装之上复用，多态在继承之上变化
课堂代码

一段代码，三大特性全露脸

class Animal:                        # 父类：所有动物的公共模板
    def __init__(self, name):
        self.name = name             # 属性被「装进」对象 —— 封装的雏形

    def breathe(self):               # 所有动物共有的行为
        print(f'{self.name}在呼吸')

    def speak(self):
        print(f'{self.name}发出声音')

class Dog(Animal):                   # 继承：Dog(Animal) 表示狗是动物的一种
    def speak(self):                 # 重写：狗有自己专属的叫法
        print(f'{self.name}：汪汪！')

class Cat(Animal):
    def speak(self):                 # 同一方法名，猫是另一种行为
        print(f'{self.name}：喵喵～')

d = Dog('旺财')
c = Cat('咪咪')
d.breathe()      # breathe 是从 Animal 继承来的 —— 继承
d.speak()        # 狗叫汪汪 —— 重写带来的多态
c.speak()        # 猫叫喵喵 —— 同一调用，不同行为

输出结果：

旺财在呼吸
旺财：汪汪！
咪咪：喵喵～
  • class Dog(Animal) 括号里写父类名，这就是继承的语法（8.09 细讲）
  • d 不会叫喵喵、c 不会叫汪汪——同一个 speak()，各自对象各有行为，这就是多态
  • breathe 只在父类写了一次，两个子类直接就能用——代码复用
❓ 测验

「子类自动获得父类的属性和方法，并在此基础上扩展或修改」，这体现的三大特性是？

✏️ 填空

三大特性：将属性和方法包装在类中、隐藏内部细节只暴露必要接口，叫＿＿；子类继承父类的属性和方法实现代码复用，叫＿＿；同一方法被不同对象调用产生不同行为，叫＿＿。（三空用空格隔开）

⚠️ 避坑
三个初学误区

①把「多态」背成「多种状态」：这里的多态指同一方法调用，不同对象表现出不同行为，不是物理里的状态变化；

②以为封装就是「把代码藏起来看不见」：封装是不该碰的藏起来、该用的留接口，方法照样可以正常调用；

③以为继承是「复制一份代码」：继承是子类指向父类、直接借用——父类改一处，所有子类同步受益，而不是各抄一份。

✅ 小结
你现在知道了

三大特性：封装——属性和方法包装进类、隐藏细节只留接口（银行账户）；继承——子类白得父类的属性和方法、还能扩展（动物→狗）；多态——同一方法不同对象各有行为（乐器各奏各音）。本页是概览，细节分别在 8.08、8.09、8.11 展开。下一节：先认识类、对象、属性、方法四个核心概念。
