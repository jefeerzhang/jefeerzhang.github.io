为什么学这个

余额要是谁都能改，银行早关门了

上一节的 stu1.score = 92 说明：默认情况下，任何人拿到对象就能改它的属性。对成绩单无所谓，对银行账户就是灾难——acc.balance = -99999 一行代码把余额改成负数？封装就是来解决这个问题的：把重要的数据藏起来，只留规范的窗口供人办事。这也是面向对象三大特性（封装、继承、多态）中的第一个，是本章承上启下的一节。

💡 打个比方
银行：金库藏起来，柜台开出来

银行把重要的东西——金库、现金、账本——全部藏进不能随意进出的内部区域；对外只开放标准化的安全窗口：柜台和 ATM。你想取钱？在窗口办手续，柜员（公开方法）先核对金额够不够（内部检查逻辑），通过了才动账本（私有属性）。这样既保护了资金安全，又让办事简单——你不需要知道账本记在哪一页，只需要会排队按密码。类的封装一模一样。

核心概念

封装：藏细节，留接口

  • 封装是 OOP 的核心思想：将数据（属性）与操作数据的方法（函数）捆绑在一起，对外隐藏内部具体实现细节，只保留对外的交互接口
  • 具体实现：在属性或方法名前加双下划线 __，将其标记为私有属性 / 私有方法——外部将无法直接访问，从而有效保护数据不被随意篡改
  • 公开属性 / 公开方法：名字不带双下划线前缀，外部随便读、随便调——它们就是「对外的窗口」
  • 访问私有的正确姿势：不是直接碰 __balance，而是调用公开方法（如 withdraw()），让方法在类内部替你检查、修改
  • 硬闯的下场：外部执行 print(acc.__balance) 会抛 AttributeError——藏起来但留着窗口

🔬 银行柜台实验台：点按钮体验「藏起来但留着窗口」

先开户，再试试从「窗口」取款、以及硬闯私有属性（会有意外发生哦）。
课堂代码

PPT 原例：BankAccount 的私有余额

class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner            # 公开属性：户主
        self.__balance = balance      # 私有属性：余额（双下划线开头）

    def withdraw(self, amount):       # 公开方法：取款的「安全窗口」
        if amount >= 0 and self.__checkbalance(amount):
            self.__balance -= amount
            print(f"取款 {amount} 元，余额：{self.__balance}")
        else:
            print("取款失败：金额无效或余额不足")

    def __checkbalance(self, amount): # 私有方法：内部核账
        return amount <= self.__balance

acc = BankAccount('张三', 1000)
acc.withdraw(500)

输出结果：

取款 500 元，余额：500

而外部硬闯私有属性：

print(acc.__balance)
print(acc.__checkbalance(500))

输出结果：

AttributeError: 'BankAccount' object has no attribute '__balance'
AttributeError: 'BankAccount' object has no attribute '__checkbalance'
  • self.owner 是公开属性——窗口里挂着「户主」的牌子，谁都能看
  • self.__balance 双下划线开头——私有属性，外部访问直接 AttributeError
  • withdraw() 是公开方法（窗口）：先确认金额合法（amount >= 0）、再调私有方法核账（余额够不够），都通过才扣款
  • __checkbalance() 是私有方法——只在类内部被 withdraw 调用，外部也调不到，内部核账流程不外传
  • 数据的每一次变动都必须走 withdraw 这个窗口，且窗口里自带校验——这就是「保护数据不被随意篡改」

✏️ 填空

封装将数据与操作数据的方法捆绑在一起，对外隐藏内部＿＿细节，只保留对外的＿＿接口；在属性或方法名前加＿＿，可将其标记为私有属性或私有方法。（三空用空格隔开）

⚠️ 避坑
三个高频翻车点

①双下划线必须是「前缀」：__balance 才是私有；写成 _balance（单下划线）只是「约定俗成的受保护」，Python 并不真正拦截它；

②私有方法同样访问不到：acc.__checkbalance(500) 也抛 AttributeError——私有不只管属性，方法也能藏；

③私有 ≠ 绝对保险箱：Python 的「私有」是通过改名实现的（内部记成 _BankAccount__balance），高手仍有办法绕过——课堂上记住规则「外部不能直接访问」即可，重点是养成走公开方法的习惯。

✅ 小结
你现在知道了

封装是 OOP 的核心思想：把数据（属性）与操作数据的方法捆绑在一起，对外隐藏内部实现细节，只保留交互接口。实现方式：属性或方法名前加双下划线 __ 即为私有，外部直接访问抛 AttributeError；外部想动私有数据，必须走公开方法（如 withdraw），而公开方法内部自带校验。下一节：封装之外的第二大特性——继承与 super()。
