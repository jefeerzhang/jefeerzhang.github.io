为什么学这个

程序 = 数据 + 运算，运算符就是"发动机"

数据装进变量之后，真正让程序"动起来"的是运算。Python 提供了 7 个基本算术运算符和 7 个对应的增强赋值运算符，其中 /、//、% 三个的行为和数学课上的直觉不完全一样，是考试和实战的常客。这一节逐一摸清它们的脾气。

💡 打个比方
增强赋值 = 发工资直接入账

a += b 就像发工资：把 a 账户里的钱加上 b，直接存回 a 的账户，省得先取出来再加再存两趟——它基本等价于 a = a + b，写起来更简洁（对数字、字符串这类不可变对象，两者完全等价；对列表这类可变对象，+= 是就地扩展，见 3.16）。同理 a -= b 是从 a 里扣掉 b，a *= b 是让 a 翻 b 倍……一套操作行云流水。

7 个增强赋值运算符

写法等价于名称
a += ba = a + b加法赋值（对列表是就地扩展）
a -= ba = a - b减法赋值
a *= ba = a * b乘法赋值
a /= ba = a / b除法赋值
a //= ba = a // b整除赋值
a %= ba = a % b取余赋值
a **= ba = a ** b幂赋值

💡 记忆口诀：增强赋值就是「运算符 + 等号」的合体，先算后存，一步到位。

实战演示

跑一遍 PPT 原例，看清"脾气"

print(10 + 2, 10 - 2, 10*2, 10 ** 2, 10/2)
# 输出：12 8 20 100 5.0　（注意：/ 的结果是浮点数 5.0，不是 5）

再来看两个"反直觉"的重头戏——整除和取余，点击切换体验：

print(11 // 2, -11. // 2, -10.5 // 2)
print(11 % 2, -11. % 2, -10.5 % 2)

输出：5 -6.0 -6.0　和　1 1.0 1.5

解读：// 是向下取整不是四舍五入，-11.0//2 得 -6.0 而不是 -5.0；% 的结果符号跟除数走——除数为正（2）时结果非负，所以 -11.0 % 2 是 1.0、-10.5 % 2 是 1.5。

a, b = 10, 2
a /= b        # 等价于 a = a / b → a 变成 5.0
print(a, b)   # 输出：5.0 2
b /= a        # 等价于 b = b / a → b 变成 2/5.0
print(a, b)   # 输出：5.0 0.4

解读：a /= b 让 a 从 10 变成 5.0（/ 的结果带小数点）；接着 b /= a，b 从 2 变成 2÷5.0 = 0.4。每一步增强赋值都立即更新变量本身。

❓ 测验

10 // 3 的结果是？

✏️ 填空

10 / 2 的结果是 5.0，说明 / 的结果永远是＿＿类型。（填"浮点"或 float 均可）

⚠️ 避坑
三大"反直觉"陷阱，考试高频

① / 的结果永远是浮点数：10 / 2 是 5.0 不是 5——哪怕整除得尽，也带小数点。

② // 是向下取整，不是四舍五入：-11.0 // 2 是 -6.0 不是 -5.0。往数轴左边取，负数时尤其容易翻车。

③ 取余结果的符号跟除数走：-11.0 % 2 是 1.0、-10.5 % 2 是 1.5（除数为正，结果非负）；换成负除数就不一样了：7 % -2 是 -1、10 % -3 是 -2。所以别按"被除数的符号"猜，也别记成"一定非负"——记「符号跟除数走」最稳。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 的 7 个算术运算符（+ - * / // % **）和 7 个增强赋值运算符（+= -= *= /= //= %= **=）。请：1）用例子解释 / 永远得浮点数、// 向下取整、% 结果符号跟除数走这三个特性；2）演示 a, b = 10, 2 后连续执行 a /= b、b /= a 的每一步变化；3）出 3 道运算结果判断题考我，等我作答后再公布答案。
🔧 试一试：亲手踩一遍坑（4 分钟）
  1. 打开命令行输入 python 进入交互模式。
  2. 输入 print(11 // 2, -11.0 // 2) 回车，对照预期输出 5 -6.0——体会"向下取整"。
  3. 输入 a, b = 10, 2 回车，然后连续执行 a /= b 回车、b /= a 回车。
  4. 输入 print(a, b) 回车，对照本页输出 5.0 0.4——想清楚 a 为什么从 10 变 5.0，b 为什么从 2 变 0.4。
  5. 加餐：print(-10.5 % 2)，看看是不是 1.5？
✅ 小结
你现在知道了

7 个算术运算符里，/ 永远得浮点数（10/2=5.0），// 向下取整（-11.0//2=-6.0），% 结果符号跟除数走（除数为正时 -11.0%2=1.0，除数为负时 7%-2=-1），** 是幂运算。7 个增强赋值运算符（+= 等）等价于「变量 = 变量 运算符 值」，先算后存一步到位。下一节：比较运算符与逻辑运算符，让程序学会"做判断"。
