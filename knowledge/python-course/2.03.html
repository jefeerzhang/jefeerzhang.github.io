为什么学这个

名字起不好，程序直接罢工

上一节你学会了用 = 给变量赋值，但变量名不能随便起——起得不合法，Python 会当场报 SyntaxError（最常见的是 invalid syntax 和 invalid decimal literal）；起得不规范，别人（包括两周后的你自己）根本看不懂。

这一节解决两个问题：

  • 硬规矩：必须遵循的 4 条命名规则，违反就报错
  • 好品味：推荐的 2 种命名风格，让变量名一看就懂
💡 打个比方
变量名 = 给宠物取名

给宠物猫取名有几条「行规」：① 有些字不能用——像「交通信号灯」这种系统专属词（保留字），你不能拿来做名字；② 名字不能以数字开头，总不能叫「7号猫」吧；③ 叫「豆豆」和叫「doudou」大小写不同，会被当成两只完全不同的猫。

变量名也一样：有禁区（保留字）、有格式（字符与首字符限制），而且 Python 眼里 age 和 Age 是两个八竿子打不着的变量。

核心概念

必须遵循的 4 条规则

  • ① 字符组成限制：只能包含字母、数字、下划线，以及汉字等 Unicode 文字字符；禁止空格（也不能有 -、. 等其他符号）。
  • ② 首字符限制：不能以数字开头，必须以字母、下划线或汉字开头（Python 按 Unicode 规则识别标识符，汉字可以当首字符，数字不行）。
  • ③ 严格区分大小写：age 和 Age 是两个完全不同的变量，互不干扰。
  • ④ 禁用保留字：不可使用 if、for 等系统内置关键字（2.06 会专门讲）。

命名不合法时，Python 会直接报错：

2name = 18
# SyntaxError: invalid decimal literal
实战演示

合法示范 vs 违规翻车

name2 = '小李'      # 字母+数字，数字不在开头，合法
_score = 95        # 下划线开头，合法
学生成绩 = 88       # 汉字可以做变量名，合法
my_name = '小红'   # 字母+下划线，合法且可读性好

💡 其中 my_name 这种「下划线命名法」正是最推荐的风格。

2name = 18     # ✗ 以数字开头
my-name = 'x'  # ✗ 含连字符 - ，不在允许的字符里
my name = 'x'  # ✗ 含空格
if = 10        # ✗ if 是保留字，被系统征用了

以上写法全部会报 SyntaxError——不是「不建议」，是「根本跑不起来」。具体提示语各不相同：2name = 18 报 invalid decimal literal，my-name = 'x' 报 cannot assign to expression here，my name = 'x' 与 if = 10 报 invalid syntax。

推荐的两种命名风格

  • 下划线命名法（推荐）：全小写单词，单词之间用下划线连接。如 my_name、student_id——单词边界一目了然。
  • 驼峰命名法：首字母小写，后续每个单词首字母大写。如 myName、studentId——这是其他语言（如 Java、JavaScript）的通行写法，在 Python 里虽然合法，但 PEP 8 不推荐。

💡 两种都对，但同一个项目里保持统一最重要。本课程示例默认使用下划线命名法。

❓ 测验

下列哪个变量名是合法的？

✏️ 填空

① 变量名不能以＿＿开头，必须以字母或下划线开头；② Python 严格区分＿＿，age 和 Age 是两个不同的变量。（两空连填，中间用空格隔开）

⚠️ 避坑
三个新手最容易踩的命名坑

坑一：数字开头。想给变量名加编号，写成 1st_place 直接报错。改成 place1 或 first_place 就好了。

坑二：以为大小写无所谓。先写了 age = 20，后面不小心写成 print(Age)——报 NameError，因为 Age 根本没被定义过。这不是 bug，是 Python 在严格执行「区分大小写」。

坑三：拿内置函数当变量名。比如 print = 5，语法上合法但会把内置函数 print 覆盖掉，之后再 print(...) 就会报错。保留字（2.06）不能碰，内置函数名也别占用。

✅ 小结
你现在知道了

变量命名的 4 条硬规矩：只能用字母、数字、下划线和汉字；不能以数字开头；严格区分大小写；禁用保留字。违规会报 SyntaxError（提示语可能是 invalid syntax 或 invalid decimal literal）。推荐的两种风格：下划线命名法（my_name，最常用）和驼峰命名法（myName）。下一节：变量能装哪些「种类」的东西？——认识 Python 的数据类型大家庭。
