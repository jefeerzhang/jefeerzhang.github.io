为什么学这个

把数学公式「翻译」成递归代码——递归的第一门手艺

6.15 搭好了两要素的骨架，6.16 在「食堂传餐盘」实验台里看完了执行过程。这一节做一件事：把数学公式翻译成代码。阶乘 n! = n × (n-1) × … × 1 是递归的「标准入门题」，公式里两要素清清楚楚——递推关系式 n! = n × (n-1)! 对应 else 分支，基项 0! = 1 对应 if 分支。作业第 6 题的递归求和是它的同构题，学会了这一节，那道题就是「换个零件再装一遍」。

💡 打个比方
翻译公式像「填双栏对照表」：左栏数学式，右栏代码行

写递归代码别凭感觉，做一张对照表：左栏写数学事实——「0! = 1」「n! = n × (n-1)!」；右栏填代码——前者译成 if n == 0: return 1，后者译成 else: return n * factorial(n-1)。上一节「食堂传餐盘」里的往下传单子，就是 factorial(n-1) 被一层层调用；往回端餐盘，就是每一层的 n × … 在返回的路上算出来。公式会写，代码就会写。

核心概念

从公式到代码的三步翻译法

  • 第一步：写出递推关系式——n! = n × (n-1)!，即 F(n) = F(n-1) × n（呼应 6.15 的递归链条：后一项依赖前一项）
  • 第二步：找出基项——0! = 1（数学规定），这是链条拆到头时的现成答案，不需要再递归
  • 第三步：对号入座翻译——基项 → if n == 0: return 1；链条 → else: return n * factorial(n-1)；参数 n-1 保证每层向基项靠近
  • 执行过程回顾：factorial(5) 先递推拆到 factorial(0)，再回溯步步相乘：1 → 1 → 2 → 6 → 24 → 120（完整单步演示见上一节实验台）

🔬 阶乘计算器：输入 n，看「翻译好的代码」算出什么

点「计算」看看递推与回溯各走了几步
课堂代码

PPT 原例：factorial

def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)

print(factorial(5))

输出结果：

120
  • if n == 0: return 1：基项 0! = 1，守住停止点
  • else: return n * factorial(n-1)：链条 F(n) = F(n-1) × n，参数每层减 1
  • 验证：5! = 5 × 4 × 3 × 2 × 1 = 120，和递归结果一致
交互示例

手算 factorial(4)：递推 5 层，回溯 4 步

# 递推（层层拆解 ↓）
factorial(4) = 4 * factorial(3)
factorial(3) = 3 * factorial(2)
factorial(2) = 2 * factorial(1)
factorial(1) = 1 * factorial(0)
factorial(0) = 1        # 基项！不再调用

# 回溯（步步返回 ↑）
factorial(1) = 1 * 1 = 1
factorial(2) = 2 * 1 = 2
factorial(3) = 3 * 2 = 6
factorial(4) = 4 * 6 = 24
  • 递推阶段不做任何计算，只负责「把问题拆小、把调用压下去」
  • 所有乘法都发生在回溯的路上：从基项的 1 开始，一层乘回来
  • 「翻译公式」和「看懂执行」是两回事：这一节练前者，后者的单步动画在 6.16 实验台
❓ 测验

按课堂代码，factorial(4) 的返回值是？

✏️ 填空

阶乘的递归链条是 F(n) = ＿＿ × n；基项是 ＿＿! = 1，对应代码里 if 分支的 return ＿＿；所有乘法都发生在＿＿（返回）的路上。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①基项写成 0! = 0：写成 if n == 0: return 0，回溯时一路上全是乘 0，任何 n 算出来都是 0——基项的值必须准确；

②else 分支漏乘 n：写成 return factorial(n-1)，只拆不乘，最后返回的是基项的 1——递推关系式里的「× n」一个都不能丢；

③负数没有基项兜底：factorial(-1) 会越过 n==0 一路负下去直到 RecursionError——基项只挡住了「从 0 往上拆」的路，这提醒我们基项必须是链条真正的「终点」。

✅ 小结
你现在知道了

递归阶乘 = 公式翻译：链条 F(n)=F(n-1)×n → else 分支；基项 0!=1 → if 分支。三步翻译法「写关系式 → 找基项 → 对号入座」适用于一切递归题。下一节用同样的方法攻克最后一个实战：字符串逆序。
