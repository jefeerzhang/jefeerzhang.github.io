✍️ 本章作业（ipynb 格式提交）

  1. 已知两个点的坐标以元组方式存储到变量 p1 = (0, 4) 和 p2 = (3, 0)，请计算并输出两个点的距离。
  2. 现有一组数据以元组方式存储 tp=(68, 87, 59, 92, 92, 76, 87, 59, 89, 76)，要求利用集合特性去除重复数据，并将数据按照从大到小排列，结果仍以元组类型输出。
  3. 现有两个列表 lst1 = [1, 2, 3, 5, 6, 3, 2]，lst2 = [2, 5, 7, 8, 9]。要求利用集合运算输出同时存在于 lst1 和 lst2 中的数、在 lst1 中但不在 lst2 中的数，以及总共有多少个不同的数。
  4. 小明一天去逛超市，先买了 3 只牙膏，后买了 4 个面包、最后买了 5 瓶矿泉水，结账前退回了 2 瓶矿泉水。请你通过代码以字典元素添加、修改的方式（字典键为物品、值为数量）展示小明的购物过程（总共四个阶段，每个阶段均输出一次字典）。
  5. 给定一个字典 m_dic = {'python': 95, 'math': 99, 'english': 100, 'chinese': 77}，请用代码依次完成：输出字典的长度；修改 'math' 这个 key 对应的 value 值为 98；求所有科目的总成绩。
  6. 现有一段字符串 str1="张三,李四,张三,赵六"，请利用 split 方法通过逗号分隔符将其拆分成列表，输出该列表，再输出将该列表转化为元组、集合和字典的结果。
