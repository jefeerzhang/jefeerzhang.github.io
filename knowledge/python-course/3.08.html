为什么学这个

「这个词出现了几次？在哪里？能全换掉吗？」

处理文本的三大刚需：数一数某个字符出现几次、找一找某个子串在哪里、批量替换敏感词或错别字。这四个方法 count()、find()、index()、replace() 就是干这些的，也是本章作业第 2 题的直接考点。

💡 打个比方
点名器、定位器和「查找替换」功能

count() 像点名器报数——喊一声某个名字，报出全班举了几次手；find() 和 index() 是定位器——告诉你目标第一次出现的位置，区别在于性格：find 找不到时耸耸肩，优雅地退场给你 -1；index 找不到时当场翻脸，直接抛 ValueError 报错；replace() 就是 Word 里的「查找替换」功能——一键把所有旧词换成新词。

核心概念

四个方法各管一摊

  • str.count(sub)：返回 sub 在字符串中出现的次数
  • str.find(sub)：返回第一个 sub 的索引，找不到返回 -1
  • str.index(sub)：返回第一个 sub 的索引，找不到报错（ValueError）
  • str.replace(old, new)：把 old 全部替换成 new，返回新字符串
  • ⭐ 铁律：这些方法都不改变原字符串——尤其 replace，返回的新字符串必须用变量接住，否则替换结果就丢了
print('hello world'.count('l'))       → 3
print('hello world'.index('o'))       → 4
print('hello world'.find('0'))        → -1　（字母 o 和数字 0 是两回事，找不到）
print('hello world'.replace('l', 'L')) → heLLo worLd
交互示例

方法速查表 + find vs index 大对决

方法作用找不到时示例
str.count(sub)返回 sub 出现次数返回 0'hello world'.count('l') → 3
str.find(sub)返回第一个 sub 的索引返回 -1'hello world'.find('0') → -1
str.index(sub)返回第一个 sub 的索引报错 ValueError'hello world'.index('o') → 4
str.replace(old, new)old 全部替换成 new原样返回新串'hello world'.replace('l','L') → heLLo worLd

同样找「不存在的 z」，两种性格当场对比：

🤝 find——找不到不吵不闹
print('hello world'.find('z'))
→ -1

返回 -1 这个「哨兵值」，程序可以继续往下跑，用 if result != -1 判断即可。

💥 index——找不到直接报错
print('hello world'.index('z'))
→ ValueError: substring not found

程序当场中断。除非你确定子串一定存在，否则日常更推荐 find。

❓ 测验

'hello world'.find('z') 的输出是？

✏️ 填空

str.replace(old, new) 会将字符串中的 ____ 全部替换成 new，并返回新字符串。（填参数名）

⚠️ 避坑
大小写敏感 + 结果要接住

坑一：都区分大小写。'Good'.count('o') 得到 2（只数小写 o），写 'Good'.count('O') 才是 1；'python is Good'.count('g') 是 0 而不是 1——大写 G 根本不认。想不分大小写统计，可以先用 s.lower() 统一后再数。

坑二：字母 o 和数字 0 长得像但不是一回事，'hello world'.find('0') 返回 -1 就是这个原因，敲代码时看仔细。

坑三：replace 返回新字符串，原串不变。'abc'.replace('a', 'x') 执行完，原来的 'abc' 还在原地——必须写成 s = s.replace('a', 'x') 用变量接住结果。这是「字符串不可变」这条铁律最常见的翻车现场。

✅ 小结
你现在知道了

count() 报数、find()/index() 定位（找不到时前者给 -1、后者报错）、replace() 全文替换；四个方法区分大小写、都不改变原字符串，replace 的结果必须用变量接住。下一节：把字符串拆开、接上、修边——分割、联合与剔除！
