为什么学这个

集合不是建好就完事——元素要能加、能删

集合是可变类型，增删元素是它的基本功：加元素有 add（加一个）和 update（加一批）两个方法；删元素有 pop、remove、discard、clear 四个方法。其中 remove 和 discard 只差几个字母，遇到「元素不存在」时反应却完全不同——这是考试高频考点。

💡 打个比方
社团的人事变动

add 像「邀请一位新社员」，一次只来一个人；update 像「整批转入」，另一个班整个并进来。remove 和 discard 都像「请出社团」：一个较真——名单上没这人当场吵起来（报错）；一个佛系——没这人就算了。pop 则是「随机抽一人离场，还告诉你是谁」。

核心概念

两加四删，六般武艺

增加元素（2 个方法）：

方法作用
st.add(x)向集合 st 中添加一个元素 x
st.update(iter)向集合中扩充添加可迭代对象 iter（列表、元组、集合、字符串）

删除元素（4 个方法）：

方法作用
st.pop()删除集合 st 中随机元素，并返回该元素
st.remove(x)删除集合 st 中的元素 x，如果 x 不存在，则报错
st.discard(x)删除集合 st 中的元素 x，如果 x 不存在，不报错
st.clear()清空集合 st 中的所有元素
ST6 = {1, 2, 3, 4, 5}
ST6.add(0)
print(ST6)               # {0, 1, 2, 3, 4, 5}
ST6.update({4, 5, 6})
print(ST6)               # {0, 1, 2, 3, 4, 5, 6}（重复的 4、5 不会加进去）
交互示例

⚔️ remove vs discard 大对决

同样是「删除一个可能不存在的元素」，两位选手的反应截然不同：

ST7 = {1, 2, 3, 4, 5}
ST7.remove(99)
# KeyError: 99　→　没有此人，当场报错！

remove：要删的元素不存在就报 KeyError，程序直接中断。

ST7 = {1, 2, 3, 4, 5}
ST7.discard(99)
print(ST7)
# {1, 2, 3, 4, 5}　→　没有就算了，默默返回 None

discard：元素不存在也不报错，集合原样不动。

课堂代码：删除四连（对照输出逐行看）

ST7 = {1, 2, 3, 4, 5}
print(ST7.pop(), ST7)        # 1 {2, 3, 4, 5}（删哪个是随机的）
# print(ST7.remove(5), ST7)  # remove 删除指定元素，不存在会报错
print(ST7.discard(6), ST7)   # None {2, 3, 4, 5}（没有 6 也不报错）
print(ST7.clear(), ST7)      # None set()（清空后返回 None）
❓ 测验

已知 st = {1, 2, 3}，执行 st.remove(99) 会发生什么？

✏️ 填空

向集合添加一个元素用 ____ 方法；扩充添加可迭代对象（列表、元组、集合、字符串）用 ____ 方法。（两空连填，中间用逗号隔开）

⚠️ 避坑
add 加不了一个列表；pop 你说了不算

坑一：st.add([7, 8]) 会报 TypeError——列表不可哈希，没资格当集合元素；想批量加请用 update。而且 update 会把可迭代对象拆开逐个加入：update('ab') 加进去的是 'a' 和 'b' 两个字符，不是字符串 'ab'。

坑二：pop 删的是随机元素，你不能指定删谁；想指定删除请用 remove / discard。另外记住：所有删除操作都直接改变原集合。

✅ 小结
你现在知道了

增：add 加一个、update 加一批（拆开可迭代对象逐个进）；删：pop 随机弹、remove 有错必报、discard 佛系无声、clear 一键清空；所有删除都就地修改原集合。下一节：把集合运算结果「直接覆盖回去」的 *_update 三兄弟。
