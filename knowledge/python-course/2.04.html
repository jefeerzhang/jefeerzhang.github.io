为什么学这个

数据不分类，程序乱成一锅粥

变量只是「收纳盒」，但你总得知道盒子里装的是什么——是一个数？一段文字？还是「真/假」的判断结果？这就是数据类型的任务。不同类型的运算规则完全不同：3 + 4 得 7，而 '3' + '4' 得 '34'（字符串拼接）。

这一节先看全局地图——Python 的数据类型分两大门派：

  • 简单数据类型：一个数据就是一类——数值（int / float / complex）、字符串（str）、布尔值（bool）、空值（NoneType）
  • 组合数据类型：多个数据组合在一起——列表（list）、元组（tuple）、集合（set）、字典（dict）
💡 打个比方
单件快递盒 vs 多格收纳箱

简单类型像单件快递盒：一盒只装一样东西——一双鞋、一本书、一支笔，清清楚楚。

组合类型像多格收纳箱：一次装一整个家庭的东西——列表像可以随时增减物品的抽屉柜，元组像上了封条的收纳箱（装好后不许改），集合像不重样的徽章收藏册，字典像贴了标签的格子（按「标签」找东西）。

另外，字符串像一串糖葫芦——一个个字符用签子（引号）串起来，'hello' 里 h、e、l、l、o 一颗颗排好队。

❓ 测验

下列属于组合数据类型的是？

✏️ 填空

有序不可变序列使用圆括号()表示，叫做＿＿（英文类名是 ＿＿）。（两空连填，中间用空格隔开）

⚠️ 避坑
符号混用，一用就报错

坑一：列表用错括号。列表是方括号 [1, 2]，元组是圆括号 (1, 2)——很多人顺手全写成圆括号，后面想修改元素时才发现装进了元组，报 TypeError。

坑二：大括号两用易混淆。{1, 2, 3} 是集合，{"name": "张三"} 是字典——区别在于有没有「键: 值」结构。光写 {} 创建的空对象是字典，不是集合。

坑三：布尔值大小写。必须写 True / False，首字母大写；写成 true / false 会被当成变量名，报 NameError。

🔧 试一试：亲眼查一查类型（3 分钟）
  1. 打开命令行输入 python 进入交互模式。
  2. 输入 type([1, 2]) 回车——输出 <class 'list'>，方括号果然是列表。
  3. 输入 type({1: 2}) 回车——输出 <class 'dict'>，带冒号键值对的大括号是字典。
  4. 再对比试试 type({1, 2})——输出 <class 'set'>。同样是花括号，有没有「键: 值」结构，类型完全不同！
✅ 小结
你现在知道了

Python 数据类型分两大门派：简单类型装单一数据——整数 int、浮点数 float、复数 complex、字符串 str、布尔值 bool（只有 True/False）、空值 NoneType（None）；组合类型装多个数据——列表 list（[]有序可变）、元组 tuple（()有序不可变）、集合 set（{}无序不重复）、字典 dict（{}键值对）。下一节：怎么亲眼验证一个数据的类型？认识内置函数 type()。
