为什么学这个

定义好的函数是「睡着的」——不喊它，它永远不会动

上一节我们定义了 hello、getsum、circular 三个函数，但它们一行都没执行过。让函数「醒过来干活」的唯一方式是调用。这一节要解决三件事：调用怎么写？参数值从哪来？有返回值和没返回值的函数，调用方式有什么讲究？最后还有一个经典谜题：print(hello()) 为什么会打出两个东西——其中一个是莫名其妙的 None？

💡 打个比方
调用函数像「点菜」：菜谱是定义，点菜是调用，端上桌的菜是返回值

菜谱写进菜谱本（定义），厨房并不会自动开火；顾客喊一声「来一份宫保鸡丁」（调用），厨房才照着步骤做（执行函数体），最后端上桌（返回值）。有的菜品重点是「过程」（比如现场表演拉面，不上桌）——对应无返回值的函数；有的重点是「端上桌那份成品」——对应有返回值的函数，你要用盘子接住它（用变量保存返回值）。

核心概念

调用的两种语法，各配一种用途

  • 语法一：<函数名>(<参数值>)——直接调用。无返回值的函数通常这样用，目的就是执行函数体（如 hello()）
  • 语法二：<变量名> = <函数名>(<参数值>)——接住返回值。有返回值的函数通常这样用，目的是获取返回值（如 result = getsum(3, 5)）
  • 参数传递：调用时对参数赋予实际值，这一动作称为参数传递；参数值可以是具体的数据值（如 3），也可以是已赋值的变量（如 x = 3 后传 x）
  • 铁律：定义好的函数必须调用才会执行——只定义不调用，函数体永远不会跑，也不报错
课堂代码

PPT 原例：调用上一节定义的三个函数

def hello():
    print("Hello World!")

def getsum(a, b):
    c = a + b
    return c

def circular(r):
    area = 3.14 * r**2
    perimeter = 2 * 3.14 * r
    return area, perimeter

print(hello())
result = getsum(3, 5)
print(result)
S, L = circular(30)
print(S, L)

输出结果：

Hello World!
None
8
2826.0 188.4
  • 重点看第一、二行：hello() 没写 return，它没有返回值吗？不——「没写 return」的函数返回 None。print(hello()) 先执行 hello()（打印出 Hello World!），再把它的返回值 None 交给 print 打印，于是多出一行 None
  • result = getsum(3, 5)：把 3、5 传递给 a、b，函数算出 8 经 return 交回来，变量 result 接住 → 打印 8
  • S, L = circular(30)：circular 返回一个元组 (2826.0, 188.4)，用两个变量解包接收——S 得面积、L 得周长（第四章元组解包在此实战）
交互示例

参数值可以是「字面值」也可以是「变量」

def getsum(a, b):
    c = a + b
    return c

# 参数值 = 具体数据值
print(getsum(3, 5))

# 参数值 = 已赋值的变量
x, y = 10, 20
print(getsum(x, y))

输出结果：

8
30
  • 第一次调用把字面值 3、5 传给 a、b；第二次把变量 x、y 里存的 10、20 传过去
  • 传的永远是「变量里的值」，不是变量本身——准确说，传进去的是变量指向的那个对象：Python 传的是对象引用，不会把对象复制一份（6.09 会展开）
  • 无论哪种，动作都叫参数传递：调用时对参数赋予实际值
❓ 测验

已知 def hello(): print("Hello World!")（函数体内无 return），执行 print(hello()) 会输出第二行 None，原因是？

✏️ 填空

定义好的函数必须＿＿才会执行；没有 return 语句的函数返回值为＿＿；有返回值的函数通常用＿＿名 = 函数名(参数值) 来获取＿＿。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①print(无返回值函数) 多出 None：函数没有 return，print(hello()) 就会打印 None——想「只要执行」就直接写 hello()，别在外面套 print；

②定义顺序没搞清：必须先定义、后调用——Python 从上往下执行，调用时函数还没登记过，就报 NameError；

③调用时忘写括号：写 hello 只是「提到这个函数的名字」（函数对象本身），不会执行；必须写 hello() 才是「喊它干活」。

✅ 小结
你现在知道了

调用语法：直接调用 函数名(参数值)（无返回值时常用，目的是执行函数体）、赋值调用 变量名 = 函数名(参数值)（有返回值时常用，目的是获取返回值）；调用时对参数赋予实际值叫参数传递，参数值可以是字面值或已赋值变量；函数必须先定义后调用、必须调用才执行；无 return 的函数返回 None。下一节：形参与实参到底谁是谁。
