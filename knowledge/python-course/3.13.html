为什么学这个

一个变量装不下「一整组」数据？

前面学的字符串只能装「一串字符」，可现实中的数据往往是成批出现的：全班 40 个成绩、一周 7 天的天气、购物车里的 10 件商品。难道要写成 score1、score2、score3……？列表（List）就是为此而生：一个变量，装下一整组数据。Python 列表以其灵活性和强大功能，成为数据处理的首选工具，本章后半段的主线全部围绕它展开。

💡 打个比方
石碑 vs 白板：字符串不可变，列表可变

字符串像刻在石碑上的字——刻完就改不了，想改只能重新刻一块（生成一个新字符串）；列表像白板上的购物清单——随时可以添一项、改一项、擦掉一项。

而且白板上什么都能写：数字、文字混着来，甚至还能再贴一张小清单上去——这就是列表里可以装列表（嵌套列表）。

核心概念

列表是什么

列表（List）是包含 0 个或多个元素组成的有序序列，用于存储一组有序的元素数据。书写时使用中括号 [] 包裹元素，元素之间用逗号 , 分隔：

ls = [1, 'a', True, [2, 3]]   # 数字、字符串、布尔值、列表混装
print(ls)        # [1, 'a', True, [2, 3]]
print(type(ls))  # <class 'list'>
print(len(ls))   # 4 —— 内层列表只算「一个」元素

列表有三大特性，点下面的卡片逐个揭开：

有序性

元素按照插入顺序排列，可以通过索引直接访问
写在前面的索引小、写在后面的索引大；ls[0] 取第 1 个、ls[-1] 取最后 1 个——和字符串的规矩一模一样。
点击展开 ▾

可变性

创建后可随时修改、添加或删除其中的元素
这是列表与字符串最大的区别：ls[0] = 99 完全合法，而字符串 s[0] = 'x' 会直接报错。后面几节的增删改方法全都建立在「可变」之上。
点击展开 ▾

任意类型

可包含数字、字符串、列表、对象等不同数据类型
一个列表里可以同时装整数、小数、字符串、布尔值，甚至再装一个列表（嵌套）。混装是列表的常态，不需要「同一类型」。

❓ 测验

下列哪种说法是错误的？

✏️ 填空

列表使用中括号 [] 包裹，元素之间用＿＿分隔。

⚠️ 避坑
「可变」是列表的身份证，字符串只能羡慕

s = 'abc' 之后执行 s[0] = 'A'，会报 TypeError: 'str' object does not support item assignment；而 ls[0] = 99 完全没问题——这就是「字符串不可变、列表可变」。以后凡是看到「直接改变原列表」的方法，都在享受这份可变性。

另外两个小坑：① 分隔符必须是英文逗号，写成中文逗号 [1，2] 会直接报错；② 别把变量命名为 list——它覆盖了内置的列表类型名，之后 list('123') 就会报错。

✅ 小结
你现在知道了

列表是包含 0 个或多个元素的有序序列，用中括号 [] 包裹、逗号分隔；三大特性——有序（可索引访问）、可变（可增删改）、元素类型任意（可混装、可嵌套）。与字符串最大的不同：字符串不可变，列表可变。下一节：把数据装进列表的两种创建方式。
