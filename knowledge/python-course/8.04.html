为什么学这个

上一节认识了图纸，这一节学会画图纸

上一节我们说：类是设计图纸，对象是真车。这一节就学怎么画这张图纸——也就是创建类。只需要记住一个语法骨架和三个关键词：class（唯一的保留字）、__init__、self。它们是整章的「地基」，后面私有属性、继承、多态全都建立在今天的 Student 类之上，务必逐行看懂。

💡 打个比方
创建一个类，像开一间「新员工入职接待处」

class 是挂牌成立——宣布「学生处成立了」；__init__ 是入职接待流程——每个新学生来报到时自动被接待，登记姓名、发成绩单，一人一套；self 是「当前这位学生」本人——接待员嘴里说「给你登记」时，「你」指的就是眼前报到的那一位。每来一个学生（对象），接待流程就跑一遍，但登记的资料各归各的。

核心概念

语法骨架 + 三个关键词

class 类名:                        # 类名：首字母大写（驼峰命名法），如 Student、BankAccount
    """类的文档说明（可选）"""       # 三引号字符串，说明这个类是干嘛的

    def __init__(self, 参数1, 参数2, ...):    # 初始化方法：创建对象时自动调用
        self.属性1 = 参数1            # 初始化属性：把参数装进对象
        self.属性2 = 参数2
        ...

    def 方法名(self, ...):            # 实例方法：第一个参数惯例写 self
        方法体
  • class——定义类的关键字；类名默认要求首字母大写（驼峰命名法），如 Student、BankAccount；类体靠缩进表示从属关系，和函数一样
  • __init__——初始化方法（注意是前后各两个下划线）：创建对象时自动调用，专门用来初始化属性，不需要（也不应该）手动去调用它
  • self——代表当前对象本身：调用方法时 Python 会自动把对象传给 self，不需要手动传；方法内通过 self.属性 访问对象自己的数据
  • 文档字符串 """...""" 可选，但写上是个好习惯——相当于给类贴说明书
课堂代码

PPT 原例：Student 类完整代码

class Student:                              # 类名首字母大写
    """学生类"""                             # 文档说明（可选）

    def __init__(self, name, score):        # 初始化方法：创建对象时自动调用
        self.name = name                    # 属性：姓名
        self.score = score                  # 属性：成绩

    def introduce(self):                    # 方法：自我介绍
        print(f"我是{self.name}，我的成绩是{self.score}分")

    def is_pass(self):                      # 方法：判断是否及格
        return self.score >= 60

用最简单的方式用它一把（创建对象的完整语法下一节细讲）：

stu = Student('小明', 92)   # 创建对象的一瞬间，__init__ 被自动调用
stu.introduce()             # 我是小明，我的成绩是92分
print(stu.is_pass())        # True（92 分 >= 60 分）

输出结果：

我是小明，我的成绩是92分
True

🧩 Student 类结构一览

📦 属性（2 个）：name 姓名 · score 成绩
⚙️ 方法（3 个）：__init__ 初始化方法 · introduce 自我介绍 · is_pass 判断及格
  • def __init__(self, name, score) 的 name、score 是参数；self.name = name 里的 self.name 是属性——同名但身份不同，左边才是「装进对象里的」
  • introduce、is_pass 的第一个参数都是 self——不需要传值，Python 自动搞定
  • is_pass 里有 return，会返回 True/False；introduce 只打印不返回——方法和其他函数一样
❓ 测验

执行 stu = Student('小明', 92) 时，下列哪个方法被自动调用？

✏️ 填空

定义类用关键字＿＿；创建对象时被自动调用、用于初始化属性的是＿＿方法；代表当前对象本身、由 Python 自动传入的参数是＿＿。（三空用空格隔开）

⚠️ 避坑
三个高频翻车点

①方法忘写 self：def introduce(): 调用时会报 TypeError: Student.introduce() takes 0 positional arguments but 1 was given——实例方法的第一个参数必须有（惯例叫 self），哪怕方法里用不到它；

②__init__ 下划线数量不对：写成 _init_ 或 init 就只是普通方法，创建对象时根本不会被调用——Student('小明', 92) 会直接报 TypeError: Student() takes no arguments；前后各两个下划线一个都不能少；

③类名不大写、缩进混乱：类名按惯例首字母大写（Student 而不是 student）；类体必须整体缩进，方法与属性对齐在类体内。

✅ 小结
你现在知道了

创建类的骨架：class 类名: + 缩进的类体；__init__ 是初始化方法（习惯上也叫构造方法），创建对象时自动调用、负责初始化属性；self 代表当前对象本身，由 Python 自动传入。Student 类两张卡片：属性 name/score，方法 __init__/introduce/is_pass。本章是扩展章、不安排作业，把「试一试」当练手即可。下一节：正式学习创建对象与访问成员。
