为什么学这个

本章最后一战：把「翻译法」用在字符串上

阶乘翻的是数字公式，这一节翻文字问题：把字符串「123456789」变成「987654321」。思路和阶乘一模一样——每次把第一个字符摘出来放到最后，剩下的字符串继续递归，直到剩下的是空串。它比阶乘多了一个新工具：切片 s[1:]（3.04 学过，「从下标 1 取到末尾」＝去掉第一个字符）。这是本章最后一节，学完你就能独立完成「公式 → 递归代码」的全套翻译。

💡 打个比方
逆序像「发牌收牌」：每次抽最左一张放桌尾，抽完牌堆空了，桌上从右往左就是答案

把字符串想成一排扑克牌：每次从左边抽出第一张（s[0]），扣在桌子末端（+ s[0]），剩下的牌继续照此办理；直到牌抽光了（空串，基项）。桌上那叠牌从上往下看，正好是原串的逆序。和 6.16 的「食堂传餐盘」对上号：抽牌往下传是递推，每抽一张桌上多一层「待拼接的字符」；串从空往回长出来是回溯。

核心概念

字符串逆序的两要素与翻译

  • 问题描述：将字符串的第一个字符放到最后，再对剩下的字符串做同样的事，依次执行，直到剩下字符串为空停止
  • 递归链条：rev(s) = rev(s[1:]) + s[0]——「去掉头的串」逆序后，把「头」接到末尾；参数从 s 变成 s[1:]，每次少一个字符
  • 基项：len(s) == 0（空串）时直接返回 s——空串逆序还是空串，不必再拆
  • 切片工具：s[1:] 表示「下标 1 取到末尾」，即去掉第一个字符（衔接 3.04 字符串切片）；s[0] 是第一个字符
  • 对照表：基项「串空 → 返回空串」→ if len(s) == 0: return s；链条「去头逆序接尾」→ else: return rev(s[1:]) + s[0]——和阶乘的翻译法完全同构，只是「× n」换成了「+ s[0]」

🔬 逆序实验台：输入一个字符串，看它被递归翻转

点「逆序！」看递推与回溯全过程
课堂代码

PPT 原例：rev

def rev(s):
    if len(s) == 0:
        return s
    else:
        return rev(s[1:]) + s[0]

print(rev("123456789"))

输出结果：

987654321
  • if len(s) == 0: return s：基项——空串直接返回，停止递归
  • else: return rev(s[1:]) + s[0]：链条——先逆序「剩下的」，再把摘下的头接在末尾
  • 注意顺序：rev(s[1:]) + s[0] 是「头放最后」；若写成 s[0] + rev(s[1:]) 就成了原样返回——拼接方向决定成败
交互示例

手算 rev("12345")：递推五层拆空，回溯五步长成

# 递推（层层拆解 ↓，每层摘走一个头）
rev("12345") = rev("2345") + '1'
rev("2345")  = rev("345")  + '2'
rev("345")   = rev("45")   + '3'
rev("45")    = rev("5")    + '4'
rev("5")     = rev("")     + '5'
rev("")      = ""           # 基项！串空停止

# 回溯（步步返回 ↑，串从空长成答案）
rev("5")  = ""  + '5' = "5"
rev("45") = "5" + '4' = "54"
rev("345")  = "54"  + '3' = "543"
rev("2345") = "543" + '2' = "5432"
rev("12345") = "5432" + '1' = "54321"
  • 递推阶段一个字符都没拼上，只是「摘头、留字、往下传」
  • 回溯阶段从空串开始，每次把之前摘下的字符接到串尾——先摘的后接上，所以恰好逆序
  • 和阶乘对照：链条「问题变小」、基项「小到不用再拆」、拼接/乘法都发生在返回路上——结构完全同构
❓ 测验

执行 rev("123456789") 时，回溯阶段第一个被拼接到结果串上的字符是？

✏️ 填空

字符串逆序的递归链条是 rev(＿＿) + ＿＿；基项是 ＿＿ 时返回空串；所有拼接都发生在＿＿（返回）的路上。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①拼接方向写反：s[0] + rev(s[1:]) 得到的是原字符串——「第一个字符放到最后」意味着头要接在右边：rev(s[1:]) + s[0]；

②基项漏写：没有 if len(s) == 0，切片 s[1:] 会一路切到空串还要继续切，最终报 RecursionError——空串就是「抽完牌的桌子」；

③切片下标手误：写成 s[:1] 拿到的是「只剩第一个字符」而不是「去掉第一个字符」——s[1:] 才是去头，切错方向递归永远拆不到头。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 递归实现字符串逆序。请：1）列出 rev(abcde) 递推 6 层、回溯 6 步的完整清单（含每层的拼接结果）；2）解释 rev(s[1:]) + s[0] 和 s[0] + rev(s[1:]) 的输出为什么一个逆序一个原样；3）出 3 道「给递归字符串代码求输出」的题考我（比如统计字符个数、判断回文的递归写法），等我答完再讲解。
🔧 试一试：变着花样玩 rev（5 分钟）
  1. 把课堂代码抄进交互模式，试 rev("Python") 和 rev("上海自来水来自海上")——中文也能逆序，后者逆序后还是它自己（回文）。
  2. 改拼接方向：return s[0] + rev(s[1:])，确认输出等于原串，体会「头放最后」与「头放最前」的区别。
  3. 改造基项：让 rev 只逆序前 n 个字符——写 def revn(s, n):，链条 revn(s[1:], n-1) + s[0]，基项 n == 0 返回空串，试试 revn("abcdef", 3)。
  4. 用递归数一数：def slen(s): 空串返回 0，否则 return 1 + slen(s[1:])——同一个「去头」套路还能算长度。
✅ 小结
你现在知道了——顺便把整章串起来

字符串逆序 = 链条 rev(s[1:]) + s[0]（去头逆序接尾）+ 基项 len(s) == 0（空串停止），拼接发生在回溯路上。本章两大板块至此收官：① 函数基础（定义、调用、参数、作用域、global）——学会「造工具、用工具」；② 特殊函数（lambda、map/filter、sorted、递归）——学会「把函数当值传递、让函数调用自己」。函数是后面一切内容的基石，下一章我们进入第七章《文件及目录操作》，让程序真正读写硬盘上的数据。
