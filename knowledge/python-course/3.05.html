为什么学这个

前四节的「毕业考试」来了

索引能取一个字符，切片能取一段字符——把这两招合起来，就能从真实的 18 位身份证号里读出地区、生日和性别。这是本章第一个完整实战：一小段代码，解决一个听起来「像回事」的问题。以后你注册账号时填的身份证校验、银行系统的身份识别，背后都是这类字符串操作。

💡 打个比方
身份证号是一张「压缩的个人信息表」

18 位号码看着是一串数字，其实是一张压缩过的表格：前 6 格写着「住址」，中间 8 格写着「生日」，再 3 格是「当天出生的人排队序号」，最后 1 格是「防伪校验章」。字符串索引和切片就是「按格拆表」的工具。

核心概念

18 位身份证号的结构（标准常识）

  • 第 1~6 位（索引 0~5）：地区码——省、市、县（区）的行政区划代码
  • 第 7~14 位（索引 6~13）：出生日期，格式为年 4 位 + 月 2 位 + 日 2 位
  • 第 15~17 位（索引 14~16）：顺序码——同一天同地区出生者的编号
  • 第 18 位（索引 17）：校验码（可能是数字或 X）
  • 关键规则：第 17 位（索引 16）数字为奇数表示男性，偶数表示女性

把示例号码 id_c = "110101199003077758" 按格拆开，正好对上：

每格下方是它的索引号（正向 0~17）。注意：身份证号要存成字符串而不是数字——按位取字符是它的核心用法，而且存成整数会丢掉前导零、也取不出单个字符。

id_c = "110101199003077758"
# 输出地区
print(id_c[:6])

输出：110101

一句拆解：[:6] 省略起点，从索引 0 取到索引 6 之前——正好是前 6 位地区码。

id_c = "110101199003077758"
# 输出生日
print(id_c[6:10], id_c[10:12], id_c[12:14])

输出：1990 03 07

一句拆解：年 [6:10]、月 [10:12]、日 [12:14]，三段切片左闭右开，各取各的，用逗号隔开一次性打印。

id_c = "110101199003077758"
# 输出性别
print("男" * (int(id_c[16]) % 2) + "女" * (1 - int(id_c[16]) % 2))

输出：男

一句拆解：索引 16 的字符是 5，转成整数后 5 % 2 得 1（奇数），于是 "男" * 1 保留、"女" * 0 变空串——只打印出「男」。

核心概念

精讲：判性别那一行的「巧思」

print("男" * (int(id_c[16]) % 2) + "女" * (1 - int(id_c[16]) % 2))
  • 字符串可以乘数字实现重复："男" * 1 是 男，"男" * 0 是空串（什么都没有）——这招下一节正式讲，先混个眼熟
  • int(id_c[16])：先把索引 16 取出的字符（如 '7'）转成整数，才能做算术
  • % 2：对 2 求余——奇数余 1，偶数余 0，正好把「奇偶」变成「1 或 0」
  • 整个表达式等于「用乘法代替 if 判断」：条件为真时乘 1（留下），为假时乘 0（清零）。流程控制要到第五章才学，这里看懂套路即可
❓ 测验

对 id_c = "110101199003077758" 执行 print(id_c[6:10])，输出的是？

✏️ 填空

身份证第 17 位（索引 16）数字为奇数，则该号码主人的性别为＿＿。

⚠️ 避坑
「字符串 7」和「数字 7」是两回事

① id_c[16] 取出的是字符 '7'，不是数字 7——直接拿它做 % 2 会报 TypeError，必须先 int() 转换。② 身份证号务必写成字符串：如果存成整数，前导信息的位置含义就乱了，而且部分环境里 18 位整数还会出精度问题。③ 校验码可能是字母 X，所以整串号码不能当纯数字处理。④ 别拿真实身份证号做练习发到网上，用编造的 18 位数字串就好。

✅ 小结
你现在知道了

身份证号是「压缩的个人信息表」：6 位地区 + 8 位生日 + 3 位顺序码 + 1 位校验码，第 17 位奇男偶女；用切片 [:6] [6:10] [10:12] [12:14] 分段提取，用 int() + % 2 判奇偶，再借「字符串乘数字」用乘法代替 if 输出性别。字符串还有哪些好玩的操作？下一节：运算符与内置函数！
