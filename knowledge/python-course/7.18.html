为什么学这个

路径其实是「目录 + 名字」两截，拆开装上都有专门工具

一个文件或目录的路径由两部分构成：所在上级目录 + 文件/目录名。想把文件存到「某个目录 + 某个文件名」的新位置，就得把两截合并；想从完整路径里取出文件名或所在目录，就得分解。本节的方法是路径的「螺丝刀套装」，也是全章的收官——作业第 4 题要把 7.15、7.16 和本节串成一条完整流水线。

💡 打个比方
路径像「小区 + 门牌」：dirname 是小区，basename 是门牌，join 是把它们写在同一张纸条上

C:\Users\XXX\校训.txt 里，dirname 是小区地址（C:\Users\XXX），basename 是门牌（校训.txt）。split 是把一张完整地址撕成两半；join 是把小区和门牌重新写在一张纸条上——交给快递员照样能送到。pathlib 更酷：用 / 运算符直接把地址「粘」起来，像拼积木一样优雅。

核心概念

五个方法（双写法）

os.path 写法pathlib 写法作用
path.realpath(p)Path(p).resolve()获取文件或目录的真实路径（完整绝对路径）
path.basename(p)Path(p).name获取路径中最后一层文件或目录名
path.dirname(p)Path(p).parent获取文件或目录所在目录的路径
path.split(p)(Path(p).parent, Path(p).name)把路径分成「目录 + 名字」两部分，返回一个二元元组（os.path 版返回字符串元组，pathlib 版返回 Path 对象元组）
path.join(p1, p2, …)Path(p1) / p2 / …将多个路径拼贴到一起（pathlib 用 / 运算符，很优雅）
  • realpath / resolve 只对「相对路径」才有变身效果——把校训.txt 变成带盘符的完整地址
  • basename / name 取「门牌」，dirname / parent 取「小区」——一个管尾巴、一个管前面的路
  • split 是 dirname + basename 的一次性打包，返回二元元组 (目录, 名字)
  • join 是它们的逆操作：把目录和名字拼回完整路径，比自己写字符串相加安全得多

课堂代码

PPT 原例：拆解与组装（不同电脑结果不同）

import os.path as path
from pathlib import Path

filepath = path.realpath('校训.txt')
print(filepath)
print(path.basename(filepath))
print(path.dirname(filepath))
print(path.split(filepath))
print(path.join(path.dirname(filepath), path.basename(filepath)))

filePath = Path('校训.txt').resolve()
print(filePath.name)
print(filePath.parent)

输出结果（你的电脑上 XXX 是你的用户名）：

C:\Users\XXX\校训.txt
校训.txt
C:\Users\XXX
('C:\\Users\\XXX', '校训.txt')
C:\Users\XXX\校训.txt
校训.txt
C:\Users\XXX
  • realpath 把相对路径校训.txt 变身成完整绝对路径——「真实住址」
  • basename 取出校训.txt，dirname 取出 C:\Users\XXX——地址撕成两半
  • split 一次撕好：返回元组 ('C:\Users\XXX', '校训.txt')（print 显示为 \\ 是转义写法）
  • join 把两半拼回完整路径；pathlib 的 .name 和 .parent 给出同样结果
交互示例

pathlib 的 / 运算符：拼路径像拼积木

from pathlib import Path

p = Path('temp5') / 'subtemp2' / '校训.txt'
print(p)
print(p.name, '的上级目录是', p.parent)

输出结果：

temp5\subtemp2\校训.txt
校训.txt 的上级目录是 temp5\subtemp2
  • Path(p1) / p2 / p3 用斜杠运算符一路拼下去，不用写分隔符——Windows 上自动用 \，很优雅
  • 拼好的 p 是 Path 对象，.name、.parent 随取随用——第七章前半与后半的知识在这里会师
  • 比 path.join('temp5', 'subtemp2', '校训.txt') 更直观，也比手写字符串相加 + '\\' 安全得多
❓ 测验

path.split('C:\\Users\\XXX\\校训.txt') 的返回值是？

✏️ 填空

获取路径中最后一层名字用 path.＿＿(p)；获取所在目录的路径用 path.＿＿(p)；将多个路径拼贴到一起用 path.＿＿(p1, p2, …)。（三空填方法名，用空格隔开）

⚠️ 避坑
三个高频翻车点

①拼路径别用字符串相加：'temp5' + '/' + name 遇到忘了分隔符、多写反斜杠就翻车——用 path.join 或 pathlib 的 /，跨平台不出错；

②split 返回的是元组：想分开用得 dirname, basename = path.split(filepath) 解包，或取下标 [0]、[1]——它不是列表；

③真实路径因电脑而异：print realpath 的结果里 XXX 是你的用户名，别人的电脑不一样——考试写思路，别死记输出。
