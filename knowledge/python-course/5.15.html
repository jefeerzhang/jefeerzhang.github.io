为什么学这个

语法全对，为什么一跑还是炸了？

运行异常（Exceptions）是指代码语法正确、但在执行过程中遇到了问题——比如把字符串和整数相加、访问列表不存在的下标、除以 0。这时解释器会「抛出异常」，程序中途崩溃。和语法错误不同，异常是跑到一半才炸的。认识下面十种高频异常，学会「怎么认、怎么防」，下一节的异常处理语句才能学得顺手。

💡 打个比方
语法错误是「考前被刷」，运行异常是「上场受伤」

语法错误连考场都进不去；运行异常则是顺利进场、比赛开始后才出状况——类型不符（TypeError）像让短跑选手去游泳，查无此人（NameError / KeyError）像点名点到一个没来的人，越界（IndexError）像伸手去拿货架第 4 层的商品而货架只有 3 层，除零（ZeroDivisionError）则是数学上就注定无解的操作。每种伤有每种伤的「伤情报告」，就是报错最后一行。

交互示例

翻车现场点名：点卡片看真相

'1' + 1 为什么报 TypeError？

字符串 + 整数，类型不符
点击揭晓 ↓
+ 号对字符串是「拼接」、对整数是「加法」，'1' + 1 两种解释都讲不通，Python 直接拒绝并抛 TypeError: can only concatenate str (not "int") to str。想得到 '11' 就写 '1' + str(1)；想得到 2 就写 int('1') + 1。

s[3] 为什么越界？

s = '123' 只有 3 个字符
点击揭晓 ↓
s = '123' 的合法下标是 0、1、2——最后一个下标永远是 len-1，也就是 2。访问 s[3] 就像伸手去拿不存在的第 4 层货架，抛 IndexError: string index out of range。负下标 -1 是「最后一个」，是合法的。

import Math 为什么错？

模块名区分大小写
点击揭晓 ↓
标准数学模块叫 math（全小写），import Math 找不到对应模块，抛 ModuleNotFoundError: No module named 'Math'。同理变量名 Age 和 age 也是两个不同的变量——Python 里大小写从来不是「装饰」。

运行 dic = {'张三':1} 后执行 print(dic['李四'])，程序会抛出 ＿＿ 异常。（填异常名）

⚠️ 避坑
三个高频翻车点

①报错最后一行就是「异常类型 + 说明」：一大段 Traceback 里最先看最后一行，如 TypeError: can only concatenate str (not "int") to str——先认出异常名，再回头看它指向的代码行；

②不要用内置函数名当变量名：max=[1,2]、type='A' 之类写法会把内置函数「顶掉」，之后再调用就报 TypeError: 'list' object is not callable（max 已被列表占用）或 TypeError: 'str' object is not callable（type 已被字符串占用）；注意报的是 TypeError，不是 AttributeError；

③字符串/列表/元组的最后一个下标是 len-1：长度 3 的序列下标只到 2，遍历时写 range(len(s)) 最保险，别手滑写 range(len(s)+1)。

✅ 小结
你现在知道了

运行异常是语法正确、执行时才出现的问题。十大高频异常各有「伤情报告」：TypeError 类型不符、IndexError 越界、KeyError 键不存在、ValueError 值不合格、NameError 查无此人、AttributeError 无此属性、ZeroDivisionError 除零、OverflowError 溢出、ModuleNotFoundError 模块名错（区分大小写）、FileNotFoundError 文件找不到。看报错先看最后一行。下一节：用 try-except 把异常稳稳接住。
