为什么学这个

不循环，也能对整个列表「算总账」

想知道两个班级合并的名单？想把一份模板重复三遍？想知道全班最高分、总分、有没有人缺考？这些需求都不用写循环——Python 给列表准备了 4 个运算符和 4 个内置函数，一行搞定。它们也是下一节实战「成绩排序和统计」的主角，务必练熟。

💡 打个比方
合并班级、复印名单、点名查人

+ 像「两个班合并成大班」——产生一个新班级，原来两个班原封不动；* 像「把名单复印 N 份」；in 像「点名」——喊到名字答「到」（True），没喊到就没声（False）。而 len/max/min/sum 像体检四件套：数人数、量最高、量最矮、称总重，一次体检全知道。

核心概念

4 个运算符 + 4 个内置函数

点击下面的卡片，展开每张「速查表」：

运算符篇（+　*　in　not in）

拼接、重复、判断成员是否存在
写法作用
ls1 + ls2将两个列表相加形成新列表
ls * N列表重复 N 遍形成新列表
x in ls判断元素 x 是否在列表内，返回 True/False
x not in ls判断元素 x 是否不在列表内，返回 True/False

函数篇（len　max　min　sum）

长度、最大、最小、求和
写法作用
len(ls)求长度，返回元素数量
max(ls)求最大值（元素之间必须能互相比较，数字与字符串混放会报 TypeError）
min(ls)求最小值（元素之间必须能互相比较，数字与字符串混放会报 TypeError）
sum(ls)求和（全为数字才能求和）

🔬 试试看：in 的细节——先猜再切

print(1 in [1, 2])　→　True
# 数字 1 确实在列表里
print('2' in [1, 2])　→　False
# 类型也要匹配！字符串 '2' 不等于数字 2
课堂代码

PPT 原例：八行全跑一遍

print([1, 2]*3)              # [1, 2, 1, 2, 1, 2]
print([1, 2] + ['5', '6'])   # [1, 2, '5', '6']
print(1 in [1, 2])           # True
print('2' not in [1, 2])     # True（'2' 确实不在）
print(len([4, 5, 1, 3, 2]))  # 5
print(max([4, 5, 1, 3, 2]))  # 5
print(min([4, 5, 1, 3, 2]))  # 1
print(sum([4, 5, 1, 3, 2]))  # 15
  • 注意第 2 行：数字和字符串可以共存于一个列表，+ 只是照单全收
  • 第 4 行：not in 是 in 的反面——'2' 不在 [1, 2] 里，所以返回 True
  • 四个函数都不改变原列表，只「看」不「动」
❓ 测验

print('2' in [1, 2]) 的输出是？

✏️ 填空

sum() 要求列表中的元素＿＿才能求和。

⚠️ 避坑
三个最常见的 TypeError 现场

坑一：max/min 要求元素类型可比较。max([1, 'a']) 直接报 TypeError——数字和字符串没法比大小，混合类型列表先想清楚再求极值。

坑二：sum 要求全为数字。sum([1, 2, '3']) 报错——'3' 是字符串，加不动。

坑三：+ 两边都必须是列表。[1, 2] + 3 报错！想追加元素要写成 [1, 2] + [3]，或者用下一节之前学过的 append。

✅ 小结
你现在知道了

+ 拼接、* 重复都生成新列表，原列表不动；in / not in 判断成员且类型要匹配。len 求长度、max/min 求极值（类型须可比较）、sum 求和（须全为数字）。下一节：列表的五个常用方法，其中 sort 是重中之重。
