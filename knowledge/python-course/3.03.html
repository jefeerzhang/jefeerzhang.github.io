为什么学这个

想精确取出某一个字符？靠索引

上一节我们能把一整段文字装进 Python 了，但真实任务往往是「取出身份证的第 17 位」「取出名字的第一个字」。由于字符串是一个有序字符序列，每个字符都站在自己的位置上——只要报出位置，就能精确定位。这个反映字符所处位置的序号，就叫索引（Index）。本节是下一节切片、以及 3.05 身份证实战的直接地基。

💡 打个比方
电影院的一排座位，两种数法

字符串像电影院的座位排：从入口顺着数是第 0、1、2…座（正向递增）；从出口倒着数是倒数第 1、2…座（反向递减）。同一个座位有两种叫法——比如最后一排的位子，正向叫 5 号，反向叫 −1 号。数法不同，指的都是同一把椅子。

核心概念

正向递增从 0 起，反向递减从 -1 起

  • 正向递增：以字符串最左端字符标记为 0，依次向右加 1
  • 反向递减：以最右侧字符标记为 -1，依次向左减 1
  • 取单个字符的写法：字符串名[索引]，如 s[0]、s[-1]
  • 两种索引可以换算：对长度为 L 的字符串，正向 i 对应反向 i − L

以 s = 'Python' 为例，点击任意字符，看看它的两种索引取值：

上排：正向索引 0 → 5 下排：反向索引 -6 → -1
👆 点击上面的任意字符试试
s = 'Python'
print(s[0])    # P   正向第 0 个
print(s[5])    # n   正向最后一个
print(s[-1])   # n   反向第 1 个，也是最后一个
print(s[-6])   # P   反向数到最后，正是第 0 个字符

同一个字符能被两种索引取到：s[0] 和 s[-6] 都是 P，就像同一把椅子从两头数有两个编号。

❓ 测验

s = 'Python'，s[-2] 的值是？

✏️ 填空

正向索引以最左端字符标记为＿＿开始。（填数字）

⚠️ 避坑
三个最容易踩的坑

① 正向从 0 开始，不是从 1 开始——「第 1 个字符」的索引是 0，写 s[1] 拿到的是第二个字符。② -1 是最后一个字符本身，不是「不存在的第 -1 个位置」；倒数第几个就从 -1 往左数。③ 单字符索引越界会报错：长度为 6 的 'Python'，s[6] 或 s[-7] 都直接抛 IndexError。顺带预告：切片越界反而不报错（有多少取多少），下一节讲。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 字符串索引（正向从 0 递增、反向从 -1 递减）。请：1）以字符串 'python' 为例画一张双排索引对照说明（文字版即可）；2）出 5 道 s[?] 求值题考我（正负索引混着出，含一道故意越界的），等我作答后公布答案和讲解；3）解释 s[0] 和 s[-len(s)] 为什么取到同一个字符。
🔧 试一试：先猜后验，索引速练（5 分钟）
  1. 交互模式输入 s = 'Python'。
  2. 输入 s[0] 之前先心里猜答案，再回车验证。
  3. 依次试 s[-1]、s[-6]、s[5]，每次都先猜后验。
  4. 最后输入 s[6]，亲眼看一次 IndexError 长什么样——以后遇到就不会慌了。
✅ 小结
你现在知道了

索引是字符在有序序列中的位置号：正向从 0 递增、反向从 -1 递减，用 s[索引] 取单个字符；两种索引殊途同归；单字符越界报 IndexError。下一节：一次取一段——更强大的字符串切片！
