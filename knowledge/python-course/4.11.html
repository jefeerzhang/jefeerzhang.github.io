为什么学这个

想让运算结果「直接写回原集合」？

上一节的四大运算（& - | ^）都会产生新集合，原集合保持不变。但很多时候我们就是想把结果直接覆盖回 st1——这节先讲三个 *_update 方法，最后再补一个同样就地修改的 st1.update(st2)。它们还有个共同的「怪脾气」：返回值是 None，考试特别爱考。

💡 打个比方
算完抄新纸 vs 算完撕账本重写

普通集合运算像「算完抄在新纸上」——原账本一个字都不动；*_update 方法像「算完直接把账本撕了重写」——账本还是那个账本（内存里的对象没变），内容已经被运算结果覆盖了。

核心概念

三个 *_update：运算 + 覆盖，一步到位

方法作用等价写法
st1.intersection_update(st2)取交集，并把结果覆盖到 st1st1 = st1 & st2
st1.difference_update(st2)取差集，并把结果覆盖到 st1st1 = st1 - st2
st1.symmetric_difference_update(st2)取对称差（并集去掉交集），并把结果覆盖到 st1st1 = st1 ^ st2
st1.update(st2)把 st2 的元素并进 st1（就地并集，不去重以外的额外操作）st1 = st1 | st2
  • 就地修改：把运算结果直接覆盖回 st1，思路类似列表的 sort()
  • 返回值都是 None——打印方法调用本身，只能看到 None
  • 等价写法 st1 = st1 & st2 效果相同，考试两种都要会
ST8 = {1, 2, 3}
print(ST8.intersection_update({2, 3, 4, 5}))
# None　→　方法的返回值是 None！
print(ST8)
# {2, 3}　→　但 ST8 已被覆盖成交集
ST8 = ST8 & {3, 4, 5}
print(ST8)
# {3}
交互示例

🔀 两种写法，殊途同归

同一个任务「把 ST8 覆盖为它与 {2, 3, 4, 5} 的交集」，两种写法结果一样：

ST8 = {1, 2, 3}
ST8.intersection_update({2, 3, 4, 5})
print(ST8)
# {2, 3}

方法直接改 ST8 本尊，返回值 None 被丢弃。

ST8 = {1, 2, 3}
ST8 = ST8 & {2, 3, 4, 5}
print(ST8)
# {2, 3}

先算出新集合，再让 ST8 这个名字指向它。

❓ 测验

ST8 = {1, 2, 3}，print(ST8.intersection_update({2, 3, 4, 5})) 的输出是？

✏️ 填空

st1.difference_update(st2) 取差集并覆盖回 st1，等价于 st1 = st1 ___ st2。（填一个运算符号）

⚠️ 避坑
返回 None！千万别把 None 赋回去

经典错误：st1 = st1.intersection_update(st2)——方法已经就地改好了 st1，却把返回值 None 又赋给 st1，集合当场变成 None，后面再用就报错。

另一个高频考点：上一节「& - | ^ 产生新集合、原集合不变」与这一节「*_update 就地覆盖、返回 None」的区别，考试经常拿来对比。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 集合的三个就地更新方法：intersection_update、difference_update、symmetric_difference_update。请：1）对比普通集合运算（产生新集合、原集合不变）和 *_update（就地覆盖、返回 None）的区别；2）出 5 道「给代码猜输出」的题，专考「返回 None」和「别把 None 赋回去」这个坑；3）讲讲这种设计为什么和列表的 sort() 是一个思路。
🔧 试一试：盯住 None 的出场顺序（5 分钟）
  1. 运行 ST8 = {1, 2, 3}，再 print(ST8.intersection_update({2, 3, 4, 5}))——先看到 None。
  2. 紧接着 print(ST8)，确认集合已变成 {2, 3}——记住这个输出顺序：先 None，后 {2, 3}。
  3. 继续 ST8 = ST8 & {3, 4, 5} 和 print(ST8)，得到 {3}。
  4. 试一下反面教材：st = st.intersection_update({1}) 再 print(st)，看看它是不是变成了 None。
✅ 小结
你现在知道了

三个 *_update 方法 = 运算 + 覆盖回 st1，等价于 st1 = st1 □ st2（□ 为对应运算符号）；返回值全是 None，千万别再赋回去；「产生新集合」与「就地更新」的区分是考试高频。下一节：集合的函数与判断方法，给集合做「体检」。
