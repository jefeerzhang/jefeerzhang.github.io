为什么学这个

建字典的两条路：手写一对对，还是让 dict() 帮你配对

认识了字典的四大特性，接下来就是把它造出来。创建字典主要有两种方式：直接创建——用大括号 {} 把键值对一对对写进去；dict() 函数——把参数名和参数值自动配成键值对。两种都要会，作业里手写数据用第一种，函数转字典、建空字典会用到第二种。还记得 4.08 里提到过的 {} 吗？它其实是空字典、不是空集合——空字典的专属写法这一节一并搞定。

💡 打个比方
手写花名册 vs 填表生成花名册

直接创建像「手写花名册」：翻开本子，自己一笔一笔写下「姓名 → 张三」「年龄 → 20」，想写几对写几对。dict(a=1, b=2) 像「填表生成花名册」：你在表格的抬头处报名字（a、b、c），系统自动把它们登记成键——注意，报名字时不用带引号，登记进册子后自动变成字符串键。

核心概念

两种创建方式，四种常见写法

  • 直接创建：用大括号 {} 直接包含键值对，键冒号值、对间逗号，是最直观的方式
  • dict() 函数：通过给定参数和参数值，将其配对形成键值对——参数名自动变成字符串键
  • {} 与 dict() 都能创建空字典（呼应 4.08：单独一个 {} 是空字典，不是空集合）
  • 键只要求不可变，不要求是字符串——数字 {1:2} 完全合法，还能和字符串键混用

交互示例

🔬 两种创建方式现场演示

大括号手写键值对（含空字典两种写法）

DC1 = {}
DC2 = dict()
print(DC1, DC2)          # 空字典：两种写法等价

DC3 = {1:2, '姓名':'张三', '年龄':15, '语文':80}
print(DC3)

输出结果：

{} {}
{1: 2, '姓名': '张三', '年龄': 15, '语文': 80}

注意 DC3：数字键 1 和字符串键 '姓名' 混用也没问题——键只要求不可变。

dict(参数名=参数值)，自动配对成键值对

DC4 = dict(a=1, b=2, c=3)
print(DC4)

输出结果：

{'a': 1, 'b': 2, 'c': 3}

看清楚：写的是 a=1，输出的是 'a': 1——参数名 a 被自动转成了字符串键 'a'。

❓ 测验

dict(a=1, b=2, c=3) 生成的键是什么？

✏️ 填空

创建空字典可以用 {} 或 ___。（填一种写法）

⚠️ 避坑
dict() 的参数名有「标识符」规矩

dict(a=1) 里的 a 本质是一个参数名，要遵守标识符规则：不能以数字开头、不能带空格和连字符。dict(2a=1)、dict(my key=1) 都会报语法错。键里有特殊字符的需求，请老老实实用直接创建 {'2a':1, 'my key':1}。

另一个常见误解：以为字典的键必须是字符串——错，{1:2} 用数字当键完全合法。键只要求不可变，不要求是字符串。

你现在知道了

创建字典两条路：直接创建（{} 手写键值对）和 dict() 函数（关键字参数自动配对，参数名转成字符串键）；空字典用 {} 或 dict()。键只要求不可变，数字、字符串、元组都行。下一节：建好的字典怎么取值——[] 与 get()，以及 keys / values / items 三视图。
