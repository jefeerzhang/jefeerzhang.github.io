为什么学这个

Person 写好的代码，Student 难道要再抄一遍？

上一节我们把细节藏进了私有属性，这一节解决另一个大问题——复用。现实里「学生」首先是「人」：有姓名、有年龄、会自我介绍。如果 Student 类把这些全部重写一遍，代码就重复了。继承就是模拟这种分类关系的机制：一个类可以继承另一个类的属性和方法——被继承者叫父类（Superclass），继承者叫子类（Subclass）。子类自动拥有父类的一切，再补上自己独有的部分即可。

💡 打个比方
继承像「继承父母的基因」：先全盘接收，再活出自己

我们天生继承父母的基因——外貌、血型这些不用自己努力就拥有，正如子类自动拥有父类的属性和方法；但我们同时也有自己独特的性格和技能（比如只有你会弹吉他），正如子类可以新增自己的属性和方法，实现个体的差异化扩展。而 super() 就像回头对父母说一句「这份底子我先接住」——在搭建自己的部分之前，先把父类的构造跑完。

核心概念

继承怎么写：括号里装父类，super() 找父类

  • 继承语法：把父类写在子类名称后的括号里——class 子类(父类):，子类就自动拥有父类的属性和方法
  • 新增成员：子类里新定义的属性和方法是父类没有的，比如 Student 独有的 major 和 study()
  • super() 按 MRO 找父类：需要调用父类的方法时，用 super() 顺着方法解析顺序去找父类，如 super().__init__(name, age)
  • 重写 __init__ 的铁律：子类一旦重写了 __init__，父类的 __init__ 就不会自动执行——必须在开头写 super().__init__()，否则父类的属性没有被创建，后面一用就报错
  • 父类方法直接用：子类没重写的方法（如 introduce()）可以拿来直接调用，不用重抄一遍

课堂代码

PPT 原例：Student 继承 Person

class Person:                       # 父类
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f'我叫{self.name}，今年{self.age}岁')

class Student(Person):              # 子类：Student 继承 Person
    def __init__(self, name, age, major):
        super().__init__(name, age)  # 调用父类的初始化方法
        self.major = major           # 子类新增属性

    def study(self):                 # 子类新增方法
        print(f'{self.name}正在学习{self.major}')

s = Student('王五', 19, '经济学')
s.introduce()
s.study()

输出结果：

我叫王五，今年19岁
王五正在学习经济学
  • s.introduce()：Person 里定义的方法，Student 对象直接就能用——这就是继承带来的复用
  • super().__init__(name, age)：把 name、age 交给父类的初始化方法去处理，子类只管新增 major
  • s.study() 里能用到 self.name——这个属性虽然由父类创建，但子类方法同样访问得到
❓ 测验

Student 重写了 __init__，如果忘写 super().__init__(name, age)，执行 s.introduce() 会发生什么？

✏️ 填空

继承的写法：class 子类(＿＿):，子类自动拥有＿＿的属性和方法；子类重写 __init__ 后，第一句应写 ＿＿(name, age) 来调用父类的初始化方法。（第一空填「父类」或「Superclass」，第二空填完整调用）

⚠️ 避坑
三个高频翻车点

①忘写 super().__init__()：子类重写 __init__ 后父类属性没初始化，调用时报 AttributeError: 'Student' object has no attribute 'name'——实验台里有翻车演示，亲手点一下印象更深；

②以为继承会带上私有属性：父类的私有属性 __xxx 会被「名称改写」成 _父类名__xxx（子类里写的 self.__xxx 则会被改写成 _子类名__xxx，名字对不上），所以子类方法里直接写 self.__xxx 访问不到——继承的是「公开接口」，私有细节仍锁在父类里；

③括号里写错成对象：class Student(person):（小写变量）不行，括号里要写类名 Person——继承的是类与类之间的关系。

✅ 小结
你现在知道了

继承是模拟分类关系的机制：父类（Superclass）写在子类（Subclass）名称后的括号里，子类自动拥有父类的属性和方法，并可以新增自己的成员实现差异化扩展；调用父类方法用 super()，尤其是重写 __init__ 后必须先 super().__init__() 把父类属性初始化好。下一节：一个子类能不能同时继承两个父类？——多重继承。
