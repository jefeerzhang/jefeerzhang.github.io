为什么学这个

函数调用自己？听起来玄，其实是「把大问题拆成同款小问题」

有的问题天生是「套娃结构」：求 5! 可以变成 5 × 4!，求 4! 又可以变成 4 × 3!……每一层都是同一种问题、规模更小。这种「在函数定义中调用自己」的函数叫递归函数——一些特殊问题用它求解比循环更简单方便。但递归也是本章最容易翻车的地方：不设好停止条件，程序会一层层拆下去直到崩溃。这一节先把「两要素」这副骨架搭好，后三节（执行逻辑、阶乘、字符串逆序）都是往骨架里填肉。

💡 打个比方
递归像「俄罗斯套娃」：一层层打开是拆解，最小的娃娃打不开就是终点

拿到一个大套娃，你想数清一共几层：打开 5 号，里面是 4 号；打开 4 号，里面是 3 号……一直开到最小的实心娃娃——它打不开，数数到此为止（这就是基项）。然后你手里攥着从最小到最大的娃娃往回一个一个合上、逐层计数。层层打开 = 问题拆小，实心娃娃 = 停止点。下一节你还会在「食堂传餐盘」的例子里看到同样的过程：往下传单子是拆解，答案往回端是返回——两个比方说的是同一件事。

核心概念

递归函数必须满足两个特征

  • 什么是递归函数：在函数定义中调用自己的特殊函数——一些特殊问题（如阶乘、斐波那契数列）用递归求解更简单方便
  • 特征① 递归链条：后一项的值依赖前一项或前几项——如 F(n) = F(n-1) × n、F(n) = F(n-1) + F(n-2)。「要求 F(n)，先去要 F(n-1)」，问题就这样一层层变小
  • 特征② 基项：存在一个或多个不需要再次递归的实例（停止于此）——如 0! = 1，是整条链条的起点答案，不必再拆
  • 注意事项①：必须有明确的基项来停止递归，否则无限拆解、程序报错
  • 注意事项②：递归链条内调用函数的参数形式一定要有变化（如 n 变成 n-1），保证问题不断向基项靠近
  • 注意事项③：递归函数通常与分支语句 if…else… 搭配使用——if 分支处理基项，else 分支处理递归链条

🔬 套娃演示台：5 层套娃，先「一层层打开」，再「一层层合上」

点「下一步」开始拆套娃……
课堂代码

把两要素「长」在代码上

def factorial(n):
    if n == 0:
        return 1                # 基项：实心娃娃，不再拆
    else:
        return n * factorial(n-1)   # 递归链条：F(n) = F(n-1) × n，参数 n 变小

print(factorial(5))

输出结果：

120
  • if n == 0: return 1 对应基项——0! = 1 是数学上现成的答案，不需要再调用自己
  • else: return n * factorial(n-1) 对应递归链条——F(n) = F(n-1) × n，每次调用参数从 n 变成 n-1（有变化！）
  • if…else… 是递归的标配骨架：if 守住停止点，else 负责继续拆——两要素各占一个分支
交互示例

换个链条看看：F(n) = F(n-1) + F(n-2)

def fib(n):
    if n == 1:
        return 1                # 基项一
    if n == 2:
        return 1                # 基项二（依赖前两项，需要两个基项）
    else:
        return fib(n-1) + fib(n-2)   # 链条：F(n) = F(n-1) + F(n-2)

print(fib(7))

输出结果：

13
  • 链条变成了「依赖前两项」：fib(7) = fib(6) + fib(5)，一路拆下去
  • 因为每层要「前两项」，基项也得有两个：fib(1)=1 和 fib(2)=1——基项的数量跟着链条的形式走
  • 数一数：1, 1, 2, 3, 5, 8, 13——第 7 项是 13，这就是斐波那契数列
❓ 测验

下面哪一条说明 return n * factorial(n-1) 这个递归链条是「合格」的？

✏️ 填空

递归函数是在函数定义中＿＿的特殊函数；它必须满足两个特征：＿＿（后一项依赖前一项或前几项）和＿＿（不需要再次递归的停止实例）；代码上通常与 ＿＿…else… 分支搭配使用。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①只有链条没有基项：递归会一层层拆下去永不停止，最后抛 RecursionError: maximum recursion depth exceeded——「套娃永远打不完」；

②链条参数一成不变：写成 return n * factorial(n)，参数没变化，问题规模不缩小，同样拆不到基项；

③基项位置放错：链条是「依赖前一项」（如阶乘）却只想着依赖前两项的写法，或者把基项写在了 else 后面永远执行不到——先想清楚「拆到哪一层必须停」，再动笔。

✅ 小结
你现在知道了

递归函数 = 在定义中调用自己；两要素缺一不可：递归链条（后项依赖前项，如 F(n)=F(n-1)×n）+ 基项（停止点，如 0!=1）；参数必须有变化、代码常配 if…else…。下一节把 factorial(5) 放进「食堂传餐盘」的实验台，亲眼看看递推与回溯的完整执行过程。
