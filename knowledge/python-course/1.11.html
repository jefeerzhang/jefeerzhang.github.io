为什么学这个

你天天用的这门语言，最初只是个「假期项目」？

从这一节起，我们正式走近 Python 本尊。了解一门语言的出身与成长史，不只是听故事——它能帮你理解这门语言为什么是现在这个样子，也常常出现在课程作业与考试的选择题里：

  • 考试常问：Python 之父是谁？Python 诞生于哪一年？哪个版本引入了重要特性？
  • 理解 Python 的家谱，你才能明白为什么今天大家都在用 Python 3（后面 1.14 节细讲）。
  • 看到「一门语言从兴趣项目成长为 AI 时代霸主」，你会对「持续迭代」这件事更有感觉——写代码如此，学习也如此。
💡 打个比方
一个圣诞假期的兴趣项目，结果改变了世界

Python 的出身，特别像那种「寒假闲着没事做，干脆搞个小发明」的同学：1989 年底，Guido 只是想在假期里做点有趣的事，顺手构思一门新语言。谁也没想到，这个「打发时间」的项目一迭代就是三十多年，如今支撑着人工智能、数据分析等前沿领域。

这里有两层启发：第一，好点子 + 持续迭代，小项目也能长成参天大树；第二，Guido 并不是从零发明——他是站在 ABC 语言的基础上「扬长避短」。学习编程也一样，不必追求一开始就完美，先做出来，再一点点变好。

核心概念

Python 的前世今生：一条时间线看懂

  • Guido van Rossum（吉多·范罗苏姆）：Python 的创始人与长期核心架构师，被社区亲切地称为「Python 之父」（Benevolent Dictator For Life，仁慈的终身独裁者）。
  • 继承者身份：Python 的设计继承了 ABC 语言的可读性与易用性，同时修复了 ABC 的诸多不足（比如扩展性差的问题）。
  • 名字由来：与蟒蛇无关！Guido 是英国喜剧团体 Monty Python（蒙提·派森）的粉丝，于是借用了这个名字。不过后来 Logo 设计成了两条缠绕的蟒蛇，也算将错就错。
1989 年 · 起源构思
圣诞节期间，Guido 为了打发假期时间，开始构思一种新的脚本语言——作为 ABC 语言的继承者，希望它既好读又好用。
1991 年 · 首个版本
发布 Python 0.9.0，已经包含核心数据类型、函数以及异常处理机制，语言的基本骨架就此搭成。
2000 年 · 版本迭代
Python 2.0 发布，引入垃圾回收机制和列表推导式等新特性，语言功能日趋完善，社区生态迅速壮大。
2020 年 · 生态成熟
Python 2 停止维护，Python 3 成为绝对主流，在人工智能等领域占据统治地位。
🐍 冷知识：「Python」取自喜剧团体 Monty Python，而不是大蟒蛇——但它的 Logo 恰恰是两条蟒蛇，成了编程界一个著名的「美丽的误会」。
💡 观察时间线：从 1989 年的假期构思，到 1991 年的 0.9.0，再到 2000 年的 2.0 与 2020 年的生态成熟——三十多年里，Python 靠一次次「小步快跑」的迭代走到了今天。
❓ 测验

✏️ 填空

1989 年圣诞节，Guido 为了打发时间，开始构思一门新的脚本语言，作为 ＿＿语言的继承者。请在框里填上这门语言的名字：

⚠️ 避坑
「Python = 蟒蛇」？名字的由来别答错

考试和作业里最容易错的一点：Python 这个名字来自英国喜剧团体 Monty Python，与蟒蛇无关。Guido 是这个喜剧团体的粉丝。虽然官方 Logo 画的是两条蟒蛇，但那是后来的视觉设计，不是命名原因。

另外注意时间线上的两个版本节点容易混淆：2000 年发布的是 Python 2.0（引入垃圾回收、列表推导式），而 2020 年是 Python 2 停止维护的年份——一个是「诞生」，一个是「退役」，方向刚好相反。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了 Python 的诞生与发展史（1989 年 Guido van Rossum 圣诞节构思、1991 年发布 0.9.0、2000 年发布 2.0、2020 年 Python 2 停止维护）。请：1）用编年体的方式帮我梳理一遍并补充 2 个有意思的冷知识；2）解释 Python 为什么能从一门假期兴趣项目成长为 AI 时代的主流语言；3）出 2 道单选题考我，等我作答后再公布答案。
🔧 试一试：让你的电脑报出 Python 的「出生信息」（3 分钟）
  1. 按 Win + R 输入 cmd 打开命令行，输入 python 回车，进入交互模式。
  2. 看输出首行，例如 Python 3.11.5——这就是你电脑上 Python 的版本号，相当于它的「身份证」。
  3. 对照上面的时间线想一想：这个版本号远大于 3.0，说明它诞生在 2020 年生态成熟之后，属于 Python 3 家族。
  4. 输入 exit() 退出交互模式。下一节我们要看看：这门语言的「规章制度」是怎么制定的。
✅ 小结
你现在知道了

Guido van Rossum 是 Python 之父：1989 年圣诞节他为打发时间构思了这门语言，作为 ABC 语言的继承者；1991 年发布 0.9.0，2000 年发布 2.0（引入垃圾回收和列表推导式），2020 年 Python 2 退役、Python 3 成为绝对主流。名字取自喜剧团体 Monty Python，与蟒蛇无关。下一节，我们聊聊 Python 社区的「立法机制」——PEP。
