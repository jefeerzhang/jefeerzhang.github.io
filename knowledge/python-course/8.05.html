为什么学这个

类是图纸，对象才是能用的「活物」

上一节你用 class、__init__、self 三件套画好了 Student 这张「图纸」——但图纸不能上课、不能考试。这一节要做的就是把图纸造出真东西：一行 stu1 = Student('张三', 85)，一个有名字、有成绩、会自我介绍的学生对象就诞生了。造出来之后怎么问他的名字、怎么给他改成绩、怎么让他开口说话？——对象名.属性名 和 对象名.方法名()，这就是本节的全部主旨，也是后面所有节的日常操作。

💡 打个比方
类像「饼干模具」，对象是一块块压出来的饼干

stu1 = Student('张三', 85) 就是拿模具压一块饼干——这个动作叫「实例化」。压下去的一瞬间，__init__ 自动执行，把「张三」和「85」刻进这块饼干（属性初值）。同一副模具可以压第二块：stu2 = Student('李四', 55)——两块饼干形状相同、味道各异，你在 stu1 上咬一口，stu2 完好无损。

核心概念

实例化 + 点号访问，两步走

  • 创建对象（实例化）：向初始化方法 __init__ 提供所需的数据，生成一个具体实例。语法：对象名 = 类名(参数)，参数要和 __init__ 的形参对上号
  • __init__ 是自动调用的：写 stu1 = Student('张三', 85) 这一行时，Python 自动执行 __init__，把 '张三' 交给 self.name、85 交给 self.score——你从不需要手写 stu1.__init__(...)
  • 访问属性：对象名.属性名——既能读（print(stu1.score)）也能改（stu1.score = 92）
  • 调用方法：对象名.方法名()——括号不能省，方法是在「让对象做一件事」
  • 每个对象都是独立的：实例化几次就有几个对象，各自的属性各自保存、互不影响

🔬 实例化实验台：按 PPT 流程点按钮，观察两个对象互不影响

先点「stu1 = Student('张三', 85)」创建第一个对象——注意观察：这一行一执行，__init__ 就自动跑起来了。
课堂代码

PPT 原例：创建两个 Student 对象并访问成员

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def introduce(self):
        print(f"我是{self.name}，我的成绩是{self.score}分")

    def is_pass(self):
        return self.score >= 60

# 创建对象（实例化）：给构造函数提供所需的数据
stu1 = Student('张三', 85)
stu2 = Student('李四', 55)

# 通过 对象名.属性名 访问属性
print(stu1.name)
print(stu1.score)

# 通过 对象名.属性名 修改属性值
stu1.score = 92
print(stu1.score)

# 通过 对象名.方法名() 调用方法
stu1.introduce()
print(stu1.is_pass())

输出结果：

张三
85
92
我是张三，我的成绩是92分
True
  • stu1 = Student('张三', 85) 执行的瞬间，__init__ 被自动调用——'张三' 传给 name、85 传给 score
  • stu1.score = 92 直接用点号给属性赋新值，再读就是 92 了
  • stu1.is_pass() 返回 self.score >= 60 的判断结果，92 分 → True
  • stu2 完全没被改动，print(stu2.score) 依然是 55——两个对象互不影响
❓ 测验

接 PPT 原例，执行 stu1.score = 92 之后，print(stu2.score) 的输出是？

✏️ 填空

把类变成具体对象的过程叫＿＿，语法是 对象名 = 类名(参数)；对象生成后，通过 对象名.＿＿名 和 对象名.方法名() 来访问和操作对象；调用方法时，方法名后面的＿＿不能省。（三空用空格隔开）

⚠️ 避坑
三个高频翻车点

①拿类名直接访问实例属性：Student.name 报 AttributeError——name 是 __init__ 里挂在对象身上的，必须先实例化再访问；

②调用方法漏了括号：print(stu1.introduce) 输出的是「这是一个方法」的信息而不是自我介绍——方法要加括号才真正执行；

③以为改了一个对象会影响另一个：stu1.score = 92 只改 stu1 的——但如果你改的是「类属性」（下一节内容），那就真的会一改全改。

✅ 小结
你现在知道了

创建对象（实例化）就是向构造函数提供所需数据、生成一个具体实例：stu1 = Student('张三', 85) 这一行自动触发 __init__；对象生成后用 对象名.属性名 读改属性、对象名.方法名() 调用方法；每次实例化都得到一个独立对象，互不影响。下一节：属性还分「实例属性」和「类属性」两种，规则大不相同。
