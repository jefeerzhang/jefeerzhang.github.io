为什么学这个

清单写好了，还想再加几样？

字符串是「石碑」，写完就不能加字；列表是「白板」，想加就加。往列表里加元素有三种常用方法：append、insert、extend。它们都直接改变原列表——这正是上一节说的「列表可变」最直接的体现。

💡 打个比方
整箱上架、插队、拆箱倒货

append 像「整箱上架」：一次一件，放到货架最末端；insert 像「插队」：指定一个位置硬塞进去，后面的人集体往后挪；extend 像「拆箱倒货」：把包裹里的东西逐个倒进货架，而不是把整包扔上去。

核心概念

三个增员方法

方法作用
ls.append(M)向列表 ls 的最后一个位置添加一个元素 M
ls.insert(i, M)向列表 ls 的第 i 个位置添加一个元素 M
ls.extend(iter)向列表 ls 最后面扩充添加可迭代对象 iter（列表、元组、字符串）
L5 = [1, 2]
L5.append(4)         # [1, 2, 4]
L5.insert(2, 'ABC')  # [1, 2, 'ABC', 4]
L5.extend('DE')      # [1, 2, 'ABC', 4, 'D', 'E']
print(L5)

输出结果：

[1, 2, 'ABC', 4, 'D', 'E']
  • insert(2, 'ABC') 是插到索引 2 的位置，原来的 4 被往后挤
  • extend('DE') 把字符串拆开成 'D'、'E' 两个元素，逐个加到末尾
  • 三个方法都在原地修改 L5，列表越变越长
🔬 交互示例

append vs extend 关键对决

L = [1, 2]
L.append('DE')
print(L)

输出结果：

[1, 2, 'DE']

整箱上架——'DE' 整个字符串被当成一个元素塞到末尾，列表只多 1 个元素。

L = [1, 2]
L.extend('DE')
print(L)

输出结果：

[1, 2, 'D', 'E']

拆箱倒货——字符串被拆开，'D'、'E' 作为两个元素逐个加入，列表多 2 个元素。

❓ 测验

L = [1, 2]，执行 L.append([3, 4]) 后，L 是？

✏️ 填空

向列表第 i 个位置插入元素用＿＿方法。

⚠️ 避坑
append 只认「一个元素」，方法都返回 None

append 一次只加「一个元素」——哪怕传的是列表 [7, 8]，也会整体塞入变成嵌套（L 多 1 个元素），不会拆开；想拆开请用 extend。insert 的位置 i 超过列表长度时不会报错，等效于加到末尾。

最重要的坑：append / insert / extend 都直接改变原列表、返回 None。写成 L = L.append(4) 反而会把 L 变成 None！列表是可变的，原地修改即可，不需要（也不能）接收返回值。

✅ 小结
你现在知道了

append(M) 末尾加一个元素；insert(i, M) 在第 i 个位置插入；extend(iter) 把可迭代对象拆开逐个扩充到末尾。记住口诀：append 整体塞、extend 拆开加；三者都直接改变原列表、返回 None——列表可变，原地增员。下一节：把元素从列表里删掉。
