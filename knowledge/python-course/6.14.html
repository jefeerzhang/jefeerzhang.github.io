为什么学这个

排序听谁的？——按大小排谁都会，「按规则排」才见真章

3.20 学过列表的 sort() 和 reverse() 方法，但它们只会按「天然大小」排。可实际问题常常是：按离某个数的远近排、按成绩排姓名、按字典的值排键……这时就需要 sorted() 的 key 参数：把「按什么排」写成一条规则（还是 lambda），递给 sorted 执行。作业第 5 题「按成绩从低到高输出学生名单」，就是这一节的主场。

💡 打个比方
sorted 像「运动会入场排序」，key 是「检录员手里的排序依据」

运动员排队入场，怎么排？按身高？按学号？按离主席台的远近？sorted 负责排，但排法取决于检录标准——你把「每人报个数」（key 函数）交给检录员，他就按这个数从小到大排。key=lambda n: abs(3-n) 就是告诉检录员：「每人报一下自己离 3 号位有多远，按报数排队」——于是 3 号第 1 个，2 号、4 号紧随其后。reverse=True 则是「反过来报，从大到小排」。

核心概念

sorted(排序对象, key=匿名函数, reverse=False)

  • sorted 是高阶函数：对可迭代对象排序，返回一个新列表（原对象不动——这是它和列表方法 sort() 的区别，sort() 是原地修改、返回 None）
  • key 参数：指定按什么规则排——key 函数对每个元素求一个「排位值」，sorted 按排位值从小到大排；key 只影响排序依据，不影响输出内容（输出的还是原元素）
  • reverse 参数：默认 False 升序；reverse=True 降序（衔接 3.20 列表的 sort / reverse 方法）
  • 对字典排序：字典不能直接按「值」排，先用 items() 把键值对转成元组列表，再用 key=lambda x: x[1] 让「值」当排位值——作业第 5 题的核心套路

🔬 「离 3 越近越靠前」实验台：看 key=abs(3-n) 怎么给 [1, 2, 3, 4, 5] 排队

点上方按钮开始演示……
课堂代码

PPT 原例：按「与 3 的距离」排序

ls = [1, 2, 3, 4, 5]
st = sorted(ls, key=lambda n: abs(3-n))
print(st)

输出结果：

[3, 2, 4, 1, 5]
  • key 函数给每个元素「报数」：1 报 |3-1|=2、2 报 1、3 报 0、4 报 1、5 报 2
  • sorted 按报的数从小到大排：3（报 0）→ 2、4（都报 1，谁先在前面谁先）→ 1、5（都报 2）
  • 注意：输出的还是原元素 [3, 2, 4, 1, 5]，不是距离值 [0, 1, 1, 2, 2]——key 只是「排位依据」
交互示例

作业第 5 题完整演示：字典按成绩排序

dic1 = {'张三': 85, '李四': 92, '王五': 79}

# items() 把字典转成键值对元组：[('张三', 85), ('李四', 92), ('王五', 79)]
items = sorted(dic1.items(), key=lambda x: x[1])
print(items)

输出结果：

[('王五', 79), ('张三', 85), ('李四', 92)]
  • 每个元素是元组 ('张三', 85)，x[0] 是姓名、x[1] 是成绩
  • key=lambda x: x[1]：让成绩当排位值，默认升序 → 79、85、92，即按成绩从低到高
  • 想从高到低？加 reverse=True → [('李四', 92), ('张三', 85), ('王五', 79)]——正好是「成绩单」的顺序
  • 作业第 5 题就是这套写法：sorted + items() + lambda x: x[1]（+ reverse 看题目要求），下面「试一试」必须亲手演练
❓ 测验

sorted([10, 20, 30, 40], key=lambda n: abs(30-n)) 的输出是？

✏️ 填空

sorted 中用 ＿＿ 参数指定按什么规则排；想降序要写 ＿＿；字典要先调用 ＿＿() 转成键值对元组列表，再用 lambda x: ＿＿ 让值当排序依据。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①sorted 与 sort() 用混：sorted(ls) 返回新列表、原列表不动；ls.sort() 是原地修改、返回 None——写成 ls = ls.sort() 会把列表变成 None；

②字典直接 sorted 按值排：sorted(dic1) 只会按键排（得到姓名列表），想按成绩排必须先 items() 再 key=lambda x: x[1]；

③x[0] 和 x[1] 下标记反：元组里 x[0] 是键（姓名）、x[1] 是值（成绩）——按成绩排序却写了 x[0]，排出来的是按姓名的字典序。

✅ 小结
你现在知道了

sorted(对象, key=匿名函数, reverse=False) 返回排好序的新列表；key 指定「按什么排」，输出的仍是原元素；reverse=True 降序；字典按值排序的套路是 items() + key=lambda x: x[1]。至此 lambda 的三大用武之地（map、filter、sorted）集齐——接下来进入本章压轴主题：递归。
