为什么学这个

这些单词，Python 不许你占用

2.03 讲命名规则时提到过一条「禁用保留字」。什么是保留字？

  • 定义：保留字（也叫关键字，Keyword）是 Python 预先定义的、具有特殊含义的单词。
  • 用途：它们是 Python 语法的「骨架」——控制流程、定义函数、处理异常都靠它们指挥。
  • 规矩：因此不能用作变量名、函数名等标识符——你一占用，Python 就分不清你说的是「语法指令」还是「变量」了。
  • 数量：Python 3 共 35 个关键字（不同版本数量可能有差异）。
💡 打个比方
保留字 = 交通信号灯的红绿黄

红灯停、绿灯行、黄灯等——这三种颜色是交通系统专属指令，人人都懂、必须遵守。你不能给自家电动车装一个红灯，然后跟交警说「这只是我车的名字」。if、for、True 这些保留字就是 Python 的红绿黄灯——系统专属，含义固定，谁也不能拿去当变量名。

核心概念

控制流

if, elif, else, for, while, break, continue
控制程序执行流程：让代码「有条件地走」「重复地走」「中途拐弯」。
if 条件判断、elif 否则如果、else 否则、for / while 循环、break 跳出循环、continue 跳过本轮。

逻辑判断

and, or, not, is, in
逻辑运算与成员判断：and 与、or 或、not 非、is 判断是否同一对象、in 判断是否在某个组合里。

模块与函数

import, from, as, def, return, lambda
导入模块、定义函数及匿名函数：import / from / as 导入模块并起别名、def 定义函数、return 返回结果、lambda 创建匿名函数。

类与作用域

class, global, nonlocal（self、super 不是保留字）
面向对象与作用域的骨架：class 定义类，global / nonlocal 声明要修改的全局变量 / 外层函数变量，这三个都是保留字。self、super 虽然「看着像关键字」，却是普通名字，不是保留字（keyword.iskeyword('self') 返回 False）——官方只是强烈约定这么写，理论上可以改名，但没人会这么干。这一部分到面向对象章节会详细展开。

异常处理

try, except, finally, raise, assert
捕获处理错误，让程序出错时不崩溃：try 尝试执行、except 捕获异常、finally 无论如何都执行、raise 主动抛出异常、assert 断言（条件不成立就抛 AssertionError）。

其他

True, False, None, del, pass, with, yield, async, await
布尔值、空值、删除对象、代码占位：True / False 布尔值、None 空值、del 删除对象、pass 空语句占位、with 上下文管理、yield 生成器返回值、async / await 异步编程。

怎么查看所有保留字？

Python 自带一个 keyword 模块，一行代码列出全部关键字：

import keyword
print(keyword.kwlist)
['False', 'None', 'True', 'and', 'as', 'assert', 'async', 'await',
 'break', 'class', 'continue', 'def', 'del', 'elif', 'else', 'except',
 'finally', 'for', 'from', 'global', 'if', 'import', 'in', 'is',
 'lambda', 'nonlocal', 'not', 'or', 'pass', 'raise', 'return', 'try',
 'while', 'with', 'yield']

💡 数一数正好 35 个。不同的 Python 版本，关键字数量可能有差异，用这行代码就能查到当前版本的全部名单。

❓ 测验

下列哪个是保留字？

✏️ 填空

使用 import keyword 导入模块后，执行 print(keyword.__) 可查看全部关键字（填那个属性名）。

⚠️ 避坑
「内置函数」和「保留字」不是一回事

最大的混淆点：print 不是保留字！它是内置函数——语法上你甚至可以写 print = 5（虽然会覆盖掉打印功能，是坏习惯）。而 if 是保留字，写 if = 10 直接报 SyntaxError。一句话：保留字是语法骨架，碰都不能碰；内置函数是系统提供的工具，能碰但不该碰。

坑二：大小写把关键字「伪装」成变量。True 是保留字，但 true 不是——写成小写会被当成普通变量名，使用时才报 NameError，这种错很隐蔽。

坑三：背名单不查版本。不同 Python 版本的关键字数量会有增减（例如 3.5 新增了 async、await），别死背网上旧名单，用 keyword.kwlist 查当前环境最可靠。另外 keyword.softkwlist 里还有一份「软关键字」名单（_、case、match、type），它们不是硬关键字，只在特定语法位置才有特殊含义，照样能当普通名字用。

✅ 小结
你现在知道了

保留字是 Python 预先定义、具有特殊含义的单词，不能用作变量名、函数名等标识符。35 个关键字分六大类：控制流（if/for/while…）、逻辑判断（and/or/not/is/in）、模块与函数（import/def/return…）、类与对象（class/self/super）、异常处理（try/except/finally/raise）、其他（True/False/None/del/pass）。用 import keyword + print(keyword.kwlist) 可查看全部名单。别忘了：print 是内置函数，不是保留字。下一节：正式认识「处理」的核心工具——函数的定义与调用。
