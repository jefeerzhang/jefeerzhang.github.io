为什么学这个

面向对象的世界里，先把这四个词分清

从这节起你会频繁听到四个词：类、对象、属性、方法。它们是面向对象的「四面墙」，后续每一节都在这四个词上做文章。先把概念和比喻建立起来，下一节动手写类时就不会晕。类和对象的关系第二章其实打过前站：函数像 y=f(x) 的加工流水线——类是这条流水线的升级版：不仅装函数（能加工），还装数据（记得住状态）。

💡 打个比方
一张汽车图纸，生产出千千万万辆真车

类是汽车的设计图纸——它规定「车应该有几个轮子、能做什么动作」，但图纸本身不能开上路；对象是按图纸生产出的具体汽车——每辆都真真切切能开；属性是每辆车自带的数据——颜色、品牌、价格；方法是每辆车会做的动作——驾驶、刹车、鸣笛。图纸一张，车造千辆：这就是「类是模板、对象是实例」。

核心概念

四大概念卡片：点开看细节

① 类 Class · 抽象模板

定义共同特征（属性）与共同行为（方法）的抽象蓝图
定义：类定义某一类事物的共同特征（属性）与共同行为（方法），是抽象的蓝图、模板。

比喻：汽车的设计图纸——规定结构，但不能直接上路。

关键词：抽象、模板、蓝图——「描述一类东西，而不是某个具体东西」。
👆 点击展开 / 收起

② 对象 Object · 具体实例

根据类模板创建的具体实体，是类的具象化体现
定义：对象是根据类模板创建出的具体实体，拥有类定义的全部属性和方法。

比喻：图纸生产出的具体汽车——一辆真正能开的车。

关键词：实例、具象、真实存在——「由类生成，一个类可以造出任意多个对象」。
👆 点击展开 / 收起

③ 属性 Attribute · 数据特征

对象拥有的静态数据或特征，描述对象的状态
定义：属性是对象拥有的静态数据或特征，通常对应类中的变量，描述对象当前的状态。

比喻：汽车的颜色、品牌、价格——看一眼就知道的数据。

关键词：变量、状态、数据——「它是什么样子的」。
👆 点击展开 / 收起

④ 方法 Method · 动态行为

对象可执行的动态操作或行为，通常对应类中的函数
定义：方法是对象可执行的动态操作或行为，通常对应类中的函数。

比喻：汽车的驾驶、刹车、鸣笛——需要「做出来」的动作。

关键词：函数、行为、操作——「它能干什么」。
👆 点击展开 / 收起
  • 类 vs 对象：类是图纸（抽象），对象是车（具体）；先有类，后有对象
  • 属性 vs 方法：属性是「静态的数据」，方法是「动态的行为」；一个回答「长什么样」，一个回答「会做什么」
  • 和函数的关系：类像第二章 y=f(x) 流水线的升级版——不仅装函数，还装数据
课堂代码

在代码里认出这四个概念

class Car:                              # ① 类：一张「汽车设计图纸」
    def __init__(self, brand, color, price):
        self.brand = brand              # ③ 属性：数据特征
        self.color = color
        self.price = price

    def drive(self):                    # ④ 方法：动态行为
        print(f'{self.color}的{self.brand}正在行驶')

    def brake(self):
        print(f'{self.brand}刹车了')

my_car = Car('比亚迪', '白色', 150000)   # ② 对象：图纸造出的具体汽车
print(my_car.brand)      # 访问属性：比亚迪
my_car.drive()           # 调用方法：让这辆车干活

输出结果：

比亚迪
白色的比亚迪正在行驶
  • class Car: 定义类；Car('比亚迪', '白色', 150000) 创建对象——语法下一节正式拆解
  • brand、color、price 是属性；drive、brake 是方法
  • 同一个 Car 类还可以再造 Car('特斯拉', '红色', 250000)——一张图纸，多辆真车
❓ 测验

关于类和对象的关系，下列说法正确的是？

✏️ 填空

抽象的蓝图与模板叫＿＿；根据类模板创建的具体实体叫＿＿；对象拥有的静态数据特征叫＿＿；对象可执行的动态行为叫＿＿。（四空用空格隔开）

⚠️ 避坑
三个初学误区

①「类」和「对象」混用：Student 是类（图纸），stu = Student() 造出来的 stu 才是对象（具体的学生）——说「stu 这个类」就错了；

②属性和方法分不清：写括号调用的是方法（my_car.drive()），直接取值的是属性（my_car.color）——属性后面不跟括号；

③以为改类会影响已造好的对象：实例属性在创建时就写到对象自己身上，改类不会回头改动它们（图纸改了，造好的车不会自动变色）。但类属性是另一回事——它属于类、被所有对象共享，改类属性时，没有单独设过同名属性的对象会立刻跟着变（见 8.06）。

✅ 小结
你现在知道了

类是抽象模板（图纸），对象是根据类创建的具体实例（真车），属性是对象的静态数据特征（颜色/品牌/价格），方法是对象的动态行为（驾驶/刹车/鸣笛）；类是 y=f(x) 流水线的升级版——既装数据又装函数。下一节：动手创建第一个类。
