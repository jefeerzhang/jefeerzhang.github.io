为什么学这个

程序产生的临时文件、过期数据，总得有个「清理」的办法

写文件、建目录、搬东西都会留下痕迹——临时文件、空文件夹越攒越多，程序需要自己动手清理。本节一次讲清 5 个删除方法：删文件的、删空目录的、层层删空目录的，各司其职。删错一个就报错还是删错一个就丢数据，取决于你有没有分清它们。作业第 4 题末尾删文件、第 6 题删空文件夹都用得上。

💡 打个比方
remove 像撕一页纸，rmdir 像收一个空纸箱，removedirs 像拆一摞套起来的空纸箱

删文件是把一页纸撕掉——remove / unlink 干这个；删目录像收纸箱：箱子必须先腾空才能收走（rmdir 只删空目录）；removedirs 则是拆一摞套娃纸箱——从最里层往外逐层收，能收几层收几层，遇到还装着东西的那一层就停手（不报错，里面那几层已经删掉了）。撕掉的东西不进回收站，收走前先看清楚箱子是不是你要的那个。

核心概念

5 个删除方法

方法作用要求与报错
os.remove(path)删除指定路径的文件path 必须为文件路径；文件不存在或路径为目录都会报错
Path(path).unlink()删除指定路径的文件path 为目录将报错；参数 missing_ok=True 可在文件不存在时不报错
os.rmdir(path)删除指定路径的空目录仅当目录为空才可删除；目录不存在、路径为文件、目录非空都报错
Path(path).rmdir()删除指定路径的空目录同上（只能删空目录）
os.removedirs(path)递归删除指定路径，并连带删除因此变空的各级父目录最里层目录必须为空；删完叶子后逐级向上尝试，遇到非空目录就停下、不报错
  • 核心分工：删文件用 remove / unlink，删空目录用 rmdir，层层删空目录用 removedirs
  • unlink 与 remove 是同义词（pathlib 用 unlink 这个名字），效果完全一样
  • rmdir 遇到非空目录报错，这是保护机制——防止一失手连里面所有文件一起陪葬
  • removedirs('temp4//subtemp4') 先删最里层的 subtemp4，若 temp4 因此变空也一并删掉

🔬 删除实验台：对着这套目录点按钮，注意「删文件」和「删空目录」的分工（试试对目录用 remove）

点按钮删除，报错也是学习的一部分～
课堂代码

PPT 原例：5 种删除姿势

import os
from pathlib import Path

os.remove('abc.txt')
Path('《悯农》.txt').unlink()
os.rmdir('temp')
os.removedirs('temp4//subtemp4')
Path('temp5//temp6').rmdir()

运行后逐一观察删除结果：

abc.txt        删掉了（文件）
《悯农》.txt    删掉了（文件）
temp           删掉了（空目录）
temp4/subtemp4 两层空目录一起删掉了
temp5/temp6    只删掉了 temp6，temp5 还在
  • 第 4、5 行删的是文件——路径必须是文件，换成目录就报错
  • 第 6 行删空目录 temp；若里面还有东西，报 OSError
  • 第 7 行 removedirs 从最里层 subtemp4 删起，temp4 变空后被连带删除
  • 第 8 行 Path 版 rmdir 只删 temp6——removedirs 的「层层连删」是 os.removedirs 独有的
交互示例

删空文件夹前先确认：判断 + 删除两步走

import os

p = 'temp'
if len(os.listdir(p)) == 0:
    os.rmdir(p)
    print(p, '是空文件夹，已删除')
else:
    print(p, '不为空，先处理里面的内容')

输出结果：

temp 是空文件夹，已删除
  • 先 len(os.listdir(p)) == 0 判断是否为空——这正是 7.13 与作业第 6 题的判断式
  • 确认是空文件夹再 rmdir，程序既不会报错、也不会误删有内容的目录
  • 「先判断、再动手」是删除类操作的通用安全习惯，下一节的 exists 判断也是同一思路
❓ 测验

✏️ 填空

⚠️ 避坑
删除无小事：三个保命提醒

①删除不可恢复：程序删的东西不进回收站，删错路径后果严重——动手前先 print 一遍路径、确认无误再执行，重要数据先备份；

②目录非空报错是保护机制：rmdir 对非空目录报错不是 Python 找麻烦，而是在拦住你——别想着绕过去强删，先把里面的文件逐个处理掉；

③分工别搞混：remove / unlink 只认文件（删目录报错），rmdir 只认空目录（删文件也报错）——「对象是什么类型、用什么方法」要对上号。

✅ 小结
你现在知道了
