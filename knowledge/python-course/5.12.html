为什么学这个

循环跑起来之后，还得会「踩刹车」和「跳过这轮」

循环结构有两个辅助循环控制的保留字：break 和 continue。break 可以结束当前所在层的整个循环，即当前所在层程序终止；而 continue 用于跳过当前所在层的本次循环，直接继续执行下次循环。一个管「提前收工」，一个管「这轮不要，接着来」——没有它们，while True 死循环就出不来，筛选「不要的元素」也得写得很别扭。

💡 打个比方
continue 像「跳绳绊了一下，甩掉这次继续跳」；break 像「绳断了直接收工」

跳绳时绊了一下，你不会脱鞋回家，而是重新起跳——这就是 continue：本次剩下的动作不做了，下一轮照常。绳子断了没法跳了，只能收工——这就是 break：整个循环当场终止。while True + if …: break 则像「闹钟叫你起床」——不停响，直到条件满足才停。

核心概念

break 与 continue 的分工

  • break：结束当前所在层的整个循环，程序跳到循环之后继续执行——「整层终止」
  • continue：跳过当前所在层的本次循环中剩余的语句，直接进入下一次循环判断——「只废这一轮」
  • 两者通常和 if 搭配：满足某个条件时才触发
  • break 是逃出 while True 死循环的标配：循环条件永远为真，靠内部条件判断 + break 收场
  • 只作用于「当前所在层」：嵌套循环里，break 只能跳出它所在的那一层，不能一步跳出两层（5.13 细讲）
for c in 'PYTHON':
    if c == 'H':
        continue
    print(c, end=" ")

H 踩雷：print 被 continue 跳过，但循环还活着，继续把 O、N 跑完。

课堂代码

PPT 示例 02：break 逃死循环、continue 筛奇数

# 用 break 逃出 while True 死循环：输出三行后停止
count = 0
while True:
    print("热血男儿当自强。")
    count += 1
    if count == 3:
        break
热血男儿当自强。
热血男儿当自强。
热血男儿当自强。
# 用 continue 只让奇数累加：跳过所有偶数
total = 0
i = 0
while i < 100:
    i += 1
    if i % 2 == 0:
        continue
    total += i
print(f"1+3+5+...+99={total}")
1+3+5+...+99=2500
  • 第一段：while True 条件永真，全靠 if count == 3: break 刹车——break 是死循环唯一的出口
  • 第二段：i 为偶数时 continue 跳过 total += i，只剩奇数被累加：1+3+5+…+99 = 2500
  • 注意 i += 1 放在 continue 之前——如果放在后面，偶数轮 i 永远不再更新，直接死循环

✏️ 填空

break 结束当前所在层的＿＿循环，continue 跳过＿＿循环，直接继续执行下次循环。（两空连填，中间用空格或顿号隔开）

⚠️ 避坑
两个高频翻车点

①break / continue 只作用于「当前所在层」循环：嵌套循环里内层的 break 只跳出内层，外层照常运转，不能一步跳出两层——想跳两层要借助标志变量或函数，5.13 会再见到它；

②while 里用 continue，小心更新语句的位置：i += 1 若写在 continue 之后，一旦触发 continue 就轮不到它执行，i 永远不变、条件永远成立——死循环伺候。正确姿势是把更新语句放在 continue 之前（对照上面奇数求和的写法）。

✅ 小结
你现在知道了

break 与 continue 是两个辅助循环控制的保留字：break 结束当前所在层的整个循环，continue 跳过本次循环直接进入下次；break 是逃出 while True 死循环的标配；while 里用 continue 时，更新语句必须放在它前面。下一节：循环嵌套，外层走一步、内层跑一圈。
