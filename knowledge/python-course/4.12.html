为什么学这个

给集合做「体检」：数一数、比一比、问一问

集合建好了、增删也会了，还差两件事：一是统计——多少个元素、最大最小是多少、总和多少；二是判断集合之间的关系——谁包含谁、有没有共同元素。这节的两张表就是全部内容，也是作业里的常客。

💡 打个比方
体检四件套与背包三连问

len / max / min / sum 是第一章就认识的老朋友，如今给集合「体检」照样好用。三个判断方法则像互相检查背包：issuperset 是「你的背包里装得下我的行李吗」，issubset 是「我的行李全都塞得进你背包吗」，isdisjoint 是「咱俩背包里有没有一模一样的东西」。

核心概念

四个统计函数 + 三个判断方法

统计函数：

函数作用
len(st)求长度，返回集合元素数量
max(st) / min(st)求极值，返回集合中的最大值 / 最小值；元素之间必须能互相比较（数字与字符串混放会报 TypeError）
sum(st)求和，返回集合中所有元素之和，全为数字才能求和

判断方法（都返回 True 或 False）：

方法作用
st1.issuperset(st2)判断父集：st1 是否是 st2 的父集
st1.issubset(st2)判断子集：st1 是否是 st2 的子集
st1.isdisjoint(st2)判断无交集：st1 和 st2 是否无交集

📢 小提醒：有的 PPT 把 issuperset 误印成了「issupperset」（多一个 p），正确拼写是 issuperset（super + set），上机请以正确拼写为准。

ST9 = {1, 2, 3, 4, 5}
print(len(ST9), sum(ST9))   # 5 15
print(max(ST9), min(ST9))   # 5 1
交互示例

🔬 两张卡 + 一个「谁包含谁」切换台

📊 四个统计函数

len / max / min / sum
len 数元素个数；max / min 求最大最小值（集合内类型不同、无法比较时会报错）；sum 求和——全为数字才能求和。
👆 点击展开

🔍 三个判断方法

issuperset / issubset / isdisjoint
issuperset 判父集（st1 装得下 st2）；issubset 判子集（st1 被装在 st2 里）；isdisjoint 判无交集（完全不来往）。返回值全是 True / False。
👆 点击展开
ST10 = {1, 2, 3, 4, 5}
ST11 = {2, 4}
print(ST10.issuperset(ST11))
# True —— ST10 装得下 ST11（ST10 是父集）
ST10 = {1, 2, 3, 4, 5}
ST11 = {2, 4}
print(ST11.issubset(ST10))
# True —— ST11 被装在 ST10 里（ST11 是子集）
ST10 = {1, 2, 3, 4, 5}
ST11 = {2, 4}
print(ST10.isdisjoint(ST11))
# False —— 有共同元素 2、4，并非「完全不来往」
❓ 测验

print({2, 4}.issubset({1, 2, 3, 4, 5})) 的输出是？

✏️ 填空

判断两个集合是否「无交集」（完全没有共同元素）用 ____ 方法。

⚠️ 避坑
拼写陷阱 issuperset；方向陷阱别搞反

坑一：正确拼写是 issuperset（super + set），照着课件上误印的 issupperset（两个 p）敲代码，会直接 AttributeError——Python 不会帮你猜拼写。

坑二：方向别搞反——st1.issuperset(st2) 问「st1 装得下 st2 吗」，st1.issubset(st2) 问「st1 被装在 st2 里吗」，判断方向跟着调用者（点号前面那个集合）走。

坑三：max / min / sum 只对「可比较」的内容有效——max({1, 'a'}) 会报 TypeError，数字和字符串没法比大小。

✅ 小结
你现在知道了

统计四件套：len / max / min / sum（max / min 要求元素之间能比较，sum 要求全是数字）；关系三连问：issuperset 父集、issubset 子集、isdisjoint 无交集，返回值全是布尔值；注意 issuperset 的正确拼写与判断方向。至此集合部分完结，下一节进入「序列与映射」。
