为什么学这个

整理文件第一步：先有文件夹

程序写的文件越来越多，总不能全堆在工作目录里——得学会用代码新建文件夹。这一节有三个方法：os.mkdir()、os.makedirs() 和 Path().mkdir()。它们名字像、脾气不同：有的只能建最后一层，有的能一路建到底——这正是本页的核心考点，作业第 5 题新建 Python 文件夹也会用到。

💡 打个比方
mkdir 像「在现成的柜子里放新抽屉」，makedirs 像「连柜子带抽屉一起定制」

想放一个新抽屉（最后一级目录），前提是柜子（上级目录）已经存在——这就是 os.mkdir()：柜子没有、或者抽屉已经有了，都会直接报错。而 os.makedirs() / Path().mkdir(parents=True) 是全屋定制：中间缺几层柜子就顺手造几层，一路装到底；再配上 exist_ok=True，抽屉已经存在也不闹脾气（不报错）。

核心概念

三个方法对比一览

方法能力注意
os.mkdir(path) 创建多层目录的最后一层 上级目录不存在报错；目录已存在报错
os.makedirs(path) 递归创建多层目录 参数 exist_ok=True 可在目录已存在时不报错
Path(path).mkdir() 创建目录（pathlib 版） 参数 parents=True 可创建多层目录；exist_ok=True 不报错
  • 核心考点一句话：mkdir 只能建最后一层（上级必须已存在），makedirs / parents=True 才能多层递归创建
  • 目录已存在时默认都报 FileExistsError，加 exist_ok=True（makedirs 或 Path 版）可以容忍
  • 运行代码后记得打开文件夹亲眼看看目录是否创建成功——这是本章实验的基本功
课堂代码

PPT 原例：三种写法各建一个目录

import os
from pathlib import Path

os.mkdir('temp')
os.makedirs('temp2//subtemp2', exist_ok=True)
Path('temp3').mkdir()
Path('temp4//subtemp4').mkdir(parents=True, exist_ok=True)

运行后到文件夹里观察，四个目录都创建成功：

temp          （单层目录）
temp2         （里面含子目录 subtemp2）
  └─ subtemp2
temp3         （单层目录）
temp4         （里面含子目录 subtemp4）
  └─ subtemp4
  • os.mkdir('temp')：工作目录下直接建一层，上级（工作目录）本来就在，所以成功
  • os.makedirs('temp2//subtemp2', exist_ok=True)：temp2 不存在也一并建出，递归创建
  • Path('temp3').mkdir()：pathlib 单层写法，等价于 os.mkdir
  • Path('temp4//subtemp4').mkdir(parents=True, exist_ok=True)：parents=True 就是 pathlib 版的「递归」开关
交互示例

什么情况下 mkdir 会翻车？

import os

# 情况 1：上级目录不存在
os.mkdir('a/b/c')        # a、b 都不存在 → FileNotFoundError！

# 情况 2：目录已存在
os.mkdir('temp')         # temp 已建过 → FileExistsError！

# 正确做法：多层用 makedirs
os.makedirs('a/b/c', exist_ok=True)   # 一路建到底，已存在也不报错
  • os.mkdir('a/b/c') 只想建最后一层 c，但 a、b 缺席——mkdir 不代劳，直接抛 FileNotFoundError
  • 同一个目录重复 mkdir 会抛 FileExistsError，代码重跑一次就翻车——加 exist_ok=True 免疫
  • 记忆口诀：单层 mkdir，多层 makedirs（或 parents=True），怕重复 exist_ok=True

⚠️ 避坑
四个高频翻车点

①目录已存在还硬建：代码重跑第二次就抛 FileExistsError——makedirs 或 Path 版加 exist_ok=True；

②mkdir 建多层：os.mkdir('a/b/c') 上级不存在直接报错——多层需求换 makedirs / parents=True；

③Windows 路径里的 \ 没转义：写字符串路径要么用 \\、要么用 /，PPT 里的 temp2//subtemp2 双斜杠也能跑，但规范写法是单斜杠或双反斜杠；

④建完不检查：代码没报错不等于建对了位置——去工作目录（用上一节的 getcwd 确认）亲眼看看目录在不在。

✅ 小结
你现在知道了

新建目录三方法：os.mkdir(path) 只建最后一层（上级不存在、目录已存在都报错）；os.makedirs(path) 递归创建多层，exist_ok=True 容忍已存在；Path(path).mkdir() 是 pathlib 版，parents=True 开多层、exist_ok=True 不报错。口诀：单层 mkdir、多层 makedirs（或 parents=True）、怕重复 exist_ok=True。下一节：查看目录里都有什么——展示目录内容。
