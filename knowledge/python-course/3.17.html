为什么学这个

加得进，也要删得掉

白板清单写错了一项怎么办？擦掉就行。删除列表元素有一整族工具：remove、pop、clear 和 del 语句。它们各有分工——按值删还是按位置删？删完给不还你？这一节一次分清。所有操作同样直接改变原列表。

💡 打个比方
点名出列、弹夹退弹、撕掉一行、扔掉白板

remove 像「点名让它出列」——按内容找人，叫到谁谁走；pop 像「弹夹退弹」——按位置取走，还把子弹递给你看一眼；del 像「直接撕掉清单的某一行」——不吭声就删了；而 del 整个列表则是「把白板扔了」——再问白板上有什么，Python 只能告诉你：查无此物（NameError）。

核心概念

删除元素全家福

写法作用
ls.remove(V)删除列表 ls 中指定的元素 V（第一个），没有匹配将报错
ls.pop()删除列表 ls 中最后一个元素，并返回该元素
ls.pop(M)删除列表 ls 中索引（位置）为 M 的元素，并返回该元素
ls.clear()删除列表 ls 中的所有元素，列表仍然存在
del ls[M]删除索引为 M 的元素
del ls[M:N:K]删除位于 [M, N) 区间内步长为 K 的元素
del ls删除整个列表，列表将被销毁
L6 = [1, 2, 3, 4, 5, 6, 6, 8, 9, 10]
print(L6.pop(), L6)     # 10 [1, 2, 3, 4, 5, 6, 6, 8, 9]
print(L6.pop(2), L6)    # 3 [1, 2, 4, 5, 6, 6, 8, 9]
print(L6.remove(6), L6) # None [1, 2, 4, 5, 6, 8, 9]
del L6[2]               # [1, 2, 5, 6, 8, 9]
del L6[3:]              # [1, 2, 5]
L6.clear()              # []
del L6                  # 之后 print(L6) → NameError
  • pop() 弹出末尾的 10 并返回它；pop(2) 弹出索引 2 上的 3 并返回它
  • remove(6) 只删第一个 6，第二个 6 还在；它返回 None
  • del L6[2] 删掉索引 2 上的 4；del L6[3:] 按切片删掉索引 3 之后的全部
  • clear() 清空后 L6 还是 []；del L6 连名字一起销毁，再用就 NameError
🔬 交互示例

按值删 vs 按位置删

L = ['a', 'b', 'a', 'c']
L.remove('a')    # 删掉第一个 'a'，返回 None
print(L)         # ['b', 'a', 'c']
L.clear()        # 清空所有元素，L 仍然存在
print(L)         # []

按内容办事：不用知道位置，点名谁就删谁（第一个匹配）；clear 一键清空但名单还在。

L = ['a', 'b', 'c', 'd']
print(L.pop())    # d（返回被删元素）
print(L.pop(1))   # b（返回被删元素）
del L[0]          # 直接删，不返回
print(L)          # ['c']

按位置办事：pop 删完还把元素返回给你；del 是语句，删完什么都不给。

❓ 测验

L = [1, 2, 3]，执行 L.pop() 的返回值和之后 L 的值分别是？

✏️ 填空

删除列表中指定值的第一个匹配元素用＿＿方法，没有匹配将＿＿。（两空连填，中间空格隔开）

⚠️ 避坑
remove 只删第一个；del 之后名字都没了

列表里有两个 6 时，remove(6) 只删第一个 6，第二个还在——想删干净得再执行一次；如果列表里根本没有这个值，会直接报 ValueError。

返回值也要分清：pop 有返回值可以接住（x = L.pop()），remove 返回 None，接不住东西。最狠的是 del L6——之后 L6 这个名字都不存在了，再 print(L6) 报 NameError；而 clear() 只是清空内容，L6 还是一个空列表，还能继续用。

✅ 小结
你现在知道了

remove(V) 按值删第一个匹配（没有匹配报错）；pop() / pop(M) 按位置删并返回该元素；clear() 清空所有元素但列表还在；del 可按索引删、按切片删，del 列表名则整个销毁（再用报 NameError）。记住主线：所有删除操作都在直接改变原列表——列表可变！下一节：原地修改列表元素。
