为什么学这个

程序的"收纳盒"，从这里开始

上一章你已经在交互模式里算过 1 / 2 了，但结果算完就"丢了"。想让程序记住一个数、之后反复用它，就需要变量。这一节解决三个问题：

  • 变量到底是什么？它住在内存里，有三个"身份证信息"
  • 怎么把数据"装进"变量？——赋值的语法和三种姿势
  • 为什么 = 不是数学里的"相等"？
💡 打个比方
变量 = 贴了标签的收纳盒

内存就像一排快递储物柜，变量就是其中一个贴了名字标签的柜子。执行 age = 21，就是把数字 21 放进名叫 age 的柜子里。柜子里的东西可以随时换（age = 22），换完标签还挂在原处——变的是"值"，不变的是"名字"。

核心概念

变量是什么？

  • 定义：程序中用于表示数据的符号，存储于内存中。
  • 三大属性：id（内存地址）、type（数据类型）、value（值）——每个变量都有这三张"身份证"。
  • Python 三大特性：①使用前无需声明类型；②使用前必须赋值（没赋值就用会报错）；③类型动态——类型由值决定，且可随时改变。
  • 基本形式：变量名 = 数据值。注意：等号（=）表示"赋值动作"而非数学"相等"；左侧必须是变量名，右侧是值，不可交换。

🔍 变量档案卡：同一个变量 x，换个值类型就变——点击切换体验「类型动态」

x = 7
print(x, type(x))

输出：7 <class 'int'>　—— x 此刻是整数型变量

x = 3.14
print(x, type(x))

输出：3.14 <class 'float'>　—— 没声明过类型，值是什么类型，变量就是什么类型

x = '你好'
print(x, type(x))

输出：你好 <class 'str'>　—— 同一个名字 x，类型随时可变，这就是动态类型

实战演示

赋值的三种姿势

A = 1
print(A)

输出：1　—— 最基本的「变量名 = 值」

a = b = c = 2
print(a, b, c)

输出：2 2 2　—— 链式赋值，三个变量指向同一个值

c, d, e = 3, 4, 5
print(c, d, e)

输出：3 4 5　—— 多元赋值，等号两边按顺序一一对应

# 综合演示（课程例题）
A = 1            # 1. 单变量赋值
a = b = c = 2    # 2. 多变量赋相同值
c, d, e = 3, 4, 5  # 3. 多变量赋不同值
print(A, a, b, c, d, e)  # 结果为 1 2 2 3 4 5

💡 注意：上面的 c 先被赋值为 2，随后又被覆盖为 3——后一次赋值会覆盖前一次，这也正是"变量"名字的由来。

❓ 测验

下列哪一项不属于变量的三大属性？

✏️ 填空

① 在 Python 中，= 表示＿＿动作而非数学上的相等；② Python 变量的类型是＿＿的，由值决定且可随时改变。（两空连填，中间用空格隔开）

⚠️ 避坑
变量没用过就使用，会怎样？

Python 变量必须先赋值后使用。直接写 print(score) 而从没给 score 赋过值，会报 NameError: name 'score' is not defined——名字还没定义，程序不认识它。

另一个坑：10 = x 是非法的。赋值号左边必须是变量名，右边是值，方向不能反，否则报 SyntaxError。

✅ 小结
你现在知道了

变量是内存中表示数据的符号，有 id / type / value 三大属性；赋值用 =，它是动作不是相等；Python 变量无需声明、必须先赋值、类型动态可变。赋值有单变量、链式、多元三种姿势，后赋的值会覆盖先前的。下一节：给变量起名字有哪些规矩？
