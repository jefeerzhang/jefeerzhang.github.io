为什么学这个

len、sum、max、min、in 这些「老朋友」，碰上字典会怎样？

学列表和集合时你已经用过 len()、max()、min()、in 这些内置函数和运算符。它们同样能用在字典上，但有一个非常关键的新规矩：只看键，不看值。搞不清这一点，作业里求总成绩（第 5 题要用 sum）就会踩坑。这一节把这条规则一次讲透。

💡 打个比方
只看房客名单的管理员

把字典想成一栋公寓：键是门牌号，值是住在房间里的住户。字典的内置函数就像一位「只看房客名单的管理员」——数一数有几个房间（len）、找最大门牌号（max）、把门牌号加一加（sum），全部按门牌号（键）办事。你想统计屋里住了哪些人（值）？管理员不会主动告诉你，必须主动说一句「我要看住户名单」——也就是写出 .values()。

核心概念

四个内置函数 + 一个判断运算

以 DC9 = {1: 'a', 2: 'b', 3: 'c'} 为例，常用的字典内置操作如下（注意它们默认全部作用于键）：

写法作用注意
len(dc)求字典中键值对的个数键值对成对计数，3 对就是 3
max(dc) / min(dc)求字典键的最大 / 最小值键之间必须能互相比较（数字与字符串混放会报 TypeError）
sum(dc)求字典键的和键必须全为数字才能求和
key in dc判断 key 是否是字典的键返回 True 或 False
  • 核心规则：只看键不看值。sum(DC9) 算的是 1+2+3=6（键的和），跟值 'a''b''c' 毫无关系
  • 想对值操作，要显式包一层 .values()：max(DC9.values()) 才会得到 'c'
  • in 判断的是键：'a' in DC9 是 False（'a' 是值不是键），'a' in DC9.values() 才是 True
  • max/min 还能配 .keys()、.items() 等视图使用，思路相同：先「点名」，再操作
交互示例

🔬 键视角 vs 值视角：同一本字典的两种问法

下面两组代码操作的是同一个字典 DC9，切换视角看看结果差多少：

直接写 DC9 —— 全部作用于键：

DC9 = {1: 'a', 2: 'b', 3: 'c'}
print(len(DC9))             # 3    → 键值对的个数
print(sum(DC9))             # 6    → 键的和：1+2+3
print(max(DC9), min(DC9))   # 3 1  → 键的最大 / 最小值
print(1 in DC9)             # True → 1 是键

包一层 .values() —— 这才轮到值登场：

DC9 = {1: 'a', 2: 'b', 3: 'c'}
print(max(DC9.values()))      # c    → 值里最大的是 'c'
print('a' in DC9.values())    # True → 'a' 是值，得这样问
print(sum(DC9.values()))      # ❌ 报错！值是字符串，不能求和

对比左边：sum(DC9) 能算出 6，是因为键 1、2、3 都是数字；换成值就求不动了——所以「键还是值」不是小事，直接决定代码能不能跑。

课堂代码

PPT 原例：五行代码全部走一遍

DC9 = {1: 'a', 2: 'b', 3: 'c'}
print(len(DC9), sum(DC9))
print(max(DC9), min(DC9))
print(max(DC9.values()))
print(1 in DC9, 'a' in DC9)
print('a' in DC9.values())

输出结果：

3 6
3 1
c
True False
True
  • 第 1 行：len 是 3（三对键值），sum 是 6（键 1+2+3）——「只看键」规则的直接体现
  • 第 4 行：1 in DC9 是 True（1 是键），'a' in DC9 是 False（'a' 是值）
  • 第 3、5 行：想碰值，就得写 .values()
❓ 测验

DC9 = {1: 'a', 2: 'b', 3: 'c'}，print('a' in DC9) 的输出是？

✏️ 填空

key in dc 用于判断 key 是否是字典的____，返回 True 或 False。

⚠️ 避坑
「只看键」不是bug，是规矩——但你得记得它

坑一：sum(DC9) 得到 6，有同学以为是「1+'a'+2+'b'+3+'c' 加起来的」——字典的 sum、max、min 只作用于键。值的和要写 sum(DC9.values())（作业第 5 题求总成绩就是这么写的）。

坑二：'a' in DC9 想查「'a' 在不在字典里」，结果 False 就以为数据丢了——其实 'a' 是值。查值必须 'a' in DC9.values()。

坑三：max/min 要求键（或值）之间能互相比较。字典里既有数字键又有字符串键时，max(DC9) 会报 TypeError: '>' not supported between instances of 'str' and 'int'——不是「类型必须一致」，而是「必须能比大小」。

✅ 小结
你现在知道了

字典上的 len / sum / max / min / in 默认只看键不看值：sum(DC9) 是键的和，'a' in DC9 查的是键；想对值操作要显式写 .values()。记住「只看房客名单的管理员」，下一节进入全章收官——四大容器一表总结。
