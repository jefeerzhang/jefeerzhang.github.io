为什么学这个

学完四大容器，是时候「一表定乾坤」了

这一章你认识了列表、元组、集合、字典四种组合数据类型，各自的方法学了一大堆。但真正拉开差距的是：拿到一个实际问题，你能不能选对容器？这一页是全章收官——一张总结表 + 一组场景选择题，帮你把零散的知识点串成「选型直觉」。本章作业第 6 题会同时用到这四种类型。

💡 打个比方
四种容器 = 四种收纳工具

列表是「背包」：啥都往里装、随取随放、按顺序排队（有序、可变、可重复）；元组是「塑封袋」：装好就封死，谁也改不了（有序、不可变、可重复）；集合是「抽奖箱」：只认人不认顺序、绝不重复（无序、可变、不重复）；字典是「带标签的抽屉柜」：凭标签（键）秒找东西（靠键定位、键值对、键唯一）。下次选容器前，先想想：我要背包、塑封袋、抽奖箱，还是抽屉柜？

核心概念

四大容器一表定乾坤

这是本章最重要的一张表（PPT 原表），建议截图保存：

数据类型核心特性适用场景
列表 List有序、可变、可重复存储有序、需要频繁修改的数据，如动态变化的序列
元组 Tuple有序、不可变、可重复存储不可修改的常量数据，如坐标点、配置信息或其他受保护的数据
集合 Set无序、可变、不重复需要对数据进行去重操作，或需要进行交集、并集等数学集合运算的数据
字典 Dict靠键定位、键值对、键唯一存储具有映射关系的数据，如对象属性、配置项或通过关键字快速查找
  • 记忆抓手：四组「核心特性」各三个词，考试爱考原文
  • 「有序」是列表、元组的专利；「不重复 / 键唯一」是集合、字典的看家本领
  • 元组是四者中唯一不可变的——所以它能当字典的键、能放进集合

场景选择题：先自己心里作答，再点开看答案。

要存一个地理坐标点 (30.57, 104.07)，存进去之后绝不允许被改动，选哪种类型？

✅ 答案：元组 Tuple

理由：坐标是典型的「不可修改的常量数据」。元组不可变，谁也改不了它，天然受保护；写成列表万一被误改，误差就是几十公里。

要存全班成绩单，需要按分数排序、随时增删，选哪种类型？

✅ 答案：列表 List

理由：这是「有序、需要频繁修改的数据」的标准画像。sort() 排序、append() 添加、remove() 删除，列表的看家本领全部用上。

手上有一列数据，只想快速去掉重复项，选哪种类型？

✅ 答案：集合 Set

理由：set() 转换一步到位、自动去重。如果还要做交集、并集等数学集合运算，更是只有集合能干（下一节讲转换细节）。

要存「姓名 → 电话号码」的对应关系，输入姓名立刻查到电话，选哪种类型？

✅ 答案：字典 Dict

理由：这是「具有映射关系的数据」——键唯一（姓名）、值对应电话，d['张三'] 一步取值。列表要一个个比对，字典凭键秒查。

❓ 测验

需要对一批数据去重，还要做交集、并集运算，应该选哪种数据类型？

✏️ 填空

元组核心特性：有序、____、可重复；字典核心特性：靠键定位、键值对、____唯一。（两空连填，中间用中文逗号隔开）

⚠️ 避坑
没有「万能容器」——选型前先问自己三个问题

很多同学写作业永远只用列表，什么数据都往背包里塞。正确姿势是选型前三连问：① 要不要顺序？要 → 列表 / 元组；不要 → 集合 / 字典。② 要不要改？要改 → 列表 / 集合 / 字典；不许改 → 元组。③ 要不要按键查？要 → 字典，没得商量。

另外注意：元组「不可变」常被记成「不能删除整个元组」——准确说法是不能增删改其中的元素，del 整个元组是可以的。核心特性背错一个词，考试就丢分。

✅ 小结
你现在知道了

四大容器的核心特性与适用场景：列表（有序、可变、可重复）装动态序列；元组（有序、不可变、可重复）装受保护的常量；集合（无序、可变、不重复）管去重与集合运算；字典（靠键定位、键值对、键唯一）做按键快速查找。选型三连问：要不要顺序？要不要改？要不要按键查？下一节是全章最后一节：四种容器互相转换。
