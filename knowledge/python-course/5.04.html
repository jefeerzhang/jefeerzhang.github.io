为什么学这个

六行变三行：把「二选一赋值」压进一行

上一节求最大值的 if-else 写了六行，但它的逻辑其实很简单：条件真就把 a 赋给结果，假就把 b 赋给结果。凡是「根据条件给变量赋两个值之一」的场景，Python 提供了更简洁的写法——IF 表达式（也叫三元表达式、条件表达式）。它是 5.03 示例 02 的「一行版」，在本章作业里会经常见到。

💡 打个比方
普通 if-else 像「先开会决定再行动」，IF 表达式像「一句话拍板」

普通的 if-else 是开个小会：先判断，再执行对应分支里的语句，郑重其事。IF 表达式是一句话拍板：「最大值嘛，a 大就取 a，否则取 b」——判断和取值一口气说完。但只有简单的二选一赋值才适合拍板；决策一复杂（分支里要干好几件事），还是老老实实「开会」写普通 if-else。

核心概念

语法格式与三个要点

变量 = 值1 if <条件> else 值2
  • 用途：用于变量赋值——条件为真把值1赋给变量，条件为假把值2赋给变量
  • 表达式形式不需要冒号，也不需要换行缩进——整句写在一行里
  • 读法：「变量 = （真时取）值1，前提是条件成立，（否则取）值2」——条件紧跟在「想要的那个值」后面
  • Python 里它也叫三元表达式或条件表达式，本质是一个「会算出值」的表达式，而不是一条控制语句
交互示例

同一个最大值问题：普通双分支版 vs IF 表达式版

a = eval(input('请输入第一个数字：'))
b = eval(input('请输入第二个数字：'))
if a >= b:
    print(f'最大值是{a}')
else:
    print(f'最大值是{b}')

普通版把「判断」和「输出」写在两条分支里：输出语句要写两遍，共六行。它能干的事不止赋值——分支里可以放任意多条语句。

a = eval(input('请输入第一个数字：'))
b = eval(input('请输入第二个数字：'))
c = a if a >= b else b
print(f'最大值是{c}')

IF 表达式版把「赋值给谁」的判断压进了一个表达式：先算出 c，再统一输出——先算后用，逻辑清爽。输入 5 和 3 时，5 >= 3 为真，c 取到 a（即 5），输出「最大值是5」。

课堂代码

PPT 原例：IF 表达式求最大值

a = eval(input('请输入第一个数字：'))
b = eval(input('请输入第二个数字：'))
c = a if a >= b else b
print(f'最大值是{c}')

输入 5 和 3 的执行过程：

  • 读入 a=5、b=3
  • 计算 c = a if a >= b else b：条件 5 >= 3 为 True → 取 if 前面的值1（也就是 a）→ c = 5
  • 若条件为假（比如 a=3、b=5），则取 else 后面的值2（也就是 b）→ c = 5
  • 输出「最大值是5」——与 5.03 六行版结果完全一致
❓ 测验

执行 c = a if a >= b else b，当 a=3、b=5 时，c 的值是？

✏️ 填空

IF 表达式用于变量＿＿，表达式形式不需要＿＿，也不需要换行缩进。（两空连填）

⚠️ 避坑
三个高频翻车点

①它是「取值」不是「执行语句」——IF 表达式算出来一个值交给变量。把 print(...) 塞进值1/值2 的位置虽然语法上可行，但可读性很差，初学阶段只把它用于赋值；

②顺序别记反——是「值1 if 条件 else 值2」，先写值再写 if，条件紧跟在你想要的那个值后面。写成 c = if a >= b: a else b 是普通语句的写法，直接语法错误；

③三样一个都不能少——值1、条件、值2 缺一不可，漏写 else 值2 部分会直接 SyntaxError。分支逻辑一复杂，就退回普通 if-else。

✅ 小结
你现在知道了

IF 表达式的语法是变量 = 值1 if 条件 else 值2：条件真取值1、假取值2，专门用于变量赋值；它不需要冒号、不需要换行缩进，是普通双分支在「二选一赋值」场景下的一行版，Python 里也叫三元表达式 / 条件表达式。决策简单就一句话拍板，决策复杂就老老实实写 if-else。下一节：分支再多也不怕——多分支结构 if-elif-else。
