为什么学这个

「对每个元素都做同一件事」，别再手写循环了

想把列表里每个数都平方？想筛出所有偶数？用 for 循环写要四五行，而这两件事恰恰是「一个函数 + 一批数据」的组合。Python 的函数式编程提供了 map 和 filter：把一个函数（经常就是上一节的 lambda）当作参数传进去，让它替你跑循环。这种「能接收函数作为参数」的函数，就叫高阶函数——理解了这一点，函数就从「被调用的东西」升级成了「可以传递的素材」。

💡 打个比方
map 是「加工流水线」，filter 是「质检传送带」

map 像苹果削皮机流水线：每个苹果挨个进机器，出来时都变了样（每个元素都做同样变换，一个不少）。filter 像质检传送带：每个苹果挨个过质检员，合格的留下、不合格的踢出去（每个元素都做同样判断，只留合格的）。两条传送带的共同点：你都得先把「加工规则 / 质检标准」交给它们——那个规则，就是传进去的 lambda 函数。

核心概念

map 与 filter：两个高阶函数

  • 高阶函数：函数式编程的重要概念——可以接收函数作为参数、或者返回一个函数的函数。map 和 filter 的第一个参数就是函数
  • map(匿名函数, 映射对象)：把函数应用于可迭代对象的每个元素，返回一个新迭代器——像「每个都加工」，结果个数不变
  • filter(匿名函数, 过滤对象)：用函数判断每个元素（真 / 假），保留满足条件的项——像「挑出合格的」，结果个数只减不增
  • 返回的都是迭代器：不能直接 print 出内容，要 list() 转换后才能查看——和 5.09 的 range 是「菜谱不是菜」一个道理
  • 判断函数返回真值才保留：filter 的 lambda 通常返回 True / False（如 n%2==0），为真才让元素通过

🔬 map / filter 流水线实验台：固定序列 [1, 2, 3, 4, 5]，看每个元素「进 → 变换 → 出」

课堂代码

PPT 原例：filter 筛偶数，map 全平方

ls = [1, 2, 3, 4, 5]

ft = list(filter(lambda n: n%2==0, ls))
print(ft)

sq = list(map(lambda n: n**2, ls))
print(sq)

输出结果：

[2, 4]
[1, 4, 9, 16, 25]
  • filter 那行：lambda n%2==0 是「质检标准」——1 不合格丢弃、2 合格保留……最终 [2, 4]，个数变少了
  • map 那行：lambda n**2 是「加工工序」——每个数都平方，1→1、2→4……最终 [1, 4, 9, 16, 25]，个数不变
  • 两行都要 list(...) 包一下：map / filter 返回的是迭代器，直接 print 看不到内容
交互示例

不用高阶函数 vs 用高阶函数：同两件事

ls = [1, 2, 3, 4, 5]

# 手写 for 循环版：筛偶数 + 平方，各要 4 行
ft = []
for n in ls:
    if n % 2 == 0:
        ft.append(n)
sq = []
for n in ls:
    sq.append(n ** 2)

# 高阶函数版：各 1 行，规则一目了然
ft2 = list(filter(lambda n: n%2==0, ls))
sq2 = list(map(lambda n: n**2, ls))
print(ft2, sq2)

输出结果：

[2, 4] [1, 4, 9, 16, 25]
  • 结果完全相同，但高阶函数版把「怎么筛、怎么变」浓缩成一条规则直接写在调用里
  • map 和 filter 也能串起来用（流水线接流水线）：list(map(lambda n: n**2, filter(lambda n: n%2==0, ls))) → 先筛偶数再平方，得 [4, 16]
❓ 测验

list(filter(lambda n: n%2==0, [1, 2, 3, 4, 5])) 的输出是？

✏️ 填空

可以接收函数作为参数的函数称为＿＿函数；其中对每个元素逐个「加工」的是 ＿＿，按条件筛选「保留合格项」的是 ＿＿；它们都返回迭代器，需用 ＿＿() 转换后才能查看内容。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①忘了 list() 转换：直接 print(map(lambda n: n**2, ls)) 看到的是 <map object at 0x…> 这类对象地址，不是数据——迭代器是「菜谱」，要 list() 才是「菜」；

②filter 的 lambda 判断写错方向：lambda n: n%2 筛出的是奇数（1、3、5 非零为真），想要偶数得写 n%2==0——「结果为真才保留」；

③map 和 filter 记反：map 是「每个都变、个数不变」，filter 是「每个都判、个数只减不增」——想要平方结果却写了 filter，得到的还是原数字。

✅ 小结
你现在知道了

高阶函数 = 能接收函数作为参数（或返回函数）的函数；map(函数, 对象) 对每个元素加工、个数不变；filter(函数, 对象) 按真假筛选、只留满足条件的项；两者都返回迭代器，需 list() 转换查看。lambda 在这里如鱼得水——下一节的 sorted 用同样的思路传「排序规则」。
