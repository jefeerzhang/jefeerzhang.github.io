为什么学这个

先看全局，再学细节

从这一节开始，我们进入第二章「基础概念与数值」。在正式学变量、类型之前，先回答一个最顶层的问题：一个程序到底是由什么构成的？

答案只有两个词——「数据」和「处理」。程序要处理信息，信息就是数据；数据不能自己动，必须有人按照章法去加工它，这个「章法」就是处理。本章的 17 个小节，全部都是围绕这两大核心展开的，学之前先看清地图，后面每一节你都会知道自己走到哪儿了。

  • 数据要有人管——靠变量来存放，靠数据类型来区分种类
  • 处理要有章法——靠运算符做计算，靠函数封装可复用的步骤
  • 本章分两大部分：第一部分·基础概念（变量 / 数据类型 / 保留字 / 函数 / 输入输出 / 格式规范），第二部分·数值与运算（数值类型 / 运算符 / 数值函数）
💡 打个比方
做菜 = 食材（数据）+ 菜谱步骤（处理）

做一桌菜，你得先有食材——米、肉、菜、调料，它们就是程序的数据；光有食材不够，还得有菜谱步骤——先切、再炒、后焖，这就是程序的处理。缺了食材，菜谱写得再好也没用；缺了步骤，一堆食材永远变不成菜。数据和处理，缺一样都做不成一桌菜，也写不成一个程序。

而本章学的变量、类型，就是给食材分类、贴标签、放进收纳盒；运算符、函数，就是把菜谱步骤写清楚、写得能复用。

核心概念

两大核心，两条学习主线

  • 核心一：数据——程序里所有要被处理的信息。谁来看管它们？变量负责「存放」，数据类型负责「分类」，保留字则是命名时不能碰的「系统专属词」。
  • 核心二：处理——对数据做的动作。运算符（算术、比较、逻辑）负责具体计算，函数负责把一批动作打包成可反复调用的整体，输入输出函数则负责程序与你的对话。
  • 两大核心各自都对应本章的一半内容：前半打「地基」，后半学「计算」。学数值运算之前，必须先掌握变量与类型，否则算出来的结果连「放的地方」都没有。

❓ 测验

程序构成的两大核心是什么？

✏️ 填空

一个程序由「数据」和「＿＿」两大核心构成；数据由变量与数据类型来管理。

⚠️ 避坑
只背术语、不动手，是最大误区

「数据 + 处理」听起来很抽象，很多同学把这页当成需要背诵的名词。其实它是一张导航图：后面学到任何小节（比如「浮点数与精度陷阱」），都应该能回答「它属于数据还是处理？」——答不出来的地方，就是你对全局还不熟的地方。

另一个坑：以为「处理 = 运算符」就够了。本章后半会看到，处理还包括函数——运算符像单个动作，函数像整套动作的打包，二者共同构成章法。

✅ 小结
你现在知道了

一个程序 = 「数据」+「处理」两大核心。数据要有人管——变量与数据类型；处理要有章法——运算符与函数。本章前半（2.02 ～ 2.10）学基础概念，后半（2.11 ～ 2.17）学数值与运算。下一节：进入第一大核心，认识程序里最基本的数据管家——变量。
