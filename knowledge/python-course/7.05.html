为什么学这个

同样是 open()，选错模式轻则报错、重则清空文件

open() 是三步曲的第一步，但「打开」绝不是按一下门那么简单：用 'r' 打开一个不存在的文件会当场报错；用 'w' 打开一个有内容的文件会把它清空。打开模式（mode）决定了你打开这扇门之后能读还是能写、文件不在怎么办、指针停在哪。作业第 1 题创建 scores.txt 要用哪个模式？学完这页自然有答案。

💡 打个比方
打开模式像「进图书馆阅览区的规矩」：有的区只许看，有的区只许写

'r' 是「阅览区」——只能看，不能动笔，而且这个区必须已经存在；'w' 是「誊抄区」——进去先把旧纸清空，只管写新的；'a' 是「留言墙」——不许撕旧留言，只能往末尾继续贴。带 + 的模式（如 r+、w+）则是「VIP 区」，看和写的权限都给你。

核心概念

open() 的语法与三兄弟

文件对象名 = open(filename, mode='r', encoding=None)
  • filename：被打开文件的名字，可以用相对路径也可以用绝对路径（上一节讲的都用得上）
  • mode：打开后的处理方式。常用文本模式 6 种：r、r+、w、w+、a、a+；对应二进制模式在末尾加 b（rb 等 6 种）。此外还有「独占创建」模式 x、x+、xb、xb+——文件已存在就直接报错、绝不覆盖。b 表示字节模式
  • encoding：编码方式。遇到中文乱码，把它改成 utf-8 一般就好；二进制文件严禁指定 encoding 参数——字节就是字节，不需要翻译
  • 最常用的三兄弟：r 只读（文件不存在直接报错）、w 只写（不存在则创建，存在则清空覆盖）、a 追加（指针在结尾，旧内容安然无恙）

'r' 只读

阅览区：只能读不能写。
文件不存在 → FileNotFoundError。
指针停在开头。

'w' 只写

誊抄区：只能写不能读。
不存在 → 创建新文件；
存在 → 清空再写！指针在开头。

'a' 追加

留言墙：只能写不能读。
不存在 → 创建新文件；
存在 → 从结尾接着写，旧内容保留。

  • 记法：w 系凶狠（打开就清空）、a 系温和（只在结尾添）、r 系挑剔（文件必须已存在）
  • 带 + 就「读写的门都开」，但文件在不在、清不清空仍由首字母决定
  • 二进制模式（rb、wb、ab…）规律完全相同，只是多了个 b，且严禁 encoding
交互示例

r 报错、w 清空：两个最经典的现场

# 现场 1：r 模式打开不存在的文件 → 直接报错
file = open('成绩单.txt', 'r', encoding='utf-8')
# FileNotFoundError: [Errno 2] No such file or directory: '成绩单.txt'

# 现场 2：w 模式打开已存在的文件 → 内容瞬间被清空
file = open('scores.txt', 'w', encoding='utf-8')   # 此刻旧内容已经没了！
file.write('新学期的成绩')

# 现场 3：作业第 1 题的标准写法——创建 scores.txt 就用 w
with open('scores.txt', 'w', encoding='utf-8') as file:
    file.write('张三 90\n李四 85')
  • 'w' 是「先清空、再动笔」——那句话写进代码前，先想想里面还有没有要保留的数据
  • 「打开即清空」是 w/w+ 打开那一刻发生的，跟之后写没写、写多少都无关
  • 第 10~11 行的 with 写法下一节详细讲，先学会抄
❓ 测验

用 'w' 模式打开一个已存在且有内容的文件，会发生什么？

✏️ 填空

文本文件遇到中文乱码，可把 encoding 参数改为＿＿；二进制模式（如 rb、wb）严禁指定＿＿参数。（两空用空格隔开）

⚠️ 避坑
三个高频翻车点

①w 模式手滑毁数据：本想追加一条记录却写成 'w'，整个文件瞬间清空——想「接着写」永远用 'a'；

②r 模式开不存在的文件：'r' 不会替你建文件，想「边建边写」用 'w' 或 'a'；

③二进制模式带 encoding 直接报错：open('照片.jpg', 'rb', encoding='utf-8') 会抛 ValueError——字节模式没有「翻译」这一说。

✅ 小结
你现在知道了

open(filename, mode, encoding) 三参数：路径可相对可绝对；常用模式文本、二进制各 6 种（另有独占创建的 x 系列 4 种）；乱码改 utf-8，二进制严禁 encoding。三兄弟：r 只读（不存在报错）、w 只写（不存在创建、存在清空）、a 追加（指针在结尾）。作业第 1 题创建 scores.txt 用 w。下一节：怎么关闭文件才优雅——with 语句。
