为什么学这个

字典不是「建好就不动」的——它是活的

字典是动态可变的：程序跑起来随时会往里添加新键值对（顾客加购商品）、修改旧值（改数量）、批量合并另一本字典。这一节三个方法各有分工：dc[key]=value 一招两用、update() 批量合并、setdefault() 只加不改。本章作业第 4 题（小明购物流程）就是连续使用 dc[key]=value 的添加和修改。

💡 打个比方
旅馆前台与只营业新房间

dc[key]=value 像「旅馆前台」：报上房间号，有这间房就换住客（修改原值），没这间房就新开一间（添加新键值对）——同一个动作，两副面孔，全看房间在不在。setdefault 像「只营业新房间」：只给没住过的房间安排客人；老房间谁来都不换人，原住客照旧。

核心概念

三个方法，三种「加改」策略

方法说明
dc[key] = value键 key 不存在，将添加新键值对；否则将修改原值为新值
dc1.update(dc2)根据字典 dc2 的键值对，添加或修改原字典 dc1（键在则改、不在则加）
dc.setdefault(key, value)键 key 不存在，将添加新的键值对，不会修改原值
  • dc[key]=value 是一招两用：写法只有一个，行为取决于键是否已存在
  • update() 是批量版的 dc[key]=value：把另一个字典的键值对逐个「并入」，键已存在时覆盖原值
  • setdefault() 是保守派：只加不改；键已存在时返回现有值，不存在时添加并返回新值（没给 value 则默认 None）
  • 这些操作都直接改变原字典，不会产生新字典
交互示例

🔬 两副面孔与保守策略

同一个写法：键不存在 = 添加，键存在 = 修改

DC7 = {'a': 1, 'b': 2, 'c': 3}
DC7['d'] = 4      # 键 'd' 不存在 → 添加
DC7['a'] = 99     # 键 'a' 已存在 → 修改
print(DC7)

输出结果：

{'a': 99, 'b': 2, 'c': 3, 'd': 4}

'd' 是新开的房间（添加），'a' 是换了住客（1 → 99，修改）——一行代码两副面孔。

setdefault：只加不改，返回的是「值」

DC7 = {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6}
print(DC7.setdefault('g'), DC7)
print(DC7.setdefault('a', 7), DC7)

输出结果：

None {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6, 'g': None}
1 {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6, 'g': None}

第一行：'g' 不存在 → 添加 'g': None，返回值 None；第二行：'a' 已存在 → 原值 1 原样不动，返回现有值 1。「只营业新房间」，老房间谁来都不换人。

课堂代码

PPT 原例：DC7 的完整加改过程

DC7 = {'a': 1, 'b': 2, 'c': 3}
DC7['d'] = 4
print(DC7)              # 添加
DC7.update({'e': 5, 'f': 6})
print(DC7)              # 批量添加
print(DC7.setdefault('g'), DC7)
print(DC7.setdefault('a', 7), DC7)

输出结果：

{'a': 1, 'b': 2, 'c': 3, 'd': 4}
{'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6}
None {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6, 'g': None}
1 {'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6, 'g': None}
❓ 测验

DC7 = {'a': 1}，执行 DC7.setdefault('a', 99) 后，DC7['a'] 的值是？

✏️ 填空

dc[key] = value：键 key 不存在时将 ___，键存在时将 ___。（两空连填，中间用空格隔开）

⚠️ 避坑
返回值不是字典、update 会覆盖

setdefault 返回的是值不是字典：print(DC7.setdefault('g')) 打出的 None、print(DC7.setdefault('a', 7)) 打出的 1，都是方法的返回值；字典本身的变化要看逗号后面 print 出来的 DC7。新手常把返回的 None 误当成「字典变成了 None」。

update 的键已存在时会覆盖原值：它不是保守派，DC 本来有 'a':1，update({'a': 100}) 之后 'a' 就变成 100 了——想「只加不改」请用 setdefault。

这些操作都直接改变原字典，改完原字典就真变了，需要保留原样的要先复制一份。

✅ 小结
你现在知道了

dc[key]=value 一招两用（不存在=添加，存在=修改）；update() 批量合并（键在则改、不在则加）；setdefault() 只加不改（已存在返回现有值）。三者都直接改变原字典。下一节：怎么把键值对从字典里删掉。
