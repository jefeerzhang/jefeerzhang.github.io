为什么学这个

所有文件操作，都是同一套「三步舞」

不管是往 scores.txt 里写成绩，还是从日记里读一段话，Python 对文件的所有操作都遵循同一个固定套路——打开 → 读写 → 关闭。后面三节讲的打开模式、write、读文件三方法，全都是往这三步里的某一步「填细节」。先把整体骨架搭起来，细节就好学了。

💡 打个比方
操作文件像「取快递」：拆箱 → 取放东西 → 封箱归位

①拆箱：快递到了先打开包裹（open() 打开文件），才能碰到里面的东西；②取放：从包裹里拿东西出来（读，外存 → 内存），或把自己的东西放进去（写，内存 → 外存）；③封箱归位：收拾完把包裹封好放回原处（close() 关闭文件）——不封箱，东西容易掉出来，箱子也一直被你占着。

核心概念

三步曲：打开 → 读写 → 关闭

1

打开文件

用 open() 函数打开（或建立）文件，返回一个文件对象，赋值给变量。之后的读写全靠这个对象。

→
2

读 / 写操作

用文件对象的读写方法操作。读（r）：数据从外存 → 内存；写（w）：数据从内存 → 外存。

→
3

关闭文件

用文件对象的 close() 方法关闭，释放资源、把缓冲区数据落盘。用完不关是大忌（第 6 节细讲）。

  • 文件对象是 Python 替你管理文件的那只「手」——open 返回它，读写、关闭都调用它的方法
  • 读和写是两个方向相反的搬运：r 把磁盘数据搬进内存供程序用，w 把内存数据搬到磁盘存起来
  • 本页是概览：第 5 节讲「怎么打开」（打开模式），第 6 节讲「怎么关得漂亮」（with 语句），第 7、8 节讲「读写细节」
课堂代码

三步曲的完整骨架

file = open('古诗.txt', 'r', encoding='utf-8')   # ① 打开：得到文件对象
text = file.read()                                # ② 读：磁盘 → 内存
print(text)
file.close()                                      # ③ 关闭：收工

  • 第 1 行：open 三个参数——文件路径、打开模式 'r'、编码方式（下一节逐个拆解）
  • 第 2 行：file.read() 把整个文件内容读进内存变量 text
  • 第 4 行：close() 之后，file 这个「手」就松开了文件
  • 对照记忆：读是「外存 → 内存」，写是「内存 → 外存」，方向别搞反
❓ 测验

文件操作三步曲的正确顺序是？

✏️ 填空

三步曲中：①打开文件用＿＿() 函数，返回一个文件对象；③关闭文件用文件对象的＿＿() 方法。（两空填函数 / 方法名，用空格隔开）

⚠️ 避坑
三个高频翻车点

①没打开就读写：变量 file 还没接住 open() 的返回值就调用 file.read()，直接 NameError——先开后面才有的用；

②读写方向记反：读操作是「外存 → 内存」（把文件内容拿进程序），写操作是「内存 → 外存」（把程序数据存进文件），考试常考；

③打开后忘记关闭：数据可能没真正写进磁盘（还堵在缓冲区），文件也会一直被程序占用——下一节用 with 语句彻底解决。

✅ 小结
你现在知道了

所有文件操作都是三步曲：①open() 打开（或建立）文件、返回文件对象；②用文件对象读写——读是外存到内存，写是内存到外存；③close() 关闭。后面几节分别拆解三步的细节。下一节先看第一步：open() 的各种打开模式。
