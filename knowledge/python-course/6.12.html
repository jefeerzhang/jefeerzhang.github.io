为什么学这个

有些小功能，配得上一个「名字」吗？

前面学的函数都要用 def 郑重其事地起个名字。可有时候你只想算一句「两数相加」「两数取大」，为它专门写 def、起名字，像借图书馆的书只为了翻一眼。Python 提供了匿名函数：不用名字、一行搞定、随手写随手用。更重要的是，它可以作为参数传给别的函数——下一节的 map、filter，以及作业第 5 题的 sorted 排序，全都靠它出场。

💡 打个比方
lambda 像「一次性纸杯」：用完即弃，不占名字；def 是「正式水杯」

def 定义的函数像正式水杯：有名字、能反复用、摆在工位上谁都能拿来喝。lambda 像一次性纸杯：接杯水（算个结果）就扔了，不值得刻上名字、也不占地方——「用完即弃、不增加额外变量」。但纸杯装不了满汉全席（只能写一行、功能有限），要干重活得用正式水杯。

核心概念

lambda 参数: 表达式

  • 语法：lambda 参数: 表达式——lambda 是希腊字母 λ，冒号前面放参数，冒号后面放一个表达式，表达式的值就是返回值（不需要写 return）
  • 优点：① 代码简洁精炼，不增加额外变量（不用起函数名）；② 可以作为参数传递给其他函数——这是它最大的用武之地
  • 缺点：① 可读性较差；② 只能写一行，能实现的功能有限，复杂逻辑还得用 def
  • 本质上仍是函数：可以赋值给一个变量，之后像普通函数一样调用——f = lambda x, y, z: x + y + z 之后 f(1, 2, 3) 就是 6
  • 冒号后可以放 IF 表达式：衔接 5.04 学的 a if 条件 else b，让 lambda 也能做「二选一」的判断

🔬 lambda 实验台：两个现成的匿名函数，填数字现场调用

点上面按钮试试——f 是三元求和，Max 是二元取大
课堂代码

PPT 原例：求和与取大

f = lambda x, y, z: x + y + z
print(f(1, 2, 3))

Max = lambda x, y: x if x > y else y
print(Max(3, 5))

输出结果：

6
5
  • f = lambda x, y, z: x + y + z：三个参数相加，调用 f(1, 2, 3) 得 6——冒号后的表达式直接就是返回值
  • Max = lambda x, y: x if x > y else y：冒号后是 IF 表达式（5.04 学过）——条件成立返回 x，否则返回 y；Max(3, 5) 中 3 > 5 不成立，返回 5
  • 对照 def 版：同样的功能 def 要写 3 行（def 行、return 行、调用），lambda 一行搞定——但函数体一多，lambda 就写不下了
交互示例

同一个功能，def 版 vs lambda 版

# def 标准版：有名字，三行
def add(a, b):
    return a + b
print(add(10, 20))

# lambda 版：一行
add2 = lambda a, b: a + b
print(add2(10, 20))

# 真正的匿名用法：不起名字，直接当参数传给 sorted（作业第 5 题预告）
scores = [('张三', 85), ('李四', 92)]
scores.sort(key=lambda x: x[1])
print(scores)

输出结果：

30
30
[('张三', 85), ('李四', 92)]
  • 前两个输出完全一样——lambda 版只是「更省事」，功能上没有任何区别
  • 第三段是 lambda 的主场：key=lambda x: x[1] 把「按第二个元素排」这条规则现场递给 sort，用完即弃——如果用 def 还得专门起个名字，反而累赘
❓ 测验

Max = lambda x, y: x if x > y else y，则 Max(3, 5) 的返回值是？

✏️ 填空

匿名函数用关键字 ＿＿ 定义；冒号后只能写＿＿行表达式；表达式的值就是返回值，不需要写 ＿＿ 语句；冒号前面放的是＿＿。（四空用空格隔开）

⚠️ 避坑
三个高频翻车点

①冒号后想写多行：lambda 函数体只能是一行表达式，写 if 语句块、循环体都会语法报错——要判断用 IF 表达式，要循环就老实用 def；

②忘了写 return 也以为要写：def 里返回值得写 return，lambda 里表达式本身就求值，多写 return 反而报错；

③可读性牺牲过度：把复杂逻辑硬塞进一行 lambda，过两周自己都看不懂——「一行能写清才用 lambda」是实用底线，功能复杂就回到 def。

✅ 小结
你现在知道了

lambda 定义匿名函数：语法「lambda 参数: 表达式」，一行搞定、表达式的值即返回值；优点是简洁、可作参数传递，缺点是可读性差、只能一行；冒号后可配合 IF 表达式做二选一。它的主场是把「规则」当参数传给别的函数——下一节的 map 和 filter 正是如此。
