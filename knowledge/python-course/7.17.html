为什么学这个

文件多大？什么时候改的？——不打开文件也能「验明正身」

做下载进度条要算文件大小，做备份工具要比对修改时间——这些信息都藏在文件系统里。本节的 getsize 和几个 get*time 方法就像文件的「体检报告」：不用打开文件，一查就知道大小（字节）和创建 / 修改 / 访问时间。作业第 3 题（获取文件信息）就是把这批方法挨个用一遍。

💡 打个比方
文件信息像「体检报告」：体重（大小）+ 三个时间戳（出生、最近改动、最近来看病）

getsize 是量体重——单位是字节；getctime、getmtime、getatime 分别记录「出生（创建）、最近一次动手术（修改）、最近一次来看病（访问）」的时间。只是报告上的时间是「Unix 时间戳」这种医生才懂的写法（从 1970 年起的秒数），得用 datetime.fromtimestamp() 翻译成人话。

核心概念

两组等价写法

os.path 写法pathlib 写法作用
path.getsize(p)Path(p).stat().st_size获取文件大小（字节）
path.getctime(p)Path(p).stat().st_ctime获取文件创建时间（Windows 上是创建时间；Linux / macOS 上是元数据最后变更时间）
path.getmtime(p)Path(p).stat().st_mtime获取文件最后修改时间
path.getatime(p)Path(p).stat().st_atime获取文件最后访问时间
  • 返回的时间值是 Unix 时间戳（浮点型秒数，从 1970-01-01 起算），不能直接给人看
  • 用 datetime.fromtimestamp(时间戳) 转换为可读时间格式（datetime 模块第四章学过）
  • pathlib 版要先 .stat() 拿到「体检报告」对象，再取属性 st_size / st_ctime / st_mtime / st_atime
  • 注意属性拼写是 st_ctime / st_mtime（time 结尾）——PPT 例子里误写成 st_ctme / st_mtme，照抄会 AttributeError，本页一律用正确拼写

课堂代码

PPT 原例：先写文件，再体检

import os.path as path
from datetime import datetime

with open('校训.txt', 'w', encoding='utf-8') as file:
    file.write("追求真理、造福社会、自强不息")

print(path.getsize('校训.txt'))
print(path.getctime('校训.txt'))
print(datetime.fromtimestamp(path.getctime('校训.txt')))

输出结果（时间因电脑而异）：

42
1776325658.91659
2026-04-16 15:47:38.916590
  • 42 = 14 个字符 × 3 字节/汉字（UTF-8 编码；标点「、」同样占 3 字节）——大小是字节数不是字符数，这是本节最重要的一课
  • getctime 返回 1776325658.91659 这样的浮点数——Unix 时间戳，人看不懂
  • fromtimestamp 把时间戳翻译成 2026-04-16 15:47:38.916590 这样的可读时间
  • 第 9 行把 getctime 的结果「套」进 fromtimestamp——方法嵌套调用，从里往外读
交互示例

pathlib 版：先 stat() 拿报告，再取属性

from pathlib import Path
from datetime import datetime

st = Path('校训.txt').stat()
print(st.st_size)
print(datetime.fromtimestamp(st.st_mtime))

输出结果：

42
2026-04-16 15:47:38.916590
  • .stat() 一次拿到整份「体检报告」，存进 st 之后想查几项查几项
  • 属性名 st_size、st_mtime 千万别照 PPT 抄成 st_ctme、st_mtme——time 结尾，抄错直接 AttributeError
  • ctime 与 mtime 是两回事：ctime 是创建时间、mtime 是最后修改时间。刚写完文件时两者几乎相同，改过内容之后 mtime 才会变新，别把它们当成同一个值
  • os.path 版适合「只查一项」，pathlib 版适合「一次查多项」——各有所长
❓ 测验

文件「校训.txt」内容是 14 个汉字，以 UTF-8 编码保存，path.getsize('校训.txt') 返回？

✏️ 填空

path.getsize(p) 返回的文件大小单位是＿＿；各时间方法返回 Unix＿＿（浮点型秒数），可用 datetime.＿＿() 转换为可读时间格式。（三空用空格隔开）

⚠️ 避坑
三个高频翻车点

①大小是字节数不是字符数：汉字在 GBK 里占 2 字节、UTF-8 里占 3 字节——同一篇文章不同编码的 getsize 结果不同，别按字符数心算；

②时间戳不能直接给人看：1776325658.91659 不是「1776 年」，是距 1970 年的秒数——展示前先 fromtimestamp 转换；

③拼写陷阱：属性是 st_ctime / st_mtime（time 结尾），PPT 例子里误写为 st_ctme / st_mtme，照抄会报 AttributeError——以本页为准。

✅ 小结
你现在知道了

getsize 返回文件大小（字节数！汉字 UTF-8 占 3 字节、GBK 占 2 字节，同一段文字编码不同结果就不同）；getctime / getmtime / getatime 返回创建、修改、访问时间的 Unix 时间戳，用 datetime.fromtimestamp() 转成可读时间；pathlib 版先 stat() 再取 st_size / st_ctime / st_mtime / st_atime（time 结尾，别照 PPT 抄错）。最后一节：路径的合并与分解——收好本章的「螺丝刀套装」。
