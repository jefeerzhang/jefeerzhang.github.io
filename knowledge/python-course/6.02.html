为什么学这个

你已经用过很多函数了，但你知道它们「从哪来」吗？

print()、input()、len()、max()……这些其实全是函数！只是它们的来源不同：有的开箱即用，有的要先 import 才能请出来，还有的——从本章开始——要你自己动手造。分清这三类，你才能回答两个实际问题：这个函数我要不要导入？如果三类都解决不了同一个问题，该用哪个？

💡 打个比方
三类函数像三种 App：出厂自带、应用商店下载、自己开发

内置函数像手机出厂自带的 App——电话、相机、计算器，开机就能用，不用下载（不用导入）；第三方库函数像应用商店下载的 App——功能丰富、社区开发，但要先「下载安装 + 导入」才能用；用户自定义函数像自己开发的 App——灵活性最高，想要什么功能自己写，这正是本章 6.03 起要学的内容。

核心概念

三类函数对照：来源、使用方式、灵活度

👇 三张卡片点击展开看示例代码与要点：

内置函数

解释器自带，无需导入模块，覆盖常用基础功能
print("Hello")     # 输出
name = input()     # 输入
n = len([1, 2, 3]) # 长度 → 3
m = max(3, 7, 5)   # 最大值 → 7

回望：第二章学的 print、len、max、input 都是内置函数——当时你就已经在用函数了。

👆 点击展开示例

第三方库函数

功能丰富、由社区开发，需 import 导入后使用
import math
print(math.sqrt(16))   # 4.0

import numpy
a = numpy.array([1, 2, 3])

回望：2.17 节用 math.sqrt() 算平方根，就要先 import math。严格说 math 属于 Python 标准库、numpy 才需要额外安装，它们的共同点是——都必须先导入才能用。

👆 点击展开示例

用户自定义函数

按需定制、灵活性最高，用 def 关键字自己定义
def add(a, b):
    c = a + b
    return c

print(add(3, 5))   # 8

内置和库函数解决「通用问题」；你的作业题、你的业务逻辑，往往要自己定义函数——从 6.03 开始学。

👆 点击展开示例
  • 内置函数：拿来就用，是「语法的一部分」；第三方库函数：先 import 再用，生态强大；自定义函数：def 定义，想怎么设计怎么设计
  • 三类的调用方式完全一样——都是 函数名(参数)，区别只在「要不要导入」和「谁来定义」
课堂代码

三种函数同台演出

# 1. 内置函数：直接用
print(max(10, 25, 8))

# 2. 第三方库函数：先导入再用
import math
print(math.sqrt(25))

# 3. 用户自定义函数：先定义再调用
def add(a, b):
    return a + b

print(add(10, 25))

输出结果：

25
5.0
35
  • 第 2 行：max 是内置的，不导入、直接喊名字
  • 第 5 行：math.sqrt(25) 先 import math——注意调用时要带「库名.」前缀
  • 第 8~9 行：add 是我们自己定义的，定义之后它的用法和内置函数一模一样
❓ 测验

math.sqrt() 属于哪一类函数？（math 是 Python 自带的标准库，用之前必须先 import）

✏️ 填空

内置函数＿＿导入即可使用；第三方库函数需要先用＿＿语句导入；用户自定义函数用＿＿关键字定义。（三空用空格隔开）

⚠️ 避坑
三个高频翻车点

①给内置函数画蛇添足：写 import print 会报 ModuleNotFoundError: No module named 'print'——内置函数不需要也不能导入，要导入的是 math、numpy 这类模块；

②忘了带库名前缀：import math 之后直接写 sqrt(25) 会报 NameError，必须写 math.sqrt(25)；

③自定义函数与内置函数重名：把变量或函数命名为 print、max，会「遮住」内置函数，之后 print() 就不再是原来那个 print 了——起名要避开。

✅ 小结
你现在知道了

函数分三类：内置函数（解释器自带、无需导入，如 print/len/max）、库函数（需要 import 才能用，又分两类：Python 自带的标准库，如 math.sqrt；需要额外安装的第三方库，如 numpy.array）、用户自定义函数（def 定义、灵活性最高）。调用方式三类完全一致。下一节：正式学怎么用 def 定义一个函数。
