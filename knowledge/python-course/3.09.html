为什么学这个

「按逗号切开存起来，用完再拼回去」

读入一行「张三,18,计算机」，想拆成三份数据分别处理——用 split()；处理完想用逗号拼回一句话——用 join()；从文件或输入读来的字符串两头带着多余空格——用 strip()。这三个方法是字符串和列表之间的桥梁：split 把字符串变成列表，join 把列表变回字符串。这一节学会了，后面学列表会顺畅得多。

💡 打个比方
切香肠、串珠子、修盆栽

split() 像「按记号切香肠」——沿着逗号（或指定符号）一刀刀切下去，得到一节一节的香肠（一个列表）；join() 像「用线把珠子串回去」——拿一根线（连接符），把一串珠子（列表元素）重新穿成一条项链（字符串）；strip() 像「修剪盆栽两侧的杂叶」——只动左右两边的叶子，中间的枝叶一概不碰。

核心概念

三个方法：拆、接、修

  • str.split(sep=None)：按 sep 符号分割字符串，返回列表；不指定 sep 时默认按空白字符切
  • str.join(iter)：用 str 符号把 iter 对象里的所有元素连接起来，返回新字符串
  • str.strip(chars)：剔除字符串两侧的 chars 字符，默认剔除空格，返回新字符串
  • ⭐ split ↔ join 互为逆操作：'.'.join('3.14'.split('.')) 又变回了 '3.14'（严格说只在「join 用的分隔符和原字符串里的分隔符一致」时才互逆：''.join('a,b'.split(',')) 得到 'ab'，并没有还原）
  • ⭐ 铁律：strip 也返回新字符串，不改变原字符串，需要时用变量接住
print('3.14'.split('.'))      → ['3', '14']
print('.'.join(['3', '14']))  → 3.14
print(' 123 '.strip())        → 123
print('%123%'.strip('%'))     → 123
交互示例

方法速查表 + split ↔ join 互逆实验

方法作用返回示例
str.split(sep=None)按 sep 分割字符串列表'3.14'.split('.') → ['3','14']
str.join(iter)用 str 连接所有元素新字符串'.'.join(['3','14']) → '3.14'
str.strip(chars)剔除两侧的 chars（默认空格）新字符串' 123 '.strip() → '123'

一对互逆操作，先拆再接，见证原地复原：

parts = '3.14'.split('.')
print(parts, type(parts))
['3', '14'] <class 'list'>
字符串被按「.」切成了两个元素的列表
s = '.'.join(['3', '14'])
print(s, type(s))
3.14 <class 'str'>
列表又被「.」粘回了字符串——分隔符一致时，一来一回正好还原
❓ 测验

'a,b,c'.split(',') 的结果类型和值是？

✏️ 填空

strip() 不指定参数时，默认删除字符串两侧的 ____。（填两个字）

⚠️ 避坑
strip 只管两侧，join 只收字符串

坑一：strip 只处理两侧。'1 2 3'.strip() 的结果还是 '1 2 3'——中间的空格原样保留，盆栽中间的枝叶它一概不碰。想去掉中间空格得用 replace(' ', '')。

坑二：split 返回的是列表。'3.14'.split('.') 的结果是 ['3', '14']，不能直接当字符串用，要取某一段得用列表索引（下一节就学）。

坑三：join 的元素必须是字符串。'-'.join([1, 2, 3]) 会报 TypeError——数字不是珠子是石头，线穿不过去。要先把数字转成字符串：'-'.join([str(1), str(2), str(3)])。

✅ 小结
你现在知道了

split() 按符号拆成列表、join() 把列表串成字符串（元素必须是字符串）、strip() 只剔除两侧字符（默认空格）；split 和 join 互为逆操作；三个方法都返回新结果、不改变原字符串。下一节：一眼判断字符串的「成分」——判断字符串类别！
