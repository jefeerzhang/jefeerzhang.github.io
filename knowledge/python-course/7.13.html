为什么学这个

建了文件夹、存了文件，可代码怎么「看见」里面有什么？

上一节用 mkdir 新建了目录，但程序不能靠肉眼去资源管理器里翻——想知道某个文件夹里有哪些东西，得让 Python 自己报出来。这一节的 os.listdir() 和 Path().iterdir() 就是目录的「透视镜」，作业第 6 题「判断文件夹是否为空」的第一步就是先把内容列出来。它们俩功能相同，但「给的东西」不一样，这正是本节要讲透的地方。

💡 打个比方
listdir 像「点名册」，iterdir 像「把学生本人请到台前」

查一个班级：os.listdir() 给你的是一份点名册——上面只有名字（文件名字符串组成的列表）；Path().iterdir() 则是把每个学生本人请到台前一个个走过（Path 对象组成的迭代器）。点名册只够你念名字，本人到场才能继续「量身高、看性别」——也就是直接链着调用 .is_file()、.stat() 等方法。

核心概念

两个展示方法

方法作用要求与返回
os.listdir(path)展示当前目录内容path 必须为目录路径，返回文件名列表（字符串）
Path(path).iterdir()展示当前目录内容path 必须为目录路径，返回由Path 对象组成的迭代器（常用 for item in p: print(item.name) 取名字；文件属性要用 .stat() 取）
  • listdir 给「名字列表」：拿到的是字符串，可以直接 len()、endswith() 等字符串操作
  • iterdir 给「Path 对象流」：拿到的是 Path 对象，可继续 .is_file()、.stat() 等链式操作
  • iterdir 返回的是迭代器，只能从头遍历一次；想再遍历一遍要重新调用一次 iterdir()
  • 两者列出的都只是「这一层的名字」，不含上级目录，要拼完整路径得配合下一节的 join

🔬 展示实验台：目录 temp2 里有一个子文件夹 subtemp2，两种方法各会吐出什么？

temp2/ └─ subtemp2/
点上面的按钮，看看两种写法各自的返回～
课堂代码

PPT 原例：两种写法对照

import os
from pathlib import Path

print(os.listdir('temp2'))

p = Path('temp2').iterdir()
for item in p:
    print(item.name)

输出结果：

['subtemp2']
subtemp2
  • 第 4 行 os.listdir('temp2') 一次性给出名字列表 ['subtemp2']
  • 第 6 行 Path('temp2').iterdir() 拿到的是迭代器，装在变量 p 里
  • 第 7~8 行用 for 循环逐个取出 Path 对象，再 item.name 取出名字——所以逐行打印出 subtemp2
  • 两种方法「看到的目录」完全一样，差别只在给的是名单还是本人
交互示例

iterdir 的优势：拿到「本人」直接接着查

from pathlib import Path

for item in Path('temp2').iterdir():
    if item.is_file():
        print(item.name, '是文件')
    else:
        print(item.name, '是文件夹')

输出结果：

subtemp2 是文件夹
  • iterdir 给的 item 是 Path 对象，直接链着 .is_file() 判断类型，不用再拼路径
  • 若用 listdir，得先 os.path.join('temp2', name) 拼出完整路径才能判断——多一步
  • 批量处理目录内容时（筛选 .txt、逐个改名），iterdir 的「对象流」写起来更顺手

✏️ 填空

os.＿＿(path) 返回文件名组成的列表；Path(path).＿＿() 返回 Path 对象组成的迭代器，遍历时用 item.name 取名字。（两空填方法名，用空格隔开）

⚠️ 避坑
三个高频翻车点

①参数必须是目录路径：把文件路径传给 listdir 或 iterdir 会抛 NotADirectoryError——「展示目录内容」只能展示目录；

②iterdir 的迭代器只能用一次：for 遍历完再遍历一遍是空的，想重来必须重新 iterdir() 一次；

③拿到的是「名字」不是「路径」：listdir 返回 ['subtemp2']，不含 temp2 这个上级目录——后续操作要拼路径，别直接拿名字去 open。

✅ 小结
你现在知道了

展示目录内容两大方法：os.listdir(path) 返回文件名列表，Path(path).iterdir() 返回 Path 对象的迭代器（用 item.name 取名字、可直接链式 is_file 等操作）；参数都必须是目录路径。空文件夹判断 len(listdir) == 0 正是作业第 6 题的钥匙。下一节：重命名与移动——一招两用。
