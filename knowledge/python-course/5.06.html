为什么学这个

先分大类、再分小类——分支里还能装分支

很多判断是有层次的：先看是不是本校学生，再看是不是本班；先看成绩是否及格，及格了再看是良好还是优秀。在分支语句中再包含一个或多个分支语句，就是嵌套分支结构。学会它，你才能真正读懂别人的代码——因为缩进从此不只是「好看」，而是决定逻辑的东西。

💡 打个比方
嵌套像「两道门」：先过大门（外层 if），进了大门才有资格被小门（内层 if）拦住问话

外层条件是大门：「是本校学生吗？」不是，直接走大门的 else 通道；是，才来到小门前：「是本班的吗？」是或不是，走的是小门的两条路。两道门有主次关系——而缩进就是门牌：哪个 else 缩进到哪一层，它就挂在哪个门上。缩进错一格，「本班的判断」就挂到错误的大门上去了。

核心概念

嵌套分支的语法与三条注意事项

if <条件1>:
    内层 if <条件2>:
        <代码块_真1_真2>
    else:
        <代码块_真1_假2>
else:
    内层 if <条件3>:
        <代码块_假1_真3>
    else:
        <代码块_假1_假3>
  • if 语句和 else 语句都能有新的分支结构——四个角落（真1真2 / 真1假2 / 假1真3 / 假1假3）各有一条路
  • 不同层次的分支语句的对应关系取决于其缩进程度，相同缩进的为同一层——else 挂在谁头上，看缩进，不看距离远近
  • 嵌套不宜超过 2 层；嵌套分支结构可以转换为多分支结构，建议使用多分支结构（下一节就对比给你看）
交互示例

缩进挪一格，语义全变：示例 1 vs 示例 2

a = eval(input("请您输入数字a的值"))
if a >= 0:
    if a > 0:
        print("a大于0！")
    else:                    缩进 4 格：跟内层 if 对齐 → 是内层的 else
        print("a等于0！")
外层a >= 0 ？→ 真，才进内层
内层a > 0 ？→ 真 输出「a大于0！」；假 输出「a等于0！」
  • 输入 0：外层 0>=0 真 → 内层 0>0 假 → 走内层 else，输出「a等于0！」
  • 输入 5：外层真 → 内层真 → 输出「a大于0！」
  • 输入 -1：外层 0>=-1 为假，外层没有 else → 什么都不输出
a = eval(input("请您输入数字a的值"))
if a >= 0:
    if a > 0:
        print("a大于0！")
else:                        缩进 0 格：跟外层 if 对齐 → 是外层的 else
    print("a小于0！")
外层a >= 0 ？→ 真 走内层；假 输出「a小于0！」
内层a > 0 ？→ 真 输出「a大于0！」；假？没有 else 接住！
  • 输入 -1：外层假 → 走外层 else，输出「a小于0！」
  • 输入 0：外层真 → 内层 0>0 假，而内层没有 else → 什么都不输出（「沉默」）
  • 两段代码字符几乎一样，只差内层 else 的缩进位置，语义却完全不同——这就是 Python 的缩进即逻辑

⚠️ 避坑
三个高频翻车点

①嵌套不宜超过 2 层（PPT 原文建议）：层数一多，缩进层层叠叠，谁也读不懂——能转成多分支就转（下一节教你转）；

②写内层分支时，先想清楚它的 else 挂在哪一层：是跟内层 if 对齐（缩进 4 格），还是跟外层 if 对齐（缩进 0 格）？位置不同，逻辑天差地别；

③示例 2 输入 0 时程序「沉默」不是 bug：它没报错也没输出，是因为内层 if a>0 为假且内层没有 else，分支没覆盖到这种输入——这是逻辑漏洞的典型样子，比报错更难发现，写完代码要把每种输入都过一遍。

✅ 小结
你现在知道了

在分支语句中再包含分支语句就是嵌套分支：if 和 else 都能有新分支，层次由缩进决定、相同缩进是同一层；else 的缩进位置不同，语义可能完全不同，还要小心分支没覆盖到时程序「沉默」。嵌套不宜超过 2 层，能转多分支就转多分支。下一节：把同一道酒驾判定题的两种写法摆在一起，看看多分支为什么更清爽。
