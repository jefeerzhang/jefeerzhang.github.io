为什么学这个

不确定类型？问 Python 本人

上一节你认识了数据类型大家庭，但「听名字」和「验真身」是两回事。比如 {1, 2, 3} 和 {"name": "张三"} 都是大括号，到底哪个是集合哪个是字典？

好消息是：Python 自带一台「类型透视机」——内置函数 type()。这一节就学它：

  • type() 是 Python 的内置函数，给它一个对象，它返回该对象的数据类型
  • 返回结果的固定格式是 <class 'xxx'>，其中 xxx 就是上一节学的类型英文名
  • 它是你调试程序、排查类型错误时用得最勤的工具，必须练到肌肉记忆
💡 打个比方
type() = 机场安检的透视机

行李箱外面看不出装的什么，放上安检机扫一下，屏幕上立刻显示「液体 / 电子产品 / 衣物」。变量也一样——光看字面（{1, 2} 是集合还是字典？）容易猜错，放进 type() 里「扫一下」，类型立刻原形毕露。而且安检机只看不改：type() 只报告类型，不会动你的数据。

核心概念

type() 用法与输出格式

  • 语法：type(对象)——把任何数据（或变量）放进括号里即可。
  • 返回值格式：<class 'xxx'>——「class」意为「类」，引号里的名字就是类型名，如 <class 'int'>、<class 'str'>。
  • 上一节的 10 个类型英文名（int / float / complex / str / bool / NoneType / list / tuple / set / dict）在这里全部对上号。

下面是完整代码与输出，一行对一行：

print(type(1), type(1.0), type(1 + 2j))
print(type('A'), type("China"))
print(type(None))
print(type(True), type(False))
print(type([1, 2, 3]))
print(type((1, 2, 3)))
print(type({1, 2, 3}))
print(type({"name": "张三", "age": 18}))
<class 'int'> <class 'float'> <class 'complex'>
<class 'str'> <class 'str'>
<class 'NoneType'>
<class 'bool'> <class 'bool'>
<class 'list'>
<class 'tuple'>
<class 'set'>
<class 'dict'>

💡 观察第 1 行：1 是 int 而 1.0 是 float——只差一个小数点，类型就不同；再对比第 7 行和第 8 行，同样是大括号，没有键值对是 set，有键值对就是 dict。

❓ 测验

print(type("China")) 的输出是？

✏️ 填空

使用 Python 内置函数 ＿＿ 可以返回对象的数据类型，输出格式形如 <class 'int'>。

⚠️ 避坑
两个高频翻车现场

坑一：加引号 = 变字符串。type(20) 是 <class 'int'>，type('20') 却是 <class 'str'>。从 input() 读进来的数字也是字符串（后面学输入输出函数时细讲），先 type() 查一查再运算，能省很多调试时间。

坑二：把输出格式当成类型名。类型名是引号里的部分：'int'、'str'。填空或写代码时别把尖括号和 class 一起抄进去。注意：在 Python 里写 <class 'str'> 是代码输出，尖括号要交给 print 显示，自己敲代码时只写 type(...)。

✅ 小结
你现在知道了

type() 是 Python 内置函数，返回对象的数据类型，输出固定格式为 <class 'xxx'>。它像安检透视机：只看不改、原形毕露。重点记住三组对照——1 是 int、1.0 是 float；{1,2,3} 是 set、{"k": v} 是 dict；20 是 int、'20' 是 str。下一节：有一批单词被 Python 系统征用了，起变量名时绝不能碰——认识保留字。
