为什么学这个

元组不能增删改，那能对它做什么？

元组自己不能增删改，但拿到一个元组能做的「加工」其实不少：求长度、找最大最小值、求和、排序、数个数、查位置——这些活儿全靠内置函数（len、max、min、sum、sorted、reversed）和它仅有的两个方法（count 与 index）完成。作业里「求最高分」「统计某元素出现次数」「找元素位置」类题目都要靠它们。

💡 打个比方
元组不能自己整队，就请外援

元组是塑封卡片，队形永远定死，没法「整队」。想看排好序的样子？sorted 像叫外卖——把队员名字抄到一张新纸（列表）上整好队送回来，塑封卡片本身毫发无损。而 count 和 index 是元组仅有的两个自带方法，都只「看」不「改」，属于纯只读操作——一个数人数，一个查座位号。

核心概念

六个内置函数 + 两个只读方法

  • 函数：len 求长度、max/min 求极值、sum 求和、sorted 排序（返回列表）、reversed 逆序（返回迭代器）
  • 方法：tp.count(x) 数 x 出现几次；tp.index(x) 查 x 的位置，找不到会报错
  • max / min 要求元素之间能互相比较——数字之间、字符串之间都行，但数字和字符串混在一起会报 TypeError: '>' not supported between instances of 'str' and 'int'；sum 要求全为数字才能求和
  • sorted 和 reversed 都不改动原元组——一个返回新列表，一个返回迭代器
交互示例

🔬 点开两张卡片认识全套工具 + sorted vs reversed 大对决

TP6 = (2, 1, 5, 3, 4)

函数表（6 个）

len / max / min / sum / sorted / reversed
函数说明
len(tp)求长度，返回元组元素数量
max(tp) min(tp)求极值，返回最大/最小值；元素之间必须能互相比较（数字与字符串混放会报 TypeError）
sum(tp)求和；全为数字才能求和
sorted(tp)排序，返回一个列表
reversed(tp)逆序，返回一个迭代器
点击展开说明

方法表（仅 2 个）

count 计数 / index 求索引
方法说明
tp.count(x)计数，返回元组 tp 中元素 x 的数量
tp.index(x)求索引，返回元素 x 的索引值；找不到会报错
点击展开说明
print(sorted(TP6))
print(type(sorted(TP6)))

输出：

[1, 2, 3, 4, 5]
<class 'list'>

解读：sorted 返回排好序的列表——元组的排队结果装在列表里交给你，原元组不变。

print(reversed(TP6))
print(tuple(reversed(TP6)))

输出：

<reversed object at 0x1BFA1B1C6A0>
(4, 3, 5, 1, 2)

解读：reversed 返回的是迭代器对象，直接 print 只能看到类型和内存地址（地址每次运行都不同，这里只是示意）；必须用 tuple() 或 list() 包一层才能看到内容。

课堂代码

PPT 原例：五行代码全考点

TP6 = (2, 1, 5, 3, 4)
print(len(TP6), sum(TP6), max(TP6), min(TP6))
print(sorted(TP6, reverse=True))
print(reversed(TP6), tuple(reversed(TP6)))
print(TP6.count(5), TP6.count(0))
print(TP6.index(5))
# print(TP6.index(0))  # 找不到会报错

输出结果：

5 15 5 1
[5, 4, 3, 2, 1]
<reversed object at 0x1BFA1B1C6A0> (4, 3, 5, 1, 2)
1 0
2
  • len=5、sum=15、max=5、min=1：四个函数一行看全
  • sorted(TP6, reverse=True) 返回列表 [5, 4, 3, 2, 1]——加 reverse=True 即降序
  • count(0) 返回 0 表示「没找到但不报错」；index(0) 找不到会直接报错，所以那行被注释掉了
❓ 测验

sorted(TP6) 的返回类型是？

✏️ 填空

sorted() 返回一个____，reversed() 返回一个____。（两空连填，用空格隔开）

⚠️ 避坑
三个最容易翻车的返回值

坑一：reversed(TP6) 直接打印是对象地址 <reversed object at ...>，不是内容——必须用 tuple() / list() 包一层。

坑二：sorted(tp) 返回的是列表不是元组——类型变了！想要元组要再 tuple(sorted(tp)) 一次。

坑三：tp.index(x) 找不到会报 ValueError，而 tp.count(x) 找不到只安静地返回 0——查位置前最好先用 in 或 count 确认元素存在。

✅ 小结
你现在知道了

元组的加工靠内置函数 len / max / min / sum / sorted / reversed 和仅有的两个只读方法 count / index；sorted 返回列表、reversed 返回迭代器（要包一层才能看内容）；index 找不到报 ValueError、count 找不到返回 0；max/min 要能比较、sum 要全数字。下一节：挖到底——「不可变」三个字的真正含义。
