为什么学这个

文件建错了名、放错了地方，难道只能手动去资源管理器改？

批量整理下载文件夹、把作业统一改名归档——这些活儿用代码干又快又稳。本节的 os.rename() 和 Path().rename() 看名字只管「改名」，实际上还兼职「搬家」：newpath 换个上级目录，文件或目录就被移动过去了。一个方法两种用途，作业第 5 题后半（把 Python 改名为 Python123）就是它的直接应用。

💡 打个比方
rename 像「改快递面单」：包裹不动，改地址就是改名，换城市就是搬家

包裹（文件内容）本身原封不动，你改的只是面单上的地址（路径）。rename('temp2', 'temp5') 是同一栋楼里换门牌——重命名；rename('temp3', 'temp5//temp6') 是把地址直接写到另一个城市——搬家（移动）+ 改名一步到位。快递员只认面单：oldpath 这个地址必须真实存在，newpath 的「城市」（上级目录）也必须存在，否则包裹送不到、直接报错。

核心概念

两个 rename

方法作用要求与返回
os.rename(oldpath, newpath)文件或目录重命名oldpath 必须存在，newpath 上级目录必须存在，无返回值
Path(oldpath).rename(newpath)文件或目录重命名规则相同，返回新的 Path 对象
  • 对文件或目录进行重命名，还能实现文件或目录的移动——newpath 换个上级目录就是「搬家」
  • newpath 只换名字不换目录 → 重命名；只换目录不换名字 → 移动；两者都换 → 移动 + 改名一步到位
  • 文件和目录用同一个方法，Python 会自动识别 oldpath 是文件还是目录
  • newpath 的上级目录必须已存在——想搬进还没建的文件夹，得先用 7.12 的 mkdir 建好

课堂代码

PPT 原例：一招改名，一招搬家

import os
from pathlib import Path

os.rename('temp2', 'temp5')

p = Path('temp3')
p.rename('temp5//temp6')

运行后当前目录的变化：

temp2   →  改名为 temp5
temp3   →  移进 temp5 里面，并改名为 temp6
  • 第 4 行：temp2 与 temp5 在同一层——只是重命名
  • 第 7 行：newpath 是 temp5//temp6，上级目录变成了 temp5——移动 + 改名
  • 运行后 temp3 消失了：它是「搬家」，不是「复制」——原位置不再保留
  • 两种写法效果一致，Path 版会返回新的 Path 对象，方便继续链式操作
交互示例

批量改名：给目录里所有 .txt 加前缀

import os

for name in os.listdir('temp'):
    if name.endswith('.txt'):
        os.rename(os.path.join('temp', name), os.path.join('temp', '备份_' + name))

print(os.listdir('temp'))

输出结果：

['备份_《悯农》.txt', '备份_校训.txt']
  • listdir 给出名字列表，配合 7.13 的知识逐个处理
  • oldpath 和 newpath 都在 temp 目录下——目录没变，只改名字，所以是纯重命名（用 os.path.join() 拼路径，比手写 // 更稳）
  • rename 一次只改一个，批量任务靠 for 循环驱动——第五章的循环在这里派上用场

✏️ 填空

对文件或目录调用 ＿＿(oldpath, newpath) 方法可完成重命名；当 newpath 换了上级目录时，它还能实现「＿＿」。（两空用空格隔开）

⚠️ 避坑
三个高频翻车点

①newpath 的上级目录必须存在：os.rename('a.txt', 'backup//a.txt') 里 backup 若不存在，直接 FileNotFoundError——先 mkdir 再搬家；

②oldpath 必须存在：名字写错一个字就报错，动手前先用 listdir 核对一遍真实名字；

③rename 是「搬」不是「复制」：执行后原位置的东西就没了，别指望两处同时保留——需要副本得用读写文件的方式另存。

✅ 小结
你现在知道了

os.rename(oldpath, newpath) 与 Path(oldpath).rename(newpath) 一招两用：newpath 只换名字是重命名，换了上级目录就是移动（可移动 + 改名一步到位）；oldpath 和 newpath 的上级目录都必须存在；rename 是搬不是复制。下一节是删库跑路级的操作——删除文件和目录，务必系好安全带。
