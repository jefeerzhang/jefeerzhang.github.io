为什么学这个

给字符串装上「四则运算」和「百宝工具箱」

字符串不光能装文字、能按位取字符，还能做运算：拼接、重复、包含判断；还能调用一批内置函数：量长度、转类型、查编码。上一节实战里那句 "男" * (int(id_c[16]) % 2)，其实就是字符串乘法——本节把它正式讲透，再送你 ord / chr 这对「编码翻译官」。

💡 打个比方
串糖葫芦、复印机和查字典

+ 像串糖葫芦——几颗果子一根签，首尾相连成一串；* 像复印机按 N 份——原件一份，复几分就重复几遍；in 像查名单——翻翻名单里有没有你（而且是整名连续匹配，不能拆开）。ord 和 chr 像查字典的两面：一面按字查页码（字符 → 编码），一面按页码查字（编码 → 字符）。

课堂代码逐行验证（含输出）：

print("ABC"+"DEF"+"XYZ")        # ABCDEFXYZ
print("ABC"*3)                  # ABCABCABC
print('AB' in  "ABC")           # True
print('ab' not in  "ABC")       # True
print(len(""), len("英文字母包括：ABC"))        # 0 10
print(str(510100200001010001))                  # 510100200001010001
print(ord('+'), ord('A'), ord('a'), ord('四'), ord('川'))
                                                # 43 65 97 22235 24029
print(chr(42), chr(66), chr(98), chr(22234), chr(24030))
                                                # * B b 囚 州
  • len("英文字母包括：ABC") 得 10：英文字母包括 6 个 + 中文冒号 1 个 + ABC 3 个——每个字符都算 1
  • ord('ab') 这类多字符参数会报错——ord 只收单个字符
  • ord 和 chr 互为逆运算：chr(ord('A')) 还是 'A'
print(ord('A'))    # 65
print(ord('a'))    # 97
print(ord('川'))   # 24029

查字典第一面：把字符翻译成它的 Unicode 编码（相当于页码）。大写 A 是 65，小写 a 是 97——正好差 32，这就是大小写转换方法的底层原理。

print(chr(65))     # A
print(chr(22235))  # 囚
print(chr(ord('A')))   # A —— 互逆：翻过去再翻回来

查字典第二面：报出页码，字典还你那个字。ord 进 chr 出，正好互相抵消——「互变魔术」成立。

❓ 测验

print('AB' in "ABC") 的输出是？

✏️ 填空

ord() 返回字符对应的＿＿编码，chr() 是它的逆运算。（填一个英文单词）

⚠️ 避坑
三个高频翻车点

① ord() 的参数必须是单个字符——ord('AB') 直接报 TypeError；② len() 把中文、英文、标点都算 1 个字符，别以为中文占几个「格」就多算；③ in 是整体连续匹配且区分大小写：'ab' in "ABC" 是 False（小写的 ab 不是 ABC 的连续子串），而 'ab' not in "ABC" 才是 True。另外 + 只能字符串拼字符串，"123" + 1 会报错，想拼接数字得先 str()。

✅ 小结
你现在知道了

四个运算符：+ 拼接、* 重复、in / not in 判断包含（连续匹配、区分大小写）；四个函数：len() 数长度（中英文标点都算 1）、str() 转字符串、ord() 字符变 Unicode 编码（只收单字符）、chr() 编码变字符——两者互为逆运算。下一节：用这对编码差 32 的规律，揭秘大小写转换方法！
