为什么学这个

Python 到底跑在什么东西上？

你马上要在这台电脑上安装 Python、写代码、跑程序。可「计算机」到底是什么构成的？为什么有的电脑跑 Python 快、有的慢？把计算机系统的架构搞清楚，后面「环境搭建」「编译与解释」这些概念才不会悬在半空。学完这一节，你能回答：

  • 计算机系统由哪两大部分组成？（第一章常考）
  • 硬件的「五大件」分别是什么，谁是核心？
  • 为什么说没有软件的计算机只是一台「裸机」，什么都干不了？
💡 打个比方
一家餐厅：硬件是厨房设备，软件是菜谱和管理制度

硬件就像餐厅的灶台、冰箱、锅碗瓢盆——看得见摸得着，但光有设备做不出菜。软件是菜谱和管理流程——告诉设备「先切菜、再开火、炒几分钟」。两者缺一不可：只有硬件的餐厅开不了张，只有软件（没有厨房）的餐厅更是空中楼阁。

而操作系统就是这家餐厅的大堂经理：调度厨师（CPU）、安排库房（存储器）、对接服务员（输入输出设备）。下一节我们就专门讲这位经理。

核心概念

计算机系统 = 硬件 + 软件

  • 硬件：构成计算机的物理部件，经典说法是「五大件」——运算器（负责算）、控制器（负责指挥），两者合称 CPU（中央处理器，整台电脑的大脑）；存储器（内存断电即忘、速度快，外存如硬盘断电不忘、容量大）；输入设备（键盘、鼠标、麦克风）；输出设备（显示器、音箱、打印机）。
  • 软件：运行在硬件上的程序与数据的总称，分两大类——系统软件（操作系统、驱动程序等，负责管理硬件、为其他软件提供运行环境）和应用软件（微信、浏览器、Python 等直接帮用户干活的程序）。
  • 裸机：只有硬件、没装任何软件的计算机。裸机几乎什么都做不了——「没有软件的计算机是裸机」，这句是判断题常客。
运算器 + 控制器合称 CPU，负责计算与指挥全局
存储器内存快而小、外存慢而大，分工合作
输入 / 输出设备人机交互的「耳朵嘴巴」和「脸和嗓子」

CPU（中央处理器）由哪两部分组成？

✏️ 填空

计算机系统由＿＿和＿＿两大部分组成。请在框里按顺序填这两个词（空格隔开，先后顺序不限）：

⚠️ 避坑
这三个常见误解，考试里最爱挖坑

误区一：「CPU 就是机箱」。机箱里装着主板、硬盘、电源等一大堆部件，CPU 只是里面指甲盖大小的一块芯片——它是核心，但远不是全部。

误区二：「内存和硬盘是一回事」。内存断电后数据全部丢失、速度快、容量小；硬盘（外存）断电不忘、速度慢、容量大。买电脑说的「16G 内存 + 512G 硬盘」就是这两样。

误区三：「显示器是核心部件」。显示器属于输出设备，负责把结果「演」给你看；它坏了电脑照样能算，只是你看不到结果。

🤖 用 AI 巩固这一节

复制下面这段话发给任意 AI 助手，让它换个角度帮你消化：

我刚学了「计算机系统 = 硬件 + 软件」：硬件五大件是运算器、控制器（合称 CPU）、存储器、输入设备、输出设备；软件分系统软件和应用软件。请：1）用快递站或餐厅的类比把这套架构再讲一遍；2）出 2 道单选题和 1 道填空题考我，等我作答后再公布答案；3）告诉我内存和外存最关键的两点区别。
🔧 试一试：认识你自己的「金字塔底座」（3 分钟）
  1. Windows 用户：打开设置 → 系统 → 关于，找到「设备规格」，查看你的 CPU 型号（如 Intel Core i5-12500H）和已安装内存（RAM）大小。
  2. Mac 用户：点屏幕左上角 → 关于本机，同样能看到芯片与内存信息。
  3. 对照本节内容大声说出：「我的 CPU 里包含运算器和控制器；这个 16G 是内存，512G 是外存硬盘。」
  4. 进阶：按 Ctrl + Shift + Esc 打开任务管理器，看「性能」标签里 CPU 和内存的实时占用——你正在亲眼看见硬件被操作系统调度。
✅ 小结
你现在知道了

计算机系统 = 硬件 + 软件。硬件五大件：运算器、控制器（合称 CPU）、存储器（内存 / 外存）、输入设备、输出设备；软件分系统软件（操作系统、驱动）与应用软件；没有软件的计算机叫裸机。从用户到硬件，一层层分工、层层支撑——就像刚才点开的金字塔。下一节，我们去认识金字塔里最重要的一位「中间管理者」：操作系统。
