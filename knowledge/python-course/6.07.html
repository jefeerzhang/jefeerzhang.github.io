为什么学这个

有的参数每次都得给，有的可以「不给就用老的」

上一节学了按位置传参和按名称传参，但还有一个更实际的问题：调用函数时，是不是每个参数都必须亲手给值？答案是：调用执行时每个参数都必须有值——但定义函数时，我们可以提前给某些参数指定默认值，这样调用者不给它传值也能跑。这两类参数分别叫必须参数和可选参数，学会了函数会灵活得多。

💡 打个比方
定义函数像点奶茶：杯子必选，甜度可以不选

点单页上有两栏：杯子——不选就没法下单，这是必须参数；甜度——你不说，店员就默认给你「五分甜」，这是可选参数（定义时已经写好了默认值）。但注意：你要是主动说了「七分甜」，店员就按七分甜做——一旦传了值，默认值就被覆盖。还有一个店规：可选的那栏必须排在必选的后面，否则点单机器直接罢工。

核心概念

必须参数与可选参数的分工

  • 铁律：调用执行时每个参数必须有值——可选参数「可以不传」，是因为定义时已经有默认值兜底，不是因为它不需要值
  • 必须参数：必须由调用者提供值，一个都不能少，少传就报 TypeError
  • 可选参数：定义时指定了默认值（如 b=2），调用者不提供就用默认值，提供了就用新值
  • 位置规则（必考）：可选参数必须位于所有必须参数后面——先排「不给不行」的，再排「有默认」的
  • 一个函数可以既有必须参数又有可选参数，也可以全部是可选参数
课堂代码

PPT 原例：getpow(a, b=2)

def getpow(a, b=2):
    c = a ** b
    return c

print(getpow(5))     # a 必须参数；b 可选参数，用默认值 2
print(getpow(5, 3))  # b 用传入的 3，默认值被覆盖

输出结果：

25
125
  • getpow(5)：只传了 a=5，b 自动取默认值 2，算 5² = 25
  • getpow(5, 3)：a=5、b=3 都传了，算 5³ = 125
  • 同一个函数，调用 1 次或 2 次参数都行——这就是可选参数带来的灵活性

🔬 getpow 实验台：填 a（必填）和 b（可留空），看默认值什么时候生效

def demo(a, b=2): return a ** b，print(demo(5)) 的输出是？

✏️ 填空

调用执行时每个参数都必须有值：必须由调用者提供值的参数叫＿＿参数；定义时指定了默认值的参数叫＿＿参数，它必须位于所有必须参数＿＿面。（三空用空格隔开）

⚠️ 避坑
四个高频翻车点

①可选参数写到了必须参数前面：def getpow(a=2, b) 直接 SyntaxError（parameter without a default follows parameter with a default）——有默认值的必须排后面；

②传了新值还以为用默认：getpow(5, 3) 里 b 已经是 3，别再按默认值 2 算成 25——一旦传值，默认值立即被覆盖；

③必须参数一个都不能少：getpow() 报 TypeError——a 是必须参数，没有默认值兜底，「点奶茶不选杯子」是下不了单的。

④可变对象不能直接当默认值：def add(x, lst=[]) 里的 [] 只在定义函数时创建一次，之后每次调用都共用同一个列表，结果越攒越多。默认值要写 None 占位，进函数后再判断 if lst is None: lst = []。

✅ 小结
你现在知道了

调用执行时每个参数都必须有值；必须参数由调用者提供，可选参数定义时带默认值、不给就用默认、给了就覆盖；可选参数必须位于所有必须参数后面。下一节：参数数量不定怎么办——不定长参数 *args 与 **kwargs。
