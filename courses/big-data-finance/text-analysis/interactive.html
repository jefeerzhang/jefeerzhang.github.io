02 / 词频

整组评论在说什么？

词云与词频表使用上方同一组虚构评论；清理广告和重复后，两者会同步重新计算。

词云：出现越多，字号越大

展示出现次数最多的 12 个词；次数相同时按词语排序。点击词语，可回到案例查看对应评论。

词频表：每个词出现了几次

词频为当前纳入的全部评论中该词出现的总次数；文档数表示有多少条评论包含该词。

词语出现次数出现的评论数

展示前 12 个词。词语由教学示例预先切分；词云大小表示次数，不代表情绪或重要程度。

03 / 关键词

TF-IDF：这个词为什么值得注意？

选一条评论，再点击一个词：先观察它在当前评论中出现几次，再观察它在多少条评论中出现。

第一步：看当前评论

TF 是该词在当前评论中的次数除以该评论全部预设词数，和整组评论的词频次数不同。

第二步：看整组评论

每个方块代表一条纳入统计的评论，绿色表示包含所选词。清理重复和广告后，文档总数会变。

TF-IDF 帮助寻找有区分度的词，但罕见词可能是错字，也可能与问题无关；需要回看原文。

05 / 情感

一句话的态度怎样计算？

选取同一组评论，找出词典中的积极词和消极词，再观察一个简化情绪得分。

词典与评论

教学词典：积极词为“期待、不错、满意、乐观、稳”；消极词为“担心、跌”。

情绪得分

情绪得分 =（积极词数 − 消极词数）÷ 总词数

这个得分与上方“简单词典分类”是两种不同规则；得分为 0 可能是没有情绪词，也可能是正负词互相抵消，不一定代表中性。否定、反讽和混合态度必须回看原文。

07 / 公式

把核心计算写清楚

公式用于理解计算思路。具体数字可在上方案例中点击词语或切换样本查看。

词频 TF

TF = 词在当前评论中的次数当前评论的总词数

衡量一个词在当前评论中出现的频繁程度。上方词频表统计的是整组评论的出现总次数，两者口径不同。

逆文档频率 IDF 与 TF-IDF

IDF = log₁₀ 评论总数包含该词的评论数
TF-IDF = TF × IDF

在同一组评论里较少见的词，IDF 通常较高。本例使用未平滑的基本公式，其他实现可能不同。

简化情绪得分

情绪得分 = 积极词数 − 消极词数当前评论总词数

这是本课的示例口径；正负词抵消后为零，并不能证明语气中性，还要阅读原文。

积极评论占比

积极评论占比 = 积极评论条数纳入统计的评论总条数

分母包含当前所有纳入的评论，包括不确定类别；口径改变时不能直接比较。

08 / 理解

刚才发生了什么？

同一个案例中的不同步骤，回答的是不同问题。

从词语到观点

词频关注一个词在当前文本中出现得有多频繁。TF-IDF 还会考虑这个词在整个文本集合中有多常见，帮助寻找具有区分度的词。

词频：当前文本IDF：全部文本情绪：结合语境

例如“公告”常出现时，可能不如某个较少出现的词有区分度。但罕见词也可能无关或是错字，仍然需要检查。

词袋与词向量：词袋记录词是否出现或出现多少次，通常忽略词序；词向量把词表示为一组数字，可利用上下文反映词语关系。二者都有适用范围。

大模型辅助：可以协助归纳话题、提取信息、给评论分类或生成摘要；结果仍要回看原文。输入非公开或含个人信息的内容前，要先确认授权和工具的数据使用方式。

工作台把预设的分词结果当作输入，并按页面标明的基本公式实际计算；它不是自动分词器，也没有调用大模型。

09 / 应用

同一思路还能用在哪里？

换一个问题，也要重新选择文本、确定分析结果并检查使用边界。

银行客户反馈

把经过授权和适当处理的反馈按收费、办理速度等话题归类，帮助定位需要进一步核查的问题。

公司公告

辅助定位公告中的经营变化或风险描述，帮助读者快速找到需要细读的原文；摘要可能遗漏条件。

金融新闻

按话题整理新闻，观察报道重点；报道数量、报道立场与事实本身是不同概念。

数据来源和授权决定能分析什么；大模型的摘要、分类或其他输出，都应与原文和其他证据核对。
