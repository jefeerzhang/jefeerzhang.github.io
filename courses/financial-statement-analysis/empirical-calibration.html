实证口径说明

使用说明：

  1. 本文件规定共同基准的数据、变量、样本和模型口径。各组按本文件驱动 Agent 取数、建变量、估计模型。任务 5 起在课内并行进行，做不完的课后继续。
  2. 把本文件整份发给你的 Agent，要求它逐条遵守。Agent 提出改口径时，先问自己：这是共同基准的改动，还是本组拓展？共同基准不改，拓展写进研究方案。
  3. 共同基准用于各组结果互相比较。口径不同，结果就不能比，所以本文件里「必须」的条目不得自行调整。
  4. 本文件不提供数据集和代码。数据与代码由各组自己生成，并作为成果提交。

第一节 数据来源与权限

  1. 参考接口：Tushare Pro 的利润表 income、现金流量表 cashflow、资产负债表 balancesheet 与股票列表 stock_basic。字段名以 Tushare 为准。
  2. 取数范围与权限：本课样本限定为申万「机械设备」行业的公司（约 630 家当前成员），按第二节的成员名单逐只查询 income、cashflow、balancesheet 即可，不需要批量接口。有 income_vip 等批量接口权限时，可以按报告期取全市场，再按名单筛选。
  3. 其他数据源：允许使用其他接口，但必须：
    • 写出每个变量对应的原字段名；
    • 通过第六节的「数据核对」；
    • 在报告中说明与 Tushare 口径的差异。
  4. 单页上限：Tushare 单次返回有条数上限，批量查询必须用 offset/limit 分页，直到某页返回条数小于上限。没有分页的数据会悄悄少一截，这是最常见的取数错误。
  5. 令牌（token）由教师提供，不得写进代码文件或报告，用环境变量传入。

注意比较数据的调整：公司在下一年年报里可能调整上年数字（会计政策变更、差错更正）。本口径的期初总资产取上一年年报首次披露的期末数，不取下一年年报里「调整后」的上年数。

第三节 变量定义（必须）

变量定义Tushare 字段
\(NI_{i,t}\)合并净利润（含少数股东损益）income.n_income
\(CFO_{i,t}\)经营活动产生的现金流量净额cashflow.n_cashflow_act
\(TA_{i,t}\)期末资产总计balancesheet.total_assets
\(AvgTA_{i,t}\)\((TA_{i,t}+TA_{i,t-1})/2\)；\(TA_{i,t-1}\) 取 \(t-1\) 年年报—
\(E_{i,t}\)\(NI_{i,t}/AvgTA_{i,t}\)—
\(CF_{i,t}\)\(CFO_{i,t}/AvgTA_{i,t}\)—
\(ACC_{i,t}\)\(E_{i,t}-CF_{i,t}\)—
\(E_{i,t+h}\)\(t+h\) 年报按同一口径计算的 \(E\)，\(h=1,2,3\)—
  • 净利润用合并净利润，不用归母净利润。原因：经营现金流和总资产都是合并口径，分子分母要对齐。
  • \(AvgTA \le 0\) 或任一组成项缺失时，该公司年度不进入样本，不做填补。
  • \(E_{i,t+h}\) 缺失（多为停止披露）时，该公司年度只退出对应期限的样本。不得用 0 或上一年数据填补。
  • \(ACC\) 按 \(E-CF\) 计算。它除营运资本变动外，还含折旧摊销、资产减值、利息费用、投资收益和公允价值变动。解释 \(ACC\) 时，不得直接等同于「应计项目的可靠性」。

第四节 样本区间与处理规则（必须）

  1. 报告期 \(t\)：2014 年起。2013 年年报只用于期初总资产。
  2. 各期限的截止年份：样本窗口到 2025 年年报为止。
    • \(h=1\)：\(t\) 为 2014–2024 年；
    • \(h=2\)：\(t\) 为 2014–2023 年；
    • \(h=3\)：\(t\) 为 2014–2022 年。
  3. 缩尾：在每个报告期 \(t\) 内，对 \(E\)、\(CF\)、\(ACC\)、\(E_{t+1}\)、\(E_{t+2}\)、\(E_{t+3}\) 分别按 1% 与 99% 分位缩尾。不删除极端值。缩尾后 \(ACC\) 不再严格等于 \(E-CF\)，这是预期结果，不是数据错误。
  4. 不预先剔除被特别处理（ST）或业绩恶化的公司。已退市公司（list_status = D）整家删除。
  5. 样本流失表：按上面的顺序逐步筛选，每一步记录剩余的公司年度数和公司数；每个期限另记未来盈余缺失的观测数。
  6. 局限：申万分类会调整。公司按成员名单一次性归入机械设备，不按年份处理中途改行。样本只有一个行业、9 个左右的报告期，结论只适用于机械设备，只作小样本演示。

第五节 共同基准模型（必须）

模型一：总体持续性

\[ E_{i,t+h}=\alpha_h+\beta_h E_{i,t}+\text{年份固定效应}+\varepsilon_{i,t+h} \]

模型二：现金与应计分解

\[ E_{i,t+h}=\alpha_h+\beta^C_h CF_{i,t}+\beta^A_h ACC_{i,t}+\text{年份固定效应}+\varepsilon_{i,t+h} \]
  • \(h=1,2,3\) 各估计一次，共 6 个回归。
  • 年份指报告期 \(t\)。样本只有一个行业，基准不加行业固定效应。
  • 标准误按公司聚类。
  • 共同基准不加控制变量。控制变量属于本组拓展，写进研究方案。

必须报告的检验

假设检验报告内容
H1：当前盈余包含未来一至三年盈余的信息模型一中 \(\beta_h=0\) 的 \(t\) 检验系数、标准误、\(p\) 值、样本量、\(R^2\)
H2：应计构成的持续性低于现金构成模型二中 \(\beta^C_h=\beta^A_h\) 的 Wald 检验（双侧）差值、\(p\) 值；支持 H2 须 \(\beta^C_h>\beta^A_h\) 且差异显著；不能只比较两个系数谁大
H3：两者的差异随期限变化「差异」固定为差值 \(\beta^C-\beta^A\)，用下面的堆叠检验检验方法、结果

H3 的检验方法：把 \(h=1\) 与 \(h=3\) 的样本堆叠，让系数和固定效应按期限分开，检验 \((\beta^C-\beta^A)_{h=3}\) 与 \((\beta^C-\beta^A)_{h=1}\) 的差异。比值 \(\beta^A/\beta^C\) 可以作为补充，不替代差值。

第七节 稳健性检查

共同基准之外，每组至少做一项有明确目的的稳健性检查，并说明它回答什么问题。可选：

检查回答的问题
在基准上加公司固定效应结果是否只反映公司之间长期盈余水平的差异
在基准上加二级行业固定效应结果是否由机械设备内部的细分行业差异驱动
三个期限使用同一批公司年度（共同样本）系数随期限变化，是否只是样本构成变化造成的
用最新更正版记录替代首次披露版单独发布的更正公告是否影响结论。不含下一年年报对上年数的调整
剔除准则换版年份（2018–2021 年）结果是否由 CAS 22、CAS 14、CAS 21 的施行造成的口径断点驱动
公司与年份双向聚类（年份聚类数只有 8–10 个，仅供参考）同一年份公司之间的相关性是否使标准误被低估
剔除某一二级行业或某一时期结果是否由个别细分行业或年份驱动

第八节 报告必须写明的事项

  1. 数据源、接口名、查询参数、取数日期。
  2. 第六节数据核对的结果。
  3. 样本流失表（第四节第 5 条）。
  4. \(E\)、\(CF\)、\(ACC\)、\(E_{t+h}\) 的描述统计。
  5. 6 个基准回归的结果，以及 H1、H2、H3 的检验结果。
  6. 系数的经济含义，例如：「本期资产收益率高 1 个百分点，下一年平均高多少个百分点。」
  7. 结论能支持什么，不能排除哪些替代解释。
  8. 可复现的完整代码。另一组拿到代码，用自己的令牌运行，应能得到同样的数字。

第九节 准则换版提示

样本跨越多次会计准则修订。取数和解释前，必须按报告期适用的准则版本判断字段。把本节一并发给 Agent。

准则其他境内上市企业施行年份境内外同时上市企业施行年份对报表的影响
CAS 22（2017 修订，财会〔2017〕7 号）20192018以预期信用损失计提减值。执行该准则的企业，利润表列示「信用减值损失」（财会〔2018〕15 号、财会〔2019〕6 号格式）。未执行的企业，应收款项减值计入「资产减值损失」
CAS 14（2017 修订，财会〔2017〕22 号）20202018出现合同资产、合同负债。无条件收款权列应收款项（第四十一条）
CAS 21（2018 修订，财会〔2018〕35 号）20212019承租人确认使用权资产和租赁负债。偿还租赁负债本金和利息列筹资活动现金流出（第五十三条）

执行企业会计准则的非上市企业，三项准则均自 2021 年起施行。

  1. 口径断点：CAS 21 施行后，承租人的经营现金流上升，总资产上升。\(E\)、\(CF\)、\(ACC\) 在各企业的施行年份出现断点。年份固定效应吸收共同冲击，不吸收企业间施行年份的差异。可以把「剔除 2018–2021 年」作为稳健性检查。
  2. 字段存在性：2020 年前的年报（境内外同时上市企业为 2018 年前）没有合同资产、合同负债。跨年度比较合同资产增速时，必须说明。
  3. 减值转回：存货跌价准备可以转回（CAS 1 第十九条）。信用损失准备的转回额计入当期损益（CAS 22 第四十八条）。长期资产减值损失一经确认，不得转回（CAS 8 第十七条）。
  4. 字段对应：字段由 Agent 查找，常用字段见第十节。F5 不要求填字段名；F6 报告中写明每个变量对应的原字段名。
