3.0 盈余是什么，怎样从利润表算出来

← 返回任务 0

3.0.0 盈余的界定

「盈余」不是《企业会计准则》的用语。准则的对应概念是会计要素「利润」。学术研究把它叫作 earnings，本课沿用「盈余」。界定分四步：

  1. 准则怎样定义利润。《企业会计准则——基本准则》第十条把利润列为六个会计要素之一。第三十七条规定：「利润是指企业在一定会计期间的经营成果。利润包括收入减去费用后的净额、直接计入当期利润的利得和损失等。」
  2. 利润由哪几部分构成。
    • 收入减去费用后的净额：收入是日常活动形成的经济利益总流入（第三十条），费用是日常活动发生的经济利益总流出（第三十三条）。
    • 直接计入当期利润的利得和损失：非日常活动形成，应当计入当期损益（第三十八条）。例如营业外收入、营业外支出。
  3. 哪些不属于利润。直接计入所有者权益的利得和损失不计入当期损益（第二十七条），在利润表中列为「其他综合收益」，位于净利润之后。所有者投入资本和向所有者分配利润也不是利润。
  4. 利润按什么基础确定。企业以权责发生制为基础确认、计量和报告（第九条）。收入和费用按归属期间计入，不按现金收付计入。利润项目列入利润表（第四十条）。
本课的界定：盈余是企业一个会计期间按权责发生制确认的经营成果，取合并利润表「净利润」项目的金额，即营业利润加营业外收支、减所得税费用之后的数。它包含少数股东损益，不包含其他综合收益。本课问「盈余能不能持续」，就是问这一数字在未来几年还能延续多少。

3.0.1 利润表的计算顺序

利润表从营业收入出发，逐行加减，依次得到营业利润、利润总额和净利润：

  营业收入
− 营业成本                ← 营业收入 − 营业成本 = 毛利（分析用语）
− 税金及附加
− 销售费用、管理费用、研发费用、财务费用（教材合称期间费用）
+ 其他收益
+ 投资收益
+ 公允价值变动收益
+ 信用减值损失、资产减值损失（损失用负数列示，加上负数就是扣减）
+ 资产处置收益
= 营业利润
+ 营业外收入
− 营业外支出
= 利润总额
− 所得税费用
= 净利润
    按所有权归属分类：归属于母公司股东的净利润（简称“归母净利润”）
                      少数股东损益

投资收益、公允价值变动收益和资产处置收益为损失时，同样用负数列示。

哪些是报表项目，哪些是分析用语。上面各行的项目名称都是利润表的列报项目，以财会〔2019〕6 号、财会〔2019〕16 号的报表格式为准。箭头后的「毛利」、括号里的「期间费用」和 3.0.4 节的「平均总资产」是分析用语，报表上没有这几行。算毛利，用利润表的「营业收入」减「营业成本」；算平均总资产，用资产负债表的「资产总计」。

三个容易记错范围的项目（依据财会〔2019〕6 号的项目说明）：

  • 其他收益：计入其他收益的政府补助，以及其他与日常活动相关的项目。与日常活动无关的政府补助，记入营业外收入。收到补助不等于确认收益：与资产相关的补助先记为递延收益，再分期确认。
  • 资产处置收益：出售持有待售的非流动资产或处置组，以及处置固定资产、在建工程、生产性生物资产和无形资产形成的利得或损失。处置金融工具、长期股权投资和投资性房地产的损益不在这一行。
  • 营业外收入、营业外支出：与日常活动无关的利得和损失。例如，固定资产报废、毁损的损失记入营业外支出，不记入资产处置收益。

读年报时注意三点：

  1. 行前编号因报表而不同。合并利润表（财会〔2019〕16 号格式）先列「营业总收入」「营业总成本」，净利润排在「五、」。母公司利润表（财会〔2019〕6 号格式）从「营业收入」开始，净利润排在「四、」。找行次时认项目名称，不认编号。
  2. 减值损失的位置随年份变化。较早年份的报表把资产减值损失列在「减」的项目里，用正数列示。财会〔2019〕6 号格式起，减值损失列在「加」的项目里，用负数列示。两种写法对净利润的影响相同。信用减值损失只在企业执行新金融工具准则后出现，见《实证口径说明》第九节。
  3. 年报另列扣非净利润。年报「主要会计数据和财务指标」一节列示「归属于上市公司股东的扣除非经常性损益的净利润」。它扣除了偶发项目，可以和净利润对照着看。

3.0.2 每一行都按权责发生制确认，不等于现金

项目什么时候计入利润表本期有没有对应的现金
营业收入客户取得商品或服务的控制权时不一定。赊销时先确认收入，形成应收账款
营业成本与对应的收入同期确认不一定。存货可能在以前期间买入，也可能是赊购
期间费用费用发生的期间不一定。例如已计提、尚未支付的工资和利息
折旧与摊销（含在营业成本和期间费用中）在资产使用年限内分期确认没有。现金在购置资产时已经付出
信用减值损失、资产减值损失估计资产价值下降时没有。它是会计估计
投资收益例如按持股比例分享被投资单位的净利润时（权益法）不一定。分享的净利润不等于收到的分红
公允价值变动收益持有的金融资产价格变动时没有。资产尚未出售

因此，净利润是按权责发生制一行行算出来的，不是本期现金的增加额。净利润与经营现金流之差就是应计项目，3.2 节、3.3 节接着讲。

3.0.3 哪些行更可能延续

  • 毛利和期间费用来自主营业务，每年都会发生，通常更能延续。
  • 资产处置收益、营业外收入和营业外支出多来自偶发事项，下一年不一定再出现。
  • 其他收益、投资收益和公允价值变动收益要看来源。同一类补助或投资每年都有，就可能延续；一次性的，就难以延续。
  • 减值损失来自会计估计，金额每年变化，还可能在后续期间被修正。

这只是常见情况。判断某家公司的某个项目，要查附注中的明细。

3.0.4 本课用哪个净利润，怎样换算成 \(E\)

本课用合并净利润（含少数股东损益），不用归母净利润。原因：经营现金流和总资产都是合并口径，分子分母要对齐。

公司规模差别很大，净利润的金额不能直接比较。所以本课用平均总资产缩放净利润：

\[ E_t=\frac{\text{净利润}_t}{(\text{期初总资产}_t+\text{期末总资产}_t)/2} \]
  • 总资产取资产负债表的「资产总计」。期初总资产取上年年报的期末数。本年年报「上年年末」栏的数字可能因追溯调整与之不同，本课以上年年报为准，见《实证口径说明》第三节。
  • \(E\) 相当于资产收益率。
  • 例：净利润 60 万元，期初总资产 900 万元，期末总资产 1,100 万元。平均总资产为 1,000 万元，\(E=6\%\)。

盈余持续性问的就是：今年的 \(E\)，到明年、后年、大后年还能延续多少。今年 \(E\) 中偶发项目越多，能延续的部分通常越少。

3.1 盈余持续性是什么

← 返回任务 0

盈余持续性是当前盈余所代表的经营结果在未来期间延续的程度。

  • 持续性不等于盈余永远不变，也不等于盈余一定增长。
  • 净现比（经营现金流除以净利润）描述当前盈余有多少现金支持；持续性描述当前盈余在未来能延续多少。两者相关，但不是一回事。
  • 盈余增长描述盈余的变化方向。连续增长的盈余也可能难以持续，例如增长来自越积越多的应收账款。

3.2 三张表怎样记录同一件事

← 返回任务 0

收付与确认存在时间差 → 形成应计项目 → 在资产负债表中积累 → 后续兑现、反转或减值 → 影响未来盈余。
  • 利润表记录本期确认的经营成果。
  • 现金流量表记录本期实际收付的现金。
  • 资产负债表保留尚未完成的确认、收付和估值结果。

任务 0 的 100 万元说明：净利润、现金和资产负债变化，是同一事项的三个侧面。三表勾稽关系本身是会计关系，不自动产生预测力。要检验的是：三表共同揭示的盈余构成，是否包含关于未来盈余的信息。

3.3 应计项目：信息还是风险

← 返回任务 1

把本期盈余拆成两部分：

\[ \text{盈余}=\text{经营现金流}+\text{应计项目} \]
  • 应计项目有信息。权责发生制把收入和费用放在「应该属于」的期间，比单看现金收付更能反映本期经营成果。
  • 应计项目也有风险。它依赖估计：应收账款能不能收回、存货会不会跌价、费用该不该资本化。估计越多，后续被修正、反转（应计项目在后续期间转为相反方向）或减值的可能越大。
  • 因此一种常见的推测是：应计构成的持续性低于现金构成。这是本课共同基准要检验的假设 H2，不是结论。

共同基准的 \(ACC\) 按 \(E-CF\) 计算。它除营运资本变动外，还含折旧摊销、资产减值、利息费用（筹资活动支付，不在经营现金流内）、投资收益和公允价值变动。解释 \(ACC\) 时，不得直接把它等同于「应计项目的可靠性」。

3.4 两个必须保留的反面判断

← 返回任务 1

  1. 应计项目不等于盈余操纵。正常经营和增长也会形成应计项目。例如快速扩张的公司，应收账款和存货随收入一起增长。
  2. 经营现金流高于净利润，不必然代表高质量；低于净利润，也不必然代表风险。例如大额预收款可以让现金流暂时很高；正常的赊销扩张会让现金流暂时偏低。

做任何判断，都要给出机制证据，不能只凭一个比率下结论。

3.5 从案例到可检验的假设

← 返回任务 3

筛选候选公司的思路（不是公式，按你们的机制选一条或组合）：

思路报告期 \(t\) 的信号\(t+1\) 至 \(t+3\) 要看的结果基准 \(ACC\) 是否反映
高应计\(ACC\) 在同年机械设备行业中处于很高的位置资产收益率下降是：就是 \(ACC\) 本身
应收先行应收账款或合同资产增速远高于收入增速信用减值、坏账、收入增速下降是：应收增加使 \(ACC\) 上升
存货积压存货增速远高于营业成本增速存货跌价准备、毛利率下降是：存货增加使 \(ACC\) 上升
资本化扩张开发支出、在建工程或无形资产快速增加资产减值、折旧摊销上升否：资本化支出列投资活动，\(ACC\) 不上升，须自己构造变量
净利润与经营现金流背离净利润连续增长，经营现金流持续为负或下降盈余中断、减值是：\(ACC\) 持续为正

筛选与重建时的口径提醒：

  1. 基准 \(ACC\) 按 \(E-CF\) 计算。费用资本化使现金流出转入投资活动，经营现金流不下降，\(ACC\) 不显示这类异常。选「资本化扩张」须自己构造变量。
  2. 「异常」须有数据阈值，并写入 F3。高应计思路统一用：\(ACC\) 位于同年机械设备行业内前 10%。其他思路由小组写明阈值。
  3. 「信用减值损失」「合同资产」「合同负债」在不同年份的报表中不一定存在，见《实证口径说明》第九节。
  4. 重建链条时，先查年报附注：现金流量表补充资料（净利润调节为经营活动现金流量）、应收账款账龄与坏账准备、存货跌价准备的计提与转回（转回的范围见《实证口径说明》第九节）、重要会计政策变更。

从公司故事到一般机制：

层次例子
公司故事「这家公司 2018 年大量赊销，后来应收坏账，盈余下滑。」
一般机制「由应收账款增长带来的应计构成，持续性低于现金构成。」
可检验假设「在机械设备行业中，应收账款变化占平均总资产比例越高的公司，\(ACC_t\) 对 \(E_{t+h}\) 的系数越低。」

一个好的假设要能被数据否证：写清自变量、因变量、预期方向，以及什么结果会推翻它。

3.6 怎样把持续性变成回归

← 返回任务 5

持续性看不见，但可以用「今天的盈余能在多大程度上预测未来的盈余」来度量：

\[ E_{i,t+h}=\alpha_h+\beta_h E_{i,t}+\text{固定效应}+\varepsilon_{i,t+h} \]
  • \(E\) 是用平均总资产缩放的净利润，相当于资产收益率。
  • \(\beta_h\) 越接近 1，说明盈余越能延续；越接近 0，说明盈余很快回到平均水平。
  • 把 \(E_t\) 拆成现金构成 \(CF_t\)（经营现金流除以平均总资产）与应计构成 \(ACC_t\)（应计项目除以平均总资产），分别估计系数 \(\beta^C\)、\(\beta^A\)，就能检验哪一部分更能延续。
  • \(h=1,2,3\) 分别估计，看持续性随期限怎样变化。
  • \(\beta_h\) 是全样本的平均关系，不是单家公司的属性。案例公司的结果不能用 \(\beta_h\) 解释。

完整口径见《实证口径说明》。你们的拓展假设，通常是在共同基准上增加一个变量或一个交互项。例如检验「应收账款变化大的公司，应计构成的持续性更低」，可以加入 \(ACC_{i,t}\times \Delta AR_{i,t}\) 的交互项。其中 \(\Delta AR_{i,t}\) 为应收账款变化占平均总资产的比例，预期交互项系数为负。

3.7 怎样读回归结果

← 返回任务 5

  1. 先看大小和方向，再看显著性。例如 \(\beta_1=0.5\) 的含义是：本期资产收益率高 1 个百分点，下一年平均高 0.5 个百分点。
  2. 比较两个系数，要检验它们的差。\(\beta^C=0.6\)、\(\beta^A=0.4\) 看起来不同，但要用 Wald 检验 \(\beta^C=\beta^A\)，才能说「差异显著」。
  3. 「差异变化」要先定义。共同基准的 H3 固定用差值 \(\beta^C-\beta^A\)。差值变小时，比值 \(\beta^A/\beta^C\) 可能同时也变小，两者的结论可以不同。拓展若用比值，先说清度量。
  4. 设定不同，问题就不同。加公司固定效应后，系数度量的是「偏离本公司常态的盈余」能延续多久，和只含年份固定效应的基准回答的问题不同。
  5. 显著不等于因果。应计持续性低，可能来自会计估计误差，也可能来自经营本身的周期，还可能来自盈余管理。说清你的证据能排除哪一种，不能排除哪一种。
  6. 负结果也是结果。拓展假设没有得到支持，如实报告并解释，同样可以得高分。
