# 实验结果评价标准与记录表

> **版本与适用说明**：本表为逐项计分试评稿（实验A自主方案版）。现已确认为“每个实验模块独立使用一张评分表、按16个评分点逐项赋分并汇总”，不再采用笼统的1—4档整体印象给分模式。文中所列的0—3分赋分细则及50分底线限分方案均为本轮拟议规则，须经真实学生作品试评校准并由任课教师最终确认后方能正式生效。在四项能力的正式权重及“整个能力维度确认未开展”的计分标准尚未由教师确认前，相关参数槽位继续留空，系统不擅自输出正式实验总评成绩。

实验A按“固定范围、方案自拟”执行；不统一要求80期、五分组或NW滞后3。正式计算前的方案问答与教师确认属于O1证据，不另设口才分。R1—R3按本人确认方案核查；Q1—Q4仍评价任务二的新问题，不以重述任务一选方法重复得分。

## 一、教师评阅操作流程与基本准则

### 1.1 标准评阅八步法

1. **登记全局参数**：在配套Excel工作簿的「参数」工作表中登记本批次适用的规则版本号与评分参数。在正式能力权重未确认前保持对应单元格空白，系统不默认按四项各占25%计算。
2. **建立学生档案**：在「实验A」或「实验B」工作表中录入学生基本信息。每张工作表仅评阅一名学生的单次实验成果，不再将单一实验拆分为“基础任务”与“扩展任务”两套分数进行重复加权。
3. **调取原始证据**：对照O1—Q4共16个评分点，在学生提交的材料包中精确定位原始人机交互记录、输入数据、代码脚本与阶段产物。严格遵循**“先确认证据足以支撑判断，再行赋分”**的原则。
4. **逐项对照赋分**：当证据链完整可判时，对照该评分点的0—3分判定条件，选择**全部要求均已满足**的最高分档，仅填入整数`0`、`1`、`2`或`3`。
5. **记录评阅依据**：在每个评分点旁如实填写证据所在位置、学生的具体研究判断，以及未能获得更高分档所缺失的具体条件；经任课教师人工复核确认后，该项得分方才计入汇总。
6. **核查关键底线**：在“审查复核”维度，重点核查数据（R1）、计算（R2）、图表（R3）三类规定核查及自选点（R4）是否全面达标；在“结果解释”与“提出问题并组织验证”维度，同步核对是否存在触发第四节底线限分的情形。
7. **换算能力得分**：每项核心能力先将内部4个评分点的得分相加（原始满分12分），再折算为百分制得分（$\text{原始分} \div 12 \times 100$），并按已确认的底线规则执行限分处理。
8. **合成综合成绩**：待全部16个评分点、底线核查、能力权重与未开展计分规则均由教师确认完毕后，工作簿自动加权汇总单次实验成绩；实验A与实验B各占课程实验总成绩的50%。

### 1.2 赋分边界与免责保护原则

- **“0分”绝不等于“暂未找到文件”**：`0分`仅适用于现有证据已足以证实学生的实际表现未达到`1分`标准，或经核实直接确认该评分点对应的工作根本未开展。凡属提交材料缺漏、数值容差判据尚未确定或独立复算基准存在争议的情形，一律标记为**“待补核”**，得分单元格保持空白。若经核实整个能力维度的四个评分点均未开展，须先如实记录“确认未开展”状态，其对应的正式折算分值须待教师在参数页另行确认，评阅人或辅助工具不得自行将其直接记为0分。
- **累计递进与全覆盖要求**：`1—3分`仅在相关工作确已开展且现有证据足以支撑判断的前提下使用。凡在判定条件中注明**“在上一分档基础上”**的条款，必须同时满足此前所有低分档的全部要求；未作此注明的分档，则按该单元格列出的全部条件独立判定。当某一评分点涉及多个核心研究对象时，学生的分析必须实现全覆盖（例如实验A的`I1`必须按自己的确认方案分别阐释动量与反转，不得顾此失彼）。
- **科学容错与反重复计分原则**：本量表中的分档细则尚待真实学生习作试评校准。在实验过程中，**未发现智能体程序报错、实证检验结果在统计上不显著、中途未发生推倒返工，或者扩展研究未提出学术界首创的新理论，均不属于扣分理由**。同时，学生的同一项技术动作不会因为分别写进了基础报告与扩展报告而重复得分；若同一份证据同时支撑了两个不同评分点，评阅时须分别注明其在两个评分点下所印证的不同能力侧面。

## 二、16个评分点赋分细则（O1—Q4）

每项核心能力下设4个评分点，每个评分点最高3分，单项能力原始满分为12分。需注意，“每项能力12分”仅为能力维度内部的计分刻度，并不代表四项能力在总评中默认平分秋色；四项能力的正式权重须在「参数」页单独确认，不由评分点数量决定。

### 2.1 编排智能体（Orchestration，原始满分12分）

#### O1 将研究任务转化为明确的执行规范
- **核查依据**：调阅学生确认的任务解析与执行前方案、选择理由，以及对应的输入、程序和产物。实验A另查关键选择、一个替代方案与一项风险的问答及教师执行前确认；教师确认不担保方案正确。

| 分档 | 判定条件 |
|---|---|
| **0分** | 虽有尝试，但在研究对象、样本区间或基础业务规则上存在明显错误且始终未予纠正；或经核实直接确认此项未开展。 |
| **1分** | 学生准确确认了实验的研究对象与样本时间区间。 |
| **2分** | 在1分基础上，确认任务书版本、自己采用的研究规则及其理由与预期产物；实验A须解释关键选择、替代方案和风险，并在正式计算前取得教师确认。 |
| **3分** | 在2分基础上，逐一核对实际输入数据、程序执行选项与最终产物均同既定要求严丝合缝；实验中途若涉及业务规则微调，均先经学生本人审阅拍板后再行执行。 |

#### O2 科学把控分析步骤的前置依赖顺序
- **核查依据**：调阅数据接口小样本试取、交易日历或计算口径确认、全量批量执行的人机交互日志及对应时间戳记录。

| 分档 | 判定条件 |
|---|---|
| **0分** | 虽有执行动作，但未经任何前置探查便直接全盘接受智能体生成的批量结果；或经核实直接确认此项未开展。 |
| **1分** | 书面方案中列有“数据准备 $\rightarrow$ 量化计算 $\rightarrow$ 结果阐释”的步骤安排，但实际操作时未按前置依赖顺序推进。 |
| **2分** | 严格遵循“先开展小范围数据试取或微缩样本试算，验证无误后再启动全量批量执行”的顺序，且各环节时间戳与记录清晰可查。 |
| **3分** | 在2分基础上，学生能够结合试取或试算的具体输出说明放行后续步骤的依据，并明确指出一旦哪项前置指标未达标就必须暂缓全量计算。 |

#### O3 在关键节点实际启用人工检查点（Checkpoints）
- **核查依据**：调阅基础实验中的交易日历/股票样本/基金口径确认记录，以及在最终结论形成前对中间输出结果的人工审阅痕迹。

| 分档 | 判定条件 |
|---|---|
| **0分** | 仅在计划书中空谈设置检查点，经核实确认在实际执行过程中从未调阅过中间输出结果。 |
| **1分** | 实际调阅并检查了1个中间检查点的输出，但其余预设的关键检查点流于形式、未予执行。 |
| **2分** | 完整调阅并核查了“批量执行前的日历/样本/口径输出”与“结论形成前的汇总结果输出”两类关键节点，并分别作出了继续、修正或暂缓的明确决定。 |
| **3分** | 在2分基础上，能够针对每个检查点具体说明：自己是依据中间输出里的哪一项关键信息作出的决定，以及该决定具体传导并影响了下游的哪一步操作。 |

#### O4 将审阅决定精准落实到下游执行与产物管理
- **核查依据**：交叉比对学生下达的审阅指令、决策理由、随后智能体的工具调用记录以及更新后的产物版本。

| 分档 | 判定条件 |
|---|---|
| **0分** | 全程完全由智能体自行作主推进；或经核实直接确认学生从未审阅过关键执行决定。 |
| **1分** | 学生明确表达了“接受、修改或暂缓”的决定，但未给出任何基于实证输出的决策依据。 |
| **2分** | 学生能够引用具体的中间输出数据阐明决策理由，且智能体随后的实际执行动作与学生的决定完全吻合。 |
| **3分** | 在2分基础上，能够精确定位该项决定所波及的文件产物与代码修改范围，确认智能体在执行时未越权篡改其他无关模块（注：若首次执行即准确无误，无需为拿满分而刻意制造错误或返工）。 |

### 2.2 审查复核（Review & Verification，原始满分12分）

#### R1 系统核查底层数据质量
- **核查依据**：对照第三节“本实验必查清单（R1数据类）”，调阅数据源、股票代码/基金份额、交易日期、核心字段、缺失值/特殊状态（如ST、停牌）的核查输入与输出记录。

| 分档 | 判定条件 |
|---|---|
| **0分** | 仅凭API返回“请求成功”状态码或智能体自称“数据无误”便草率采信；或经核实直接确认未开展任何数据核查。 |
| **1分** | 实际动手核对了至少1项数据规则，但对照教师必查清单，仍存在已确认的核查遗漏或对已暴露的数据错误置之不理。 |
| **2分** | 第三节教师数据必查清单中的所有适用项目，均留有具体的核查输入、比对结果以及学生作出的“接受/修正/暂缓”判断记录。 |
| **3分** | 在2分基础上，能够深入阐明某一项底层数据潜在风险会如何扭曲下游实证结论，并客观界定现有数据核查手段尚无法完全排除的盲区。 |

#### R2 采用独立路径复核核心量化计算
- **核查依据**：对照第三节“本实验必查清单（R2计算类）”，调阅小样本测试输入、独立于原脚本的另路复算方法（如手工公式表、独立验证脚本）、输出差值比对及预登记容差判据。

| 分档 | 判定条件 |
|---|---|
| **0分** | 仅让同一段程序原地重跑一遍，或单纯把结果丢给另一个聊天智能体询问“对不对”，未展示任何在逻辑上能真正揪出计算错误的独立复核方法；或经核实直接确认未开展计算复核。 |
| **1分** | 虽对部分实际数值进行了另路复算，但对照必查清单仍遗漏了关键计算节点，或对复算发现的输入错位/数值差异未作妥善处理。 |
| **2分** | 计算必查清单中的所有适用项目均完成了另路独立复核；复算所用输入与公式口径严格对齐，并严格依据第七节预登记的容差判据对差值作出了合乎规范的判定。 |
| **3分** | 在2分基础上，能够清楚说明所采用的复核方法在机制上擅长捕获哪一类算法错误、又有哪些潜在缺陷无法覆盖（对于复算确认无误的结果，有据采信即可得分）。 |

#### R3 交叉核查汇总表格与可视化图表
- **核查依据**：对照第三节“本实验必查清单（R3结果类）”，调阅分组只数/基金份额、统计汇总表、量纲单位、正负符号、累计/回撤路径以及“表—图—底层序列”三方一致性核对记录。

| 分档 | 判定条件 |
|---|---|
| **0分** | 仅凭肉眼印象声称“图表走势看起来很合理”；或经核实直接确认未对汇总结果与图表开展任何核查。 |
| **1分** | 实际核对了至少1项结果呈现规则，但对照必查清单仍存在已确认的漏检项或图表错漏未予修正。 |
| **2分** | 结果必查清单中的所有适用项目均有扎实的比对记录与审阅判断；报告中的汇总表格、可视化图形与底层计算结果序列三者完全一致。 |
| **3分** | 在2分基础上，能够准确界定局部抽样核查所能背书的结论范围，并清醒指出仅靠当前图表核查仍不足以直接证明的宏观推论。 |

#### R4 自主遴选一个足以左右研究判断的关键核验点
- **核查依据**：调阅学生阐述的选点理由、测试输入、有效核验方法、实际输出及后续处置记录（允许与R1—R3共享底层技术证据，但须体现自主选点的针对性思考）。

| 分档 | 判定条件 |
|---|---|
| **0分** | 经核实直接确认未开展自选点核验，或所选核验点纯属边缘细节、与核心研究判断毫无关联。 |
| **1分** | 所选节点确与核心判断相关且开展了实际检查，但仅给出了“检查通过”的空洞结论，缺乏可查验的核对依据或处置过程。 |
| **2分** | 完整呈现了选点理由、规则依据、有效的独立核验方法、输入/输出数据，并据此作出了有理有据的接受、修正或暂缓决定。 |
| **3分** | 在2分基础上，能够深入剖析：倘若该节点发生差错将如何逆转报告中的哪一项核心判断，以及当前核验手段能够排除与尚不能排除的具体风险。 |

### 2.3 结果解释（Interpretation，原始满分12分）

#### I1 紧扣实证结果直接回答基础研究问题
- **核查依据**：对照基础研究问题审阅结论——实验A按学生已确认方案分别回答动量与反转，不要求统一REV1/MOM12–1；实验B综合任务书12项指标，回答收益排序能否度量主动管理能力。

| 分档 | 判定条件 |
|---|---|
| **0分** | 虽有文字阐述但对核心信号/指标方向解读错误，或通篇答非所问；经核实直接确认此项未开展亦记0分。 |
| **1分** | 仅罗列组合或其他检验的方向、基金名次，未结合本人方案的统计不确定性或必算风险指标展开论证。 |
| **2分** | 用本人已确认方案的完整基础结果分别回答动量与反转（实验A），或用规定的主要风险评价指标回答基金评价问题（实验B），无核心对象遗漏。 |
| **3分** | 在2分基础上，在行文中严谨区分“现有统计证据明确支持”“当前样本证据尚不充分”与“仅凭现有设计无法判断”三种状态，绝不将“统计上不显著”草率等同于“证明市场上不存在该效应”。 |

#### I2 为每一项核心论断配备精准的实证证据
- **核查依据**：先列核心论断：实验A包括按本人方案得到的动量与反转方向、经济量级和统计不确定性，不强制多空组合；实验B包括跨基金绩效、指标排名分歧（如有）及能力归因边界。

| 分档 | 判定条件 |
|---|---|
| **0分** | 经补核确认，报告中的核心论断完全缺乏实际计算产物支撑，或文中所引述的数值与真实图表产物严重不符且未予修正。 |
| **1分** | 至少有1项核心论断准确关联到了真实表图依据，但其余核心论断中仍存在经确认毫无数据支撑的空泛断言。 |
| **2分** | 报告中的所有核心论断均能精确锚定到真实的汇总表、净值/回撤图或统计检验数值，且所涉样本范围、时间区间与量纲单位严丝合缝。 |
| **3分** | 在2分基础上，能够同时结合效应量大小（经济显著性）与置信区间/波动范围（统计不确定性）展开解读，并在表述上严格区分“客观观测到的样本统计事实”与“有待进一步检验的机制猜想”。 |

#### I3 结合金融理论与指标构造机理阐释实证差异
- **核查依据**：审阅报告中关于指标经济学含义、模型方法与实证结果内在联系的论述，以及提出机制解释时所依托的客观材料。

| 分档 | 判定条件 |
|---|---|
| **0分** | 对核心金融指标或价格信号的经济学定义理解错误且未纠正；或经核实直接确认未作任何机理阐释。 |
| **1分** | 对主要指标的字面定义表述正确，但仅停留在教材概念摘抄，未能与本次实验的具体计算结果建立联系。 |
| **2分** | 紧密结合本次实证数字，阐明不同绩效指标为何在回答不同维度的财务问题（实验B），或价格信号的实证方向如何与行为金融/风险补偿理论预期相呼应（实验A）。 |
| **3分** | 在2分基础上，能够针对核心现象提出合乎逻辑的竞争性替代解释（Alternative Explanations），并清晰划定哪些部分已获当前数据支持、哪些部分尚待后续验证（注：若实证中多项指标结果高度一致，据实剖析其背后的共同驱动因素即可，无需刻意虚构指标分歧）。 |

#### I4 严谨界定研究结论的适用范围与外推边界
- **核查依据**：审阅报告中关于样本筛选特征、观察期市场环境及本实验方法论局限的讨论段落。

| 分档 | 判定条件 |
|---|---|
| **0分** | 在报告中保留了毫无证据支撑的绝对因果断言或管理能力定论，或将未扣费的理论回测收益直接吹嘘为实盘稳赚收益；或经核实直接确认未讨论结论边界。 |
| **1分** | 提及了至少1项具体的实证限制条件，但仅作泛泛陈词，未说明该限制如何具体影响本次实验结论的成立范围（注：仅写“股市有风险、投资需谨慎”等套话不得分）。 |
| **2分** | 结合实际方案说明样本、时期与推断限制：实验A涵盖481只固定名单的事后存续筛选，以及本人设计的交易成本、成交或做空假设如何限制结论；实验B涵盖风格漂移、基准依赖、样本期与能力归因局限。 |
| **3分** | 在2分基础上，逐项指明受上述局限制约**“因此不能夸大声称什么”**，并具体提出若要支撑更强的因果或实盘结论**“还需要补充采集哪一类关键证据”**。 |

### 2.4 提出问题并组织验证（Questioning & Verification，原始满分12分）

#### Q1 学生立足理论或实证发现自主凝练研究问题
- **核查依据**：调阅学生提出初步疑问的原始对话记录、问题诱发来源（具体图表或理论文献位置）以及最终敲定扩展研究问题的确认记录。

| 分档 | 判定条件 |
|---|---|
| **0分** | 经核实直接确认扩展题目完全由智能体代劳包办，学生本人既未表达过真实研究疑问，也未参与选题拍板。 |
| **1分** | 学生本人提出了具体的拓展疑问，但未能说明该疑问究竟源于哪一项金融理论、市场特征或基础实验中的哪一处具体结果。 |
| **2分** | 学生提出的疑问具有清晰可查的理论或前期实证来源，且最终的研究问题经由学生本人审阅确认。 |
| **3分** | 在2分基础上，能够清楚阐明：为什么现有的基础实验结果尚不足以回答这一新问题，以及本次扩展比较准备用来区分哪两种不同的解释。 |

#### Q2 在动手执行扩展计算前锁定结构化比较计划
- **核查依据**：比对学生正式确认扩展研究计划（150—200字）的文档版本时间戳，与智能体首次运行扩展计算脚本的时间戳。

| 分档 | 判定条件 |
|---|---|
| **0分** | 经核实直接确认属于“先跑完代码看结果，事后再倒推补写计划”，或在启动扩展计算前根本未确认过比较计划。 |
| **1分** | 在扩展执行前留有书面计划，指明了研究问题与大致比较对象，但对“改变哪一条件、控制哪些条件不变”或“不同结果各自代表什么含义”交代不清。 |
| **2分** | 在启动扩展计算前，已完整确认比较对象、拟改变变量与保持不变的控制条件、不同实证结果的判读逻辑以及配套的关键核验节点。 |
| **3分** | 在2分基础上，在事前计划中预先设定了应对数据缺失或样本不可比时的调整预案（如暂缓或切换共同样本口径），并在执行过程中完整保留了方案变更的理由记录。 |

#### Q3 扎实实施能够有效回答所提问题的对照比较
- **核查依据**：调阅扩展分析的底层输入数据、修改后的代码脚本、实际输出结果，以及与基础实验结果的同口径对照表图。

| 分档 | 判定条件 |
|---|---|
| **0分** | 经核实直接确认未开展任何实质性的对照计算，或跑出的扩展结果与Q1所提的研究问题风马牛不相及。 |
| **1分** | 开展了针对性的对照计算，但在比较时同时变动了多个混杂条件且未加剥离（如改变窗口的同时改变了股票池却直接混为一谈），或遗漏了已确认的可比性缺陷。 |
| **2分** | 实际执行的扩展比较与事前计划严格对应，拟改变的条件与要求锁定的控制条件均在代码中准确落实，对照结果清晰可查。 |
| **3分** | 在2分基础上，能够从实验设计原理上阐明该对照方案为何能够有效识别拟检验的机制，并实事求是地指出受限于现有数据或研究设计仍无法完全剥离的混杂因素。 |

#### Q4 依据经核验的扩展证据审慎更新研究认识
- **核查依据**：审阅学生如何将扩展阶段的关键核验结论运用于最终研究判断，以及决定保留、修正或暂缓原有观点的论证逻辑。

| 分档 | 判定条件 |
|---|---|
| **0分** | 经核实直接确认对扩展计算结果未作任何核验，亦未结合新证据对研究问题作出实质判断。 |
| **1分** | 学生虽根据扩展输出作出了文字判断，但完全忽略了关键核验环节的发现，或将统计不显著直接武断等同于“彻底推翻原解释”。 |
| **2分** | 准确引用经核验无误的扩展对照结果，严谨说明原有的研究认识究竟是得到了进一步强化、有所削弱，还是受限于证据强度暂无法定论。 |
| **3分** | 在2分基础上，清晰总结本次扩展探究成功排除了哪一种可能性、还留下哪些未解疑点，并针对剩余疑点提出具体可行的后续研究设想（注：无需强求扩展结果统计显著，亦无需以“推翻初始判断”为高分前提）。 |

## 三、两个实验模块的R1—R3规定核查清单

下表所列项目为评阅`R1（数据）`、`R2（计算）`、`R3（结果）`时的基准核查清单，任课教师须在评阅前按学生已确认方案具体化各项，登记适用范围、依据及方案版本，不得把教师固定参考方案当作隐藏标准。需要说明的是，**该清单并非要求学生针对每一细项单独撰写长篇说明报告**；学生的同一次系统检查可以同时覆盖并支撑多个细项，但每一项核查判断都必须在提交档案中有迹可循。若个别细项因数据源客观限制确不适用，须由教师统一注明豁免依据，学生不得擅自省略整个核查大类。

| 核查类别 | 实验A（中证500动量与反转）必查细项 | 实验B（开放式基金主动管理能力评价）必查细项 |
|---|---|---|
| **R1 数据核查** | 1. 固定481只名单与2019-12-31至2026-09-01研究期；<br>2. 本人方案实际所需日期、历史覆盖、样本有效数及缺口；<br>3. 所用价格/收益及复权等字段的来源、单位与日期配对；<br>4. 历史特殊状态及缺失识别与本人登记处置的一致性；<br>5. 预测信息的可得时点，不用未来数据冒充过去信息 | 1. 9只候选基金的风格证据及对应报告期时点标注、至少3只参评基金及具体份额类别（防A/C份额重计）；<br>2. 单位净值、分红记录及两类基准指数的数据来源核实；<br>3. 各基金实际存续区间与横向对比共同区间的界定；<br>4. 缺失值排查及6位基金代码前导零（如`00xxxx`）完整性检查 |
| **R2 计算复核** | 1. 按本人确认方案另路核对动量与反转的变量/信号定义、窗口与日期；<br>2. 比较对象、权重或模型设定、观察/持有与异常处理；<br>3. 核心收益或效应量及统计不确定性的独立复算；<br>4. 核查所选推断方法假设、依赖/重叠/缺失处理及实际执行选项。仅采用相应方法时核对分组、HAC或其滞后，不统一指定五组或NW3 | 1. 严格按照学生预先登记确认的口径，对12项必算指标开展独立复算；<br>2. 复权净值与分红再投资的处理逻辑核验；<br>3. 年化换算天数、无风险利率折算及两类基准指数的日期截面对齐；<br>4. 全区间最大回撤与分自然年度最大回撤的波峰—波谷识别路径复算。<br>*（注：在学生计算口径未完成登记或教师未确认前，暂不对相应指标作数值对错判定）* |
| **R3 结果与图表** | 1. 按本人方案核查样本、方向、组别或估计对象及实际期数；<br>2. 权重/样本恒等关系及排除记录（适用时）；<br>3. 量级、单位、不确定性与表述一致；<br>4. 图表与明细输入对应，缺失及实际观察范围标明；<br>5. 累计路径须符合实际资金与持有定义，不将任意差值复利冒充可交易净值 | 1. 12项指标的量纲单位（%或纯比率）、计算区间与有效样本期数标注；<br>2. 汇总表格数值与底层计算序列的逐一对应；<br>3. 分年度最大回撤表的自然年度切分与标记；<br>4. **双基准严格分工**：合同基准（用于超额收益、信息比率、跟踪误差）与市场宽基指数（用于Beta、特雷诺比率）绝不混用；<br>5. 可视化图表与汇总表数字完全一致；<br>6. 共同可比区间结果与单基金全历史区间结果清晰区分、不混为一谈；<br>7. 各指标优劣排名方向及风格证据时点标注核对 |

**核心方法论提醒**：
- 两段代码读取同一份错误或未经清洗的底层源文件并算出相同结果，**绝不能证明源数据本身正确**；
- 将计算结果复制给另一个大语言模型并获得“看起来没问题”的附和，**绝不构成真正意义上的独立核验**；
- 针对独立复算中发现的微小数值差异，一律严格按照第七节预登记的容差判据处理。**只要学生在方案中预先登记的计算口径逻辑自洽、出处明确，即便与教师习惯的默认公式存在合法差异，也绝不能因此扣减学生分数**——两实验都依照已登记的学生方案核查，实验A不因未采用教师参考方案扣分。

## 四、关键底线失守时的限分处理机制

为严格落实《总体设计》中**“核心底线失守不能靠其他维度的表面高分来抵销补偿”**的原则，本表设计了清晰的量化限分方案。需要特别说明的是，**下表中的“50分”系本轮提请审议的建议限分上限，尚待任课教师在试评后最终拍板确认。** 在工作簿「参数」页未正式填入限分上限或规则未勾选确认前，受影响维度的最终折算分与实验总分将暂不输出。

| 能力维度 | 触发底线限分的判定条件（须有确凿直接证据，不含材料暂缺待补核情形） | 建议限分处理规则 |
|---|---|---|
| **编排智能体** | 不设额外的整体限分上限；直接依据O1—O4四个评分点的实际得分加总折算 | $\text{能力百分制分} = \text{原始分} \div 12 \times 100$ |
| **审查复核** | `R1`、`R2`、`R3`三项规定核查中任意一项得分低于2分，或自选核验点`R4`得分低于2分 | 能力最终得分取“$\text{原始折算百分制分}$”与“$\text{已确认限分上限（建议50分）}$”中的**较小值**（即封顶不超过上限，若原始折算分本就低于上限则按实际低分计） |
| **结果解释** | 报告中存在核心金融指标含义根本性误读、毫无证据支撑的主动能力归因或绝对因果断言、将理论回测收益直接当成实盘确定可得收益，且直至提交仍未纠正 | 同上（取原始折算百分制分与已确认限分上限中的较小值）；即便报告其余段落文笔流畅、排版精美，亦不予抵销补偿 |
| **提出问题并组织验证** | `Q1 = 0`、`Q2 = 0`、`Q3 = 0`三者居其一，或经直接证据确认未对扩展分析的关键结果开展任何核验 | 同上（取原始折算百分制分与已确认限分上限中的较小值）；执行后倒推补写的计划一律不得折抵事前计划 |

**底线规则执行说明**：
1. 在评分设计上，`R1—R4`达到`2分`即明确定义为“该类别/自选点的规定核查已实现充分覆盖”，从而避免了让教师在16个评分点之外再去主观猜测何为“覆盖充分”。若要冲击`3分`，则须进一步满足对方法局限、潜在风险传导及核查盲区的深度剖析要求。
2. 当某项指标的数值差异尚处于“待核查”状态时，对应评分点应保持空白而非先行填入`1分`，更不得据此提前触发底线限分。
3. 在配套Excel工作簿中，“结果解释是否存在未纠正的核心底线错误”由教师在下拉菜单中单独确认（`无`／`有`／`待补核`），“扩展关键结果是否完成核验”亦单独确认（`有`／`无`／`待补核`）。同一项严重错误既会拉低对应具体评分点（如`I3`、`I4`或`Q4`）的得分，又会触发该能力维度的整体限分上限，但不会在此之外再重复倒扣一笔固定分数。
4. 若经核实某学生在该实验中的整个能力维度完全未开展，则在工作簿中标记为“确认未开展”，直接调用「参数」页中由教师另行设定的“未开展分值”；评阅时严禁将“现有材料证据不足待补核”或“确有参与但完成质量较低”混同于“完全未开展”。

## 五、能力得分换算与综合成绩合成公式

- **单项能力原始分**：$\text{能力原始分} = \sum_{k=1}^{4} \text{该能力下属第 } k \text{ 个评分点得分}$（满分12分）。
- **单项能力百分制分**：先计算 $\text{未限分百分制分} = \text{能力原始分} \div 12 \times 100$；若触发第四节底线条款，则取 $\min(\text{未限分百分制分}, \text{已确认限分上限})$。
- **单次实验总成绩**：$\text{实验成绩} = \sum_{i=1}^{4} \left(\text{第 } i \text{ 项能力限分后百分制分} \times \text{已确认权重}_i\right)$。
- **两实验课程综合成绩**：$\text{综合成绩} = \text{实验A成绩} \times 50\% + \text{实验B成绩} \times 50\%$。

**计算精度与合规约束**：
四项核心能力的权重之和必须严格等于$100\%$。所有中间折算步骤均保留完整浮点数精度不作提前四舍五入，仅在最终成绩展示单元格保留两位小数。凡遇**正式能力权重未填、底线限分上限未定、全局规则未勾选确认，或存在未决的“待补核/未开展”项**，工作簿均自动锁定并显示“待确认”，绝不强行输出正式总分。严禁在评阅中将空白待补核项直接当0分加总、仅对已出分维度重新归一化分配权重，或在单一实验内部重新套用旧版“基础50%＋扩展50%”二次加权。

在证据归属上，同一名学生在基础实验与扩展探究中留存的全套记录共同支撑该实验的四项能力评定：其中`O（编排）`、`R（复核）`、`I（解释）`重点考察基础实验任务及全流程研究把控，`Q（提问与验证）`重点考察扩展探究；`Q4`聚焦于核验结果如何更新研究判断，而`R`聚焦于核验方法本身的有效性与覆盖面，二者视角不同，不为同一技术动作重复加分。

## 六、完整计分算例演示

> **算例声明**：以下算例纯属为演示计算逻辑而构造的虚拟情境，并非真实学生作品。仅在本算例演示中，假定四项能力权重各占25%、底线限分上限设为50分且各项规则均已由教师确认；这些演示性假设参数绝不会自动写入真实评分工作簿的「参数」页。

| 核心能力维度 | 所属4个评分点得分 | 原始分（满分12） | 未限分百分制分 | 关键底线核查与处理 | 计入汇总的能力得分 |
|---|---|---|---|---|---|
| **编排智能体（O1—O4）** | 3、3、3、3 | 12 | 100.00 | 不设额外整体限分 | **100.00** |
| **审查复核（R1—R4）** | 1、3、3、3 | 10 | 83.333… | 经核实数据必查清单存在漏检，`R1 = 1 < 2`，触发底线上限50分 | **50.00** |
| **结果解释（I1—I4）** | 2、2、2、3 | 9 | 75.00 | 经确认无未纠正的核心底线错误 | **75.00** |
| **提出问题并组织验证（Q1—Q4）** | 2、2、3、2 | 9 | 75.00 | 事前计划、对照比较、学生主导及扩展核验均达标 | **75.00** |

- **演示单次实验总成绩合成**：
  $$\text{演示实验总分} = 100 \times 25\% + 50 \times 25\% + 75 \times 25\% + 75 \times 25\% = 75.00\text{ 分}$$
  可以看到，由于“审查复核”维度触发了关键底线限分，该生最终得分为75.00分，而非将四个原始分简单相加除以48（$40 \div 48 \times 100 = 83.33\text{ 分}$）。这直观体现了“关键核查缺位不可由其他高分项简单抹平”的评价导向。

- **为什么算例中的`R1`只给1分？**
  假定该生在实验中确实核对了股票代码与收盘价，但在记录中直接承认“本人方案登记需核查历史ST与停牌，却未开展该项核查”。对照`R1`细则，其表现符合1分条件（实际核对至少一项但必查清单仍有已确认遗漏），未达到2分的全清单覆盖要求——这并非因为该生“没能从数据里挑出毛病”而扣分，而是因为规定核查动作本身存在确凿缺漏。反之，若评阅时只是暂时没在提交文件夹里翻到ST状态检查记录，则`R1`应留空并记为“待补核”，此时系统不会抢跑算出75.00分。

- **为什么算例中的`I4`能给到满分3分？**
  假定该生选择了未扣成本的分组方案，在报告中不仅明确指出481只固定名单存在事后存续筛选偏差、回测收益率未扣除交易成本与融券费用，还进一步分别说明了这两项局限如何制约结论向全市场动态成分股的外推以及向实盘套利策略的转化，并指出了若要检验实盘可交易性还需补充双边费率与冲击成本数据——完整满足了`I4`从1分到3分的递进条件。

在实际评阅中，倘若四项能力的正式权重尚未由教师在「参数」页敲定，即便16个评分点已全部评阅完毕，工作簿也只会展示四项能力的百分制分（100、50、75、75），而实验总分栏将继续显示“待确认”。在配套Excel工作簿中，「算分演示」工作表与真实的「参数」及学生评阅表完全物理隔离。

## 七、数值对错的预登记容差判据

在量化实证评阅中，“数值容差（Tolerance）”是指判定学生计算结果与独立基准一致时所允许的最大合理数值偏差。首轮试评严禁采用脱离指标量纲的“跨指标一刀切阈值”，且**任课教师必须在审阅学生具体差值之前，为本批次涉及的每一项量化指标预先登记暂定判定标准，严禁在看到学生计算偏差后倒推或放宽通过门槛。**

### 7.1 四类核心对象的首轮暂定判定规则

| 核验对象类别 | 首轮暂定数值判定方法 |
|---|---|
| **1. 交易日期、样本股票/基金名单、分位组归属、有效月份数及缺失值标记** | 严格对照任务边界和学生已确认方案逐项精确匹配，**要求100%完全一致**，绝不使用数值容差去豁免规则执行偏差。针对分位点边界上的并列数值（Ties），其分组归属规则须在本人计算前登记锁定，不要求全班相同 |
| **2. 原始收盘价、复权因子、基金净值及基础收益率输入** | 在统一数据来源、版本号、采样时点、量纲单位及复权/分红处理口径后，直接核对源数据保留精度范围内的数值；若因数据源或口径不同产生分歧，须先行定位差异根源，不得以放宽容差代替统一输入 |
| **3. 实验A按本人方案计算的收益/效应量，以及实验B的12项必算绩效指标**<br>（年化收益率、超额收益、年化波动率、分年度最大回撤、下行波动率、Beta、夏普比率、索提诺比率、卡玛比率、特雷诺比率、信息比率、跟踪误差） | 基于学生已确认的统一输入与公式开展独立复算，并逐项登记输出单位、小数保留位数及比对判据：<br>- 若仅在最终展示环节存在四舍五入，直接比对未舍入的底层双精度结果，并按约定舍入规则核查报告显示值；<br>- 若输入数据或中间计算步骤本身包含截断舍入，则须先依据各步精度推导或通过数值实验确定误差传播上界，再据此冻结绝对容差 $a$ 与相对容差 $r$ |
| **4. Newey–West $t$ 统计量、$p$ 值及其他统计检验输出** | 先严格对齐有效样本期、所选方法及其参数（仅采用HAC时核对登记的滞后，不固定为3）、缺失月份间隔配对及协方差估计选项，再依据独立复算基准与浮点计算精度登记容差；**检验统计量数值与 $p$ 值须分别独立比对**，严禁以“反正显著性星号相同”为由跳过具体数值核对 |

### 7.2 容差公式与预登记表规范

当对连续型计算指标启用数值容差时，须预先登记绝对容差 $a$、相对容差 $r$ 及独立复算基准值 $y$，并统一按如下不等式判定是否通过：
$$|\text{学生计算值} - y| \le a + r \times |y|$$
其中，绝对容差 $a$ 必须与对应指标的输出量纲单位保持一致。参数 $a$ 与 $r$ 的取值必须具备明确的数据源精度或数值分析依据，本稿不在缺乏真实数据测试前凭空指定硬性常数。当基准值 $y$ 接近于0时，以有据可查的绝对容差 $a$ 为主；当遇到分母为0、输入缺失或指标在数学上未定义等边界情形时，直接核对学生是否严格执行了预先约定的异常值处理规则，不套用上述容差不等式。

配套工作簿中的「数值判据」预登记表至少须完整记录以下字段：**指标名称、输入数据及版本、计算公式与自由度/年化选项、输出单位、中间各步精度、独立复算基准存放位置、舍入规则（或 $a$、$r$ 取值及其推导依据）、异常值处理规则、判据版本号及教师确认日期**。同一批次适用同一版数值判定程序；具体公式、输入和容差按各自确认方案登记。同口径同精度使用同一判据，不跨方案直接比值。对于学生在方案登记中尚未交代清楚计算细节的指标，必须先要求其明确口径，随后方可开展相应的数值对错判定。

若某一具体指标在评阅时暂缺可用的预登记判据，或独立复算基准本身尚存学术争议，评阅人须将其标记为**“数值差异待核查”**——在此状态下，**既不得直接判定学生计算错误并扣分/触发限分，亦不得草率放行判为通过**。评阅人可先行记录其他已能明确判断的能力证据；若该项待核查的数值差异足以影响对应评分点的最终档位，则暂缓敲定该维度的最终得分，待补齐判据后按同一版本规则对该批次所有相关作品统一复评。首轮试评结束后可根据实测情况优化校准判据，但严禁针对个别学生作品单独放宽或收紧标准。

## 八、证据补核程序与答辩争议处置规范

在评阅过程中若发现证据链条不够清晰，教师应首先调阅学生提交包中的原始人机交互日志、底层输入文件、代码历史版本、程序控制台输出及文件修改时间戳进行交叉检索；确有缺口时，再向学生发起针对性的补充核实询问。
- 凡因提交材料遗漏导致暂时无法下判断的，得分单元格一律留空，状态记为**“证据不足、待补核”**；
- 凡因计算口径未定或独立复算基准存在分歧的，状态记为**“数值差异待核查”**；
- 若经补核后现有材料依然无法支撑明确判断，则继续如实保留上述待定状态，**绝不用“0分”强行替代未知状态**。

经补核后证据链得以补齐并能够作出判断的，严格对照第二节细则按实际表现赋分；若学生在补核中直接确认某单项工作确实未曾开展，则按该评分点的`0分`条件处理；若确认整个能力维度均未开展，则按教师在参数页另行确认的全局政策处理。对于学生在补核阶段现场新补做的计算或核验任务，必须在记录中明确标注补做时间戳，**绝不能将其倒推视同为实验初期原本就有的事前计划或前置决定**。若学生在个人口头答辩中的陈述与其提交的原始书面记录、代码日志发生矛盾，教师须在工作簿中详细登记矛盾点及核实结果，本量表不预设专门的“口头表达扣分项”，亦不在未经确认前擅自改动原评阅记录。

同一批次使用同版评分细则与全局参数；数值依本人确认方案、按同版判定程序核查。同一口径同精度使用相同判据，方案不同本身不扣分。若在试评后对量表规则进行了修订，凡需横向对比的所有作品均须按修订后的同一版本规则重新复评。在整个评阅流程中，“教师评价助手”智能体仅负责提供逐项建议分值、证据定位索引及未达标条件提示，**最终成绩的核定权完全归属于任课教师**。
