  • 接到一个目标，自己拆成步骤
  • 自己调用工具：搜索、写代码、跑数据

用 Agent 的五个常见错误 · 对照一下，你中了几个

01

把 Agent 当成 Chatbot

一问一答，从不让它自己跑任务、自己试错。花了大模型的钱，只用了问答机的功能。

02

任务懒得说清楚

"帮我做个分析"——连分析什么、给谁看、用什么数据都不说。你自己都不清楚要什么，Agent 更不可能清楚。

03

想一步到位、一键生成

期待输入一句话就拿到最终成品。Agent 是协作伙伴，不是魔法按钮——迭代、反馈、返工，都得有。

04

没有验收标准，完全被 Agent 牵着走

Agent 说什么就是什么，它给的结论不核查、它列的假设不追问。最后锅还是你背。

05

不给 Agent 负反馈

做对了不强化，做错了不指出。Agent 不会读心——你不告诉它哪里错了，它下次还犯同样的错。

这门课的目标，就是帮你把这五条全反过来。

投资组合：这学期，我们把 Agent 带进课堂

不确定下的决策

风险与收益、有效前沿、资产定价：在没有标准答案的世界里，学会如何站位置、下注、承担后果。

证据与验证

从数据到结论，每一步都要可复查、可复算、可质疑。金融的权威不来自头衔，来自可验证的论证。

人机分工

Agent 负责检索、计算与初稿；你负责提问、判断与负责。这门课训练的是后三者。

本学期「Agent 实验」预告

  • 均值—方差与有效前沿 → Agent 现场取数算前沿，你来挑战它的假设。
  • CAPM 与因子模型 → Agent 跑回归出报告，你来判断 β 是否还讲得通今天的故事。
  • 组合业绩评价 → Agent 给归因初稿，你来为结论辩护，或推翻它。

关于未来学习

  • 与 AI 协作不是选修技能，而是和读财报、用 Excel 一样的基本素养。
  • 这门课要给你的，不是“会用工具”，而是让 AI 的产出变成证据的能力。
