一、实验任务与规范

本实验由两部分构成：第一部分（基准策略封闭回测） 在统一的股债指数上完成3项基础再平衡规则与1项组合保险（CPPI）规则的回测，帮助你校准回测程序、直观体会凹性与凸性规则的差异；第二部分（自主开放研究） 在此基础上由你自主设定投资目标、构建资产池、设计配置与调整规则，并通过预留的留出期数据检验方案。

无论选择何种具体主题，两部分研究均须遵守以下基本规范：

留出期（Holdout）隔离与使用规范

在回测中反复观察全样本表现并据此修改规则，极易产生只在历史特定路径上有效的过拟合方案。

本实验将最近33个月（2024-01至2026-09）统一划为留出期，作为检验方案稳健性的样本外试金石。执行时须遵守以下四项限定：

  1. 取数隔离：在第二部分研究方案正式冻结之前，任何数据查询的截止日期（end_date）均不得晚于 20231231，严禁提前获取、查阅或利用留出期数据筛选资产与调整参数。
  2. 参数锁定：进入留出期检验后，资产池名单、政策权重、触发阈值、滚动窗口长度等全部参数必须原样沿用冻结方案，不得在留出期内重新估计或动态微调。
  3. 状态衔接：留出期首月（2024年1月）生成信号所需的前序滚动历史窗口（例如计算过去12个月波动率或10个月均线），正常使用截至2023年12月末的样本内数据无缝衔接。
  4. 单次正式运行：冻结方案在留出期仅作一次正式检验并如实报告结果。若看到留出期结果后发现原方案存在缺陷，允许另行提出“事后修订方案”并作补充对比，但必须在报告中明确标示为看过留出期数据后的修订，且不得替换或隐瞒冻结方案的原始留出期表现。

1.2 第一部分：基准策略封闭回测

什么是回测，以及本部分要回测什么： 回测（Backtesting）是将一套事先写死、不留模糊空间的投资规则，逐期投放到真实历史行情中，模拟组合在每个时点上的权重漂移、信号触发、买卖调仓、交易费用扣减与净值演进。回测的目的不是寻找一条漂亮的净值曲线，而是检验规则在历史路径上的风险收益性质与脆弱点。

使用统一的股债双指数和2014—2023年样本内数据，逐月回测三项策略：买入持有、月度恒定比例和年度再平衡。鼓励尝试组合保险（CPPI）策略。

比较结果时，重点回答三个问题：

  1. 不同调整规则如何改变组合的收益与风险？如尝试CPPI，可比较其保护效果与震荡磨损。
  2. 换手率和交易成本如何影响收益与策略排序？
  3. 同一策略在前后两个5年子样本中的表现是否稳定？

本部分也用于检查回测程序。请核对月末权重计算、次月初调仓和单边换手成本，并检查是否使用了未来信息。

要素 设定与要求

回测期间 2014-01 至 2023-12（共120个月；以 2013-12-31 收盘价完成期初建仓；前后等分为两个60个月子样本：2014-01—2018-12、2019-01—2023-12）

1.3 第二部分：自主开放研究

完成第一部分后，进入你的自主研究。开放研究常见问题是“直接让Agent给出一个策略并跑出一条净值曲线”，导致方案缺乏投资逻辑、实证沦为数字罗列。为保证研究有据可依，本部分要求你按“初始记录 → 六步设计 → 方案冻结 → 留出期检验与核验 → 结论与反思”的完整链条推进。

（1）六步方案设计（须按顺序推进，前一步产出约束后一步选择）

每一项资产配置方案都必须从具体的投资者约束出发：先有投资者画像，才能决定需要哪些资产类别；有了资产池，才能确定长期政策权重（SAA）；有了政策基准，才能定义偏离或动态调整规则（TAA/动态）以及拿什么作对照。请严格按以下六步递进设计，每步均可请Agent协助梳理备选方案或排查漏洞，但最终选择与理由必须由你本人给出：

步骤 设计内容 必交产出与具体要求
1. 投资者画像 界定投资者类型与客观约束 明确投资期限、可承受的最大回撤阈值、流动性提取需求与目标收益要求，形成约束清单
2. 资产池构建 依据约束选择资产大类与代表标的 给出资产类别、标的代码、数据起点与纳入理由；若包含个股，须写明在样本内起点锁定名单的具体规则
3. 政策权重（SAA） 确定长期基准配置比例及定权方法 给出政策组合的固定或基准权重，并论证所用定权方法（如固定比例、风险预算、均值-方差等）为何适配第1步的约束
4. 调整规则（TAA/动态） 设定偏离或动态调整的执行条件与幅度 提交一张完整的动态配置规则卡：包含触发条件、调整幅度、权重上下限、信号日与执行日、单边交易成本假设、规则停用条件。若研究纯SAA不作动态调整，须论证定期再平衡规则及不作战术偏离的理由
5. 比较基准设计 设定对照方案与控制变量 列出比较对象清单（默认必须包含第3步的政策组合作为基准），并说明比较时哪些条件改变、哪些条件保持一致
6. 命题与检验设计 提炼核心研究主张及证伪条件 分别写出投资命题与可检验命题，明确统计或模拟检验方法，以及样本内与留出期结果的判读准则

区分投资命题与可检验命题

一段历史回测不能证明长期投资目标一定实现。例如，回测年化收益率为8%，不能证明方案能保障未来30年的养老支出。

  • 投资命题：说明配置方案为什么有助于实现投资目标。例如，通过股债搭配和下滑曲线控制临近退休时的序列风险。本实验不对长期目标作实证检验；请说明理论与制度依据。
  • 可检验命题：对规则执行、组合风险收益或结果稳健性提出具体主张。每条命题必须写明什么结果会削弱或推翻它。实证部分只检验这类命题。

示例：目标波动率规则将样本内和留出期的年化波动率控制在10%±2%以内。若留出期波动率超过12%，或单边成本升至0.3%后最大回撤不再低于政策组合，则削弱这一主张。

单凭一张跑赢基准的净值曲线，不构成有效的实证证据。

（2）研究执行与核验规范

1. 初始认识记录

向 Agent 征询研究方案之前，先在原始会话中用自己的话写下：

  • 你对投资目标的理解；
  • 初步关心的研究问题；
  • 已掌握的课程知识或市场信息；
  • 当前的初步观点；
  • 最需要澄清的一处疑问。

保存后不得事后修改。在结论部分对照这份记录，说明认识如何变化。

2. 方案冻结

完成样本内试算与六步设计后，在读取留出期数据之前，保存独立的方案文档并注明冻结时间。样本内数据截至 2023-12-31。

文档须包含核心研究问题、六步完整产出、样本内数据参数、独立核验计划，以及 Agent 可自行执行的工作和必须暂停等待你决策的节点。

保留冻结前的历史版本和修改理由。冻结后，方案文档不得修改。

3. 留出期检验

使用冻结方案，在留出期（2024-01—2026-09）完整运行一次，并与样本内结果并列对照。

若结果不佳或发现规则漏洞，可以提出补充方案。须标明“事后修正”，并保留冻结方案的原始结果。

4. 独立核验

针对至少一项会影响核心结论的数据、计算或假设，完成独立核验。例如，抽查调仓月的原始行情与权重计算，或用 Excel、另一段独立脚本复算关键指标。

记录核验对象、方法、比对结果和最终处置决定。注意检查复权、首月收益对齐和年化因子等口径。

5. 结论与反思

在报告结论中回答：

  • 证据支持哪些判断？初始记录中的哪些想法被削弱或推翻？
  • 样本内与留出期结论是否一致？不一致时，如何解释市场环境或机制原因？
  • 投资命题中哪些部分尚未检验？方案适用范围是什么？
  • 你在哪些关键环节采纳、纠正、限制或否决了 Agent？最终方案中的哪些核心主张来自你的独立判断？
