说明 实验课定位与衔接机制

定位：第 7 章 4 课时结束后的综合实验课，一次课完成，也可拆为三次课后任务。

对象：本科大三，已修完 MPT / CAPM / APT 理论，并完成本章 4 课时的 Agent 实操训练。2 至 3 人一组，自带电脑与自有 Agent（已配置 tushare MCP）。

实验链（累计完成）：E1 建仓（MPT）→ E2 验货（CAPM）→ E3 拆解与自控（APT 与行为）→《2026Q4 组合策略建议书 · 课堂版》。

组合样本：30 个标的，来自 40 个标的候选池，含个股、ETF / 场外基金与指数代理；三个实验累计使用同一样本。

产出直接对应05 小组项目任务书的 Memo Part2 / 3 / 4 / 5 草稿骨架。

修订（2026-10-04）：① 数据接口从"AkShare 免注册"改为学生端已配置的 tushare MCP，与课时 4 的数据获取约定一致；② 组合样本从 6 只股票扩为30 个标的，候选池扩为 40 个标的，允许个股、基金与其他资产；③ 2026-10-04 补测基金与 ETF 接口（fund_basic / fund_daily / fund_adj / fund_nav / fund_share / fund_div / fund_portfolio 均可用），候选池表的"课前状态"列由"待实测"改为实测结论。

修订（2026-10-04 · 第二轮）：④ 难度重心从"算得快"移到"判得准"：新增课前预训与入场券（0.3 节）、分层审计件 S1 / S2 / S3（附录 D，含答案与判据清单）、约束下的组合优化与伪分散判定、α 判决档与反例条件、预注册纪律页；⑤ 评分改为达标 / 良好 / 挑战三档，审计题分层计分（附录 B）；⑥ 04 模板卡新增卡 7（审计卡）与卡 8（预注册与反例卡），失败模式清单扩为 10 条。

难度适配（第二轮按"判断层"重设）

Agent 已能免费完成取数、标准公式、表格与文稿，这些不再作为难度来源。本课难度全部落在四件事上：① 口径与约束界定（事前固定，写进章程）；② 审计（发现 Agent 输出里的错，每个错都要给判据）；③ 判决（α / β / 因子暴露能否支撑结论，不能支撑时敢说"不足以判断"）；④ 留痕与预注册（规则写下时点，可被第三人复现）。每个陷阱都留了可核验出口：相关系数、t 值、恒等式残差。

工具仍只用 4 课时教过的：卡 2 / 卡 3 / 卡 5 / 卡 6 ＋ 新增卡 7（审计卡）与卡 8（预注册与反例卡）、Blume 公式、PlanB 因子序列、失败模式清单（10 条）。30 个标的把"算"的重活留给 Agent，审查看摘要指标（权重集中度、类别权重分布、最高相关对 Top5、|t| > 2 名单），不逐格看 30×30 矩阵；课后挑战档见附录 C。

0.3 课前预训与入场券（第二轮新增：把"算"移到课前）

Agent 让"算"几乎免费，课上 90 分钟必须全部用于判断。三件课前作业（合计约 40 分钟）构成入场券：

任务内容交付目的
T1 取数热身用本组 Agent 取 30 个标的主窗周频与日频前复权数据，逐次登记 data/tushare_manifest.csv快照 ＋ 取数清单把课上 8 分钟取数搬到课前
T2 审计包审计教师分发的三份含错 Agent 报告 S1 / S2 / S3（附录 D），用卡 7 逐处写"位置 ＋ 判据 ＋ 正确做法"《审计清单》一页把"发现错误"变成可计分动作
T3 章程与约束完成《投资委员会章程》：类别上限、前三大上限、客户约束各一条章程一页让 E1 的约束是事前写定的

入场券规则：T1 ＋ T2 齐交 → 课上正常计分（审计分层分计入 E1 / E2 / E3）；未交 → 课上改用教师 PlanB 快照照常完成全部环节，但审计分层分记 0，其余照常。既不让没预习的组掉队，也不给"没做也满分"。

0.4 取数预算与降级梯度（教师务必课前走一遍）

  • 时间预算：课前未完成取数者，课上给 8 分钟补取（30 个标的周频）；超时即整组切教师 PlanB 快照，不得在课堂上继续排查接口。
  • 降级梯度（按顺序，每次降级都要在记录单写一行"降级原因 + 证据"）：
    1. 首选：个股 daily + adj_factor；ETF fund_daily + fund_adj（或 fund_nav 的 adj_nav 复权净值）；场外基金 fund_nav 的 adj_nav；指数 index_daily。四类均已于 2026-10-04 实测可取。
    2. 一级降级：接口返回 40203 无接口权限 或字段缺失 → 同类标的改用 fund_nav（含 adj_nav 复权净值字段，场内场外均有，积分门槛 2000，低于 fund_adj 的 5000）；场外基金也可用 accum_nav 累计净值。不得把场内价格与场外净值混成一条收益序列。
    3. 二级降级：仍不可得 → 改用指数代理 index_daily，图表须注明"指数代理，不可直接持有，不含分红"。
    4. 三级降级：整组切换教师 PlanB 行情快照（候选池 40 个标的已预跑 CSV，同窗口同口径），记录单注明"使用 PlanB 数据，与现场取数的口径差异见 README"。
  • 禁止：改用 AkShare、爬虫、腾讯 / 新浪行情等非 MCP 来源冒充取数结果（课时 4 约定第 4 条）。
PlanB 降级预案（总大纲 T-2 预跑纪律的延伸）：任一 Agent 任务超过 3 分钟无输出或接口报错 → 按上面的梯度降级；整组切换教师投屏的 PlanB 预跑结果，照常完成审查与决策环节并向学生坦白。PlanB 锚点 rf = 2.0%，课堂 live 统一 rf = 1.8%，两口径差约 0.2pp/年，对照锚点时只看量级，不追精确一致。

1.3 数据接口与取数纪律（tushare MCP，学生版 6 条）

完整约定见 04_课时4_行为投资与管理\课时4_Agent提示词.md 的"数据获取约定"，本实验只列课堂要用的 6 条。

  1. 先列工具再取数：开工第一步让 Agent 列出 MCP 暴露的工具名与参数结构，说明属于"通用查询工具"还是"每接口一个工具"。
  2. 不写取数脚本：取数只能通过 MCP 工具调用；清洗与计算脚本只读本地 CSV / JSON 快照，文件里不得出现 token。
  3. 先声明后调用：每次取数前写出 api_name、参数、字段、区间；单次失败最多重试 3 次，仍失败即记录错误码与原文并按 0.4 节降级。
  4. 落盘分层、旧快照不覆盖：data/tushare_raw/<api_name>__<参数摘要>__<时间>.json、data/tushare/<api_name>.csv；同名文件另存新版本。
  5. 取数清单必填：每次取数在 data/tushare_manifest.csv 追加一行（接口、参数、字段、取数时间、行数、起止日期、缺失说明），图表的"数据来源"必须引用这张表。
  6. 复权与时点：daily / index_daily 是不复权价，前复权自算；调仓与月末日以 trade_cal 为准；不得把前复权价格叫作含现金分红再投资的总收益。

E1 实验一 · 25 分钟：建仓，约束下的组合优化与伪分散判定

D1 · S1（实验一：最小方差组合）6 处错
发给学生的含错报告我们用 30 个标的（含 510300 沪深300ETF 与 000300.SH 沪深300指数）做主线最小方差组合。数据用日频收盘价直接算周收益，年化波动用 √252 换算。求解结果：权重和 1.003，未出现负权重；组合年化波动 11.2%、年化收益 14.8%、夏普 1.16（rf = 1.8%）；最大权重为招商银行 47.4%。结论：这就是最优组合，建议直接采用。
层错误判据
基础未前复权就直接算收益用 adj_factor 折算后重算，分红日会出现假跳
基础周频收益用 √252 年化周频应为 × √52；按 √252 算会把波动放大约 2.2 倍
基础权重和 1.003 且未声明合规要求和 = 1，偏差须声明并说明来源
进阶510300 与 000300 同指数重复纳入两者日收益相关通常 ≥ 0.95，属伪分散，权重被重复放大
陷阱把最小方差称作最优组合目标函数只最小化风险；应比夏普（课时 1 P4：切点组合夏普 1.28）
陷阱未说明 30 个标的是否有缺数据被静默剔除应给出标的数、剔除名单与原因（静默剔除＝前视或样本操控嫌疑）
D2 · S2（实验二：CAPM 的 α / β）8 处错
发给学生的含错报告对 30 个标的做 r − rf = α + β(rm − rf) 回归（主窗日频）。招商银行 β = 0.83、α = 0.0003（日频），年化 α = 0.03%，结论：α 显著为正，建议买入。某科技股 R² = 0.28，结论：CAPM 对它失效。指数代理行 000300.SH 的 α = +2.1%，结论：建议买入沪深300指数。组合 β = 0.79。年化波动用 √12 换算。α / β 回归用 rf = 2.0%、夏普用 1.8%，未声明差异。
层错误判据
基础α 未年化即下结论日频 α 应 × 252；报出的 0.03% 与 0.0003 × 252 = 7.6% 相差约 250 倍
基础无 t 值就断言显著为正失败模式⑤：没有 t 值的 α 只是故事，须打回
进阶α / β 用 2.0%、夏普用 1.8%，未声明失败模式④：同一交付物内 rf 必须一致或明确分列
进阶日频回归配 √12 年化系数失败模式②：日频应为 × √252
进阶β 未做 Blume 调整就当下季度预测值β_调整 = 2/3 × β_样本 ＋ 1/3 × 1；招行 0.830 → 0.887
陷阱R² = 0.28 就断言 CAPM 失效R² 低说明特质风险大，不影响 β 可用性，但 α 的置信区间更宽
陷阱给指数代理的 α 下买入结论指数不可直接持有，无交易含义，只能作代理口径
陷阱只报主窗、未做敏感性，却称 β 是标的的稳定属性失败模式⑧；三窗口位移锚点：光迅 +1.09、恒瑞 +1.07、神华 −0.63
D3 · S3（实验三：四因子归因与压测）6 处错
发给学生的含错报告组合月超额对 RM / SMB / HML / MOM 回归（2023-01 ~ 2026-08）：RM 暴露 0.92、SMB −0.31、HML −0.44、MOM 0.06；残差 α 年化 −3.2%（t = −0.8），R² = 0.71。恒等式：年化超额 −9.63% ≈ α ＋ Σ 暴露 × 因子年化 = −6.10%，差额解释为统计误差。压测窗 2024-01-01 ~ 2024-02-08 组合 −2.46%，证明本策略在极端行情抗跌、可放心持有；含两只新上市标的，直接就现有数据算、未说明；残差 α 不显著，结论：四因子模型对本组合无效。
层错误判据
基础恒等式残差 3.53pp 未解释恒等式应闭合（残差 < 0.1pp）；锚点示例 005827：−9.63 = −29.79 ＋ 17.69 ＋ 1.33 ＋ 0.89 ＋ 0.25
基础因子名写 HML，未标 proxy构建＝中证红利 − 创业板指，必须写 HML_proxy
进阶把压测结果当可实现业绩或证明必须写候选池与组合样本为事后选定，属事后情景，非可实现业绩
进阶新上市标的静默处理应按可得子集重算并声明覆盖率
陷阱残差 α 不显著就断言模型无效课时 4 原话：不能证明有优势也是合格结果；α 不显著 ≠ 模型没用
陷阱用压测结果反推可放心持有（事后规则）规则须在揭示压测结论前写下并签名，否则是后见之明偏差
