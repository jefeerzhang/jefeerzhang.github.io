从 CAPM 到 APT

先找出遗漏的共同风险，再理解“无套利”怎样约束收益。

把投资组合想成几条船：市场像潮水，\(\beta\) 是每条船受潮水影响的程度。但船还会受风影响。即使受潮水影响一样，遇到同一阵风，也可能有的受益、有的受损。

这个比喻帮助我们理解“多种共同影响”。下面用明确的收益和现金流计算，解释它怎样成为定价关系。

① 一把尺不够② 加入第二把尺③ 无套利约束全部资产

① CAPM：为什么这三个组合都应该是 8%？

假设无风险收益是 2%，承担一单位市场风险的补偿是 6%。A、B、C 的市场 \(\beta\) 都是 1，CAPM 就给它们相同的期望收益：

\[ \mathbb{E}[r] = 2\% + 1 \times 6\% = 8\% \]

可是，我们设定的教学市场里，A 的期望收益是 11%，C 是 8%，B 是 5%。同一个市场 \(\beta\)，没能解释全部差异。

这里比较的是“期望收益”，不是某一天的涨跌。真实市场里两只股票短期收益不同，完全可能只是随机波动，不能据此推翻 CAPM。

② 多因子：原来还有一阵共同的“风”

现在揭示这个虚构市场的第二个共同因子。A 对它的暴露为 +1，B 为 −1，C 为 0。我们设定每单位暴露对应 3 个百分点的期望收益补偿：

\[ \begin{aligned} A &: 2\% + 6\% + 3\% = 11\% \\ C &: 2\% + 6\% + 0\% = 8\% \\ B &: 2\% + 6\% - 3\% = 5\% \end{aligned} \]

原来没解释的收益差异，被第二种暴露解释了。负暴露意味着反向承受这类冲击，可能有对冲价值；不是说某个组合“风险越少就越差”。

拖动上方滑块：第二因子意外增加 1 个百分点，A 的当期收益增加 1 个百分点，B 减少 1 个百分点，C 不变。

补偿与冲击不同：3 个百分点是期望收益中的风险补偿；滑块是本期偏离预期的意外变化。为突出机制，市场意外冲击固定为 0，第二因子冲击与市场冲击设为独立且均值为 0。本页没有拿真实数据估计参数，也没有证明“加入任何因子都有效”。

「因子」到底是什么？

因子不是抽象概念，它有一个可操作的定义：一个数字，当它变动时，很多资产的收益会同时按各自的系数变动。油价涨 10%，航空公司跌、石油公司涨——这个共同变动的方向就是一个因子。

找因子有两条路：

  • 指定：先想清楚有哪些共同风险源，拿它们的实现值当因子。Fama-French 三因子就是这条路——市场、规模、价值。
  • 统计：拿一堆资产的历史收益做主成分分析，第一主成分就是“最能解释共同变动的那个方向”，第二主成分是与它正交的下一个方向。

而暴露 \(\beta\) 就是回归斜率：这个因子变动 1 单位，资产 i 的收益变动多少。所以本页那个“第二因子”，具体就是那件让 A 涨 1%、同时让 B 跌 1% 的事。它叫油价、汇率还是政策，APT 并不关心——结论对任何因子都成立，这正是 APT 比 CAPM 宽松的地方。

③ APT：相同风险，为什么不能凭空多一份回报？

用 50 元买 A，再用 50 元买 B，就拼出一个 100 元的替代组合 D。A、B 的第二因子暴露一正一负，刚好抵消：

D 的市场暴露：\(\tfrac{1}{2}\times 1 + \tfrac{1}{2}\times 1 = 1\)
D 的第二暴露：\(\tfrac{1}{2}\times(+1) + \tfrac{1}{2}\times(-1) = 0\)

D 与 C 的共同风险暴露都是“市场 1、第二因子 0”。在本例没有其他随机风险的条件下，二者面对共同冲击时，收益变化完全一致。

如果同样投入 100 元，C 却在所有状态下都比 D 多付 2 元，便可以买 C，同时卖空 D。共同风险互相抵消，剩下的是确定的 2 元。

这里“各投 100 元、C 多付 2 元”是收益形式的定价偏离演示，不是在假装已经模拟了价格调整。若固定未来现金流，实际买卖会推动相对价格变化、压缩套利空间。上面的偏离滑块只是展示差异收敛，不代表真实价格路径。

那两个 \(\tfrac{1}{2}\) 是怎么来的？

暴露是权重的线性函数，所以那两个 \(\tfrac{1}{2}\) 不是凑巧设的，是解方程解出来的。要拼 \(D = w_A A + w_B B\)，让它跟 \(C\) 的暴露完全一样（市场 1、第二因子 0）：

市场暴露：\(w_A\times(+1) + w_B\times(+1) = w_A + w_B = 1\)
第二暴露：\(w_A\times(+1) + w_B\times(-1) = w_A - w_B = 0\)
解得：\(w_A = w_B = \tfrac{1}{2}\)

而风险之所以真的归零，是因为共同风险进入收益的方式也是线性的。第二因子意外变动 \(v\) 时：

A 贡献：\(\tfrac{1}{2}\times(+1)\times v = +\tfrac{1}{2}v\)
B 贡献：\(\tfrac{1}{2}\times(-1)\times v = -\tfrac{1}{2}v\)
合计：\(0\)，与 \(v\) 取多少无关

不是概率上变小，是代数上恒等于 0。

两条边界：① 归零的只是共同风险，资产自己的特质风险消不掉——这正是下方“公司意外”开关演示的内容。② 需要原料够多、能张成整个暴露空间；原料不够就复制不出来，这就是 APT 的“大规模资产市场”条件。

把“无套利”变成一张收付款账本

卖空可以理解为：先借来资产卖掉、收到现金，到期再归还资产并承担期间应付的现金流。本例用到期价值统一结算这些义务，暂不计融券费、保证金和交易限制。

今天卖空 50 元 A 和 50 元 B，收到 100 元；恰好用来买入 100 元 C。今天净投入为 0。再看未来发生什么：

现金流账本：正数为收到，负数为支付（元）
交易今天到期
买入 C−100.00
卖空 A+50.00
卖空 B+50.00
净现金流0.00

为什么换任何共同冲击都一样？

用 \(u\) 表示市场意外冲击，\(v\) 表示第二因子意外冲击，\(\lambda\) 表示第二因子风险补偿，\(\delta\) 表示 C 多出的收益；它们都以“百分点”为单位。暂时不加入公司意外：

100 元 C 到期：\(108 + \delta + u\)
50 元 A 到期：\(\tfrac{1}{2}\times(108 + \lambda + u + v)\)
50 元 B 到期：\(\tfrac{1}{2}\times(108 - \lambda + u - v)\)
买 \(C - \tfrac{1}{2}A - \tfrac{1}{2}B\) 的净现金流 \(= \delta\) 元

\(u\)、\(v\)、\(\lambda\) 都抵消了。因此结论不是“试了几次没亏”，而是这组设定下所有允许状态的共同冲击都不影响净结果。当 \(\delta > 0\)，净结果确定为正；当 \(\delta = 0\)，套利差消失。

再加一个公司意外，结论就变了

公司意外的均值为 0，因此不改变上方期望收益图；它只改变下方账本的当期结果与是否可能亏损。

因此，相同因子暴露并不自动意味着无风险套利。如果仍有剩余风险，单凭“C 平均回报更高”不能断定可以稳赚。

“无套利”到底要求什么？

一个常用的套利定义是：初始净投入为 0，不再追加外部资金；到期在所有可能状态下都不亏，且至少有正概率赚钱。本页没有公司意外且 \(\delta > 0\) 的例子更强：每个状态都赚。

无套利就是说：市场中不应持续存在这样的机会。它不保证人人赚钱，也不保证没有高收益策略；它约束的是不承担剩余风险就能获得的免费收益差。

与“一价定律”有什么关系？

若两组资产在每个状态下的未来现金流完全相同，却有不同价格，就可以买便宜的、卖贵的，把今天收到的差额存入无风险资产；到期两边义务抵消。这是一价定律背后的套利逻辑。

注意：未来现金流相同，比市场 \(\beta\) 相同、总波动相同，或几个估计出来的因子暴露接近，都更强。遗漏风险、融资限制和交易成本会影响能否真正构造套利。

为什么每个资产的“补偿”是同一个数？

上面那笔交易只涉及 C 一个资产。现在把它对每一个资产各做一遍——这是唯一的新动作，也是“无套利”升级成定价公式的那一步。

关键点：复制任何资产用的都是同一套原料。本页的原料是 A、B 和无风险资产；用它们能拼出任意目标暴露向量，变的只是配比。

  1. 取任意资产 \(i\)，它的暴露是 \((\beta_{i1}, \beta_{i2})\)
  2. 用同一套 \(A\)、\(B\)、无风险资产，拼出一个暴露一模一样的复制组合 \(R_i\)
  3. \(i\) 与 \(R_i\) 暴露一样，就该一样值钱；若不一样，差额就是上面那笔套利
  4. 无套利要求差额为 0，所以对每个 \(i\) 都有：\(\mathbb{E}[r_i] = \mathbb{E}[R_i]\)

再看等号右边是什么：

\[ \mathbb{E}[R_i] = w_A\,\mathbb{E}[r_A] + w_B\,\mathbb{E}[r_B] + w_f\,r_f \]

其中 \(\mathbb{E}[r_A]\)、\(\mathbb{E}[r_B]\)、\(r_f\) 是三个固定的数，不随 \(i\) 变；随 \(i\) 变的只有权重，而权重只由 \(i\) 的暴露决定。所以 \(\mathbb{E}[r_i]\) 必然能写成：

\[ \mathbb{E}[r_i] = r_f + \beta_{i1}\lambda_1 + \beta_{i2}\lambda_2 \]

\(\lambda\) 为什么不带 \(i\)？因为 \(\lambda_k\) 是因子模仿组合的期望超额收益——专门造出来让第 \(k\) 个暴露等于 1、其他暴露等于 0 的组合。它只跟因子有关，跟具体哪个资产无关。带 \(i\) 的只有配比，没有价格。

这就是无套利与多因子模型的接缝：没有无套利，\(A\)、\(B\)、\(C\) 可以各自拥有一套自己的 \(\lambda\)，那只是一个统计分解（②讲的东西）；有了无套利，所有资产被迫共用同一组 \(\lambda\)，它才变成定价模型。②里那句“每单位暴露补 3%”是直接给的假设，这一节就是把它变成结论。

从这个小实验，到真正的 APT

CAPM 在特定均衡假设下，用市场 \(\beta\) 定价。APT 则从收益的因子结构、特质风险可以充分分散，以及无套利出发，约束期望收益与因子暴露的关系：

\[ \mathbb{E}[r_i] \approx r_f + \beta_{i1}\lambda_1 + \beta_{i2}\lambda_2 + \cdots \]

本例为了把抵消过程讲清楚，先把特质风险设为 0，所以可以精确展示套利。一般 APT 在大规模资产市场及相应技术条件下利用分散化，得到近似定价约束；不是说每只个股都能被精确复制，也不是说回归里出现正 α 就存在无风险套利。使用无风险收益作截距，还假设存在相应的可交易无风险资产。

一条清晰的学习路径：CAPM 提供一把市场风险尺 → 多因子模型增加共同风险维度 → APT 解释为什么相同暴露的定价应受到一致性约束。它们是不同的理论与建模层次，不能仅凭“加了几个回归变量”就说推导出了 APT。

本例的设定与参考来源

全部数字为虚构教学数据；单期简单收益；期望冲击为 0；市场与第二因子冲击独立；基准情形无特质风险；允许按所需数量卖空；忽略交易、借券与融资成本。公司意外开关只改变 C 的剩余风险，不改变其期望收益。

APT 不直接指定因子名单，也不保证每个因子的风险补偿都为正。这里的 2%、6%、3% 是为了心算设置的参数。
