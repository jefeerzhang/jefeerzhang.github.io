目标 本课时学习目标

本课时结束后应能：

  1. 能区分 CAPM 的单一市场 β、APT 的多因子定价关系，以及用于归因的经验四因子回归；
  2. 能读懂因子暴露表与收益分解，回答"这只股票/这只基金的收益从何而来"；
  3. 能理解因子倾斜的两面性——定向配置风险的工具，同时也是新的风险来源（因子会拥挤、会崩溃、会反转）；
  4. 能独立驱动 Agent 完成因子构建、归因回归、定向选股与压力测试，并对每一个数字审查口径。
本课推进顺序：理论（第一节）→ 风格案例（第二节）→ 构建四条代理因子（第三节）→ 个股与基金归因（第四节）→ 观点、暴露与情景演示（第五节）。每个环节都以"运行、核对口径、说明证据边界"收尾。

一 理论：从 CAPM 到 APT

教材第三节的概念与推导；后面的四因子回归是教学应用，不能仅凭回归拟合就证明 APT 的定价关系成立。

1.1 为什么一个 β 不够

CAPM 用资产对市场组合的 β 描述其期望超额收益。β 衡量与市场共同波动的程度，却不直接指出收益差异可能关联的其他特征。实证研究记录过以下经验现象：

  • 某些样本和时期出现小市值股票相对大市值股票的超额收益（规模效应）；
  • 某些样本和时期出现高账面市值比股票相对低账面市值比股票的超额收益（价值效应）；
  • 某些样本和时期出现过去赢家在随后数月继续相对领先（动量效应）。

这些是相对于特定基准的经验规律，可能涉及风险、投资者行为或样本选择；不能仅凭其存在认定因果性的风险补偿。Ross（1976）的套利定价理论（APT）在因子结构与分散等条件下给出近似线性定价关系；本课使用的规模、价值、动量是后来的经验因子示例，不能说 Ross 已指定这些因子。纽约联储 APT 综述

1.2 从收益结构到定价公式（推导主线）

第一步：收益的因子结构。 假设任何资产的收益由少数共同因子驱动：

ri = E(ri) + bi1·F1 + bi2·F2 + … + biK·FK + εi  ……(1)
Fk：因子意外（E(Fk)=0）；bik：资产的因子暴露（敏感度）；εi：特质波动，与所有因子不相关，且组合中可分散掉。

第二步：无套利论证。 如果资产足够多、特质风险在分散组合中趋小，具有相同因子暴露的充分分散组合不应长期存在不同的期望收益；否则可构造接近无因子暴露的多空组合。由此得到近似线性定价关系。有限样本、无法完全对冲的特质风险和交易摩擦下，这不是现实中零风险、零成本的套利保证：纽约联储 APT 综述（PDF）

E(ri) − rf = bi1·λ1 + bi2·λ2 + … + biK·λK  ……(2)
λk：因子 k 的风险溢价（承担一单位因子暴露的补偿）。

第三步：与 CAPM 的关系。 若在形式上令 K=1、因子取市场组合，且相应溢价等于市场超额期望收益，(2) 与 CAPM 的证券市场线（SML）同形：

E(ri) − rf = βi × [E(rm) − rf]，其中 λM = E(rm) − rf

这是定价公式在特定设定下同形，不等于 CAPM 的均值—方差均衡假设从 APT 的无套利假设中完整推出。两者比较：

 CAPMAPT
风险描述一个数字 β一张暴露向量表 (b1,…,bK)
市场组合理论上需要市场组合；实证通常只能用指数代理，真正的总市场组合难以观测不预先指定唯一市场组合；因子仍须有明确经济或统计定义，并检验定价能力
理论性质精确的均衡定价近似（近似套利），因子清单不唯一

1.3 实证里怎么做：两步法与收益分解

第一步（时间序列回归，估暴露）：对每只资产跑

ri − rf = αi + bi1·F1 + bi2·F2 + … + biK·FK + εi  ……(3)
输出：暴露 b（要 t 值）、截距 α（年化，要 t 值）、R²。

第二步（样本内归因）：用同一组月份对含截距的普通最小二乘回归取均值，可得到下式的算术分解恒等式。它成立于样本内，不能单凭此式证明风险溢价、因果归因或模型定价能力；若要检验 APT 的截面定价，需要另做跨资产检验。只有把因子定义为可交易组合的收益，并在额外条件下，样本均值才可作为其期望溢价的估计。这里的代理因子未扣交易成本，也未检验可交易性。

月均超额收益×12 = 月截距 α×12 + Σ [ bk × (因子k月均收益×12) ]  ……(4)
(4) 把样本内算术月均超额收益分解为模型中的因子贡献和未被模型解释的截距。截距 α 不等于纯粹的选股能力或特质收益；它还可能包含遗漏因子、基准不匹配、分红口径差异及估计误差。先核对模型与口径，再评价。

1.4 本课使用的因子：市场、规模、价值、动量

教材列举的因子示例分两类：宏观因子（GDP 意外、利率意外…）与交易组合类因子（规模、价值、动量…）。本课借鉴 Fama–French 三因子加动量的四因子框架，但以下序列均为本地教学代理，构造方法与标准因子不同，不能标作正式的 Fama–French／Carhart 因子。Kenneth French 标准因子定义

因子含义预期溢价方向的"教科书说法"
RM（教学代理）固定混合股票池等权收益 − 固定无风险利率；并非全市场组合历史上常见正值，样本可变
SMB（教学代理）固定中证2000样本股组 − 固定沪深300样本股组不保证为正
HML（教学代理）中证红利 − 创业板指；不是按账面市值比分组的标准 HML方向不确定

二 案例：风格集中、规模差异与轮动

三个案例分别观察风格集中后的回撤、小盘相对大盘的下跌、以及阶段性风格轮动。价格走势能说明风险表现；若要证明"拥挤"及其因果作用，还需持仓集中度、资金流或交易行为证据。

口径预告：本节及全课时实测数字统一为——前复权日线；因子与回归用月频；年化=月×12；rf=2.0%/年（固定值，声明）；样本窗与各图表的备注口径随文标注。

案例 1 · 2021 抱团瓦解：个股分散难以对冲风格集中

背景：2019–2021 年初，消费、医药等"核心资产"上涨明显，之后部分相关指数大幅回撤。该价格路径适合讨论风格集中风险；"公募整体拥挤持有导致回撤"属于需要基金持仓与资金流证据检验的机制假说。

文献对照 A：2007 年美国量化策略共同去杠杆

Khandani 与 Lo 对 2007 年 8 月美国量化基金波动进行研究：他们的模拟多空组合显示，基于相近估值特征的策略在 7 月已开始平仓；交易数据及模拟做市策略显示，8 月第一周流动性提供能力也受到冲击。作者提出共同去杠杆与做市资本暂时退出的解释。这里有"策略持仓/交易机制"层面的证据，比只看风格指数涨跌更接近"拥挤"机制，但模拟组合的收益仍不能写成某家基金真实亏损。Khandani 与 Lo，NBER 工作论文

课堂追问：若几只策略买的是不同股票，却共同"买低估值、卖高估值"，个股名称不同能否保证多空组合独立？当资金同时减仓时，哪一项风险是静态四因子回归可能漏掉的？

文献对照 B：2009 年美国动量策略反转

Daniel 与 Moskowitz 研究发现，动量策略在市场大幅下跌后的反弹阶段可能出现显著负收益。论文举出的 2009 年 3–5 月例子里，过去输家组合涨约 163%，过去赢家组合涨约 8%；"买赢家、卖输家"的多空策略因此遭遇剧烈反转。这是论文所用美国市场、特定分组和窗口的结果，不能套到本课中国股票池的 MOM 代理上。Daniel 与 Moskowitz，《Momentum Crashes》

课堂追问：动量多空组合的市场 β 如果在下跌后反弹阶段改变，为什么"过去一年回归得到的平均 β"可能低估当期风险？应怎样用分窗或滚动暴露检查？

本地三例与文献两例共同说明：风格和规模暴露可能带来共同回撤，不同样本窗的实现收益也会变化。下一节用统一口径的经验因子模型描述暴露；模型提供描述与待检验假说，不自动识别价格变化的成因。

三 Agent 实操（一）：构建四因子（2023-01 ~ 2026-08）

本节先构建四条教学代理收益序列。它们可作为后续样本内归因与选股练习的统一标尺，但由于股票池抽样、当期成分回看历史和交易成本缺失，不能直接当作全市场风险溢价或可投资策略业绩。

怎么读这张表（四个示范）

S3_P2 · 四因子累计净值（教学代理，n=76）与各对象因子暴露（rf=2.0%/12，α 年化=月 α×12）
  1. 005827：在本课代理模型中，b_RM=0.95，月截距×12=−29.79%，普通 OLS t=−3.95；样本内分解为市场代理贡献 +17.69% 与截距 −29.79% 等项。该 t 值只表示在当前模型和标准误假设下截距明显偏离零；不能据此判断经理选股能力。基金可能持有港股，且单位净值、分红、基准、费用和时变持仓都可能影响截距。先换成匹配投资范围的基准、核对总回报，再评价。
  2. 寒武纪：月均超额收益×12 为 +141.05%，这不是实际持有一年的复合收益；截距×12 为 +87.80%，t=1.54。R²=0.263，说明这四条代理序列对样本内月收益波动的拟合有限，不能仅凭该结果断定未解释部分全是特质风险或"来源无法归因"。
  3. 贵州茅台：在本课代理模型中截距×12=−25.66%（普通 OLS t=−2.92），b_RM=1.24；R²=0.575。结论限于该样本和模型，不能单独当成错误定价证据。

审查要点

  1. 不要混淆 α 与实现超额收益：报告回归截距时附 t 值、样本量、R² 和标准误方法；报告某段实际收益时不需要机械地给出 α 的 t 值。
  2. 基准口径：RM 是 universe 等权口径；拿它与市值加权指数型产品比 α，会把口径差读成"能力差"。
  3. R² 低 ≠ 模型错：R²=0.26 仅表明四条代理因子在这组月度样本中解释了约26%的收益波动；其余可能含特质波动、遗漏因子和测量误差。
  4. 窗口单一：本表约44个月，4个解释变量另加截距；拆成前后两段后自由度更少，t 值会很不稳定。分窗仅用于观察方向变化，不宜重新给经理贴"显著能力"标签。可补做匹配基准、稳健标准误和样本外检查。

课堂手算 A：分解的是月均值，不是某个月的确定收益

假设某资产的月度回归估计为 α=0.5%、b_RM=1.2、b_SMB=−0.4，样本内两个因子的月均收益分别为 1.0% 与 −0.5%。那么样本内月均超额收益为 0.5% + 1.2×1.0% + (−0.4)×(−0.5%) = 1.9%，算术年化为 1.9%×12=22.8%。这里"SMB 贡献 +0.2 个百分点"只因为负暴露遇到负样本均值，不表示下一月一定赚 0.2%；22.8% 也不是逐月复利回报。

课堂追问：若换一个基准或多加一个遗漏因子，α 可能怎样变化？学生应回答"数值可能变化，原来分给截距的部分可能转入新因子"，不能把 α 固定解释为经理能力。

五 Agent 实操（三）：观点 → 暴露 → 压力测试

归因是事后的收益分解。本节示范如何把观点写成目标暴露，并用既定规则排序。由于名单是用截至 2026-08 的数据选出，后文 2024 年事件窗只是把事后名单放回历史的情景演示，不属于事前选股记录或无前视偏差的回测。

验证任务 P3（可直接复制给 Agent 执行）假设性观点：下一季度偏好"小盘 + 动量"、回避"红利相对成长"；这是课堂情景，并非根据历史均值作出的收益预测。 选股口径：从沪深300成分（当期名单，约300只，属前视简化，声明）中， 用最近24个自然月（2024-09 至 2026-08）月频四因子回归估计每只股票的暴露， 按 score = b_SMB + b_MOM − b_HML_proxy 降序取前10；这是任意设定的等系数启发式排序，三个暴露的经济含义和波动尺度不同，score 高不等于预期收益高。 再加约束"每个行业最多2只"重新选一遍（行业用数据源行业字段，近似口径，声明）。 输出：两次（无约束/有约束）名单与暴露表、两次名单的行业分布对比。

  1. 看名单的第 3 行：士兰微 b_RM = −0.99。其 2026-06、07 月收益分别约 +58.1%、−48.2%，提示短窗口估计可能受极端月份影响；但要证明"由这两个月导致反号"，还须剔除该月重估作敏感性检查。暴露是样本估计量，不是股票的永久性质；Blume β 调整也不能解决多因子模型中的遗漏因子、代理误差或前视偏差。

三行数字，三个结论：

  1. 危机窗：这个事后名单的终点收益差距约 0.5 个百分点，而脚本报告的区间内最大回撤差距更大；这是"终点收益会掩盖路径风险"的例子，不能倒推出该组合当时可选或其回撤由 SMB 独立造成。
  2. 急涨窗：在该历史窗口，事后名单的涨幅高于沪深300；不能由一个窗口推断未来必有"高弹性"。
  3. 估计窗 +462.81% 不是业绩：名单由含该窗口的收益数据估计后才确定，三个窗口均有事后选股问题，其中估计窗还直接重叠。报告只能写"事后情景"，不可写成策略回测或可实现收益。

课堂手算 B：用明确的因子冲击做前瞻情景

设组合暴露为 b_RM=1.1、b_SMB=0.5、b_HML_proxy=−0.3、b_MOM=0.2；只为练习，假设下月四条代理因子分别为 −8%、−12%、+5%、−10%。模型给出的超额收益冲击为 1.1×(−8%) + 0.5×(−12%) + (−0.3)×5% + 0.2×(−10%) = −18.3%。这个数是给定假设下的线性情景估算，实际收益还会受截距、残差、暴露变化和交易条件影响。让学生再改动一个冲击，观察结论是否敏感；不要把假设情景写成历史事实。
